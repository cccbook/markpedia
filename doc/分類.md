## 目錄結構（重構後）

```
markpedia/
├── README.md
├── PROGRESS.md
├── doc/分類.md        本規劃
├── tools/
└── site/
    ├── 科技/           主類入口頁 + 各概念（數學/、物理學/、人工智慧/……）
    ├── 社會/
    ├── 生活/
    ├── 人/             人物類別子目錄（人/數學家/高斯.md）
    ├── 時/             年份實體 + 曆法紀年概念
    ├── 地/             地名實體 + 地理地球科學概念
    ├── 物/             物品實體 + 材料器物概念
    └── 其他/           暫時無法歸類的概念
```

- 第二層概念資料夾移入對應主類之下：`site/數學/` → `site/科技/數學/`。
- 概念資料夾內部結構不變（README.md + 概念本文 + 子分類 + 孫分類）。
- 概念資料夾**不跨主類重複放置**；同義概念沿用既有資料夾，以連結互引。

## 遷移步驟

1. 建立 `site/科技/`、`site/社會/`、`site/生活/`、`site/其他/` 主類資料夾與入口頁。
2. 依上表把概念資料夾 `git mv` 至主類之下。
3. 人、時、地、物四類既有實體檔位置不變；其下新增概念時直接放在主類資料夾內。
4. 全站參考式連結的路徑會隨搬移改變，需批次更新連結定義。
5. 執行 `python3 tools/check_links.py` 至 0 項問題；`build_tables.py` 依新 `tools/data/concepts.py` 重建表格；`build_progress.py` 更新進度。
