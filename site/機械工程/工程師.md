# 工程師

> 隸屬：[機械工程]　·　狀態：初稿

> 對應維基百科：[中文維基百科：工程師](https://zh.wikipedia.org/wiki/%E5%B7%A5%E7%A8%8B%E5%B8%AB)　·　[English Wikipedia: Engineer](https://en.wikipedia.org/wiki/Engineer)

工程師是**把原理、經驗與約束結合起來，造出能運作的裝置或系統的人**。他們與科學家的差別在於**必須面對現實的全面約束**：不只要求原理成立，還要求成本可承受、材料可得、能被製造與維護、能被檢查與驗收。

## 工程師的四個核心問題

1. **功能**：裝置必須達成某種可量測的目的。
2. **約束**：重量、體積、溫度、壽命、安全、法規、預算——這些限制往往比「能不能做出來」更決定結果。
3. **可靠性**：工程產品的失敗是概率事件，因此設計必須包含裕度與失效分析。
4. **經濟性**：能被製造、能被賣、能被維護，技術才能真正進入社會。

[詹姆斯·瓦特] 的核心貢獻正是在第四點：他把高效率的熱機做成**可負擔、可複製、可維護**的產品，因而使蒸汽動力改變了工業。

## 工程師的三種主要路徑

| 類型 | 工作重點 | 典型代表 |
| --- | --- | --- |
| 發明型 | 找新原理與新結構 | [愛迪生] 的實驗室工作 |
| 改進型 | 在既有系統中持續提升效率與可靠性 | [詹姆斯·瓦特] 的蒸汽機改良 |
| 系統型 | 把大量子系統整合為可靠整體 | 橋梁、水利與後來的系統工程 |

三者的社會影響不同：改進型貢獻最不顯眼卻最普遍，系統型的工作往往在事後才被看見其重要性。

## 前因後果：工程師如何成為社會角色

1. **前現代的匠人**：技術與經驗依附於行會與作坊，知識不繫統化，傳承靠師徒。
2. **工業化與專業化**：工廠制度要求標準件與可互換性，工程成為需要正式訓練的職業，與[教育] 制度掛鉤。
3. **工程科學**：把力學、熱學、電學的成果用於設計，「工程師」獲得與科學家對等的知識地位。
4. **國家與大型工程**：水利、鐵路、橋梁與軍事工程使工程師成為國家能力的核心，同時也帶來對自然的幹預與安全責任。
5. **可靠性與責任倫理**：二十世紀的結構工程與航空工程，使「安全」成為工程師的職業義務與法律責任。

## 範例：一臺蒸汽機如何成為一套產業

[詹姆斯·瓦特] 的改良蒸汽機，其社會影響可以拆成四個層次，每一層都超出他個人：

1. **原理與效率**：分離冷凝器大幅減少了冷凝所需的水量與熱量浪費，效率提高數倍。
2. **機構與量產**：他以齒輪與連桿把活塞運動轉為旋轉，並使機器的各部件規格化，因而能由不同工廠製造。
3. **生產體系**：蒸汽機需要技師來操作與維護，需要煤、鐵與運輸，因此帶動了整條產業鏈。
4. **生產地點的改變**：動力不再受水力限制，工廠可以設在煤礦與市場附近，城市化與工業化因此加速。

這說明**工程師的真正產出不是機器，而是一整套能持續生產的體系**。

## 與相鄰分類的關聯

- 與 [科學家] 的關係：科學提供原理與新知，工程提供可行性與成本判斷，兩者是科學發展史上最重要的互動之一。
- 與 [創辦人] 的關係：工程判斷決定了哪些技術值得投入生產化。
- 與 [君主與統治者] 的關係：大型工程往往由國家委託，兼具經濟與軍事用途；[秦始皇] 時代的馳道與直道即是早期例子。
- 在上位概念 [企業人物] 中，本分類扮演的角色：它代表**技術的可實現性判斷**，是創辦與經營決策的技術基礎。

## 容易混淆之處

- **「工程師」在今天是職業身分，早期更多是能力稱呼**：技術人才在相當長的歷史裡並無專門頭銜。
- **工程不等於科學的應用**：工程有自己的目標體系（成本、可靠、規範），與科學的求真目標不同。
- **「技術可行」與「社會可接受」不同**：工程方案的評估必須包含社會與環境影響。

## 專業倫理的四個核心問題

工程師的專業倫理在二十世紀後半逐步成形，其核心問題包括：

1. **安全的優先性**：當安全與成本衝突時，專業規範要求安全優先——這條規範的確立與多次重大事故的教訓直接相關。
2. **對第三方的責任**：工程方案的後果常由不曾參與決策的人承擔，因此義務必須包含對非當事人的考量。
3. **誠實的披露**：工程師有義務指出技術方案的限制，儘管這可能不利於自己的收入或聲望。
4. **環境與長期的成本**：把環境外部性計入方案，是二十世紀工程倫理最重要的進展之一。

**工程倫理的成熟標誌，是它承認「做出來」不等於「應該做出來」。**

## 工程與社會的雙向塑造

1. **工程改變社會的可能邊界**：橋梁、運河、鐵路與電力線改變了城市的形狀，也改變了經濟地理。
2. **社會決定工程的形態**：不同的土地制度、勞動成本與安全規範，會讓同一項技術在不同地方呈現不同的樣子。
3. **工程事故是制度問題**：事故的後果由公眾承擔，因此事故的追責最終會回到設計標準與監管體系。
