# 取樣

> 隸屬：[電子工程] › [訊號與系統]　·　狀態：初稿

> 對應維基百科：[中文維基百科：取樣](https://zh.wikipedia.org/wiki/%E9%87%87%E6%A0%B7)　·　[English Wikipedia: Sampling (signal processing)](https://en.wikipedia.org/wiki/Sampling_%28signal_processing%29)

取樣是**每隔固定時間量測一次連續訊號的值，把類比波形變成一串數字**。它是類比世界進入數位世界的第一道門：CD、數位電話、醫療監視器、示波器的數位化，全部從取樣開始。取樣的理論核心是**取樣定理**（Nyquist–Shannon，1949 年由香農嚴格表述）：只要訊號的頻譜限制在 $B$ Hz 以內，取樣率 $f_s > 2B$ 即可**完美重建**原訊號——資訊不會因為離散化而損失。

取樣的兩個致命陷阱是**混疊**與**量化**。混疊：若訊號含有超過 $f_s/2$ 的成分，取樣後它會「偽裝」成低頻訊號混進頻帶，事後無法分離；解法是在取樣前用抗混疊 [濾波器] 截斷高頻。量化：把連續值四捨五入到 $N$ 位元，誤差近似白雜訊，每增加一個位元訊噪比提升約 $6$ dB。取樣率與位元數的組合（如音訊 $44.1$ kHz／16 位元）是所有數位系統的基本規格。

## 技術要點

- 取樣定理的前提是**帶限**：先濾波才取樣，順序不可顛倒；「先取樣再濾」必然混疊。
- 混疊公式：頻率 $f$ 在取樣後顯示為 $|f - k f_s|$ 中最接近基帶的值；例如 $f_s = 8$ kHz 時， $10$ kHz 訊號呈現為 $2$ kHz。
- 量化訊噪比： $\text{SNR} \approx 6.02N + 1.76$ dB； $16$ 位元約 $98$ dB， $24$ 位元約 $146$ dB。
- 過取樣（oversampling）與雜訊整形：取樣率高很多倍可以把量化雜訊推到頻帶外，Σ–Δ 型 ADC 由此達成高解析度。
- 取樣保持電路：ADC 轉換需要時間，取樣開關先「凍結」電壓；孔徑抖動（jitter）直接限制高頻輸入的可取樣精度。
- 重建由理想低通完成：插值核是 sinc 函數 $\frac{\sin \pi f_s t}{\pi f_s t}$ ，實務用有限階的重建濾波逼近。

## 範例

**音訊取樣率的選擇。** 人耳上限約 $20$ kHz，取樣定理要求 $f_s > 40$ kHz。CD 選 $44.1$ kHz：一方面留下約 $2$ kHz 給重建濾波器的過渡帶，另一方面 $44100 = 245 \times 180$ 與早期視訊錄音設備的線掃頻率兼容。手機語音卻只用 $8$ kHz——語音通話只需 $3.4$ kHz 頻寬（電話語音品質），過取樣只浪費傳輸頻寬。同樣的定理，兩種應用給出四倍不同的取樣率：**取樣率是頻寬需求的鏡子，不是品質的裝飾**。

## 前因後果

- **前因**：電報時代的「點陣」思想早已存在；1933 年 Kotel'nikov、1928 年 Nyquist 給出近似表述，1949 年香農在其通訊數學理論中嚴格證明；同時脈衝調變（PCM）技術成熟，取樣從定理走向商品。
- **後果**：PCM 成為數位通訊與數位音訊的基礎（1970 年代數位電話中繼、1982 年 CD）；離散時間訊號處理成為獨立學科；今天一切 ADC 的規格表（取樣率、位元數、SNR）都是取樣定理的商業化表達。

## 與相鄰分類的關聯

- 與 [頻譜] 的關係：取樣在頻域的效應是「頻譜週期複製」，整個理論在頻譜圖上最清楚；混疊就是複製重疊。
- 與 [濾波器] 的關係：抗混疊濾波（取樣前）與重建濾波（取樣後）是取樣鏈的兩端，皆為類比 [濾波器] 的重要應用。
- 與 [線性時不變] 的關係：離散 LTI 系統（數位濾波器）作用在取樣序列上；取樣定理保證序列保有原訊號全部資訊。
- 與 [數位電子] 的關係：ADC 是取樣定理的硬體化身，其規格由定理直接約束。
- 與 [通訊工程] 的關係：取樣後的數位流經壓縮與通道編碼送上電波；5G 與光纖系統的取樣率一路推高到數十 GS/s。

## 容易混淆之處

- **「取樣率高＝音質好」是誤區**：高於兩倍頻寬即可無損； $96$ kHz 相對 $44.1$ kHz 的「品質提升」不在人耳可聞頻段，主流科學觀點認為聽感無差。
- **混疊不可事後修復**：一旦高低頻混疊，資訊已不可逆地混合；唯一解法是取樣前濾波。
- **量化不是取樣**：取樣是時間上的離散化，量化是幅度上的離散化；兩種失真獨立存在，常常被混為一談。
- **取樣定理允許「無損」不等於「無失真系統」**：實際 ADC 有孔徑抖動、非線性與雜訊；定理是上限，實作永遠打折。
- **帶通取樣（欠取樣）是合法技巧**：對帶通訊號可用低於 $2f_{max}$ 的取樣率（只要不違反對頻寬的 $2B$ 要求），射頻數位化大量使用；「取樣率必須高於兩倍最高頻率」是簡化口訣而非一般定理。

## 常見的論爭

- **高解析音訊之爭**： $192$ kHz／24 位元格式是否有聽感意義，消費市場與科學界立場長期分裂；主流量測觀點認為 $44.1$ kHz／16 位元已達人耳極限，高解析價值主要在製作端預留處理餘裕。
- **取樣定理的署名權**：Nyquist、Kotel'nikov、香農、惠特克各自在不同年代給出部分或完整表述，教科書對「Whittaker–Shannon」與「Nyquist–Shannon」的稱呼不一，反映科學史的優先權爭議。
- **Σ–Δ 對 SAR 的架構之爭**：高解析低速用 Σ–Δ、高速中速用 SAR 已成共識，但「可程式化後未來誰主流」的判斷在晶片業仍持續演進。

## 取樣、混疊與量化的代價

取樣的三個代價互相牽連：取樣率決定最高可還原頻率，量化位元數決定動態範圍與雜訊底，編碼速率則決定資料量。

| 取樣率 | 最高可還原頻率 | 8 位元未壓縮碼率 |
| --- | --- | --- |
| $44.1$ kHz | $22.05$ kHz | $\approx 352$ kbps |
| $48$ kHz | $24$ kHz | $\approx 384$ kbps |
| $192$ kHz | $96$ kHz | $\approx 1.5$ Mbps |

若取樣率低於奈奎斯特率，頻譜會折疊到可觀測範圍內，形成混疊；一旦混疊發生，事後用任何濾波器都無法還原，因為資訊已在取樣當下被覆蓋，因此反混疊濾波器必須在取樣前完成。

### 設計檢查表

- 確認取樣率至少為最高頻成分的兩倍以上，並留有過取樣餘裕以利重建濾波器設計。
- 反混疊濾波器的截止頻率應低於取樣率的一半，且阻帶衰減足夠。
- 確認量化位元數足以涵蓋動態範圍： $6.02n + 1.76$ dB 的信噪比對應 $n$ 位元量化。
- 評估取樣孔徑失真：取樣脈衝並非理想，會讓高頻成分衰減，稱為孔徑效應，可用前級濾波器補償。
- 若訊號有直流偏移，先做交流耦合或扣除基準，避免浪費量化範圍。
- 檢查時脈抖動：取樣時刻的時間誤差會直接換算成電壓誤差。

- 對週期性訊號而言，取樣頻率與訊號頻率有公因數關係時會產生固定樣態（aliasing to a constant），這在量測儀器中特別容易出現。
取樣是把連續世界切成離散世界的入口，此後所有處理由數位系統完成。

取樣定理的假設是訊號帶限與取樣脈衝理想，兩者在實務中都需要額外電路補償。
