# 向量空間

> 隸屬：[代數] › [線性代數]　·　狀態：初稿

> 對應維基百科：[中文維基百科：向量空間](https://zh.wikipedia.org/wiki/%E5%90%91%E9%87%8F%E7%A9%BA%E9%97%B4)　·　[English Wikipedia: Vector space](https://en.wikipedia.org/wiki/Vector_space)

向量空間是**帶有數乘與加法的結構**，其加法構成群、並滿足分配律與結合律，且每個非零向量可被任一非零純量消去。直覺上它是「向量」這個概念的數學化：加法是拼接，數乘是拉伸。

向量空間的關鍵事實是：**同一個空間有無限多組基底，但維度唯一**。這意味著很多看似不同的問題其實是同一個問題——例如 $\mathbb{R}^3$ 與二次多項式構成的空間、連續函數構成的空間、矩陣構成的空間，只要維度相同，它們在代數上就無法區分。

加入內積之後，向量空間獲得幾何：長度、角度、距離、正交性與投影。線性代數最漂亮的部分，就是「代數結論往往有幾何解釋」，反之亦然。

## 常用術語

| 術語 | 白話解釋 | 出現場合 |
| --- | --- | --- |
| 線性無關 | 無非平凡線性組合為零 | 基底的條件 |
| 生成 | 可由集合線性組合得到 | 基底的條件 |
| 維度 | 基底的元素個數 | 結構不變量 |
| 子空間 | 對加法與數乘封閉 | 核與像 |
| 對偶 | 與空間互相配對的函數空間 | 對偶定理 |

## 技術要點

- **基底與維度**：基底是線性無關且生成全體的集合；維度是所有基底的共同大小。
- **座標**：給定基底，每個向量有唯一座標，向量的運算變成座標的運算。
- **子空間**：對加法與數乘封閉的子集；判定子空間只需檢查兩條封閉條件。
- **直和與商空間**：把空間拆成互不相交的部分，或壓縮掉一個子空間。
- **內積與正定性**：給出長度、角度與距離；正定保證只有零向量長度為零。
- **無窮維情形**：基底可能無窮，此時「維度」與「有限和」等說法需要相應調整。

## 範例

**一、 $\mathbb{R}^3$ 與二次多項式。** 空間 $P_2$ 為所有次數不超過 2 的實係數多項式。基底 $\{1, x, x^2\}$ 給出每個多項式的座標；兩個三次多項式 $f = x^3$ 與 $g = 3x^3 + 2x + 1$ 雖在多項式空間中不同，但在三次以下的部分所張成的子空間 $P_2$ 中具有相同的座標 $(0, 2, 1)$ 。這說明「座標」是相對於基底而言的。

**二、秩-零化度定理的應用。** 設 $T : \mathbb{R}^4 \to \mathbb{R}^3$ 為線性映射且秩為 2，則核的維度為 $4 - 2 = 2$ 。因此齊次方程 $Tx = 0$ 的解空間是 2 維的——這決定了無限多解的「自由度」。

**三、正交投影的計算。** 給定點 $p = (1, 2, 3)$ 與平面 $x + y + z = 0$ ，其法向量為 $n = (1, 1, 1)$ ，投影為 $p - \frac{p \cdot n}{n \cdot n} n = (1, 2, 3) - \frac{6}{3}(1, 1, 1) = (-1, 0, 1)$ ，驗證 $x + y + z = 0$ 成立。

**四、商空間的構造。** 令 $V = \mathbb{R}^3$ 、 $W$ 為平面 $x + y + z = 0$ （維度 2），則商空間 $V / W$ 的維度為 $3 - 2 = 1$ ，可用類 $(1, 0, 0) + W$ 作為生成元；其運算規則由原空間的加法繼承。

## 前因後果

向量空間的想法在 19 世紀由多條路徑匯流而成：線性方程組的理論（高斯消元）產生了「解空間」的概念；幾何中的仿射空間與射影空間提供了「點加向量」的直覺；四元數的乘法給出了三維旋轉的代數模型。20 世紀，[高斯] 的消去法與有限維線性代數被系統化，並在量子力學中成為基本語言：量子態是希爾伯特空間中的向量，演化是幺正算子，而對稱性則由群表示給出。

線性代數的實用生命也源於此：統計學的主成分分析、機器學習的線性模型、控制理論的狀態空間方法、控制與通訊的濾波器設計，全都是同一套定理的不同應用。它因此成為「應用面最廣的數學分支」。

## 與相鄰分類的關聯

- 與 [矩陣] 的關係：固定基底後，線性映射即為矩陣，基底變化即為相似變換。
- 與 [線性映射] 的關係：向量空間是定義映射的舞台。
- 與 [群] 的關係：向量空間的加法群是 [群] 的一例，構成群與代數結構的交會。
- 在上位概念 [代數] 中，本概念扮演的角色：它示範瞭如何用少量結構資訊（維度、秩）概括大量對象。

## 容易混淆之處

- **向量空間與仿射空間不同**：仿射空間不帶原點，因此不談零向量。
- **座標依賴基底**：兩個不同基底給出不同的座標，但描述同一個向量。
- **維度與「自由度」**：非線性系統的自由度數不一定是線性代數的維數。
- **正定與半正定的區別**：後者允許零向量有零長度，不能用同一套幾何直覺。

## 常見的論爭

1. **無窮維空間的處理方式**：是否應把無窮維情形與有限維並列教學，意見分歧。
2. **抽象定義與座標操作的取捨**：支持抽象者強調可遷移性，支持操作者強調可計算性。
3. **幾何直覺的地位**：代數證明與幾何直覺何者更可靠，並無普遍答案。

## 入門建議

- 先在 $\mathbb{R}^3$ 中練習基底、座標與子空間。
- 再讀多項式空間 $P_2$ 與矩陣空間，體會抽象定義的適應性。
- 然後讀秩-零化度定理與商空間。
- 進階可讀無窮維情形與對偶空間。
