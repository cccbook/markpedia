# 語音模仿

> 隸屬：[發展心理學] › [語言發展]　·　狀態：初稿

> 對應維基百科：中文與英文維基百科均無對應條目（參考：語音模仿 相關文獻）

## 定義

語音模仿（vocal imitation）是指嬰兒或幼兒聽到另一個聲音後，在特定時間內主動產生與該聲音相近的發聲；「相近」可以指發音類別、元音形式、節奏或語氣變化。這項能力通常在日常互動中自然出現，也可由研究者安排有聲示範來誘發。

語音模仿所模仿的對象稱為「模型音」，模型音可以來自照護者、其他嬰幼兒、錄音或影片，也可以是單一元音、連續語音、詞語或具有歌唱特徵的聲音。

「音類」是把聽到的聲音歸入可辨識的發音類別，而不是保留原始聲波的所有細節。因此，嬰兒模仿成人說出的 /a/，不必在每個物理層面都完全相同。

「韻律」是語音在音高、長短、速度、停頓與強弱上的變化；嬰兒可能先模仿這種整體輪廓，之後才逐漸模仿較細緻的音段。

語音模仿不只是一種反射行為，而是知覺、記憶、發聲動作控制與社交動機共同作用的結果，因此與認知發展及動作發展密切相關。

嬰兒能夠模仿一個聲音，通常表示其聽覺系統已對該聲音形成某種暫時表征，並能把這種表征轉換成自己的發聲計畫；這不等於嬰兒理解該聲音的詞義或完整語法。

語音模仿可分為「片段式模仿」與「整體式模仿」。片段式模仿只重現特定元音或音節，整體式模仿則較接近聲音的音高起伏、長度、節奏與停頓。

模仿也可能具有提示性與自發性。提示性模仿是在成人示範、要求或互動節奏之後發生；自發性模仿則是嬰兒沒有立即要求，仍主動重現先前聽到的形式。

語音模仿不應與單純的「發出恰好相同的聲音」混為一談。嬰兒可能因生理狀態、探索發聲或模仿失敗而偶然產生相似音，因而需要多次觀察、反覆示範與無提示基線相互比較。

新生兒早期的哭聲與喉音多受反射、姿勢及基本生理需求影響，其中某些聲音變化不能直接視為語音模仿。較可靠的理解是，嬰兒從新生兒期的聲音互動逐步過渡到學齡前較明確的音類模仿。

大約兩至四個月，嬰兒的呼聲、咿呀聲與成人回應之間的輪替逐漸清楚；「輪替」是指一方發聲後，另一方在短時間內接續發聲。這個階段常可觀察到對成人語音的興趣及選擇性回應。

約五至七個月，嬰兒常開始使用不同元音與輔音組合成咿呀聲。約六個月出現的「典型咿呀聲」通常被視為重要發展里程碑，但個別差異很大，不能單憑是否達到某個年齡判定語音模仿能力。

隨著語言發展持續，嬰幼兒會從模仿單一聲音、轉向模仿音節、詞語和連續語流；此時模仿對象由聲學形式逐漸擴展到音位排列與發音規則。

語音模仿並非單線式能力。嬰兒可能善於模仿元音卻較難模仿輔音，也可能模仿聲音形式很好，卻较少主動把模仿用於與成人交流。

因此，評估語音模仿時應同時考慮聲音是否相似、模仿是否穩定、是否需要提示、是否在互動中出現，以及嬰兒是否理解並使用該聲音的溝通功能。

## 技術與理論的關聯

- **聽覺辨識：** 語音模仿首先依賴嬰兒分辨聲音的音高、長短與音色差異；這種辨識能力是感知覺發展的一部分，也是形成發音類別的基礎。

- **類別化知覺：** 嬰兒通常不是逐項複製完整聲波，而是把聲音歸入某個發音類別；這種知覺方式使不同成人以不同音高說出的相同元音仍可被視為同一類。

- **聽覺至發聲的映射：** 模仿要求嬰兒把聽覺表征轉換成發聲指令，並協調呼吸、喉部、舌頭、嘴唇與下顎；這種能力需隨動作發展與精細動作逐步成熟。

- **早期姿勢與反射：** 嬰兒的頭部姿勢、口腔反射及哭聲控制會影響聲音能否被聽到與重現，因此反射與姿勢提供了早期研究語音模仿時不可忽略的背景。

- **聽覺記憶：** 成人示範與嬰兒回應之間通常存在短暫時間間隔。嬰幼兒必須暫存聲音特徵，才能在示範停止後產生相符發聲，因此與記憶發展有關。

- **聯結學習：** 若某種發聲反覆伴隨成人立即而有意義的回應，嬰兒可能逐漸學會把特定聲音與特定結果連結；這種聯結學習支持模仿行為的穩定化。

- **操作制約：** 當成人以表情、音色或語句回應嬰兒的某個聲音時，該回應可成為未來發聲的增強因素。不過，成人回應同時含有社會訊息，不能完全化約為單純的獎勵機制。

- **社會學習：** 嬰幼兒不只從成人的聲音形式學習，也會觀察何時發聲能得到回應。這使語音模仿成為社會與情緒發展中的互動能力，而不僅是感官與運動技能。

- **共同注意：** 「共同注意」是兩人或多人同時把注意力放在同一個事物或事件上。嬰兒若先看見成人的嘴部、注視模型音，再轉向聲音來源，通常更容易進行有方向的模仿。

- **嬰兒式語言：** 「嬰兒式語言」是成人對嬰兒說話時常用的高音、清楚音節、誇張口形與較慢速度。這種高度可辨識的語音能提供清楚的聲學提示，但也可能比自然成人談話更容易被模仿。

- **互動時序：** 成人示範、暫停、等待嬰兒發聲，再對回應作出反應，是常見的模仿研究與日常交流安排。這種時序讓嬰兒有時間準備自己的發聲。

- **即時回饋：** 當成人的回應緊接著嬰兒的發聲，嬰兒較容易把某種聲音與成功的交流連結。這種回饋有助於形成穩定的「發聲—回應—再發聲」循環。

- **輪替能力：** 成人與嬰兒能在一個回合中交換多輪發聲，代表嬰兒已能協調注意、等待、產生聲音及接收回應；因此輪替既是模仿的條件，也可能隨練習而改善。

- **依戀與照護回應：** 對嬰兒聲音敏感且能適時回應的照護者，較容易形成有規律的聲音互動；這使依戀形成與語音模仿在發展時間上互相支持。

- **情緒調節：** 疲勞、害怕、興奮或壓力會改變嬰兒是否發聲及發聲方式。較穩定的情緒調節能力，有助於嬰兒在需要時嘗試新聲音並接收回饋。

- **認知表征：** 較成熟的語音模仿涉及對聲音規律、發音類別及成人意圖的預期；因此它可作為觀察認知發展與思考轉變的線索，但不能單獨證明完整的語言理解。

- **整體到片段的轉變：** 幼兒起初可能只模仿一句話的音高和節奏，之後才辨認其中不同音段。這種由整體輪廓轉向片段對應的變化，可透過思考轉變來理解。

- **主體與溝通意圖：** 隨著自我概念發展，幼兒會更清楚區分自己的聲音、他人的聲音以及自己想表達的內容。不過，出現語音模仿本身仍不足以證明幼兒已具有明確的溝通意圖。

- **語言輸入：** 嬰兒接觸的成人語音數量、清晰度及互動頻率，會影響可模仿材料的豐富程度；語音模仿因此需要放在完整的語言發展歷程中解讀。

- **音韻學習：** 嬰幼兒可能先掌握元音形式，再學習輔音、長短音及音節邊界；這種逐步細化的模仿，是後續語法學習與詞彙累積的聲音基礎。

- **聲學分析：** 「聲學分析」是以可測量的物理特徵描述聲音。研究者可比較模型音與嬰兒發聲的音高範圍、長度、頻譜輪廓及出現時序。

- **時序分析：** 除聲音本身外，研究者還會記錄成人示範結束到嬰兒發聲的間隔。較短且穩定的反應延遲，通常可作為模仿意向的 supporting evidence，但單次快速反應仍可能包含偶然因素。

- **行為觀察：** 嬰兒注視成人嘴部、跟隨發聲方向、在成人停下後發聲，以及主動重現先前音節，都可作為輔助指標；這些行為應與聲學資料一起解釋。

- **實驗控制：** 完整研究通常包含無模型音基線、不同模型音比較、即時與預先錄音比較，以及對嬰兒當下活動與情緒的記錄。

- **重複測試：** 單次模仿成功可能來自偶然或當下狀態。跨回合、跨日重複出現的相符發聲，通常提供較可信的證據。

- **縱貫追蹤：** 「縱貫研究」是在較長時間內追蹤同一群參與者的變化；它能顯示嬰兒是否由單音模仿逐漸走向音節、詞語與語流模仿，因此屬於縱貫研究。

- **發展評量：** 將聲學錄音、互動錄影、照護者報告及嬰兒語言行為合併，可避免把語音模仿簡化為單一測驗分數，並與發展評量的整體證據相互補充。

- **里程碑的用途：** 里程碑量表可協助辨識嬰幼兒的整體發展階段，但典型咿呀聲或詞語模仿的出現時間存在個體差異，不能把單一里程碑當作診斷界線。

- **發展測驗的界線：** 發展測驗可用於篩檢語音與溝通發展上的疑慮，但標準化測驗未必涵蓋自然互動中的複雜模仿；測驗結果應與日常觀察及專業評估共同判讀。

- **整合性解釋：** 可靠的語音模仿證據需要聽覺、記憶、動作、社會互動及語言發展多方面的資料會合，而不是只依賴成人的主觀印象。

## 範例

**1977 年的新生兒動作模仿研究。**

1977 年，Andrew Meltzoff 與 Patricia Moore 研究 32 名、出生約十二至二十一日的嬰兒。成人先示範張口、伸舌或張開手指，嬰兒則被觀察是否在沒有立即動作提示的情況下做出相符反應。

研究中，一半嬰兒觀看真人示範，另一半嬰兒觀看顯示相同動作的影片。結果顯示，嬰兒能模仿至少一項所見動作；後續分析與相關文獻可見語言發展及認知發展。

其因果鏈相當清楚：成人示範提供視覺訊號，新生兒先感知該訊號，再把所見動作映射到自己的身體動作系統，最後產生可被觀察的相符反應。

這項實驗直接支持的是新生兒的動作模仿，而不是語音模仿。把伸舌誤寫成模仿母音，會混淆不同能力；它對語音研究的價值在於說明嬰兒可能已具有跨越感覺形式與自身動作的映射能力。

成人等待、觀察嬰兒反應，再選擇下一個示範，也呈現了語音研究所採用的基本原理：示範者的行為應配合嬰兒的時間節奏，使嬰兒能主動參與而非只被動反應。

**約六個月嬰兒的元音模仿研究。**

Conty 與 Smith（1999）以約六個月嬰兒為對象，比較成人示範元音前後，嬰兒後續發聲是否更常呈現相近的音類與形式。這個研究把問題由「嬰兒會不會重做一個動作」轉向「嬰兒能否把聽到的聲音轉換成自己的聲音」。

研究結果顯示，部分嬰兒在示範後較容易產生與模型音相符的元音，但效果會受到嬰兒當下發聲狀態、模型音的清晰程度及測試方式影響；因此，單次沒有模仿並不能直接判定能力不足。

此例的前因是成人提供可辨識、可重複的元音示範，後因則是嬰兒的發聲在音類上與示範更接近。這項結果支持聽覺至發聲映射的存在，但仍須用無提示回合排除偶然發出相同元音的可能。

元音是指像 /a/ 或 /i/ 一類、主要以口腔形狀改變形成不同共鳴特徵的發音。選擇元音作為示範材料，通常比使用完整句子更容易觀察嬰兒是否真正重現特定聲音。

**雙向驅動的互動範例。**

以下配置說明語音模仿研究如何形成雙向驅動。成人先以會話音量說出長約六百毫秒的 /a/，然後停止說話並等待約三秒，讓嬰兒有機會接續發聲。

若嬰兒發出 broadly 相符的元音，照護者立即以相同元音回應，同時維持眼神交流；若嬰兒沒有發聲，成人則短暫等待，不立即加入另一個示範，以避免搶占嬰兒的發聲回合。

若數個回合中出現「嬰兒發聲時間增加、輪替縮短、回應更接近成人元音」的趨勢，就可把這項序列視為語音模仿與社會互動共同受到強化。

其前因是成人提供清楚而單一的聲音提示，嬰兒因聲音、眼神及活動狀態而產生發聲；後因則是成人的即時回應增加下一次發聲的機會。

同時，嬰兒更頻繁的發聲也讓成人取得更多可供回應的材料，形成可預期的「成人示範—嬰兒發聲—成人模仿—嬰兒再發聲」循環。這就是模仿行為與社交互動互相驅動的例子。

上述六百毫秒與三秒是示範性實驗配置，不代表所有嬰兒或所有研究都會得到相同數值；研究仍應依嬰兒年齡、注意力與發聲能力調整等待時間。

同一原則也可出現在較大的幼兒身上。例如，成人說出「ba」並在八個月後以清楚速度重複，若幼兒先只重現 /b/、之後才加入 /a/，這種逐步接近不必立即視為失敗；它可能反映語言發展中音節結構逐步精化的過程。

## 與相鄰分類的關聯

- **發展心理學：** 語音模仿是發展心理學中研究個體如何整合知覺、記憶、動作與社會互動的例子；其結果會隨年齡、經驗及發展脈絡而改變。

- **認知發展：** 隨著認知發展，嬰幼兒對聲音規則、分類方式及他人意圖的理解逐漸複雜，模仿對象也由整體輪廓走向較細緻的音類。

- **社會與情緒發展：** 在社會與情緒發展層面，語音模仿常嵌合於眼神交流、輪替及共同注意；沒有互動對象時，相同的發聲未必具有相同意義。

- **語言發展：** 語音模仿是語言發展的一部分，但兩者不能畫上等號。嬰兒能模仿一個詞的聲音，不表示理解該詞的指稱或句法功能。

- **動作發展：** 與動作發展的關聯在於，聽覺訊號必須轉換為呼吸、喉部及口腔動作；聲音模仿能力會受到發聲器官控制能力限制。

- **發展評量：** 在發展評量中，語音模仿應以多次互動、聲學資料及年齡背景共同判讀，不能只依一次是否說出相同音節下結論。

- **感知覺發展：** 感知覺發展決定嬰幼兒能否注意、辨識及分類模型音；感知能力弱時，模仿可能表現為沒有反應，而非缺乏發聲意圖。

- **記憶發展：** 記憶發展影響嬰兒能在示範後保留多久的聲音資訊，也影響跨日重複時能否穩定重現先前模型音。

- **思考轉變：** 思考轉變可用來理解幼兒如何由模仿整體語調，逐步轉向辨認詞內不同音段及其排列位置。

- **依戀形成：** 依戀形成與語音模仿的關聯主要表現在照護者的敏感回應。穩定且及時的輪替，可讓嬰兒更願意探索不同聲音。

- **自我概念：** 自我概念逐漸發展後，幼兒會更能把聲音視為自己選擇的交流行為。不過，單純模仿不能直接視為完整主體意識的證據。

- **情緒調節：** 情緒調節會影響模仿測試中的參與程度。過度興奮、疲倦或挫折可能使嬰兒停止發聲，因此需要區分能力不足與狀態因素。

- **語法學習：** 語音模仿提供的是形式基礎，語法學習則涉及音素組合、詞序與句子結構；前者可以先發生，卻不必然表示後者已經啟動。

- **詞彙累積：** 在詞彙累積階段，幼兒會把音節模仿用於重現熟悉詞或嘗試新詞。模仿中的省略、替換或增添音段，可能反映尚未成熟的音韻規則。

- **反射與姿勢：** 反射與姿勢影響早期哭聲、口腔運動及與成人的面對面互動；研究者需避免把一般反射發聲直接判讀為有目的的語音模仿。

- **大肌肉發展：** 大肌肉發展所包含的頭部控制、坐姿與身體朝向，會影響嬰兒能否看見成人的嘴部並持續參與聲音互動。

- **精細動作：** 舌頭、嘴唇與下顎的細緻調整屬於精細動作範疇；這些動作精度提高後，嬰兒才更能複製相近的元音與輔音。

- **里程碑量表：** 里程碑量表可提供典型咿呀聲與詞語出現的群體參考時間，但語音模仿的精細程度和穩定性仍需另行觀察。

- **縱貫研究：** 縱貫研究適合回答同一名嬰兒如何從元音模仿走向音節與詞語模仿，也能辨識短期測試差異是否代表長期發展趨勢。

- **發展測驗：** 發展測驗能提供標準化篩檢資訊，但自然情境中的語音模仿、輪替能力及溝通功能，通常仍需由照護者描述與直接觀察補充。
