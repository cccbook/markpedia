# 主成分分析

> 隸屬：[人類學] › [體質人類學]　·　狀態：初稿

> 對應維基百科：[中文維基百科：主成分分析](https://zh.wikipedia.org/wiki/%E4%B8%BB%E6%88%90%E5%88%86%E5%88%86%E6%9E%90)　·　[English Wikipedia: Principal component analysis](https://en.wikipedia.org/wiki/Principal_component_analysis)

## 定義

主成分分析（PCA）是一種統計方法：把許多相互關聯的變數，濃縮成少數幾個互不相關的新變數（主成分），並讓前幾個主成分盡量保留原始資料的變異量。白話說——資料有五十個量測值，太多而看不清結構；PCA 幫你找到「最能代表整體差異的兩三根軸」，把樣本點攤在平面上，誰跟誰近、誰跟誰遠一目了然。

它的數學核心是線性代數中的特徵值分解：對資料的共變異矩陣（或相關矩陣）求特徵向量與特徵值，特徵向量是主成分的方向，特徵值是該方向上的變異量。第一主成分是資料變異最大的方向，第二主成分與第一正交、承接次大變異，依此類推。

## 為什麼需要這個概念

對 [體質人類學] 而言，資料的維度問題是結構性的：一具顱骨可量出數十個測徑值，一個人的基因組有數十萬個位點。用任何單一指標比較人群都會失真，用全部指標又無法直觀呈現。PCA 解決的正是「多維比較如何降維呈現」的問題——它讓「人群之間的親疏」變成一張二維散布圖，而這張圖在過去二十年成為人類族群遺傳學的標誌性產物。

著名的例子是遺傳學家 Cavalli-Sforza 等人在一九九○年代出版的《人類基因的歷史與地理》：以血清學頻率做 PCA，得到的第一主成分地圖竟與新石器時代農業從近東向歐洲擴散的方向高度吻合——降維後的「趨勢軸」直接對上了考古學的歷史敘事。

## 因果鏈

1. **瓶頸**：早期體質人類學用少數指標（顱指數、膚色）分類人群，指標之間相關、且選擇帶主觀性，分類結果彼此矛盾。
2. **多變量方法引入**：一九三○年代 PCA 由皮爾森（早在一九○一年）與霍特林（一九三三年）奠定；六○年代起人類學界以電腦對顱骨測量資料做多變量分析，主觀挑選指標的問題被系統化方法取代。
3. **基因頻率時代**：血清學與電泳標記的頻率矩陣成為 PCA 的新輸入；Cavalli-Sforza 團隊的合成地圖把遺傳結構與史前遷徙並排解讀。
4. **基因組時代**：二○○八年後，全基因組 SNP 資料上的 PCA 成為標準第一步——歐洲人群的 PCA 圖上，散點排布竟大致重現地理地圖（南北軸與東西軸），因為人群結構正是地理與歷史的堆疊。
5. **古 DNA 應用**：把古代樣本「投影」到現代人 PCA 圖上，使五千年前的草原人群、農夫與漁獵者的混合史變成可視化的位移軌跡。

## 範例

以顱骨測量的 PCA 為例，走一遍完整流程：

1. **量測**：對四百具出土顱骨各量取二十個測徑值（顱長、顱寬、顴寬、鼻高、眶高等）。
2. **標準化**：各指標單位與量級不同（顱長一百八十毫米、眶高三十五毫米），先標準化（轉為 z 分數），避免大數值變數壟斷變異。
3. **計算**：對相關矩陣做特徵值分解，得二十個主成分；假設前兩個主成分合計解釋了五十八%的變異。
4. **解讀第一主成分**：載荷顯示顱長、顱高、顴寬同向為正、權重接近——第一主成分捕捉的是「整體大小」。
5. **解讀第二主成分**：顱長與顱寬載荷反號——它捕捉的是「長窄型對短寬型」的形狀差異。
6. **作圖比較**：把四百具顱骨投影到前兩主成分平面上，不同遺址的樣本各成一團；某兩個遺址的點雲明顯交疊，提示兩群人在體質上高度接近，或存在 [基因流動]。
7. **交叉檢驗**：將形態學結構與同一批樣本的古代 DNA 結構對照——若兩種資料給出相同分群，推論的穩健度大幅提高；若不一致，則提示形狀差異可能來自功能適應（如咀嚼習慣）而非血統。

## 與相鄰概念的關聯

- 與 [骨骼測量] 的關係：骨骼測量提供 PCA 的原始變數；沒有嚴謹的量測協議，降維結果只是精緻的雜訊。
- 與 [基因頻率] 的關係：頻率矩陣是遺傳 PCA 的輸入；PCA 把數十個頻率濃縮成幾根「人群差異軸」。
- 與 [基因流動] 的關係：混合人群在 PCA 圖上位於兩個源人群之間，位置比例約略反映混合比例——PCA 因此成為偵測與描述流動的視覺工具。
- 與 [族群比較] 的關係：PCA 的散布圖是族群比較的呈現層；它顯示「接近」，但不自動說明「為何接近」。
- 與 [民族分類] 的關係：PCA 常顯示遺傳連續性跨越民族邊界，提醒分類研究者人群結構與文化分類不同構。

## 容易混淆之處

- 主成分不是因果變數：它是數學上的變異方向，第一主成分解釋力大不代表它「造成」其他變數。
- PCA 圖上接近不等於血統相近：相近可能來自選擇、量測誤差或取樣偏差；須搭配其他統計（如 f 統計量）檢驗。
- 投影與重算不同：把新樣本投影到既有主成分上，與把新樣本併入重新計算，結果可能不同。
- 前兩個主成分只保留部分變異：圖上看起來分離的人群，在未顯示的維度上可能有重要差異。

### 更貼近生活的三個情境

1. 音樂平台的推薦系統把數十個聽歌指標壓成「旋律取向、節奏取向」兩軸，用戶品味在平面上各據一角——同樣的降維邏輯跑在人類學資料上。
2. 城市研究者把數十項社會指標（所得、教育、房齡）合成兩三個「城市面向」主軸，比較全球城市的社會結構。
3. 教育評量把二十個子測驗濃縮成語文、數理兩個主成分，快速定位學生的相對優勢。

### 常見問答

問：PCA 與因子分析有何不同？
答：PCA 直接對變異做分解，目標是壓縮與呈現；因子分析假設背後有潛在因子製造共變，目標是解釋結構。人類學的呈現需求多以 PCA 為主。

問：要保留幾個主成分？
答：常用準則包括特徵值大於一、碎石圖的轉折、以及累積解釋變異（如七至八成）；更重要的是成分能否被實質解讀。

問：資料要先標準化嗎？
答：量綱不一時必須。人類學的骨骼測量與基因頻率混雜著不同單位，直接用共變矩陣會讓大數值變數壟斷結果。

問：PCA 圖上樣本重疊就代表沒有差異嗎？
答：只代表前兩個維度上沒有差異；後面的主成分可能藏有關鍵差異，要回頭檢視載荷。

問：可以拿 PCA 的分數做後續檢定嗎？
答：可以，但要小心解讀——主成分是資料的數學轉換，其分數的意義依附於當次計算的樣本。

### 給初學者的三個提醒

- 先看載荷再談地圖：不了解成分代表什麼就引用圖形，等於用看不懂的儀器導航。
- 樣本構成決定主成分方向：加入新族群重算，軸可能轉向，圖與圖之間不能直接比較。
- PCA 呈現結構，解釋結構仍靠考古、語言與歷史的證據。
