# 證券

> 對應維基百科：[中文維基百科：證券](https://zh.wikipedia.org/wiki/%E8%AD%89%E5%88%B8)　·　[English Wikipedia: Security (finance)](https://en.wikipedia.org/wiki/Security%20%28finance%29)

> 分類範圍：證券是表彰財產權、收益權或請求權的可交易憑證，涵蓋股票、債券、基金受益憑證及衍生性金融商品等類型，其價值在於把權利標準化並轉化為可流通的金融工具　·　隸屬第一層：[社會]　·　相關分類：[人力資源]、[人口結構]、[人際互動]　·　子分類總表見 [README]

證券是一種代表某種權利的憑證，持有者可據此享有資產權益、取得收益，或要求他人履行特定義務。
白話來說，它把「誰享有什麼權利、能分得多少利益」寫成可交易的金融工具，使資金提供者與資金需求者不必直接處理個別財產與債務關係。
它主要解決資本與資源如何跨期、跨主體配置，以及交易雙方如何降低資訊落差與履約風險的問題。
其重要性在於，證券使個人、企業與政府都能透過金融市場籌措資金、分散風險，並讓經濟活動形成更廣泛的信任網絡。

## 核心問題

證券制度首先要回答的核心問題是：如何把複雜的財產權、收益權與請求權，轉換成金額明確、標準一致且能安全交易的憑證。
其次，它必須處理「誰承擔風險、誰取得報酬」的基本分配問題，並確保投資人與發行人間的權利義務可以受到法律保障。
證券的市場價格還需反映收益能力、到期償付能力、流動性與利率變化等因素，使買賣雙方能形成合理價格。
這些問題彼此牽動：若權利內容不清，交易成本便會升高；
若資訊揭露不足，市場便難以區分風險；
若價格機制失靈，資本配置也會失去效率。

一個具體例子是 2008 年全球金融海嘯。
次級房貸被包裝成結構性商品並銷售給全球投資人，複雜的評級與定價掩蓋了標的資產的信用風險。
當房價下跌與違約率上升同時發生，許多投資人湧向拋售，流動性迅速乾涸。
這顯示證券的核心問題不只在於「能不能發行」，更在於「風險是否被真實揭露、價格是否充分反映風險，以及市場恐慌時能否維持交易秩序」。

若以到期收益的簡化觀點表示，債券的價格可理解為未來利息與本金的折現值。
其中折現率上升時，未來現金流以今日計算的價值便會下降，這也是利率風險影響證券價格的基本機制。

## 因果鏈

1. 早期商業社會以金銀、實物、商品與直接借貸交換資源，但個別交易難以跨地域、跨期間延續，資金供給者與需求者必須耗費大量成本彼此辨識與信任。

2. 隨著貨幣制度、航海貿易、城市發展與長期契約逐步成熟，社會出現對可轉讓債權、固定利息及分紅安排的制度需求，權利因而需要獨立於原始財產或債務關係而存在。

3. 證券因此把權利內容、支付條件、期限與責任集中記載於憑證，並建立發行、登記、轉讓、結算與違約處理的程序，降低了逐筆協商與保管的成本。

4. 這類制度解決了上一層「資源無法有效跨期配置」的瓶頸，使個人與企業得以把閒置資金投入企業或公共建設，也讓政府能以市場方式籌措長期資金。

5. 憑證可自由轉讓後，市場參與者不再限於原始權利人，資本得以在更廣範圍內流動；
價格機制也開始將不同資產的收益能力、風險與流動性轉化為可比較的訊號。

6. 證券市場的擴張推動了銀行、保險、基金、會計、評級與法律等配套制度發展，也促進股份公司制度、企業治理及中央銀行公開市場操作的成熟。

7. 當金融工具日益複雜，資訊揭露、會計標準、結算系統與監管框架便成為新的制度需求；
2008 年金融海嘯更凸顯市場透明度、槓桿管制與投資人教育必須同步提升。

## 子分類的定位與相互驅動

### 基礎權利憑證

基礎權利憑證用來表彰持有人對特定資產或法律關係所享有的核心財產權益，是其他證券子分類得以成立的權利基礎。
此類憑證本身通常不直接代表複雜的收益分配安排，而是把所有權、擔保權或合約請求權固定在可辨識的標的之上。
金融機構在設計後續產品時，會以這些權利作為評價、結算與風險隔離的依據。
當基礎權利透過市場交易而重新定價時，實質權利證券的收益預期也會隨之調整。

### 收益分配憑證

收益分配憑證將基礎資產所產生的租金、利息、股息或其他現金流，轉化為投資人可據以取得收益的權利。
此類證券的作用，是讓不直接持有標的資產的投資人也能分享其經濟成果。
市場對未來收益的判斷，會影響其發行條件、交易價格與流動性。
收益分配憑證的規模擴張，又會促使基礎權利憑證的發行與交易需求增加。

### 債權清償順位

債權清償順位用於區分同一債務關係中，不同請求權在清償時所受的待遇與保障程度。
它把本金、利息、違約金及擔保利益安排在不同層次，使投資人能依風險差異選擇工具。
此類結構的建立，仰賴基礎權利憑證對擔保物與債務人義務的明確界定。
當清償順位被市場評價為較為安全時，該債務工具的融資成本通常較低，並可能帶動更多基礎資產的證券化。

### 交易流通工具

交易流通工具著重於讓已表彰的權利與收益能夠在市場上轉讓、結算與價格發現。
它解決的是憑證持有者需要調整部位，而不必等待原始權利到期或另行磋商處理的問題。
交易流通工具的活躍程度，會影響收益分配憑證與債權清償順位工具的市場吸引力。
流通效率提高後，基礎權利憑證的定價資訊也能更快反映於各類證券價格之中。

### 風險移轉與保險連結

風險移轉與保險連結把資產價格、利率、信用或災害事件所造成的損失，透過合約安排轉由願意承擔風險的一方處理。
此類工具使投資人得以調整整體曝險，而不必直接出售基礎權利或放棄收益分配。
保險連結結構的發展，會促進債權清償順位與收益分配工具的創新，例如設定觸發條件或設定不同清償層級。
當市場對風險分散的需求增加時，交易流通工具也會獲得更多設計靈感與交易空間。

## 容易混淆之處

- 常見誤解是「證券就是股票」，但兩者涵蓋範圍不同。
證券是表彰財產權或收益權的憑證，股票只是其中一類。
- 常見誤解是「買了證券就完全沒有風險」，但價格波動、違約與流動性不足都可能造成損失。
投資人仍須評估風險與報酬。
- 常見誤解是「證券一定能自由轉讓」，但部分證券可能受轉讓限制。
是否可轉讓須依法律規定及發行條件判斷。
- 常見誤解是「手上有證券就代表實際持有標的資產」，但多數情況下屬於權利關係而非直接佔有。
投資人享有的是憑證所代表的權利。
- 證券與最相鄰的債券同樣屬於有價憑證，界線在於主要請求權的內容。
證券是上位概念，股票表彰股東權利，債券則表彰對發行人的債權。
- 常見誤解是「所有金融商品都是證券」，但存款、保險契約與衍生性商品未必符合此處定義。
判斷重點在於是否表彰財產權或收益權。
