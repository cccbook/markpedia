# 猿人

> 隸屬：[人種演化] › [古人類化石]　·　狀態：初稿

> 對應維基百科：中文與英文維基百科均無對應條目（參考：猿人 相關文獻）

## 定義

「猿人」是演化史、考古學與早期人類學中使用過的歷史性概念，通常泛指被認為介於現生猿類與人類之間、身上同時具有兩者部分形態特徵的史前人類近親。

人種演化是研究人類及其祖先類群如何隨世代更替、 分化與擴散的歷史過程；古人類化石則是保存古代人類近親骨骼、牙齒或活動痕跡的實物證據。

十九世紀以來，學者發現的化石往往兼具直立行走、較大的腦顱、較大的犬齒或突出的眉脊等不同特徵，因此以「猿人」概括這些介於現代猿類與現代人類之間的標本。

「猿人」不是具有統一祖先、明確邊界及正式階元的生物分類名稱，而是一個會隨證據增加而改變意義的概念性類別。

在狹義用法中，「猿人」常指向爪哇人、北京人及其同類標本；當時的學者曾以「直立猿人」或相近名稱描述這些化石。

在廣義用法中，「猿人」也可涵蓋形態介於猿類與早期人屬之間的物種，以及一部分被描述為過渡特徵明顯的早期人類化石。

過渡型是化石同時呈現兩類祖先型與後代型特徵的狀態；這種特徵組合不等於個體必定是其他已知物種的直接祖先。

直立人是腦容量與身體型態已明顯不同於現生猿類、並在亞洲及非洲留下廣泛足跡的古人類類群；歷史上若干直立人化石曾被納入「猿人」稱呼。

智人是現今所有人類所屬的物種，其形成、擴散及與其他古人類譜系的關係，是現代人種演化研究的重要核心。

丹尼索瓦人是與尼安德特人接近、但具有不同演化分支的古人類類群；其發現使「猿人」一類籠統名稱更難維持為正式分類。

在概念分類中，「猿人」可作為人種演化之下由化石比較、行為證據與譜系重建共同構成的孫分類，但這只是知識組織上的安排，不代表它具有生物分類學上的正式地位。

現代漢語中的「猿人」偶爾也可能泛指猩猩、黑猩猩等現生猿類；本條目所指的是人類演化史中的歷史性概念，因此使用時宜保留引號並交代具體年代與語境。

今天提及「猿人」，主要是重述早期人類學如何理解猿類與人類之間的形態差距，以及說明「過渡型」名稱如何被更精確的物種、年代與演化分支研究所取代。

## 技術與理論的關聯

### 化石形態與年代

- 比較解剖學透過骨骼、牙齒與顱骨形態，判斷標本是否具有直立行走、咀嚼效率及腦容量等方面的特徵。

- 地層是地下岩層形成的先後次序；化石所在位置可提供相對年代，協助判斷標本是否可能屬於同一時期。

- 腦容積變化是頭骨內腔容積隨人類近親演化而改變的現象；顱腔容積可反映腦部發展，但不能直接換算成智力。

- 早期「猿人」常以腦容量約 700 至 1,100 立方公分作為區分猿類與人類的重要指標，後來則逐漸改用整體骨骼比例、發育模式及行為證據綜合判斷。

- 直立姿勢與盆地、股骨和足部構造可用來推估行走方式，使部分化石不再被簡單視為介于四肢行走與兩足行走之間的奇異中間型。

- 形態組合的變化使「缺少一環」的直線式演化圖受到質疑；同一時期的不同人類近親，可能分別具有適合不同環境的身體構造。

- 演化譜系是依祖先與後代關係排列的物種分支圖；它顯示人類近亲的演化更像-tree-like branching的分支，而非由猿類逐步變成人類的單一直線。

- 化石年代若與地磁、沉積物或相關考古遺留共同判讀，就能檢驗某一物種是否存在數十萬年，並辨認長期延續的線系分支。

### 行為與技術證據

- 石器技術是製作、敲擊及使用石制工具的方法與形式；工具的規格和功能可以顯示 Planning、學習與社會傳承等行為能力。

- 工具與腦容量是把工具複雜度與顱腔大小並列比較的研究取徑；兩者可能共同增加，但複雜工具並不必然由較大的腦容量單向造成。

- 手斧、刮削器與尖狀器等不同工具，可用磨製痕跡、原料選擇、接觸點及使用磨耗重建其製作步驟。

- 火的使用是人類近親能夠控制火、保存熟食、嚇退動物或維持共同活動場所的行為；是否由人為點火，仍須排除天然火災與地層搬運的可能。

- 周口店等遺址曾發現灰燼、燃燒骨骼與動物化石，但這些現象的成因並非全都沒有爭議，因此火證據需要與顯微鏡、燃燒溫度及沉積環境一起評估。

- 遷徙路線是根據化石、工具、原料來源與地層分布推估的移動路徑；它能顯示某一古人類類群如何進入新地區並適應不同環境。

- 原料分布有時可顯示工具製造者曾移動，而非僅就地採集；這種證據常迫使分類學重新劃定早期人屬成員的地理分布。

- 遺址中的骨骼年齡與工具年代若能對照，可顯示獵捕、食物處理、群體活動及可能的兒童學習行為。

### 演化模型與譜系解釋

- 線系分支是演化樹中由共同祖先分出的獨立演化路線；確認此類分支，是把「猿人」拆解為不同物種的重要基礎。

- 共同祖先是兩個或更多後代類群在演化史上共享的祖先物種；共同祖先不表示後代仍具有完全相同的形態。

- 漸變模式是變化以較小幅度在較長世代中累積的演化觀點；它可用來解釋部分連續的形態梯度，但不必否認物種形成時的快速變化。

- 突變模式是部分物種形成與形態分化集中在相對短時間內完成的演化觀點；演化始終包含變異，並非所有變化都在同一瞬間發生。

- 漸變與突變可作用於不同尺度或不同特徵，因此兩者不是完全互斥的解释；化石記錄的取樣偏差也可能使短期變化看似突然。

- 替代假說是認為現生人類主要在非洲形成，之後 largely取代其他地區古人類、彼此基因交流有限的解釋；現代古 DNA 顯示這種完全無交流的版本過於簡化。

- 替代與共存是認為不同人類譜系曾在同一地區生活並相互接觸，後來既有大範圍替代，也保留有限混血或局部共存歷史的解釋框架。

- 走出非洲是現生人類主要源自非洲並向其他地區擴散的模型；它與非洲以外的古老化石、工具及古 DNA 樣本共同構成檢驗基礎。

- 歐亞擴散是現生人類進入歐洲與亞洲並形成當地人群的歷史過程；擴張途徑顯示非洲、歐洲與亞洲人群之間存在共同祖先及後續交流。

- 美洲與澳洲是人類晚期擴散所到達的兩個重要區域及相關證據；各地最早人類活動年代，可用來檢驗全球擴散是否快速完成或曾長期停滯。

## 範例

### 爪哇人與「直立猿人」名稱的形成

- 1891 年，荷蘭軍醫兼地質學家杜波依在爪哇島特里尼爾河岸發現一個頭骨化石，後來稱為「爪哇人 1 號」。

- 杜波依在 1892 年取得一枚股骨，並在 1894 年將頭骨與股骨標本命名為「直立猿人」，主張它是猿類與人類之間的過渡祖先。

- 當時估算的腦容量約為 900 立方公分；後續依完整顱骨重新估算，多落在約 900 至 1,100 立方公分之間。

- 頭骨具有較長而低的顱形，股骨則支持兩足直立行走，這種形態組合一度使「猿人」概念獲得看似具體的化石代表。

- 杜波依的發現造成兩方面影響：它支持當時流行的人類演化單線模型，也刺激其他地區的學者尋找可與爪哇人比較的化石。

- 新發現隨後反過來修正「猿人」概念；亞洲、非洲及歐洲出現形態相近的標本後，原本被視為單一過渡物種的化石逐步歸入更廣泛的古人類演化分支。

- 現代研究不再把爪哇人簡稱為由猿變人的直線中間環節，而將其置於直立人及相關早期人屬的演化譜系中。

- 這個案例說明名稱會引導發現，而新發現也會迫使名稱退位；「直立猿人」由物種式名稱轉為歷史詞彙，正是概念與證據相互修正的結果。

### 北京人與中國「猿人」稱呼的流行

- 1921 年，北京周口店洞穴發現一批被認為屬於古人類的牙齒；1929 年，裴文中在當地發現著名頭骨，標本後來稱為北京人。

- 北京人顱容量約為 850 至 1,100 立方公分，具有低而長的頭骨、厚重眉脊及直立行走所適應的身體構造。

- 這批化石曾被歸入「猿人」屬或「中國猿人」等名稱，並一度被視為爪哇人的近親或後代，而非獨立的亞洲演化支系。

- 周口店同時出土大量打製石器，使「猿人」不再只是靠骨骼形態辨識的稱呼，而能與技術行為及群體活動一起討論。

- 灰燼、燃燒骨骼與動物化石曾被用來支持早期火的使用，但天然火災與洞穴沉積作用也提供替代解釋，因此相關年代與成因至今仍有討論。

- 隨後的分類比較將北京人多數標本併入直立人，並把「中國猿人」等名稱視為歷史分類；這種調整同時推動亞洲古人類年代序列與遷徙路線的研究。

- 北京人的發現使「猿人」在中文語境中一度具有相當具體的指涉，但其研究歷史也顯示，一個通俗名稱可以涵蓋彼此有差異的標本。

### 尼安德特人、丹尼索瓦人與古人類分支

- 1856 年，尼安德河谷的 quarry workers 發現骨骼，後由約翰·卡爾·富勒與地質學家赫爾曼·沙夫豪森研究，並以尼安德特人的地區名稱標示。

- 1864 年，地質學家休·金提議將其列為獨立物種，而不只是現代人類的異常個體；這顯示「猿人」式形態比較很快被正式的分類爭議取代。

- 尼安德特人的平均腦容量常被估為約 1,200 至 1,600 立方公分，高於許多早期人屬成員，卻又保留突出眉脊、後縮顱骨等不同於智人的特徵。

- 通俗著作曾把眉脊、鼻部與顱骨形態拿來和猿類比較，使這類標本被納入「猿人」式想像；這種比較也凸顯單一特徵不足以決定分類。

- 1997 年公布的粒線體 DNA 結果顯示，尼安德特人與現代人類具有不同的演化路線；後續核基因組研究又確認兩者曾有有限基因交流。

- 2008 年，西伯利亞丹尼索瓦洞發現一根指骨；2010 年公布的研究確認其基因序列屬於另一條與尼安德特人不同的丹尼索瓦人分支。

- 古 DNA 證據使「過渡型」不再只是形態上的連續位置，而成為可由共同祖先、基因分化與混血歷史檢驗的演化問題。

- 尼安德特人和丹尼索瓦人的發現反過來限制「猿人」概念：兩者不是等待被人類取代的單一祖先，而是各自具有長期歷史的線系分支。

- 這些結果支持替代與共存的修正版模型，顯示現代人類的擴散既造成多地古老譜系衰退，也留下可由基因資料辨識的局部混血痕跡。

### 早期人屬與晚期人類擴散

- 喬治亞亞爾山iskva與德曼尼西遺址顯示，早期人屬成員約在 180 萬年前已活動於西亞；約 160 萬年前的爪哇標本則把其足跡延伸至亞洲。

- 地理分布的擴大促使學者修正「猿人」只屬單一地區或單一物種的想法，並以直立人或早期人屬的分支模型重新整理亞洲與非洲材料。

- 約 60,000 至 70,000 年前，走出非洲的擴散使智人進入歐亞多地，並與仍生活在部分地區的尼安德特人及丹尼索瓦人譜系發生接觸。

- 現代人類約在 45,000 年前廣泛進入歐洲，顯示工具、氣候、獵物資源及人口變動共同影響歐亞擴散的速度與區域差異。

- 澳洲的可靠人類活動證據可追溯至約 50,000 至 65,000 年前；美洲的早期活動證據則主要落在約 20,000 年前以前的地層。

- 美洲與澳洲的年代證據一方面支持全球擴散模型，另一方面也顯示擴散並非同步完成，促使研究重新思考沿海航線、障礙地帶與地方延續。

- 這些地理發現與古 DNA 互相驅動：前者提供最古老活動地點，後者則辨認各地人群與非洲、歐亞古譜系的親緣關係。

## 與相鄰分類的關聯

- 與人種演化的關係最為直接：「猿人」是其中一段以化石比較和過渡特徵為核心的歷史性概念，而不是獨立於演化研究之外的主題。

- 與古人類化石的關係是標本與概括名稱的關係：化石是可觀察的證據，「猿人」則是人們用來整理多種證據的稱呼。

- 與過渡型的關係是部分重疊：某些「猿人」化石曾被描述為過渡型，但過渡型是形態概念，可以套用於不同年代與不同分支。

- 與直立人的關係是歷史重疊：爪哇人、北京人等曾以「猿人」命名，後來多被納入直立人，但「猿人」這個廣義名稱本身不等於直立人。

- 與智人的關係是比較基準：早期學者常以是否接近智人來判斷「猿人」的分類位置，現代研究則避免把人類演化理解成通往智人的單一路徑。

- 與丹尼索瓦人的關係可說明概念修正：丹尼索瓦人原是依少數化石碎片辨識，後來由古 DNA 證實為獨立分支，使籠統的「猿人」稱呼更不適合正式分類。

- 與演化譜系的關係是概括與模型之別：譜系表達分支祖先關係，「猿人」則常混合多種物種及不同時期的標本。

- 與線系分支的關係是形態相似不等於同支：某些「猿人」標本外形接近，卻可能位於不同分支，不能只憑「猿人」稱呼建立親緣關係。

- 與共同祖先的關係是後代共享來源而非保留同一身分：不同古人類可共享共同祖先，並在各自演化中形成可區分的形態與基因特徵。

- 與工具與腦容量的關係在於行為證據可補充骨骼：工具序列、原料選擇與腦容量共同提供演化資訊，但任何單一指標都無法單獨完成分類。

- 與石器技術的關係在於區分製造能力與工具種類：同樣是打製石器，不同技術也可能反映學習程度、傳統或用途差異，而非物種差異。

- 與火的使用的關係在於擴大「過渡」行為的討論：控制火、熟食與群體活動使古人類不必只靠顱骨大小判斷其複雜行為。

- 與遷徙路線的關係在於空間分布會改寫分類：早期人屬分布於非洲與亞洲、智人後來進入各洲，使「猿人」從單一祖先想像轉為多地分支史。

- 與替代假說的關係是模型修正：古 DNA 顯示舊式完全替代說不足，最合理的解釋須同時承認廣泛替代、有限交流與地方差異。

- 與替代與共存的關係是從名稱走向過程：古人類與智人可能曾長期並存，競爭、混血與氣候變遷共同影響各地最終結果。

- 與漸變模式的關係是尺度的辨別：部分形態序列呈漸變，但物種形成與分支建立仍可能包含相對快速的事件。

- 與突變模式的關係是避免把「突然」誤解為瞬間完成：突變提供新變異，自然選擇、遺傳漂變與環境變化共同決定其是否保留並形成分支。

- 與走出非洲的關係是現代人類起源及擴散：非洲化石、古 DNA 與歐亞古人類樣本共同支持智人主要源於非洲並向外擴張。

- 與歐亞擴散的關係是後續歷史：智人進入歐亞後，不只取代早期人類，也與尼安德特人、丹尼索瓦人等譜系發生有限交流。

- 與美洲與澳洲的關係是最終擴散地區：兩地證據把演化譜系由舊大陆延伸到全球，但也顯示不同地區的人類連續性並不一致。

- 最主要的區分標準是：若要正式指稱某個物種，應使用可辨識的物種名稱與年代；若要討論方法史或通俗觀念，才宜使用帶引號的「猿人」。

- 因此，「猿人」最適合被理解為一段提問方式：人類究竟由哪些祖先分支演化而來，而非一個可以永久保留的單一分類答案。
