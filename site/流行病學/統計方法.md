# 統計方法

> 隸屬：[流行病學]　·　狀態：初稿

> 對應維基百科：[中文維基百科：统计学](https://zh.wikipedia.org/wiki/%E7%BB%9F%E8%AE%A1%E5%AD%A6)　·　[English Wikipedia: Statistics](https://en.wikipedia.org/wiki/Statistics)

統計方法是把流行病學的比較變成**帶不確定性的數字**的語言層：風險比回答「差多少」，信賴區間回答「這個估計有多準」，多變項模型回答「控制其他因子後還剩多少」，敏感度分析回答「假設不成立時結論還站得住嗎」。流行病學的資料特性——分類結局（發病／不發病）、人時分母、失追資料、多次測量——催生了專屬的統計工具：相對風險與勝算比、Cox 比例風險模型、廣義線性模型。沒有這一層，研究設計的精心安排無法變成可報告、可重現、可累積的證據。

## 技術與理論的關聯

- **風險比的家族**：相對風險 $\text{RR} = \frac{R_e}{R_0}$ （暴露組與未暴露組風險之比）；勝算比 $\text{OR} = \frac{p_e / (1-p_e)}{p_0 / (1-p_0)}$ ，是病例對照研究唯一可算的比值；歸因風險（風險差 $R_e - R_0$ ）則回答公共衛生層級的「這暴露造成多少絕對負擔」。疾病罕見（ $R < 1\%$ ）時 $\text{OR} \approx \text{RR}$ 。
- **信賴區間優先於 P 值**： $95\%$ 信賴區間同時呈現效應大小與不確定性—— $\text{RR} = 2.0$ （ $95\%$ CI $1.1 \sim 3.6$ ）與 $\text{RR} = 2.0$ （CI $1.95 \sim 2.05$ ）的點估計相同，可信度截然不同。
- **存活分析**：處理「何時發生事件」與失追（設限）資料；Kaplan–Meier 曲線估計無事件存活率，Cox 比例風險模型 $h(t) = h_0(t) \exp(\beta_1 x_1 + \cdots)$ 在不指定基礎風險形態下估計各因子的風險比 $\exp(\beta)$ 。
- **多變項模型**：邏輯斯迴歸（分類結局）、卜瓦松迴歸（計數／人時率）、線性迴歸（連續結局）把多個共變項納入同一模型，估計「控制其他因子後」的調整後效應；共線性與過度擬合是兩大陷阱。
- **敏感度分析**：對不可測混淆（E-value 評估需要多大的未測混淆才能推翻結論）、缺失資料機制、模型設定逐一改動，檢驗結論的穩健性。
- **後設分析與多重檢定**：合併多研究的加權平均與異質性評估（ $I^2$ ）；同時檢定多個假說時須校正（如 Bonferroni 或 FDR），否則偽陽性氾濫。

## 範例：一張 $2 \times 2$ 表到一篇論文的完整計算

某世代研究追蹤吸菸與不吸菸者的十年肺癌發生：吸菸組 10,000 人中 120 例；不吸菸組 10,000 人中 12 例。

1. **風險**： $R_e = 120 / 10000 = 0.012$ ； $R_0 = 12 / 10000 = 0.0012$ 。
2. **相對風險**： $\text{RR} = 0.012 / 0.0012 = 10.0$ ——吸菸者罹病風險是十倍。
3. **歸因風險**： $0.012 - 0.0012 = 0.0108$ ，即每萬人十年多 108 例——公共衛生的絕對負擔。
4. **信賴區間**：以對數風險比的標準誤計算，得 $95\%$ CI 約 $5.5 \sim 18.2$ ——區間不跨 1，關聯穩定。
5. **調整**：加入年齡、職業暴露的 Cox 模型後，調整後 $\text{HR} = 8.3$ （CI $4.5 \sim 15.3$ ）——年齡與職業解釋了部分但非全部關聯。
6. **解讀**：報告同時給點估計、區間與調整前後比較，並以敏感度分析檢查未測混淆——這才是完整的統計敘事。

## 前因後果

- **前因**：生命統計與抽樣理論（十九世紀末至二十世紀初）提供基礎；Fisher 的實驗設計與 Neyman 的信賴區間理論，加上 Framingham 心臟研究等大型世代，把生物統計推向醫學的中心。
- **後果**：統計方法如今滲透基因流行病學（全基因組關聯研究的多重檢定校正）、疫情即時模型（以貝氏方法整合多源資料）；機器學習預測模型與因果推論的分野，正是本條目方法論的延伸戰場。

## 與相鄰分類的關聯

- 與 [研究設計] 的關係：設計決定可用的統計量——病例對照只能算 $\text{OR}$ ，世代可算 $\text{RR}$ 與人時率，RCT 用 ITT 分析；統計不能補救設計的缺陷。
- 在上位概念 [流行病學] 中，本條目是語言層；與 [病因推論] 相比，統計量化不確定性，推論判定因果——顯著性檢定對因果結構毫無發言權。
- 與 [機率統計] 的關係：本條目是機率統計在醫學資料上的應用分支。
- 與 [資料科學] 的關係：大樣本、高維度資料讓兩者工具箱（正規化、交叉驗證）快速合流。

## 容易混淆之處

- **OR 與 RR 不可互換**：常見疾病時 $\text{OR}$ 遠大於 $\text{RR}$ ，媒體常把「勝算比 2」報成「風險加倍」——誇張化的常見來源。
- **風險比不是風險**： $\text{RR} = 2$ 不代表兩倍的人會得病；絕對風險差才反映負擔大小。
- **P 值不是「因果或機會」的判定**：它只度量「在無效假說下觀察到如此資料的機率」；混淆與偏誤不會進入 P 值。
- **調整後效應可能「過度調整」**：控制了中介因子會稀釋總效應——該放哪些變項由因果圖決定，不是全部塞進模型。

## 技術要點

- 三比值記法： $\text{RR}$ （世代）、 $\text{OR}$ （病例對照）、風險差（公共衛生負擔）。
- 罕見病假設： $R$ 極小時 $\text{OR} \approx \text{RR}$ ，可互通。
- Cox 模型前提：比例風險假設——各組風險比隨時間恆定，違反時須分時段或加交互項。
- 信賴區間解讀：重複抽樣下 95% 的區間會涵蓋真值；不是「真值有 95% 機率落在區間內」。
- 缺失資料三機制（MCAR／MAR／MNAR）決定可用方法；多重插補優於刪除。
- 多重檢定必校正；基因流行病學動輒數十萬次檢定，以 $5 \times 10^{-8}$ 為門檻。

## 常見的論爭

- **P 值危機**：2016 年美國統計學會聲明反對以 $p < 0.05$ 二分結論；改革主張改報效應量與區間，但期刊慣性仍在。
- **可重現性問題**：選擇性報告、P-hacking 與分析者自由度使許多關聯無法重現；預先註冊（preregistration）是主要改革。
- **機器學習與因果推論的邊界**：預測模型可以準到極致但不回答因果問題；「把預測當因果」的錯誤在醫療 AI 落地時不斷重演。
