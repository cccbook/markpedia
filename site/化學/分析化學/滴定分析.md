# 滴定分析

> 隸屬：[分析化學] › [定量分析]　·　狀態：初稿

> 對應維基百科：[中文維基百科：滴定](https://zh.wikipedia.org/wiki/%E6%BB%B4%E5%AE%9A)　·　[English Wikipedia: Titration](https://en.wikipedia.org/wiki/Titration)

滴定分析是用已知濃度的標準溶液逐次加入樣品，直到反應達到可觀察終點，再由耗用體積求含量的方法（白話：一邊滴一邊數用了多少才反應完）。它是 [定量分析] 中最直接的容量方法，依反應類型可分為酸鹼、氧化還原、錯合與沉澱四類。雖然儀器能自動送液，滴定原理仍是理解 [分析化學] 化學計量的核心。

## 技術與理論的關聯

- [滴定分析] 是 [分析化學] 的 [定量分析] 工具，核心是標準溶液濃度、反應莫耳比與滴定體積三者相乘。

- 當量點（理論上反應物恰好按化學式完全混合的點）與滴定終點（由指示劑或儀器偵測到的可觀察點）並非必然相同。

- 指示劑（依酸鹼度或金屬離子變化而改變顏色的物質）必須在突跳範圍內變色，才能把終點誤差壓到可接受範圍。

- 滴定曲線（滴定劑體積對應電位、pH 或其他訊號的變化圖）在突跳區形成陡峭區段，可用儀器判定終點。

- 酸鹼滴定受 [酸鹼理論] 控制，氧化還原滴定受電位控制，錯合滴定受條件穩定常數控制，沉澱滴定則受溶度積控制。

- [標準品] 與 [校正曲線] 分別負責建立試劑的已知真值及儀器訊號的換算關係；兩者不可互相取代。

## 範例

**問題**：25.00 mL 鹽酸以 0.1000 M 氫氧化鈉滴定，終點時共消耗 20.00 mL，鹽酸濃度是多少？

1. 在 [分析化學] 中，這是 [定量分析] 的 [滴定分析]；先寫出 $ \mathrm{HCl} + \mathrm{NaOH} \rightarrow \mathrm{NaCl} + \mathrm{H_2O} $ 。

2. 氫氧化鈉的莫耳數為 $ n = 0.1000\ \mathrm{mol/L} \times 0.02000\ \mathrm{L} = 2.000 \times 10^{-3}\ \mathrm{mol} $ 。

3. 酸與鹼以 1:1 反應，所以鹽酸的莫耳數也是 $ 2.000 \times 10^{-3}\ \mathrm{mol} $ 。

4. 鹽酸濃度為 $ c = 2.000 \times 10^{-3}/0.02500 = 0.08000\ \mathrm{mol/L} $ 。

5. 若終點早於當量點，結果會稍低；若晚於當量點，結果會稍高，選用適當指示劑或電位終點可降低此誤差。

6. 正式滴定前應以 [標準品] 標定氫氧化鈉並做空白，因為 0.1000 M 是已標定值，而不是滴定管自帶的標示值。

## 前因後果

1. 十八世紀末法國化學人克洛德·路易·貝托萊研究紡織漂白液的鹼度，使容量檢定開始服務工業。

2. 1790 年代法國化學人路易·尼古拉·沃克蘭發展精確容量玻璃器皿，使已知體積的溶液可被可靠配製。

3. 十九世紀德國化學人羅伯特·本生與彼得·德薩加改善活塞與指示劑，使滴定操作更快速且可重複，並推動容量分析的標準化。

4. 1870 至 1900 年間，德國化學人卡爾·莫爾推廣鉻酸鹽指示法，容量分析成為冶金與水質檢驗的日常工具。

5. 二十世紀的自動滴定儀加入感測器與馬達，讓 [滴定分析] 從人工滴加走向全天候批次作業。

## 與相鄰分類的關聯

- 與 [分析化學] 的關係：滴定把反應的化學計量直接轉成體積讀數，是建立可信定量觀念的基礎。

- 與 [定量分析] 的關係：滴定與重量法同屬古典定量，但前者量體積、後者量質量。

- 與 [滴定分析] 的關係：本條目聚焦四類反應、終點判斷及標準化，不只介紹酸鹼滴定。

- 與 [酸鹼理論] 的關係：弱酸、弱鹼及多元酸鹼的終點位置與突跳大小皆由平衡常數預測。

- 與 [電化學] 的關係：電位滴定以氧化還原電位的跳變判定終點，能避開有色樣品或指示劑變色不清的限制。

## 容易混淆之處

- 當量點不是終點；在 [滴定分析] 中，兩者差距就是終點誤差，可能來自指示劑用量或操作速度。

- 「四」不一定是滴定莫耳比；例如重鉻酸根在酸性條件的還原電子數是 6，計算前必須先配平反應。

- [定量分析] 的標準溶液標示濃度不一定等於實際濃度，尤其氫氧化鈉會吸收二氧化碳，必須定期標定。

- 終點顏色越深不一定越準確；過量指示劑可能消耗滴定劑並提高系統誤差。

## 技術要點

- [滴定分析] 使用前須沖洗滴定管並排除氣泡，讀數須估到 0.01 mL，且初終讀數使用同一彎月面基準。

- 滴定管不應以嘴吹出最後一滴；殘液應依標準操作留在管尖，避免未記錄的出口體積。

- 接近終點時應逐滴加入並充分攪拌，讓局部過量反應消散，再判斷終點是否持續出現。

- 空白試驗用來校正指示劑、玻璃器皿與溶劑對滴定劑的消耗，不能一概省略。

- 平行滴定應使用獨立配製樣品，記錄每次初讀數、終讀數與耗用量，而非只記一個平均終點。

- [分析化學] 的 [品質管制] 還要求把 [校正曲線] 或標準化紀錄與原始滴定資料一併保存，才能追溯結果。

## 常見的論爭

- 自動滴定儀是否足以取代人工滴定，爭議集中於判讀仍可能主觀，以及儀器判終點未必符合所有藥典目視要求。

- 傳統 [滴定分析] 與儀器定量何者應為指定量方法，通常取決於基質、方法專一性與法規接受度，而非單看速度。

- 指示劑是否應保留在自動滴定流程的共識尚未完全一致；支持電位終點者重視客觀性，重視目視者則強調可見性。
