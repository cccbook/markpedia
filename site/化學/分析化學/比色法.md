# 比色法

> 隸屬：[分析化學] › [定量分析]　·　狀態：初稿

> 對應維基百科：[中文維基百科：分光光度法](https://zh.wikipedia.org/wiki/%E5%88%86%E5%85%89%E5%85%89%E5%BA%A6%E6%B3%95)　·　[English Wikipedia: Colorimetry](https://en.wikipedia.org/wiki/Colorimetry)

比色法是比較試樣與標準液顏色深淺以求含量的方法（白話：顏色越深，所測物質通常越多）。它可由人眼比較色階，也可用光電比色計或分光光度計量測吸光度。現代 [比色法] 屬於 [定量分析]，並以 [光譜] 為儀器基礎，廣泛用於水質、藥物、酵素反應與食品成分測定。

## 技術與理論的關聯

- 比爾－朗伯定律（吸光度與濃度及光徑成正比的關係）寫為 $ A = \varepsilon b c $ ，是稀溶液定量的核心。

- 目視比色法（把試液與已知濃度的標準液並排，以肉眼判斷深淺）簡單快速，但受光源、背景與個人判讀影響。

- 光電比色計（用濾片選擇波段並以光電池量測強度的儀器）把「看顏色」轉成數值，卻不若分光光度計能選擇精確波長。

- 顯色試劑（與目標成分形成有色產物的化學試劑）可提高選擇性，但必須控制酸鹼度、顯色時間與試劑空白。

- 基質干擾（共存成分自身吸光或改變顯色反應）會造成正偏差，需以空白、分離或校正方法控制。

- [校正曲線] 把吸光度轉成濃度，而 [標準品] 提供已知真值；兩者共同構成 [比色法] 的可追溯定量鏈。

## 範例

**問題**：某溶液在 510 nm 的吸光度為 0.42，若吸光係數為 15000 L/(mol·cm)、光徑為 1 cm，濃度是多少？

1. 在 [分析化學] 中，這是 [定量分析] 的 [比色法]；先確認溶液澄清且量測時間落在顯色反應穩定期。

2. 採用比爾－朗伯定律 $ A = \varepsilon b c $ ，其中吸光度 $ A = 0.42 $ 、吸光係數 $ \varepsilon = 15000\ \mathrm{L/(mol\cdot cm)} $ 。

3. 光徑為 $ b = 1\ \mathrm{cm} $ ，因此 $ c = A/(\varepsilon b) $ 。

4. 代入數值得 $ c = 0.42/(15000 \times 1) = 2.8 \times 10^{-5}\ \mathrm{mol/L} $ 。

5. 若改用 2 cm 光徑，在其他條件相同時吸光度應約為 0.84；比例不一致表示儀器、顯色或基質仍有問題。

6. 正式測量前須以試劑空白扣除背景，並用至少三個標準液確認 [校正曲線] 線性，樣品超出範圍時應稀釋後重測。

## 前因後果

1. 十八世紀法國化學人 [拉瓦錫] 比較化學反應前後的顏色與沉澱，開啟以感官變化追蹤成分的傳統。

2. 1852 年德國物理學家奧古斯特·比爾與瑞士數學家約翰·朗伯分別建立吸光度與厚度、濃度的經驗關係。

3. 1930 年代，美國工程師阿諾德·貝克曼把單色器、光電池與比色槽組成可重複使用的分光光度計。

4. 1950 至 1960 年代，光電倍增管取代光電池，弱訊號的偵測能力大幅提高，常見比色計逐漸成為桌上型儀器。

5. 今日酵素聯免疫分析與水質比色套件把 [比色法] 帶入例行檢驗，自動化與微孔板則進一步降低試劑用量。

## 與相鄰分類的關聯

- 與 [分析化學] 的關係：比色法把化學顯色反應轉為可測訊號，是濕法與儀器法的交界。

- 與 [定量分析] 的關係：比色法用濃度與吸光度的比例求含量，屬於經典光學定量方法。

- 與 [比色法] 的關係：本條目整理目視、光電與分光光度技術的共同原理。

- 與 [光譜] 的關係：分光光度法選擇單一波長量測吸光度，是 [光譜] 在溶液定量上的應用。

- 與 [校正曲線] 的關係：若吸光係數不確定，便用多點標準溶液建立曲線；兩種途徑都需可靠 [標準品]。

## 容易混淆之處

- 吸光度不是透光率；[比色法] 中 $ A=-\log_{10}T $ ，透光率 50% 對應吸光度約 0.301，不能直接互換。

- 顏色深不代表所有物質都多；[定性分析] 的顯色專一性與光源背景都會影響目視判讀。

- 有色懸浮顆粒散射光，不代表目標分子真正吸收；[取樣與前處理] 應先澄清樣品。

- 高吸光度會使相對誤差增大；[校正曲線] 超過線性區時應稀釋，而不是直接外插。

## 技術要點

- 量測前以相同溶劑、顯色試劑與處理時間製備試劑空白，空白吸光度應接近零。

- 顯色反應須在指定時間內讀取，避免反應繼續造成訊號漂移。

- 比色皿應以同一方向與相同光徑放置，透光面不可用手指觸碰。

- [光譜] 量測應先選目標物的最大吸收波長，並避開溶劑與其他成分的吸收區。

- 若基質造成化學差異，應以標準添加法補償；若只是背景吸收，則可依 [校正曲線] 的截距處理。

- 結果應記錄波長、光徑、顯色條件、空白值及稀釋倍數，以支援 [方法驗證] 與重現性審查。

## 常見的論爭

- 目視比色法是否仍適合法規判定，爭議在於快速、便宜卻高度依賴人眼；[品質管制] 通常要求客觀的儀器讀值。

- 固定波長量測與全光譜資料何者更有資訊量，儀器成本、資料量與法規接受度各有考量。

- 為提高靈敏度而增加顯色試劑，可能同時提高 [沉澱反應] 或副反應的干擾，是否值得須用回收率驗證。
