# 週期性

> 隸屬：[元素週期表]　·　子分類總表見 [README]　·　狀態：初稿

> 對應維基百科：[中文維基百科：週期性](https://zh.wikipedia.org/wiki/%E9%80%B1%E6%9C%9F%E6%80%A7)　·　[English Wikipedia: Periodic trends](https://en.wikipedia.org/wiki/Periodic%20trends)

週期性指的是：元素的化學與物理性質隨原子序遞增**呈週期性的重複**——不是完全相同，而是「同中漸變、跨列重現」。鋰、鈉、鉀、銣、銫隔著幾十個原子序仍彼此相似，因為它們的價電子組態都是 $ns^1$ 。這條規律的嚴謹表述就是週期律：「元素的性質是原子序的週期函數」，而本條目關注的是它背後的機制、例外與應用。

週期性的物理根源是**電子殼層的量子化**：電子只能一層一層地填，每填滿一層、進入下一層，外層電子距核更遠且被內層屏蔽，於是「半徑、遊離能、電負度、金屬性」等性質在每個週期內漸變、在週期交界處跳回。週期表不是人為排出的表格，而是量子力學自動長出的分類樹。

## 機制與主要趨勢

- **有效核電荷**：最外層電子實際感受到的核引力；同週期向右增大（屏蔽不完全），同族向下大致持平——這一個變數同時驅動半徑縮小、遊離能與電負度升高。
- **半徑**：同週期向右縮小、同族向下增大；鑭系收縮使第 6 週期重金屬半徑異常貼近第 5 週期（鋯與鉿半徑幾乎相同，是分離工業的世紀難題）。
- **遊離能**：同週期向右升高、同族向下降低；滿殼與半滿組態造成鋸齒（鎂高於鋁、氮高於氧）。
- **電負度**：氟 3.98 最高、銫 0.79 最低，從左下到右上遞增；電負度差是判斷離子鍵與共價鍵的第一把尺。
- **金屬性**：從右上到左下增強；對角線上的硼—矽—砷—碲是類金屬過渡帶，半導體工業正是踩在這條對角線上。
- **例外即訊號**：相對論效應使金呈金色、汞在常溫為液態；例外不是規律的破產，而是更深層物理的入口。

## 範例

**一組數字看穿週期性**。

1. 遊離能重複：氦 2372 → 氖 2081 → 氬 1521 kJ/mol，三個稀有氣體的數值同屬「每列最高」階梯，逐列遞減——性質重現且系統地向下滑。
2. 鹼金屬重複：鋰 520、鈉 496、鉀 419 kJ/mol，每列最低，同樣逐列遞減；「最高與最低都向下」合起來就是縱向金屬性增強。
3. 半徑重複：第 2 週期從鋰 152 pm 縮到氟 71 pm，第 3 週期從鈉 186 pm 縮到氯 99 pm——兩列各自收縮，收縮後又跳回大值，週期性一目了然。
4. 應用：依電負度差（Cs−F 差 3.19）預測氟化銫是典型離子晶體；依碳 2.55 與氫 2.20 的微小差值預測 C−H 鍵近乎非極性——兩個預測都與實測吻合。

## 前因後果

1829 年德貝萊納的「三素組」與 1865 年紐蘭茲的「八音律」是週期性的經驗前奏；1869 年 [門捷列夫] 提出以原子量排序的週期律並用於預言新元素，把觀察升級為工具；1913 年莫色勒改用原子序，修掉了原子量排序的幾處倒序（如碘在碲之後）；1920 年代量子力學把「為何週期」解釋為殼層填充。週期性成熟的迴響包括：冶金與材料設計靠趨勢挑元素（半導體選矽、觸媒選鉑族）、合成元素的性質預估全靠趨勢外推、以及化學教育中以趨勢代替死記。

- 與 [量子力學] 的關係：殼層模型是週期性存在的物理保證。

## 容易混淆之處

- **「週期性」不等於「完全重複」**：同族元素相似但沿週期方向仍有系統差異（活潑性、半徑），重複的是「模式」而非「數值」。
- **原子量排序的歷史錯位**：碲（原子量較大）排在碘之前是正確的，因為真正依據是原子序；讀舊資料時要留意時代的排序標準。
- **趨勢有例外**：鋸齒、鑭系收縮、相對論效應都會局部破壞主趨勢；背口訣前先記住「例外集中於滿殼、半滿與重元素」。

## 技術要點

- 推理模板：先判同週期或同族，再套「右小左大、右上高左下低、左下金屬性最強」的口訣，最後查例外清單。
- 電負度差判鍵型：差大於約 1.7 偏離子、小於約 1.7 偏共價，灰區用熔點與導電性驗證。
- 數值一律以 IUPAC 實測資料為準，趨勢只用於快速排序與定性判斷。
- 遇到第 6、7 週期重元素的異常，先想到相對論效應與鑭系收縮兩個嫌疑。

## 進一步的細節

- 電子親合能也服從週期性（鹵素最大），但數據凌亂、例外更多，教學上常排在電負度之後。
- 熔點、沸點、密度沒有乾淨的週期規律——它們由晶體結構與鍵型共同決定，不是單變數趨勢；金屬性、遊離能才是「乾淨趨勢」。
- 「對角線規則」是縱向與橫向趨勢疊加的副產品：鈹與鋁、硼與矽的相似性，可用兩個方向的拉鋸解釋。
- 週期性的證據等級：光譜測得的遊離能最硬，半徑次之（依定義），電負度是導出量（最軟）——引用時注意證據等級。
- 第 2 週期元素的「小而特別」：氮不成五價擴展、氟不呈正氧化態——小原子的殼層容量限制使第 2 週期常自成例外群。
- 相對論效應在金的表現：6s 電子軌域收縮，使金的電負度（2.54）高於多數過渡金屬——重元素的趨勢要「打折」使用。
- 週期性與宇宙豐度呼應：氫、氦最多、鐵的核最穩定——核物理與化學的兩張地圖在同一張表上對齊。
- 讀趨勢圖的技巧：先看軸（原子序還是族號）、再看單位，最後記住「鋸齒＝殼層邊界」。
