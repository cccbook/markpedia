# 冰芯紀錄

> 隸屬：[第四紀](README.md) › [冰期](冰期.md)　·　狀態：初稿

> 對應維基百科：[中文維基百科：冰芯紀錄](https://zh.wikipedia.org/wiki/%E5%86%B0%E8%8A%AF%E7%B4%80%E9%8C%84)

冰芯紀錄是以鑽取並分析極地冰層為基礎，用來重建古氣候、古大氣與冰期環境變化的證據体系。研究者將冰柱依照深度排列，藉由其中的年度雪層、封閉氣泡、塵埃、化學成分及穩定同位素，建立具有時間尺度的環境變化序列。

冰芯紀錄的重要性，在於仪器观测只能提供數百年間的連續資料，而冰層能將氣候資訊保存數十萬年，甚至更久。它因此成為研究冰期與間冰期交替、溫室氣體濃度、全球碳循環、海平面變化及地球軌道因素之間關係的重要依據。

在分類架構中，本條目位於 [第四紀] 之下，並以 [冰期] 為直接分類背景。不過，冰芯紀錄是一套取樣、定年與重建方法，而不是單一地質事件；同一套紀錄也能用於辨識間冰期、冰期前驅期以及冰期结束後的環境變化。

## 技術要點

- **冰芯的取得**：研究者使用蒸汽鑽、旋轉鑽或鋸式鑽頭，在南極或格陵蘭冰蓋鑽入深層，再將分段取出的冰柱編號、記錄深度並運回低溫實驗室。
- **保存條件**：低溫、乾淨且穩定的積雪環境有助於保存氣泡、塵粒與化學訊號，因此厚冰蓋中心的冰層通常比邊緣地區保存得更完整。
- **年度層序**：在降雪穩定且未受強烈擾動的地區，連續雪層可形成近似年度的層理，可用來建立高解析度年代模型。
- **封閉氣泡**：當積雪壓密成冰而氣泡不再與外界相通時，當時的大氣便被封入冰中，因而提供二氧化碳、甲烷、氧化亞氮等氣體的直接樣本。
- **氣體年齡**：封閉氣體通常比包圍它的冰更古老，差距會隨深度、積雪率與冰體流動而改變，因此不能直接把相鄰冰層視為完全同時代。
- **氘同位素**：冰中的氘與氘比例可反映降水時的水氣來源及當地溫度，但必須結合同位素分馏模型與其他資料校準。
- **氧同位素**：氧十八與氧十六的比例可用於推估溫度、積雪量及水循環，並能協助比對不同年代與不同地點的冰芯。
- **大氣化學成分**：氣泡中的二氧化碳與甲烷可重建溫室氣體濃度的長期變化，並用來檢驗氣候與碳循環的相互回饋。
- **塵埃與氣膠**：陸地塵埃、海鹽、硫酸鹽及火山碎屑可指示風向、乾濕狀況、海冰範圍與火山活動。
- **火山灰定年**：具有已知年代或可由其他紀錄比對的火山灰層，可作為固定冰芯年代模型的時間標記。
- **化學離子**：鈣、鈉、氯、硫酸根等離子的濃度變化，反映降水源、海洋氣候、風向及近期大氣污染等資訊。
- **冰流變形**：冰芯並非靜止標尺，深層冰會因重力而流動、拉伸、剪切與折疊，因此深層樣本的水平和垂直解析度可能下降。
- **底部融化**：靠近冰蓋底部的冰可能受到地熱與壓力影響而融化，使最古老紀錄受到混合、干擾或缺損。
- **年代模型**：研究者結合層厚、氣體年齡、同位素、甲烷同步訊號、塵埃及火山灰，逐年校正每段冰芯所代表的時間。
- **解析度**：解析度由取樣間隔、年代模型、樣本保存程度及分析方法共同決定；不同深度不能一概視為具有相同的時間精度。
- **溫度重建**：冰芯溫度代理量多反映採樣地點，而非全球平均溫度，因此還需配合海溫、樹輪、珊瑚與沉積物等紀錄進行空間校正。
- **二氧化碳重建**：氣泡中的二氧化碳是重要資料，但深層樣本可能受到現代大氣交換、化學變化或測量程序影響，必須評估保存與校正方式。
- **品質管制**：空氣泡、空白樣、標準樣、重複測量與跨實驗室比對，可降低儀器漂移、污染與操作差異造成的誤差。
- **不確定性**：冰芯年代、溫度換算、氣體保存及空間代表性均存在誤差，解讀時應同時呈現誤差範圍與替代模型。
- **原始資料保存**：未經處理的冰芯、氣泡樣本、測量值與年代檔案必須封存，才能讓其他研究團隊重新分析、比較與驗證。
- **分類上的意義**：冰芯紀錄能辨識冰期內部的暖期、冷峰與轉折，但並不把所有第四紀地質資料都納入，因此它是研究 [冰期] 的重要證據類別。

## 範例

歐洲南極冰芯計畫所取得的南極 Dome C 冰芯，是冰芯紀錄如何延長氣候序列並解決定年瓶頸的典型案例。包括讓-茹貝爾（Jean Jouzel）與克洛德·洛里烏斯（Claude Lorius）在內的法國研究者，參與了 Vostok 冰芯與 Dome C 冰芯的研究。

1. **提出問題**：研究者希望知道，冰期與間冰期的溫度變化是否具有可重複的長週期，以及二氧化碳濃度是否與冰期交替同步變化。
2. **建立先驅序列**：Vostok 冰芯提供約四十二萬年的連續紀錄；在 [1998年] 發表的分析顯示，南極溫度、二氧化碳與甲烷變化和地球軌道週期具有明確關聯。
3. **選擇研究地點**：Dome C 位於南極高原，海拔約三千二百三十三公尺，年平均表面溫度約為攝氏零下五十度，積雪量低且冰層厚度大，適合保存深層紀錄。
4. **執行鑽探**：研究團隊使用低污染鑽探設備逐段取得冰芯，將冰柱依深度編號，並在現場保存，避免反覆融化造成化學或氣體訊號改變。
5. **擴展時間範圍**：在 [2004年] 公布的 Dome C 冰芯結果把可靠紀錄延伸至約八十萬年，鑽探深度超過三千一百公尺，涵蓋多個冰期與間冰期循環。
6. **建立年代模型**：團隊先依局部年層、氣體成分與塵埃變化估計深度，再利用已知火山灰層及不同冰芯間的共同訊號進行同步與校正。
7. **分取並測量樣本**：研究人員將冰芯切成小段，利用低溫抽取氣泡，測定二氧化碳、甲烷與其他氣體；另取融水分析氘、氧十八及主要化學離子。
8. **校正溫度代理量**：氘同位素訊號先轉換為當地溫度變化，再與其他南極冰芯、海溫紀錄及全球 proxies 比較，以減少單一地點代表性不足的問題。
9. **比較氣候與碳循環**：約八十萬年尺度上的二氧化碳變化大致落在約一百八十至三百 ppm 的範圍，並與冰期降溫及間冰期增溫相伴出現。
10. **解讀共同變化**：結果顯示，地軸傾角、歲差及離心率造成的日照分布變化，能夠解釋大部分南極溫度振幅；碳循環則進一步放大或維持這種氣候變化。
11. **跨越重要瓶頸**：Vostok 與 Dome C 紀錄讓研究者能在同一框架中比較數十萬年的溫度、氣體與年代，而不必只依賴長度有限的仪器序列。
12. **推動後續發展**：Dome C 結果促進南極、格陵蘭及其他地區建立標準化冰芯資料庫，也鼓勵跨地區、跨代理指標的同步比較研究。
13. **形成當代意義**：冰芯所呈現的自然二氧化碳變化幅度，提供了評估現代暖化速率、累積量及未來氣候情境的重要長期基準。

## 前因後果

1. 近代氣象與海洋觀測只有數百年的長度，無法直接涵蓋許多冰期與間冰期，因此必須尋找能保存更長時間的自然紀錄。
2. 極地積雪經長期壓密形成冰，並將當時的大氣、塵埃與同位素訊號封存在深層，使冰芯成為第四紀環境變化的連續檔案。
3. 蒸汽鑽、机械鑽探、低溫取樣及精密同位素分析技術成熟後，研究者能取得數千公尺長、年代可校準的冰芯。
4. 冰流變形、氣體與冰的年代差、底部融化等問題，使單靠深度推算年代難以成立。
5. 火山灰、甲烷、塵埃及層厚等交叉定年方法被整合，年代模型因而能由相對順序提升為可比較的時間尺度。
6. 溫度同位素與封閉氣體被放在同一時間框架中，研究者得以檢驗二氧化碳、甲烷與氣候變化之間的同步、回饋與先後關係。
7. Vostok 與 Dome C 等長紀錄支持軌道節律的解釋，並促使全球氣候模型加入冰量、海平面與碳循環的反應。
8. 不同半球、不同緯度及不同環境的冰芯開始相互比對，區域差異與全球共同訊號得以分開辨識。
9. 冰芯資料成為驗證氣候模式的基準，並協助改進未來氣候情境對冰期條件的模擬。
10. 原始樣本與數值資料的長期保存，使後來出現的新分析方法可以重新檢驗舊有結論。

## 與相鄰分類的關聯

- **與 [第四紀] 的關係**：冰芯紀錄提供 [第四紀] 晚期至晚期第四紀的重要環境證據，尤其適合研究冰期、間冰期及其內部變化。
- **與 [冰期] 的關係**：冰芯是辨識冰期降溫、積雪增加、冰量增長與間冰期暖化的直接證據來源之一。
- **分類與事件的差別**：冰期是地質時間中的氣候狀態，冰芯紀錄則是保存並重建這些狀態的方法與資料集合。
- **範圍上的限制**：冰芯可保存的連續序列通常只覆蓋數十萬年，較早的第四紀環境仍須依靠沉積物、化石、洞穴沉積與其他代理指標。
- **與其他代理指標的關係**：冰芯能提供氣體成分、同位素與年度層序，但樹輪、珊瑚、湖泊沉積及海底沉積物在較暖環境中往往具有更長的連續紀錄。
- **區域與全球的區別**：南極冰芯可清楚顯示冰期氣候變化，卻不能未經校正便直接等同於全球平均溫度或全球海平面。
- **因果與同步的區別**：同一冰芯中二氧化碳與溫度共同變化，可建立同步關係；判定碳循環是否為主要驅動因素，仍須配合模型、實驗與其他紀錄。

## 容易混淆之處

- **冰芯與冰芯紀錄並不相同**：冰芯是實際取得的冰柱樣本，冰芯紀錄則包含樣本、年代模型、測量資料、誤差評估與重建結果。
- **冰期不等於所有冰芯年代**：冰芯可跨越冰期與間冰期，不能把冰芯中的每一段都直接標成冰期。
- **第四紀也不等於冰期**：第四紀包含冰期與間冰期，冰芯紀錄只是重建第四紀氣候的重要工具之一。
- **同位素比例不是溫度計讀數**：氧十八或氘比例必須透過地區特定模型換算，不能直接把數值當作攝氏溫度。
- **南極溫度不是全球溫度**：當地同位素訊號包含區域特徵，全球推估還需要其他地區的紀錄與空間校正。
- **氣泡年代與周圍冰年代不同**：氣泡是在雪變成緻密冰、孔隙關閉時被封住，因此其化學組成代表較早時刻的大氣。
- **二氧化碳同步變化不自動證明單向因果**：冰芯能顯示關聯，卻不能單憑共變化區分溫度、海洋、陸地生態與碳循環各自的作用。
- **最深冰層不一定最清楚**：深層樣本可能年代較老，卻也可能受到冰流變形、融冰、層厚壓縮與氣體保存問題影響。
- **年度層並非處處皆可辨識**：降雪量、風力與冰流作用會破壞部分層理，低降雪地區尤其難以逐層計數。
- **保存並不等於完全未改變**：氣體仍可能擴散，融化後再凍結也可能混合或排除部分成分，測量時必須評估保存程度。
- **化學塵埃不只代表一種成因**：塵粒可能來自乾旱陸地、火山、海鹽或人為活動，必須結合粒徑、成分與其他指標判讀。
- **單一冰芯不是完整全球史**：不同冰芯的年代基準、地理範圍與代理量各異，綜合結論應建立在多地紀錄的比較上。
