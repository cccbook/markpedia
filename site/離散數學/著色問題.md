# 著色問題

> 隸屬：[離散數學] › [圖論]　·　狀態：初稿

> 對應維基百科：中文維基百科無對應條目　·　[English Wikipedia: Graph coloring](https://en.wikipedia.org/wiki/Graph_coloring)

著色問題是**用最少的顏色為圖的頂點著色，使得相鄰頂點顏色不同**。最少的顏色數稱為圖的色數 $\chi(G)$ 。

它是圖論中形式最簡單卻最難的問題之一。區分「找到一種著色」與「證明不存在更省色的著色」是本質的差別：前者是構造性問題，後者是證明性問題，四色定理正是後者的巔峰之作。

## 技術要點

- **色數**： $\chi(G) = \min \{ k : G \text{ 可用 } k \text{ 色著色} \}$ ；恆有 $1 \le \chi(G) \le \Delta(G) + 1$ 。
- **貪心著色**：依任意順序著色，可用至多 $\Delta(G)+1$ 色，這給出上界。
- ** Brooks 定理**：若圖既非完全圖也非奇圈，則 $\chi(G) \le \Delta(G)$ 。
- **平面圖的四色定理**： $\chi(G) \le 4$ ；但判定一個圖能否以 3 色著色是 NP 完全的。
- **列表著色**：每個頂點給定允許的顏色清單，題目更一般化。
- **邊著色**：對邊著色而非頂點，Vizing 定理給出 $\chi'(G) \le \Delta(G)+1$ 。

## 範例

**問題**：為圖 $G$ 的頂點著色，邊為 $\{1,2\},\{1,3\},\{2,3\},\{2,4\},\{3,4\},\{3,5\},\{4,5\}$ 。

1. **列出結構**：頂點 1、2、3 兩兩相鄰（構成三角形 $K_3$ ），頂點 2、3、4 兩兩相鄰（另一個三角形），頂點 3、4、5 兩兩相鄰（第三個三角形）。
2. **下界**：三個兩兩相鄰的頂點至少要 3 種顏色，故 $\chi(G) \ge 3$ 。
3. **構造 3 色著色**：令 $c(1) = A$ ， $c(2) = B$ ， $c(3) = C$ ， $c(4) = A$ （與 2、3 相鄰，避開 B、C）， $c(5) = B$ （與 3、4 相鄰，避開 C、A）。逐一檢查所有邊： $1-2(A,B)$ ✓、 $1-3(A,C)$ ✓、 $2-3(B,C)$ ✓、 $2-4(B,A)$ ✓、 $3-4(C,A)$ ✓、 $3-5(C,B)$ ✓、 $4-5(A,B)$ ✓ 。
4. **結論**： $\chi(G) = 3$ 。
5. **另一個例子（ $K_4$ ）**： $K_4$ 的四個頂點兩兩相鄰，每個都需要不同顏色，故 $\chi(K_4) = 4$ ，且 $K_4$ 是平面圖，說明四色定理中的「四」確實必要。
6. **最大度數檢查**：此圖中 $\Delta(G) = 4$ （頂點 3 與 4 各有 4 個鄰居），Brooks 定理給出 $\chi(G) \le \Delta = 4$ ，與我們求得的 3 一致但較鬆。

第二個例子說明著色問題的實務意義。在排程問題中，若把工作項目視為頂點、把「不能同時進行」的配對視為邊，則「用 k 個時段完成所有工作」正是一個著色問題；資源（房間、機器、頻道）的數量就是顏色數。另一個應用是地圖著色：相鄰國家需不同顏色，四色定理保證四種顏色永遠足夠——這是「地圖需要幾種顏色」這個日常問題的數學答案。

## 與相鄰分類的關聯

- 與 [平面圖] 的關聯：四色定理限定了平面圖的色數上界，是本概念最著名的成果。
- 與 [圖] 的關聯：著色問題是圖的頂點上的性質，屬於圖的「參數」之一。
- 在上位概念 [圖論] 中，著色問題扮演**難題代表**的角色：它把簡潔的陳述與 NP 完全性結合在一起。

## 容易混淆之處

- **著色的最小值與最大值不同**： $\chi(G) \le \Delta(G)+1$ 是上界，但常常可以做得更好。
- **列表著色與普通著色不同**：前者允許各頂點有不同的可用顏色，答案可以遠大於 4。
- **邊著色與頂點著色不同**：兩者是不同問題，各有獨立定理。
- **平面圖的著色不必然是 4 色**：四色定理給出的是上界，許多平面圖只需 2 或 3 色。
- **地圖著色與平面圖著色的等價性**：需注意有「海外領土」等情況時並非完全等價。

## 技術要點

- 貪心演算法按頂點度數遞減順序著色，是最實用的近似演算法。
- 判定圖是否為 3 色可著色是 NP 完全的；4 色可著色（平面圖）則在四色定理下永遠為真。
- 以隨機方法著色可快速得到接近 $\Delta/\ln \Delta$ 的著色數。
- 貪心著色與局部搜尋（k-opt）在實務地圖著色上表現極佳，通常能達到理論下界。
- 著色問題的推廣「著色帶權圖」用顏色成本最小化，是排程最佳化的模型。
- 列表著色中，Grundy 數給出單一頂點的著色數上界。

## 常見的論爭

- **NP 完全性與實務可用性的落差**：真實地圖著色多數能在合理時間內求到最優解，批評者指出這不代表問題「不難」。
- **四色定理能否有更短的人證**：至今未解，也因此四色定理在教學上仍被視為特例。
- **著色數的下界判斷**：即使能給出著色，求證「不可能更省色」仍是困難的一半，這是 NP 完全性的直接後果。
