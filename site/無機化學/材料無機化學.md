# 材料無機化學

> 隸屬：[無機化學]　·　狀態：初稿

> 對應維基百科：[中文維基百科：材料科學](https://zh.wikipedia.org/wiki/%E6%9D%90%E6%96%99%E7%A7%91%E5%AD%A6)　·　[English Wikipedia: Materials science](https://en.wikipedia.org/wiki/Materials_science)

材料無機化學把 [元素週期律]、[配位化學] 與酸鹼知識轉化為**有功能的固體**：[半導體材料]、[陶瓷] 與 [催化劑] 是三大支柱。它處理的問題從「分子」轉向「晶格」——導電、發光、硬度與催化活性不再由單一分子決定，而由原子在晶格中的排列、缺陷與摻雜決定。這是無機化學從描述自然走向設計材料的出口。

## 技術與理論的關聯

- **摻雜改變導電**：矽本身 4 價，摻入微量磷（5 價）得多餘電子成 n 型，摻入硼（3 個價電子）得電洞成 p 型——p 型與 n 型接合就是二極體與電晶體的基礎（見 [半導體材料]）。
- **能帶是導電的判據**：導體的價帶與導帶相連、絕緣體帶隙大於約 4 eV、半導體介於其間（矽 1.1 eV、鍺 0.7 eV）——能帶結構由晶格與電子組態決定。
- **陶瓷的鍵與性質**：離子鍵＋共價鍵使其耐高溫（氧化鋁熔點 2072 °C）、耐腐蝕、硬度高但脆——見 [陶瓷] 的工業面。
- **催化劑降低活化能**：非均相催化在固體表面吸附反應物、改變其電子狀態再脫附；哈伯法合成氨的鐵觸媒把反應溫度需求大幅降低（見 [催化劑]）。
- **缺陷化學**：實際晶體必有空位與雜質，氧空位決定氧化鋯的氧感測功能、摻氮讓金剛石呈黃色——缺陷不是瑕疵，是功能的開關。
- **光學材料**：磷光體（稀土摻雜的釔鋁石榴石，YAG:Ce）把藍色 LED 轉成白光，2014 年諾貝爾獎技術的無機化學核心。

## 範例

**一克硼改變世界**：每百萬個矽原子摻入約 1 個硼原子，導電率可提高約千倍——純度九個九的矽（99.9999999%）因此是半導體工業的入場券。從石英砂到晶圓的旅程，每一步都是無機化學：碳熱還原（ $\mathrm{SiO_2 + 2C \to Si + 2CO}$ ）、西門子法提純（ $\mathrm{Si + 2HCl \to SiHCl_3 + H_2}$ ，再氫還原沉積）。

**哈伯法的代價與功德**： $\mathrm{N_2 + 3H_2 \rightleftharpoons 2NH_3}$ ，以鐵為觸媒、約 400–500 °C 與 200 大氣壓操作。觸媒不改變平衡位置，但使工業規模的反應速率成為可能——今日全球約一半人口的糧食，直接或間接依賴合成氨肥料。

**觸媒轉化器**：汽車排氣通過鉑、鈀、銠塗層蜂巢，一氧化碳與氮氧化物在表面反應成二氧化碳與氮氣： $\mathrm{2NO + 2CO \to N_2 + 2CO_2}$ 。三種貴金屬各司其職，總塗層量僅數克，卻決定一座城市的空氣品質。

**氧化鋁陶瓷的兩副面孔**：作為絕緣基板，它導熱快、絕緣好，讓晶片散熱而不漏電；作為人工關節，它耐磨、生物相容。同一種化合物（熔點 2072 °C）因製程與緻密度不同而扮演完全不同的角色——材料無機化學的「配方思維」由此可見。

## 前因後果

古典無機化學專注溶液與分子，對固體內部幾乎無話可說——二十世紀電子工業需要可預測的固體，這個需求催生了能帶理論與缺陷化學，材料無機化學於焉成形。它反過來把 [元素週期表] 變成材料搜尋引擎：要耐高溫找第 IVA–VA 的碳化物、要強磁性找鑭系與鐵族、要光致發光找稀土離子。半導體（見 [半導體材料]）、陶瓷與催化三線並進，支撐了資訊、能源與環保三大產業。

## 與相鄰分類的關聯

- 與 [元素週期律] 的關係：摻雜選元素全憑週期律——磷與硼在矽兩側各差一個價電子，正好造出 n 型與 p 型。
- 與 [配位化學] 的關係：催化劑表面的活性位點本質上是金屬的配位環境；均相觸媒更是標準錯合物。
- 與 [材料學] 的關係：本分類提供化學根據，[材料學] 處理製程、機械性質與工程應用，兩者互為裡表。

## 容易混淆之處

- **觸媒不參與淨反應計量**：它降低活化能、加速正逆兩向，不改變平衡產率。
- **半導體不是「半導電的導體」**：它的導電隨溫度、光照與摻雜劇烈變化，這正是元件的原理。
- **陶瓷不只餐具**：引擎零件、人工關節、絕緣基板都是先進陶瓷，「陶瓷＝易碎碗」是過時印象。
- **高純度不是越純越好**：半導體要 99.9999999% 純，卻又要刻意摻雜——「純」與「摻」是同一工藝的兩面。

## 技術要點

- 西門子法：粗矽轉成 $\mathrm{SiHCl_3}$ 蒸餾提純，再氫還原得電子級多晶矽。
- Czochralski 法由熔融單晶種拉出晶棒，是晶圓製造的第一步。
- 帶隙數據：矽 1.1 eV、鍺 0.7 eV、碳化矽 3.3 eV、氮化鎵 3.4 eV。
- 磷光體 YAG:Ce 吸收 450 nm 藍光發黃光，與殘餘藍光混合成白光。
- 釔安定氧化鋯（YSZ）靠氧空位導氧離子，用於氧感測器與固態氧化物燃料電池。
- 觸媒載體（氧化鋁蜂巢）的功能是分散活性金屬、防止燒結。
- 缺陷的兩大類：點缺陷（空位、替位雜質、間隙原子）與線缺陷（差排）；陶瓷的強度與半導體的良率都受缺陷控制。
- 溶膠－凝膠法：以金屬醇鹽水解縮合製備奈米級氧化物粉體，是先進陶瓷低溫製程的代表。
- 摻雜量的直覺：半導體摻雜約在 ppm 量級，卻足以讓電阻下降千倍——「微量決定一切」是固態化學的鐵律。
- 晶體生長的三要素：溫度梯度、過飽和度與冷卻速率——決定晶粒大小，也決定材料品質。

## 常見的論爭

- **稀土供應鏈**：磷光體與強磁體依賴稀土，開採的環境代價與供應集中度是地緣與環境爭議焦點。
- **鉑族金屬的稀缺**：觸媒轉化器與氫能電解對鉑族金屬的需求，推動替代觸媒研究，至今未有完全等效方案。
- **固態電池的電解質**：氧化物陶瓷電解質與硫化物路線各有支持者，界穩定性與製程成本仍是難點。
- **計算材料學的地位**：高通量計算篩選（如材料基因組計畫）能否取代實驗試錯，學界仍在磨合分工。
