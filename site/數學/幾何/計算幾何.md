# 計算幾何

> 隸屬：[幾何]　·　狀態：初稿

> 對應維基百科：[中文維基百科：計算幾何](https://zh.wikipedia.org/wiki/%E8%A8%88%E7%AE%97%E5%B9%BE%E4%BD%95)　·　[English Wikipedia: Computational geometry](https://en.wikipedia.org/wiki/Computational_geometry)

計算幾何是研究如何用演算法與資料結構處理幾何問題的學科。它把點、直線、多邊形、曲線與空間物體轉換成可以計算、搜尋與比較的表示，並同時分析結果所需的時間與記憶體。幾何直覺提供問題結構，演算法則把直覺變成可重複且能處理大量資料的程序。

## 概念的核心

**計算幾何**：以演算法解決幾何問題的領域，白話說就是讓電腦按照明確步驟作圖、判斷位置、尋找最近物件與建立空間索引。

演算法是有限且明確的運算程序；資料結構則是組織資料、支援特定操作的表示方式。兩者共同決定幾何查詢的效率，而[演算法]的一般複雜度分析會延伸到幾何問題的精確、前提與反例。

幾何物件通常先轉成離散資料，例如二維點的座標是 $ p = (x, y) $，線段則由兩個端點 $ a $ 與 $ b $ 決定。實際運算多在有限精度下進行；涉及共線、重合或圓周等退化情形時，常須另外處理容差或符號判定。

## 演算法與資料結構

典型的資料管線依序包含輸入表示、候選過濾、幾何判定、拓樸重建與結果輸出。演算法與資料結構的配對會依問題而異，例如凸包需要排序與堆疊，線段相交需要平面掃描，而最近鄰搜尋常使用空間分割樹。

演算法與資料結構的配對會依問題而異，例如凸包需要排序與堆疊，線段相交需要平面掃描，而最近鄰搜尋常使用空間分割樹。

常見的基本操作如下。

1. 判斷三點的轉向，即判斷它們是左轉、右轉或共線。
2. 判斷一點是否位於某條線段上，而非僅位於其所在直線上。
3. 判斷兩個封閉圖形是否相交，以及相交點位於何處。
4. 尋找離查詢點最近的輸入點。
5. 找出包圍全部輸入點的最小凸多邊形。

**資料結構**：為特定操作安排資料的組織方式，白話說就是決定資料放在哪裡、如何比較，以及每次操作要檢查多少內容。

## 凸包與 Andrew 演算法

**凸包**：包含全部輸入點的最小凸集合；在一般位置下，它由部分輸入點依逆時針或順時針順序連接而成。

若所有輸入點都位於某個凸多邊形內，且每個邊界頂點都是輸入點，該多邊形就是這些點的凸包。位於內部或邊上的非頂點點不會出現在凸包頂點序列中。

Andrew 演算法又稱單調鏈演算法，優點是容易實作，且時間複雜度為 $ O(n \log n) $。其步驟如下。

1. 依橫座標排序；若橫座標相同，再依縱座標排序。
2. 由左至右掃描，維持只保留逆時針轉向的下凸鏈。
3. 由右至左掃描，維持只保留逆時針轉向的上凸鏈。
4. 合併兩條鏈，並刪除重複的首尾端點。

轉向由叉積決定；對三點 $ a $、$ b $、$ c $，可計算如下。

$$
\operatorname{cross}(a,b,c)
= (x_b-x_a)(y_c-y_a)-(y_b-y_a)(x_c-x_a)
$$

若叉積大於零，表示左轉；小於零表示右轉；等於零表示共線。建構下凸鏈時，遇到右轉或共線就移除中間點，最後一項不保留在鏈上。

### 凸包手算範例

考慮七個點：

- $ A=(0,0) $。
- $ B=(0,3) $。
- $ C=(1,1) $。
- $ D=(2,5) $。
- $ E=(3,1) $。
- $ F=(4,0) $。
- $ G=(4,3) $。

依橫座標、再依縱座標排序後，得到 $ A $、$ B $、$ C $、$ D $、$ E $、$ F $、$ G $。

先建立下凸鏈。加入 $ C $ 時，對 $ A $、$ B $、$ C $ 的叉積為 $ -3 $，所以移除 $ B $；鏈暫時為 $ A $、$ C $。加入 $ D $ 時，

$$
\operatorname{cross}(A,C,D)=1\cdot 5-1\cdot 2=3>0
$$

因此保留 $ C $，鏈成為 $ A $、$ C $、$ D $。加入 $ E $ 時，

$$
\operatorname{cross}(C,D,E)=(2-1)(1-1)-(5-1)(3-1)=0-8=-8
$$

所以依規則先移除 $ D $；再計算 $ A $、$ C $、$ E $ 得叉積 $ -2 $，又移除 $ C $。下凸鏈最後為 $ A $、$ F $、$ G $。

反向掃描得到上凸鏈 $ G $、$ D $、$ B $、$ A $。合併並去除重複端點後，凸包依逆時針順序為：

1. $ A=(0,0) $。
2. $ F=(4,0) $。
3. $ G=(4,3) $。
4. $ D=(2,5) $。
5. $ B=(0,3) $。

內部點 $ C $ 與 $ E $ 不在凸包上。利用鞋帶公式，凸包面積為

$$
\frac{1}{2}\left|
(0\cdot0+4\cdot3+4\cdot5+2\cdot3+0\cdot0)
-(0\cdot4+0\cdot4+3\cdot2+5\cdot0+3\cdot0)
\right|=16
$$

這個數值也可用來核對實作結果：輸出頂點必須按邊界順序連接，且面積應等於 $ 16 $。

## 線段相交判定

**線段相交判定**：判斷兩條封閉線段是否至少共享一個點，答案包含端點接觸、跨越交點與共線重疊三種情況。

對有向線段 $ ab $，令叉積 $ \operatorname{orient}(a,b,c) $ 判斷點 $ c $ 在其左側還是右側。若兩條線段各自把對方端點分處兩側，通常便相交；但共線情形必須另外檢查端點是否落在另一線段的範圍內。

```python
def orient(a, b, c):
    return ((b[0] - a[0]) * (c[1] - a[1])
            - (b[1] - a[1]) * (c[0] - a[0]))


def on_segment(a, b, p):
    return (min(a[0], b[0]) <= p[0] <= max(a[0], b[0])
            and min(a[1], b[1]) <= p[1] <= max(a[1], b[1]))


def segments_intersect(a, b, c, d):
    o1 = orient(a, b, c)
    o2 = orient(a, b, d)
    o3 = orient(c, d, a)
    o4 = orient(c, d, b)

    if o1 == 0 and on_segment(a, b, c):
        return True
    if o2 == 0 and on_segment(a, b, d):
        return True
    if o3 == 0 and on_segment(c, d, a):
        return True
    if o4 == 0 and on_segment(c, d, b):
        return True

    return (o1 > 0) != (o2 > 0) and (o3 > 0) != (o4 > 0)
```

測試 $ (0,0) $ 至 $ (4,4) $ 與 $ (0,4) $ 至 $ (4,0) $ 時，四個叉積的符號符合跨越條件，函式回傳真；測試兩條共線但不相接的線段時，範圍檢查會回傳假。

浮點數乘法可能溢位，量測資料也可能帶有誤差。因此高可靠系統常使用自適應精確度、方向判定或符號運算，而不只是直接比較乘積。

## 三角剖分

**三角剖分**：把點集或多邊形切成彼此只在共用邊相接的三角形，白話說就是用不重疊的三角形把區域完整鋪滿。

對一個無孔洞、邊界簡單的平面多邊形，設頂點數為 $ n $、邊界頂點數為 $ h $，若剖分恰有 $ T $ 個三角形與 $ E $ 條邊，則[拓樸]的歐拉公式給出

$$
n-E+(T+1)=2
$$

再由邊與三角形 incidence 的計數，可得

$$
E=3n-h-3,\qquad T=2n-h-2
$$

三角剖分常用於有限元素分析、地理疊圖、碰撞偵測與網格渲染。對一般點集，常見分治或隨機增量法可在 $ O(n \log n) $ 時間內完成。

## Voronoi 圖與 Delaunay 三角網

**Voronoi 圖**：把平面按「離哪個給定點最近」分區的圖；第 $ i $ 個站點 $ p_i $ 的區域由以下集合定義。

$$
V(p_i)=\{x:\|x-p_i\|\leq \|x-p_j\|\text{ 對所有 }j\neq i\}
$$

兩個站點的區域交界位於它們的垂直平分線上。令 $ p_j-p_i $ 為兩站點差向量，利用平方距離相等可把比較改寫為線性式。

$$
2(p_j-p_i)\cdot x=\|p_j\|^2-\|p_i\|^2
$$

這個形式使 Voronoi 圖能以半平面交集理解，也與[線性代數]中的內積和直線方程直接相關。

**Delaunay 三角網**：連接相鄰 Voronoi 區域之站點所形成的三角形網路，與 Voronoi 圖互為對偶。

Delaunay 三角網常用來求最近鄰、重建不規則散點表面，以及支援重心插值。其核心性質是：對 Delaunay 三角形的外接圓內部，除三個頂點外，不應包含其他給定點。

### 定理、前提與反例

Delaunay 空圓定理需要輸入點處於一般位置，也就是沒有四個不同點共圓，且沒有三個不同點共線。在這個前提下，每個 Delaunay 三角形的外接圓內部沒有其他輸入點，而且 Delaunay 三角網唯一。

反例是四個點恰好位於同一圓周上。此時兩種對角線都能產生空圓三角形，因此「唯一」結論不成立；若要唯一決定，必須另加符號擾動或約定打破平手。

另一個常見前提是「輸入點已經依角度排序」。若任意次序的凸多邊形直接套用只適用於已排序頂點的翻轉法，可能產生錯誤或無法終止，所以前提不可省略。

## 空間分割

**空間分割**：把整個空間或查詢區域切成較小的區塊，使查詢能略過不可能含有答案的區塊。

kd-tree 會依座標軸遞迴分割點集，常用於二維範圍查詢與最近鄰搜尋。在資料分布均勻且維度固定時，平均查詢常接近 $ O(\log n) $；最壞情況仍可能退化到 $ O(n) $。

二元空間分割樹將空間以直線或超平面分割，適合電腦圖學的可見性判斷。某些分割方式讓每個節點區域包含固定數目的物體，因此能建立平衡結構。

四叉樹把矩形或方形反覆分成四份，適合具有自相似尺度特徵的資料。範圍樹與聚合樹則為多維查詢提供較佳的最壞情況上界。

選取資料結構時，不能只看平均速度，還須比較記憶體、更新成本、輸入分佈與查詢模型。

## 演算法複雜度分析

**複雜度分析**：估計演算法隨輸入規模增長所需的時間與空間，是比較不同解法是否可扩展的主要依據。

在二維中，若有 $ n $ 個點並求凸包，Andrew 演算法先花 $ O(n\log n) $ 排序，再用 $ O(n) $ 時間掃描。由於輸出可能依輸入次序改變，凸包問題包含排序下界，所以 $ O(n\log n) $ 的最壞時間界是恰當的。

線段相交若逐一比較所有配對，需要 $ O(n^2) $ 時間。平面掃描法把端點依橫座標排序，在活動集合中維護相鄰線段，通常可在 $ O(n\log n+k) $ 時間內報告 $ k $ 個交點。

分析時應區分四個量：輸入數 $ n $、輸出大小 $ k $、邊界大小 $ h $ 與維度 $ d $。例如三角剖分的三角數是 $ 2n-h-2 $，表示演算法至少要花線性時間寫出全部三角形。

常數因子也不能忽略。掃描線資料結構每次更新可能牽涉多個相鄰元素；kd-tree 在均勻資料上很快，但資料相關的旋轉或刪除可能使節點長期失衡。

## 平面掃描與資料結構

平面掃描的核心是讓一條掃描線沿某個方向移動，並在遇到事件時更新狀態。線段相交問題中，事件是線段端點；維護結構中只需比較目前可能相交的鄰近線段。

平衡搜尋樹可讓端點插入、刪除與比較各花 $ O(\log n) $，事件排序也需 $ O(n\log n) $。若事件有相同橫座標，還須謹慎處理交換次序與退化事件。

時間戳能讓已判定永遠不可能相交的線段提早退出活動集合。這個技巧降低實際比較數，但最壞複雜度仍須由完整分析支持，不能只憑實驗平均。

## 與相鄰分類的關聯

計算幾何建立在[歐氏幾何]的距離、角度與座標概念上，但研究目標不同：歐氏幾何偏重命題、證明與公理化性質，計算幾何偏重可執行的程序與資源上界。

[拓樸]研究哪些性質在連續變形下保持不變。演算法常以拓樸不變量辨認包含、連通、交叉與邊界關係，即使頂點座標持續改變也不混淆。

[線性代數]提供內積、矩陣與線性方程，有助於處理 Voronoi 邊界、投影與座標變換。相鄰的離散數學則提供有限集合、格點與組合計數的工具。

## 前因後果

早期人工繪圖、反演問題與線性規劃研究，需要把幾何推理轉成可重複計算的程序。隨著電腦記憶體與輸入資料增加，單靠人工判讀已無法處理大量點集，凸包、線段相交與區域搜尋遂成為核心問題。

機器人路徑規劃要求快速判斷障礙物是否阻擋通道；地理資訊系統要求疊加多邊形並處理精確位置；電腦圖學要求建立網格並判斷可見性。這些需求推動掃描線、半平面法、分割樹與三角網的成熟。

成熟資料結構又回饋到機器人、CAD、醫學影像與地圖服務。網際網路服務面對數百萬物件時，索引與近似查詢的重要性，更使計算幾何從研究演算法走向系統工程。

## 容易混淆之處

1. 凸包不是所有點依輸入順序形成的折線；只有邊界頂點會保留。
2. Voronoi 圖是區域劃分，Delaunay 三角網是其對偶，兩者不是同一種圖。
3. 任意三角剖分不一定是 Delaunay 三角網；只有滿足空圓條件者才具有對應性質。
4. $ O(n\log n) $ 不表示每次查詢都只需對數時間；它可能只描述建構成本。
5. 平均情況查詢很快，不代表最壞情況也快；kd-tree 是常見例子。
6. 幾何上共線的三點在浮點運算中未必得到零叉積，因此直接實作可能需要精確判定。
7. 找到一條交叉路徑不等於求得兩個凸多邊形的最短距離，兩者是不同問題。

## 技術要點

- 用叉積統一處理左轉、右轉與共線三種方向判定。
- 閉合線段的相交判定必須包含端點接觸與共線重疊。
- 凸包演算法先排序，再以堆疊線性建構兩條單調鏈。
- 平面剖分應記錄頂點、邊、面與 incidence，避免只儲存孤立三角形。
- Delaunay 的空圓性質需要一般位置作為唯一性的前提。
- Voronoi 圖的邊是垂直平分線，計算時可改寫平方距離以避免開根號。
- 空間索引必須同時說明平均上界與最壞上界。
- 輸出敏感分析要明確寫出 $ k $、$ h $ 等參數，避免把大量輸出藏在常數中。
- 涉及容差時，須說明容差是絕對值、相對值或方向誤差，不可任意混用。

## 延伸思考

若輸入會持續增加，資料結構需要支援插入與刪除；若只處理固定快照，離線排序與批次掃描可能更簡單。若查詢維度上升，kd-tree 等方法可能受「維度災難」影響，空間填補方法則用較高記憶體換取較穩定的查詢速度。

幾何演算法也必須面對模型誤差。若座標來自感測器，可靠的答案可能是「落在某個容差範圍內」，而不是精確的等號。設計系統時因此要在速度、數值穩健性、可證明性與記憶體之間取捨。
