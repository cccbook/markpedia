# 九章算術

> 類型：物品（數學著作）　·　領域：[數學家]　·　狀態：初稿

> 對應維基百科：[中文維基百科：九章算術](https://zh.wikipedia.org/wiki/%E4%B9%9D%E7%AB%A0%E7%AE%97%E6%9C%AF)　·　[English Wikipedia: The Nine Chapters on the Mathematical Art](https://en.wikipedia.org/wiki/The_Nine_Chapters_on_the_Mathematical_Art)

**九章算術**是中國現存最早的數學專著之一，全書九章、246 題，內容涵蓋方程、面積、體積、盈不足、勾股等主題。它在「歷史人物」的脈絡中代表**算法型數學的傳統**：先有可操作的程序（術），再有抽象的符號體系，這條路線與歐幾里得式的定義—命題傳統形成有趣對照。

## 章節與方法

| 章 | 主題 | 關鍵技術 |
| --- | --- | --- |
| 方田 | 土地與面積測量 | 盈不足法、方程術 |
| 粟米 | 糧食與比例 | 比例分配、單位換算 |
| 衰分 | 按比例遞減分配 | 衰分算法 |
| 少廣 | 面積與體積 | 開方（求平方根與立方根） |
| 商功 | 工程與體積 | 立方體積、溝洫等土木計算 |
| 均輸 | 運輸與調度 | 均輸法，後世成為大型調運的標準算法 |
| 盈不足 | 不確定量的處理 | 以兩次假設反推真值 |
| 方程 | 線性方程組 | 直除法（逐步消元）與正負數運算 |
| 勾股 | 直角三角形 | 勾股定理與應用問題 |

其中「方程」章的**正負數**與**消元法**，是中國數學獨立發展的重要成果；而「盈不足」的解題思想——以兩組推測值反推真值——在世界數學史上是一種罕見而優雅的解題策略。

## 前因後果

1. **實用需求的推動**：土地丈量、賦稅、漕運與工程都要求可重複計算的程序，數學因此以「解決一類問題」的面貌出現。
2. **筆算的符號化**：正負數的引入使代數運算得以進行，解方程從此有系統方法。
3. **疑難題的註解傳承**：魏晉之後的註解家對各題給出更精簡的算法與更嚴格的推理，使原書不斷被改寫，也讓「讀注」成為數學家的基本訓練。
4. **世界數學史上的位置**：與阿拉伯—印度數系的算術、[歐幾里得] 的幾何相比，《九章算術》代表另一條可能的路徑：程序優先、符號晚出。

## 容易混淆之處

- **它不是一本系統教科書**：各章題目彼此獨立，缺乏統一理論，因此常被視為「算術題集」而非幾何那樣的演繹體系。
- **「中國數學沒有一般化」是過度簡化**：正負數與方程章的處理已相當成熟，差異主要在於抽象符號與公理化的取向。
- **章節次序與內容經歷長期變動**，今日通行本不等於原初面貌。
