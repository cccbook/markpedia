# 蒙地卡羅

> 隸屬：[機率統計] › [貝氏方法]　·　狀態：初稿

> 對應維基百科：[中文維基百科：蒙地卡羅方法](https://zh.wikipedia.org/wiki/%E8%92%99%E7%89%B9%E5%8D%A1%E7%BE%85%E6%96%B9%E6%B3%95)　·　[English Wikipedia: Monte Carlo method](https://en.wikipedia.org/wiki/Monte_Carlo_method)

蒙地卡羅方法是**以大量隨機抽樣的統計量來逼近難以解析求得的量**的方法。它可以估算積分、模擬隨機過程，也可以抽樣逼近後驗分布。

名字來自摩納哥的蒙特卡洛（Monte Carlo）賭場——[梅特羅波利斯] 與同事在 1940 年代用這個帶有戲謔意味的名字為他們的方法命名，因為它依賴隨機性與賭場的關聯。

它的力量在於把「計算問題」轉化為「抽樣問題」：只要能把目標量寫成某個隨機變數的期望，蒙地卡羅就能用抽樣把它算出來，無論原式多麼複雜。

## 技術要點

- **基本原理**： $E[f(X)] = \int f(x) p(x) \, dx$ 可由抽樣均值 $\frac{1}{n}\sum_{i=1}^n f(X_i)$ 逼近，誤差依 [大數法則] 與中心極限定理控制。
- **誤差與樣本數**：誤差以 $O(n^{-1/2})$ 收斂，欲提高十倍精度需要百倍樣本數——這是蒙地卡羅的致命弱點，也是準確求積法在低維時更優的原因。
- **重要性取樣**：從易於抽樣的分布 $q$ 取樣並以 $p/q$ 加權，可大幅降低變異，是後驗抽樣的基礎。
- **MCMC**：以馬可夫鏈的穩定分布為目標分布，抽樣效率取決於混合時間。
- **準確抽樣**：如 rejection sampling、與分層抽樣，可用於低維且有結構的問題。
- **方差縮減**：對偶變數法、控制變數法、分層抽樣等技術可在同樣本數下降低誤差。

## 範例

**問題**：估算圓面積 $\pi$ 。取單位正方形內均勻隨機點 $(X, Y)$ ，若 $X^2 + Y^2 \le 1$ 則該點落在四分之一圓內。

1. **建立估計量**：令 $I = \mathbb{1}\{X^2 + Y^2 \le 1\}$ ，則 $E[I] = \pi/4$ ，故 $\hat{\pi} = 4 \bar{I}$ 。
2. **抽樣計算**：抽 10000 個點，其中 7853 個落在圓內，則 $\hat{\pi} = 4 \times 0.7853 = 3.1412$ ，與真值 $3.14159265$ 相差約 $0.0004$ 。
3. **估計誤差**：因 $I$ 是 Bernoulli 變數，標準誤為 $\sqrt{0.785 \times 0.215 / 10000} \approx 0.0041$ ，故 $\pi$ 的估計標準誤約 $0.0164$ 。這意味著蒙地卡羅求 $\pi$ 竟不如教科書給出的位數——正是 $1/\sqrt{n}$ 收斂率的後果。
4. **改進**：若用對偶變數法（取樣點用極座標並以角度的對稱性配對），可把方差降低數倍，達到同樣精度只需數百個樣本。
5. **對照**：以數值積分求 $\pi$ 只需數十次乘加，精確度遠高。**這說明蒙地卡羅的優勢不在低維，而在高維或複雜區域。**
6. **真正的強項**：估算 $n$ 維球體體積時， $\pi^{n/2}/\Gamma(n/2+1)$ 隨 $n$ 急遽變化，蒙地卡羅的誤差卻與維度無關（除方差增長外），遠優於數值積分。

第二個例子是貝氏後驗抽樣。以 [後驗] 中的 $\mathrm{Beta}(9, 193)$ 為目標，若用 MCMC 取樣 100000 步，有效樣本數可能只有數千；相較之下，以重要性抽樣（從 $\mathrm{Beta}(9, 193)$ 本身抽）只需 1000 個樣本就能達到同等精度。可見**選對抽樣方法比增加樣本數更重要**。

## 前因後果

蒙地卡羅方法源於 1940 年代的核物理研究。中子鏈反應本質上是隨機的，模擬它需要追蹤大量中子的隨機命運；[烏拉姆] 、[梅特羅波利斯] 與 [馮·諾伊曼] 發現讓電腦做隨機抽樣，比解析求解多維積分可行得多。戰時需求加上新算力，使這個原本被認為「不實際」的方法在數年內成為主流。

戰後，蒙地卡羅方法進入統計力學（Metropolis 取樣）、生物資訊學（序列比對的動態規劃、貝葉斯分析）、金融工程（蒙地卡羅模擬）與電腦圖學（渲染路徑追蹤）。1990 年代 MCMC 與 Gibbs 取樣的成熟，讓它成為貝氏方法的計算基礎；2010 年代 GPU 與平行計算的普及，又把可處理的維度推高了一個數量級。

## 與相鄰分類的關聯

- 與 [後驗] 的關聯：後驗抽樣是蒙地卡羅在貝氏方法中最主要的用途。
- 與 [馬可夫鏈] 的關聯：MCMC 以馬可夫鏈為基礎，其混合時間決定效率。
- 在上位概念 [貝氏方法] 中，蒙地卡羅扮演**計算引擎**的角色：它讓難以解析的貝氏更新得以實現。

## 容易混淆之處

- **蒙地卡羅與隨機抽樣不同**：蒙地卡羅是系統性地用隨機性來計算特定量，不是隨意抽樣後做描述統計。
- **蒙地卡羅與準確求積不同**：前者給出隨機誤差，後者給出受捨入誤差限制的確定值。
- **樣本數與誤差**：誤差不隨樣本數線性下降， $1/\sqrt{n}$ 是硬限制。
- **「隨機」不是「沒有方法」**：蒙地卡羅的結果依賴抽樣設計、方差縮減技術與收斂診斷。

## 技術要點

- 誤差以標準誤 $\sigma / \sqrt{n}$ 表示，報告結果時應同時給出信賴區間。
- 重要性抽樣的權重要檢查尾部行為，否則可能出現極端權重導致的有效樣本數崩潰。
- MCMC 必須做多鏈比較與軌跡診斷，確認已進入穩定分布。
- 分層抽樣在能自然分層的問題中幾乎免費地降低方差。
- 對偶變數法可把方差降為零（在恰當的構造下），如求圓面積時的角度對稱。
- 平行化蒙地卡羅時，注意獨立的隨機數流（不同種子的並行序列）才能合併誤差估計。

## 常見的論爭

- **蒙地卡羅是否已被微分求積取代**：自動微分技術讓許多積分可精確求導求解，蒙地卡羅的地位因此受質疑；但對不連續目標函數與離散推論，它仍不可替代。
- **隨機性帶來的可重現性問題**：隨機抽樣的結果依賴種子與實作細節，使跨系統比較困難。
- **GPU 時代的精度爭議**：在 GPU 上以單精度累加大量樣本會使誤差累積，是否應以雙精度或 Kahan 補償引發實務討論。

## 歷史沿革

蒙地卡羅方法的名稱來自 1940 年代的洛斯阿拉莫斯國家實驗室。[烏拉姆] 、[梅特羅波利斯] 與 [馮·諾伊曼] 發現，模擬中子鏈反應所需的隨機路徑追蹤，遠比解析求積可行；「Monte Carlo」這個帶有玩笑意味的名稱隨即誕生。戰後，方法迅速擴散到統計力學（1953 年的 [梅特羅波利斯] 取樣）、金融工程與生物資訊學。

1990 年代的 MCMC 技術（Metropolis–Hastings、Gibbs 抽樣、漢明頓-鄧克威爾鏈）讓蒙地卡羅成為貝氏分析的計算基礎；2010 年代 GPU 與平行抽樣則把可處理的維度與樣本量大幅提升。

## 實務應用

蒙地卡羅應用於：投資組合的風險值計算、保險的有限 ruin 機率估計、貝葉斯模型的後驗抽樣、分子動力學模擬、輻射傳輸的積分、光線追蹤渲染。

實務的關鍵在於效率：正確設計抽樣分佈、加入方差縮減、確認混合時間，並在報告中給出誤差的信賴區間。
