# ASK

> 隸屬：[訊號調變]　·　狀態：初稿

> 對應維基百科：[English Wikipedia: Amplitude-shift keying](https://en.wikipedia.org/wiki/Amplitude-shift_keying)

ASK（幅移鍵控，Amplitude-Shift Keying）是**用載波振幅的不同取值來表示數位資料**的調變方式。白話說：讓「訊號的大小」承載 0 與 1——訊號大代表 1、訊號小或消失代表 0。它是三種基本數位調變（ASK、[FSK]、[PSK]）中最簡單的一種：產生電路只需要一個開關，解調也只需要檢波器，因此最早被廣泛使用，但抗雜訊能力也是三者中最弱的。

## 技術與理論的關聯

- **與振幅調變（AM）的關係**：ASK 是 AM 的數位特例——當調變訊號只有兩個離散值（0 與 1）時，連續的振幅調變就退化為 ASK。
- **OOK（On-Off Keying，通斷鍵控）**：ASK 的最簡特例，振幅只在「滿幅」與「零」兩態之間切換。早期的電報（摩斯電碼的通斷）與現代光通訊的亮暗編碼，本質上都是 OOK。
- **星座圖**：ASK 的星座點排在一條實數軸上，2-ASK 兩點、4-ASK 四點。點數越多頻譜效率越高，但點與點的距離縮小，錯誤率上升。
- **雜訊敏感性**：因為資訊承載在振幅上，任何通道衰減、衰落與放大器雜訊都直接擾動判決門檻，這是 ASK 在無線行動環境中罕用的根本原因。
- **包絡檢波**：非相干解調只需整流與低通濾波即可還原資料，電路成本遠低於需要載波重建的相干解調。

## 範例

**範例一：2-ASK 的頻寬與位元率。** 若符號率（baud rate）為 $1$ Msymbol/s，2-ASK 每符號攜帶 1 位元，位元率即 1 Mbit/s；採滾降係數 0.35 的根號升餘弦濾波時，所需射頻頻寬約 $(1+0.35)\times 1 = 1.35$ MHz。

**範例二：判決門檻與錯誤率。** 2-ASK 在加性白高斯雜訊下的最佳判決門檻是兩個振幅值的中點。若發送振幅分別為 0 與 $A=1$ V，平均雜訊均方根為 $\sigma=0.2$ V，距門檻 0.5 V 為 2.5 個標準差，依高斯分配估計單一判決錯誤率約 $6\times 10^{-7}$ ；若雜訊增大到 $\sigma=0.4$ V，錯誤率惡化到 $10^{-2}$ 量級，可見振幅調變對雜訊高度敏感。

**範例三：紅外線遙控器。** 家用電視遙控器以 38 kHz 載波做 OOK：按下按鍵時紅外線發光二極體以 38 kHz 閃爍（代表 1），靜默（代表 0）。選 38 kHz 是為了避開陽光與室內燈光的低頻閃爍幹擾，接收端用窄頻帶通濾波器只對 38 kHz 有反應。

## 前因後果

ASK 的歷史幾乎與無線電同齊：1895 年馬可尼時代的火花發射機只能通斷，接收端靠「聽見與否」判決，這就是最原始的 OOK。隨著真空管放大器出現，振幅可以連續控制，連續調變的 AM 廣播（1920 年代）與離散調變的 ASK 並行發展。數位時代初期，ASK 因電路簡單主宰了低頻與有線資料傳輸；但行動通訊興起後，無線通道的衰落對振幅造成劇烈擾動，ASK 逐漸退出主流射頻介面，讓位給 [PSK] 與 [QAM]。它今日的主戰場是光纖（光強度調變本質上是光域 OOK）與短距離低功耗射頻（如 RFID、遙控器）。

## 與相鄰分類的關聯

- 與 [FSK]、[PSK] 的關係：三者分別把資訊放到載波的振幅、頻率與相位上；ASK 最省電省電路，PSK 抗噪最好，FSK 介於其間。
- 與 [QAM] 的關係：QAM 可視為「兩路正交的 ASK」疊加，把資訊同時放在同相與正交兩個分量上，頻譜效率翻倍。
- 與[無線通道]的關係：通道的衰落直接改變接收振幅，因此 ASK 系統必須依賴自動增益控制或改用頻率、相位調變。
- 與[光纖通訊]的關係：直接調變的光纖系統以雷射亮暗承載資料，即光域的 OOK。
- 在上位概念[通訊工程]中，ASK 是「數位調變三大家族」的起點，理解它就理解了判決門檻與錯誤率的基本框架。

## 容易混淆之處

- **ASK 不等於 OOK**：OOK 是振幅只取 0 與滿幅兩值的特例；廣義 ASK 允許多階振幅（如 4-ASK）。
- **ASK 不等於 AM 廣播**：AM 的調變訊號是連續類比波形；ASK 的調變訊號是離散數位符號。
- **簡單不等於不好**：在光纖與短距離場景，ASK 的簡單性正是它勝出的原因；「抗噪差」只在惡劣無線通道中成立。
- **包絡檢波不是唯一解調法**：相干解調對 ASK 也能用，錯誤率更佳，但需要本地載波重建。

## 技術要點

- 發射端功率放大器可用非線性高效類（如 C 類），因為振幅資訊已由開關決定。
- 判決門檻應隨接收訊號強度自適應調整，否則固定門檻在衰落通道下錯誤率暴增。
- 深度衰落（訊號瞬間消失）會被誤判為一長串 0，系統層需靠交織與錯誤更正碼補救。
- 射頻識別被動標籤以「背向散射的振幅調變」回傳資料，屬 ASK 的反向應用。
- 眼圖張開度是評估 ASK 鏈路品質最直觀的工具。

## 常見的論爭

- **光通訊是否該升級到相位調變**：OOK 光纖系統簡單便宜，但相干光通訊（QPSK/16-QAM）已主宰長距離主幹；都會與接取網路上 OOK 與相干方案的取捨持續討論中。
- **多階 ASK 的定位**：4-ASK 以上在射頻幾乎被 QAM 取代，但在光域（如 PAM4，四階脈衝振幅調變）因雷射相位控制困難，多階 ASK 反而成為 400G 短距傳輸的主流。

## 發展里程碑

- 1837 年：摩斯電報系統以通斷電流傳送電碼，OOK 的有線原型。
- 1895 年：無線電火花發射機讓 OOK 跨入無線，摩斯電碼成為半世紀的海上通訊標準。
- 1920 年代：真空管 AM 廣播普及，振幅調變技術成熟並反哺 ASK 電路設計。
- 1960 年代：飛機應答機（二次雷達）採用脈衝位置與幅度編碼，ASK 跨入航空。
- 1980 年代：光纖通訊以直接調變雷射實現光域 OOK，成為主幹網標準。
- 1990 年代：RFID 被動標籤以背向散射 ASK 回傳資料，ASK 進入物聯網前身。
- 2010 年代：400G 光纖短距傳輸採用 PAM4（四階振幅調變），多階 ASK 在光域復活。

## 實作與量測

- 誤碼率量測以偽隨機序列（PRBS）打訊號、逐位元比對，BER 低於 $10^{-9}$ 為長途光纖門檻。
- 眼圖張開度與抖動是 ASK 鏈路的兩大品質指標，示波器眼圖模板可一秒判讀良莠。
- 消光比（開態與關態功率比）直接影響光接收靈敏度，雷射偏置點設定是工程要點。
- RFID 場景的反向散射鏈路預算須同時考慮讀取器發射功率與標籤啟動門檻。
