# 孫子兵法

> 類型：物品（兵書）　·　領域：[將領與軍事統帥]　·　狀態：初稿

> 對應維基百科：[中文維基百科：孫子兵法](https://zh.wikipedia.org/wiki/%E5%AD%99%E5%AD%90%E5%85%B5%E6%B3%95)　·　[English Wikipedia: The Art of War](https://en.wikipedia.org/wiki/The_Art_of_War)

**孫子兵法**是中國最早的兵書之一，全書十三篇，相傳成書於春秋末年，作者身分歷來有爭議。它在「歷史人物」的脈絡中有兩層意義：**它是先秦「兵家」知識的總結**，並且是**中文世界裡被援引最多的戰爭理論文本**——直到二十世紀末，企業管理者仍從中借用「不戰而屈人之兵」等概念來談競爭。

## 結構與核心主張

| 篇名 | 主題 | 白話解釋 |
| --- | --- | --- |
| 始計 | 開戰前的五事七計 | 開戰前先算清政治、軍事與氣象條件，而不是先動手 |
| 作戰 | 戰爭的經濟代價 | 打仗要花錢、拖時間，因此速戰與不戰皆有其代價 |
| 謀攻 | 以全爭全 | 最好的勝利是不經交戰而服敵；次好是破敵於城外 |
| 軍形 | 勝敗的先後條件 | 先算勝敗再決定是否開戰，勝不了就不要打 |
| 兵勢 | 節奏與勢 | 用最小的力量取得最大的效果，重視節奏而非蠻力 |
| 虛實 | 避實擊虛 | 選擇對手薄弱處，把有限的資源集中於一點 |
| 軍爭 | 時間與節奏的爭奪 | 搶先機有其代價，遲滯也有風險 |
| 九變 | 地形與將才 | 將領要能依地勢與局勢改變常規做法 |
| 行軍 | 帶兵的基本原則 | 行軍、宿營、偵察與通信的實務規範 |
| 地形 | 六種地形 | 地形不是藉口，而是可以計算的優勢 |
| 九地 | 不同戰略階段 | 隨形勢決定是進是退 |
| 火攻 | 五種火攻與條件 | 火攻需要前提，也需要承擔失控的風險 |
| 用間 | 蒐集情報 | 起用情報人員的原則與冒險 |

## 前因後果

1. **春秋戰國的戰爭規模化**：車戰轉為步兵戰、動員人數暴增，使「如何打仗」成為可系統化的知識對象。
2. **諸子互動**：兵家與儒家、法家共享同一套治理語言，兵法中的「道」「法」「勢」與政治理論互相借用。
3. **漢代以後的經典化**：它被列入經書，與儒家經典並列，使「知兵」成為文人官員素養的一部分。
4. **近代的轉譯**：清末與民國的軍事教育、二十世紀各國軍事學院的戰略教材，以及 1980 年代以後的商學研究，共同把這部古典文本轉成跨文化的理論資源。

## 容易混淆之處

- **它不是一部可以照做的操作手冊**：多數條文談的是判斷原則與風險，而非具體的陣法與編制。
- **文本流傳過程中有佚失與重編**，不同版本的篇章標題與次序並不完全一致。
- **「孫子兵法用於商業」是現代轉譯**，不是文本原意；借用的成功能否成立，應回到實際情境檢驗。
- **它是中國的兵書，但作者身分仍有爭議**，不宜把作者當成確定歷史人物。
