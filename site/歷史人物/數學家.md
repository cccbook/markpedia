# 數學家

> 隸屬：[歷史人物] › [學者人物]　·　狀態：初稿

> 對應維基百科：[中文維基百科：數學家](https://zh.wikipedia.org/wiki/%E6%95%B0%E5%AD%A6%E5%AE%B6)　·　[English Wikipedia: Mathematician](https://en.wikipedia.org/wiki/Mathematician)

數學家是**以結構、關係與必然性為研究對象的人**。他們的特殊性在於：數學的命題只要前提為真就必然為真，因此**不需要等待經驗來證實**。這種「以推理代替觀察」的能力，使數學成為一切科學中最抽象、也最能被移植的工具。

## 兩條數學傳統

| 面向 | 希臘傳統 | 中國傳統 |
| --- | --- | --- |
| 起點 | 定義、公理、命題 | 問題與算法 |
| 方法 | 由公理推導定理 | 由程序求解問題 |
| 代表文本 | [歐幾里得] 的《原本》 | [九章算術] |
| 貢獻 | 公理化、證明的嚴格性 | 實用算法與符號運算 |
| 現代影響 | 幾何、代數、邏輯 | 方程術、正負數與誤差分析 |

兩者的差別並非高下，而是**「一般化」與「可計算性」兩種取向的差別**。現代數學的發展史，正是不斷把實用算法提升為一般理論、再把一般理論轉為可計算算法的循環。

## 數學家的核心素質

1. **抽象的能力**：把具體問題中無關的細節剝去，只保留關係。群、環、空間、函數都是這樣的例子。
2. **對「證明」的耐心**：一個結論可以留待後人驗證，但不能用直覺代替。
3. **對例外的敏感**：一個反例足以推翻整個論證，因此數學家常備反例。
4. **跨領域的遷移能力**：[伽羅瓦] 的群論源於代數方程，卻成為近代物理的基本語言；[高斯] 的統計方法源於天文觀測，卻成為工程與醫學的通用工具。

## 前因後果：數學如何從技藝成為制度

1. **古希臘的公理化**：[歐幾里得] 把零散命題整理成體系，示範了「由少數前提推出大量後果」的力量。
2. **中國的算法傳統**：[九章算術] 中的方程術與盈不足法，把問題的解決寫成可重複的程序。
3. **中世紀的保存與傳譯**：歐洲透過阿拉伯世界重新取得希臘數學，伊斯蘭世界的代數工作（如花拉子米）成為橋樑。
4. **近代的專業化**：大學講席、期刊、學位與研究所制度，使數學家成為有生涯、有競爭也有傳承的職業群體。
5. **基礎研究的長週期**：[高斯] 的非歐幾何、《遺著》的整理、[陳省身] 的示性類理論，都說明**一門學科的重大突破常在生前未獲理解**。
6. **與其他領域的互相驅動**：物理學提供問題與直覺，數學提供工具；兩者的每一次大規模互動（微積分、分析、概率論、群論）都同時改變了兩個領域。

## 範例：一個定理如何改變兩個領域

以非歐幾何為例：人們最初在繪圖中發現「大地是平的」無法與多條經線同時成立，歐拉等人已嘗試建立「球面幾何」。1820 至 1830 年代，[高斯] 秘密研究此事並在 1830 年公開其結論：在曲率非零的空間中，平行的總數可以不是一條。黎曼在 1854 年的演講中把這件事推展為「流形上的曲率」，此後愛因斯坦用其語言寫出廣義相對論。

這個案例說明三件事：

1. **數學的突破常常先於其用途**——非歐幾何問世數十年後才找到物理對象。
2. **同一套概念可以同時支撐多個領域**——「曲率」先解決繪圖問題，再解決空間問題。
3. **研究的公開與否會改變學科歷史**——高斯生前選擇不公開，使其工作被遺忘了數十年，而黎曼、克羅內等人的公開工作構成了主流譜系。

## 與相鄰分類的關聯

- 與 [科學家] 的關係：數學提供語言與工具，物理提供問題與經驗檢驗；這是最緊密的跨學科合作之一。
- 與 [學者人物] 的關係：數學是「以推理代替觀察」的學科，因此它的同行評審方式最嚴格——**一個論證的每一步都必須暴露**。
- 在上位概念 [學者人物] 中，本分類扮演的角色：它示範了**方法可以獨立於對象而存在**，這是學術制度化的理論基礎。

## 容易混淆之處

- **數學不是「算得快的學問」**：計算只是其中一小部分，核心是結構與證明。
- **「數學沒有應用」是誤解**：現代數學大量直接支撐物理、工程、統計與資訊科學。
- **不同數學傳統的「優劣」**：把公理化與算法簡單對立，會忽略兩者可以互補；[九章算術] 的解法至今仍是代數算法的原型之一。

## 數學的四種基本問題

數學家的研究可以歸入四類，它們對應不同的思維習慣：

1. **存在性問題**：是否存在這樣的對象？（例如：是否存在不可數的超越數）
2. **唯一性問題**：如果有，是否唯一？（例如：方程的解是否唯一）
3. **分類問題**：所有這樣的對象可以分成哪些類？（例如：有限群的分類）
4. **計算法問題**：如何有效地求出具體結果？（例如：如何求一個大矩陣的特徵值）

前三類偏重結構與推理，第四類偏重效率與可計算性。**現代數學的一個重要趨勢，是把抽象理論重新轉化為算法**，讓原本只存在於證明中的對象可以被計算。

## 數學家的工作環境

1. **講席與研討會**：長期穩定的研究崗位，加上定期的研討與評論，這是數學傳統的核心制度。
2. **期刊與預印本**：論文的公開與評論，使錯誤能被及時發現。數學的錯誤通常不是被忽略，而是被更快地指出。
3. **會議與學術旅行**：面對面討論仍是數學交流的主要形式，電子化並未取代它。
4. **教材與訓練**：把方法轉成可教的內容，是數學傳承的關鍵；[陳省身] 對人才培養的重視即屬此類。

**數學的進步看似由個人完成，實際上高度依賴制度**：一個沒有研討會、期刊與教學崗位的群體，數學水平難以持續。
