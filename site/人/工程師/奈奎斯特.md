# 奈奎斯特

> 對應維基百科：[中文維基百科：哈里·奈奎斯特](https://zh.wikipedia.org/wiki/%E5%93%88%E9%87%8C%C2%B7%E5%A5%88%E5%A5%8E%E6%96%AF%E7%89%B9)　·　[English Wikipedia: Harry Nyquist](https://en.wikipedia.org/wiki/Harry_Nyquist)

哈里·奈奎斯特（Harry Nyquist，1889 年－1976 年）是瑞典裔美國工程師與數學家，數位通訊理論的先驅之一。他在 1928 年提出取樣定理，為所有數位錄音、通訊與影像系統奠定取樣速率的理論下限。

## 關鍵事實

- 1927 至 1928 年於貝爾實驗室工作，提出無失真傳輸所需的最低取樣頻率為訊號最高頻率的兩倍，即 $f_s \geq 2f_{\max}$ 。
- 1928 年證明電話線路的頻寬與資訊傳輸速率之間存在定量關係，為通道容量公式鋪路。
- 1932 年出版《工程通訊》（Telecommunication Systems），首次把「通訊」當作一門可定量分析的工程學科來處理。
- 1932 年提出負回授（negative feedback）放大器的理論，是控制理論與電子工程的重要基石。
- 1948 年 [香農] 在《通訊的數學理論》中推廣並系統化取樣定理，使其成為現代通訊工程的標準工具。
- 晚年擔任貝爾實驗室資訊理論部門主管，並獲得包括 IEEE 愛迪生獎章在內的多項榮譽。

## 與相關概念的關係

- 取樣定理直接決定 [訊號調變] 中各類波形的取樣率，也解釋了為何 CD 唱片取樣率為 44.1 kHz 而涵蓋 20 kHz 音域。
- 負回授理論是 [自動控制] 的核心機制，也是 [電子工程] 中放大器設計的基本手段。
- 他對頻寬與傳輸速率關係的量化，為 [多工技術] 的效率評估提供了度量。
