# 丹尼斯·里奇

> 對應維基百科：[中文維基百科：丹尼斯·里奇](https://zh.wikipedia.org/wiki/%E4%B8%B9%E5%B0%BC%E6%96%AF%C2%B7%E9%87%8C%E5%A5%87)　·　[English Wikipedia: Dennis Ritchie](https://en.wikipedia.org/wiki/Dennis_Ritchie)

Dennis MacAlistair Ritchie（1941–2011），美國電腦科學家，貝爾實驗室研究員；與 [肯·湯普遜] 共同創造 C 語言與 UNIX 作業系統，1983 年與湯普遜同獲圖靈獎。

## 關鍵事實

- **C 語言（1972 年前後）**：在 B 語言基礎上設計，目標是「夠低階以重寫作業系統、夠高階以跨機器可攜」；1978 年與 Kernighan 合著《The C Programming Language》（K&R），成為程式語言書籍的典範。
- **UNIX**：與湯普遜把 UNIX 從組合語言改寫為 C，使作業系統首次具備跨硬體可攜性；此舉證明了「系統軟體可以用高階語言寫」，是語言抽象層墊高後回頭重塑硬體生態的關鍵案例。
- **與 [電腦] 硬體的關係**：C 的「可攜組合語言」定位——直接操作指標與記憶體、同時保有型別與函式——成為其後四十年系統程式設計的標準形態。
- **圖靈獎（1983）與美國國家科技獎章（1998）**：表彰 UNIX 與 C 對整個產業的基礎性影響。
- **2011 年逝世**：其辭世與賈伯斯同月，媒體對比之下凸顯了「里奇的影響藏在每一部設備的底層」——智慧型手機的核心都運行著 C 與 UNIX 的後裔。

## 與相關概念的關係

- 與 [程式設計] 的關係：C 定義了結構化命令式語言的形狀，其語法（大括號、指標、函式）被 C++、Java、JavaScript 等大量語言繼承。
- 與 [程式語言的演進] 的關係：里奇站在「高階語言能否勝任系統軟體」這個歷史疑問的答題位上，C 的成功直接終結了「系統程式必須寫組合語言」的時代。
- 與 [控制結構] 的關係：K&R 一書把結構化程式設計的分支與迴圈寫法散布給整整一代程式師。
- 與 [軟體工程] 的關係：UNIX 的模組化工具鏈（小工具組合）是「組合優於整塊設計」的最早大型實踐。
