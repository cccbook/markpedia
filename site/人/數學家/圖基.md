# 圖基

> 隸屬：第一層 [人]　·　類別：數學家　·　狀態：初稿

> 對應維基百科：[中文維基百科：約翰·图基](https://zh.wikipedia.org/wiki/%E7%BA%A6%E7%BF%B0%C2%B7%E5%9B%BE%E5%9F%BA)　·　[English Wikipedia: John Tukey](https://en.wikipedia.org/wiki/John_Tukey)

約翰·圖基（John Tukey，1915—2000）是美國統計學家與數學家，以推廣「探索性資料分析」與「資料科學」一詞而廣為人知。他在 [1945年] 發展的時間序列分解方法（後來稱為 Box–Jenkins 方法中的分解步驟）至今仍是處理季節性時間序列的標準工具。

他與 [費雪] 同在普林斯頓統計學系任職，長期主張統計教育不應只教假設檢定，也應教學生如何「看資料」。1960 至 1970 年代，他推廣了探索性資料分析（EDA）的方法，主張以圖形、草圖與摘要統計作為理解資料的第一步。1974 年，他在《美國統計學家》期刊發表的〈The Data Analysis in the Statistical Sciences〉一文中正式使用了 "data science" 一詞。

他另一項重要貢獻是把「統計」的對象從推論延伸至「資料本身」——在電腦尚未普及的年代，他就以手繪的方式分析數千筆資料，強調快速、互動、圖形化的探索流程。今日資料科學工作流程中「先剖析再建模」的習慣，部分來自這一傳統。

## 關鍵事實

- 1915 年生於美國新罕布什爾州，1939 年於普林斯頓取得數學博士學位，導師為 [馮·諾伊曼]。
- 1945 年發表時間序列分解方法，將序列拆為趨勢、季節與不規則三個成分。
- 1960 年代提出並推廣探索性資料分析，主張以圖形作為分析的第一步。
- 1974 年在《美國統計學家》發表〈The Data Analysis in the Statistical Sciences〉，並使用 "data science" 一詞。
- 曾獲美國國家科學獎、國家科學院獎章等多項榮譽。

## 與相關概念的關係

- 他定義並推廣了 [探索性分析]，該概念是 [資料科學] 中負責理解資料形狀的環節。
- 他的時間序列分解工作連接到 [機率統計] 中的 [統計推論] 與模型選擇問題。
- 他與 [費雪]、[皮爾生] 共同建構了 20 世紀前半葉美國統計學院系的傳統。
- 他主張統計實務應服務於理解世界，而非僅止於檢定，這是 [資料視覺化] 與敘事分析的早期主張。
