# 史瓦茨

> 類型：社會學者　·　所屬類別：[社會學]（人物）　·　狀態：初稿

> 對應維基百科：[中文維基百科：施瓦茨](https://zh.wikipedia.org/wiki/%E6%96%BD%E7%93%A6%E8%8C%A8)　·　[English Wikipedia: Shalom H. Schwartz](https://en.wikipedia.org/wiki/Shalom_H._Schwartz)

## 關鍵事實

- **生平**：1930 年生於美國紐約，2026 年前仍為以色列希伯來大學的社會學教授；後移居澳洲，並主持「跨文化價值量表計畫」。
- **核心貢獻**：提出**普世價值結構**（universal value structure），以「自我超越—自我增進—保守—自我導向—享樂」五個高階類型、圓環式排列，並以「古典型別」與「特定型別」兩層區分價值內涵。
- **方法**：以「排他性量表」測量相鄰價值的差異，累積了數十國家的樣本，是少數能跨國比較價值的資料庫。
- **與家庭的關係**：其「家庭安全 values（conservation）」與「自我導向」之間的張力，解釋了為何家庭責任在現代西方價值体系中常與個人自主產生張力——家庭要求服從與延後個人目標，個人則要求自我決定。
- **另一項研究**：關於「家庭主義—個人主義」的文化腳本分類，被用來解釋不同社會中家庭與個人的相對份量。
