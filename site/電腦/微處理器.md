# 微處理器

> 隸屬：[電腦] › [電腦的演進]　·　狀態：初稿

> 對應維基百科：[中文維基百科：微處理器](https://zh.wikipedia.org/wiki/%E5%BE%AE%E5%A4%84%E7%90%86%E5%99%A8)　·　[English Wikipedia: Microprocessor](https://en.wikipedia.org/wiki/Microprocessor)

微處理器是**把整顆 CPU（算術單元、控制單元、暫存器）做進單一積體電路晶片的處理器**。1971 年 Intel 4004 以約 2300 個電晶體實現了四位元 CPU，把「電腦的心臟」從數個機櫃縮進指甲大小。這一步的意義不是省空間，而是成本曲線的轉折：當 CPU 可以像普通元件一樣量產，電腦才可能成為消費品。

微處理器的演進主線是規模與並行：四位元 → 八位元 → 十六位元 → 32 位元 → 64 位元；單核 → 超純量流水線 → 多核 → 異構（CPU 加 GPU 加 NPU）。每一級都把上一級的「機櫃」縮成「晶片」，同時把效能推進一個數量級。

## 技術與理論的關聯

- **單晶片化的組成**：ALU、控制單元、暫存器堆、匯流排介面全部在片上；4004 以 2300 個電晶體做到 16 支接腳、740 kHz。
- **指令集的商業化**：Intel 8080（1974）催生了 CP/M 與微電腦產業；8086（1978）的 x86 架構延續至今，指令集的相容性成為巨大的資產也是包袱。
- **RISC 革命**：1980 年代的學界論文（Patterson 與 Hennessy）證明簡單等長指令 + 更多暫存器 + 編譯器最佳化勝過複雜指令；ARM 以此路線佔領行動裝置。
- **微架構的深挖**：流水線、亂序執行、分支預測、超執行緒——同一指令集下，微架構的世代競賽決定了實際效能。
- **SoC 時代**：手機晶片把 CPU、GPU、NPU、數據機、ISP 整合進一顆晶片，「微處理器」的邊界擴大為「系統晶片」。
- **功耗成為第一設計約束**：2005 年前後時脈撞上散熱牆，轉向多核與動態電壓調頻（DVFS）；每瓦效能取代每時脈效能成為指標。

## 範例

**問題**：對比 Intel 4004（1971）與現代手機 SoC 的關鍵數字。

1. **4004**：2300 電晶體、10 微米製程、740 kHz、四位元、16 支腳；原本是為 Busicom 計算器設計的專用晶片。
2. **8086（1978）**：29000 電晶體、3 微米、5 至 10 MHz、十六位元；IBM PC 選擇它的變種 8088，x86 從此稱霸桌面。
3. **Pentium（1993）**：310 萬電晶體、0.8 微米、60 MHz 起、雙流水線超純量——亂序與並行進入主流。
4. **現代旗艦**：手機 SoC 約 150 至 200 億電晶體、3 奈米級製程、主頻逾 3 GHz、CPU 8 核 + GPU + NPU，峰值算力達每秒數十兆次（TOPS 級）。
5. **換算視角**：電晶體數成長約七百萬倍、面積相近而效能提升約百萬倍；以「每秒指令數/每瓦」計，能效提升逾千萬倍。
6. **結構意義**：4004 的革命不是速度（當時分立電晶體 CPU 更快），而是「可量產的可程式元件」——同一顆晶片，寫不同程式就是不同產品，通用性首次以消費品價格出售。

## 前因後果

- **前因**：積體電路讓「一片晶片一個系統模組」可行；日本 Busicom 的訂單讓 Intel 把十二顆專用晶片縮成四顆（含一顆通用 CPU），4004 意外誕生。
- **後果**：個人電腦（Apple II、IBM PC）、嵌入式控制（汽車、家電）與行動電話全部以微處理器為核心；指令集成為生態戰場（x86 對 ARM 對 RISC-V），晶片設計成為地緣戰略產業。

## 容易混淆之處

- **微處理器與微控制器不同**：前者是通用計算核心，後者整合 RAM、快閃與周邊、專為控制單一設備（如洗衣機）。
- **時脈高不等於效能高**：流水線深度、IPC（每時脈指令數）與快取同樣關鍵；近年旗艦的能效比頻率更重要。
- **多核不等於程式自動加速**：並行化軟體是前提，Amdahl 定理給出上限。
- **SoC 的 CPU 只是其中一角**：手機的體驗由 GPU、ISP、NPU 與基頻共同決定。

## 技術要點

- 4004 的十進位透過 BCD 碼處理，四位元寬度正是為 BCD 設計。
- x86 的 CISC 指令在晶片內被譯成類 RISC 的微操作——兩大流派的實務合流。
- 異構計算把資料並行的部分交給 GPU，控制流交給 CPU，是現代 SoC 的分工原則。
- DVFS 與電源閘控讓閒置單元近乎零功耗，行動晶片的續航由此而來。
- NPU（神經處理器）以低精度矩陣運算（INT8/FP16）換取數十倍能效。
- 晶片化（chiplet）把大晶片拆成小晶片互連，以良率換取總電晶體數。

## 常見的論爭

- **x86 對 ARM 的桌面攻防**：ARM 筆電以能效挑戰 x86 慣性，軟體相容性（模擬層）是決戰點。
- **RISC-V 的前景**：免費指令集能否打破生態鎖定，抑或造成碎片化，「開放即勝利」仍待驗證。
- **多核的終點**：核心數成長遇到軟體並行化瓶頸，異構與專用加速器是否取代「更多同質核」是架構界的路線之爭。

## 實務補充：頻率、製程與效能

單核頻率在 2000 年代中後期停止快速增長，效能提升改由多核、SIMD、製程微縮與專用加速器共同提供。原因是功耗與散熱在時脈提高後惡化，晶片無法再靠提高頻率換取效能。

製程微縮帶來的好處不只是更小更快：更小的單元讓快取與記憶體控制器能與運算單元同層整合，縮短資料搬移距離，這是「更快」的真正來源之一。代價是設計成本與晶圓價格急升，使先進節點僅少數廠商負擔得起。

比較處理器效能時，除了時脈，還應看快取容量與頻寬、核心數、支援的指令集擴充、製程與功耗。對大多數程式而言，記憶體延遲與頻寬往往比時脈更能決定實際速度。
