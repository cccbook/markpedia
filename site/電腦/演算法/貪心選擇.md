# 貪心選擇

> 隸屬：[貪心與分治]　·　狀態：初稿

> 對應維基百科：[中文維基百科：貪心演算法](https://zh.wikipedia.org/wiki/%E8%B4%AA%E5%BF%83%E7%AE%97%E6%B3%95)　·　[English Wikipedia: Greedy algorithm](https://en.wikipedia.org/wiki/Greedy_algorithm)

**貪心選擇**是「每一步都取當下看起來最好的選擇，且永不回頭」的策略。白話說，它把選擇權交給直覺，但這個直覺必須有理論保證才安全。貪心法在結構上最簡單、實作上最快，代價是它只對具有**貪心選擇性質**的問題有效；一旦問題不具備這個性質，貪心法會安靜地給出次優答案。

## 貪心選擇性質與最優子結構

貪心法要成立，需要兩件事同時具備：

- **貪心選擇性質**：存在一個最優解包含「貪心演算法在第一步所選的那個選擇」。
- **最優子結構**：選完之後，剩下的子問題仍然可以用同樣的貪心策略求解。

只滿足其中之一都不夠：只有貪心選擇性質而無最優子結構，剩餘部分可能需要不同方法；只有最優子結構而無貪心選擇性質，則第一步就可能走錯。

## 證明方法：交換論證

貪心法的標準正確性證明是交換論證：取一個最優解，證明它能把最優解中的某個元素「交換」成貪心演算法選的那個，而不變差；再對剩餘部分歸納。例如在區間排程問題中，可證明「最早結束的活動」一定存在於某個最優排程中。

## 常見的貪心演算法

- **活動選擇**：每次選最早結束的活動。
- **霍夫曼編碼**：每次合併權重最小的兩個節點。
- **Kruskal 與 Prim**：見 [最小生成樹]。
- **Dijkstra 演算法**：見 [最短路徑]。
- **爬山法與貪心最佳化搜尋**：以啟發式逐步往局部最佳移動。

## 範例：活動選擇

**問題**：給定 $n$ 個活動，各有開始時間 $s_i$ 與結束時間 $f_i$ ，選擇互不重疊的最大數量活動。

**演算法**：

```
activities = sort_by_finish_time(activities)
count = 0
last_finish = -infinity
for each (s, f) in activities:
    if s >= last_finish:
        count = count + 1
        last_finish = f
return count
```

**數值實例**：活動為 $(1,3)$ 、 $(2,5)$ 、 $(3,7)$ 、 $(4,8)$ 。

1. 依結束時間排序後順序不變。
2. 選 $(1,3)$ ，數量變 1，最後結束時間為 3。
3. $(2,5)$ 與 $(1,3)$ 重疊，略過。
4. $(3,7)$ 開始時間 3 不早於 3，選入，數量變 2，最後結束時間 7。
5. $(4,8)$ 開始時間 4 早於 7，重疊，略過。

結果為 2 個活動，這也是最優解：任何 3 個活動的組合都必然重疊。

**複雜度**：排序 $O(n \log n)$ ，掃描 $O(n)$ ，合計 $O(n \log n)$ 。

**交換論證**：任取一個最優解，其中第一個活動的結束時間必不小於最早結束的活動；把它換成最早結束的活動不會與後續活動衝突，因此仍是最優解。對其餘活動歸納即得整體正確性。

## 與分治、動態規劃的比較

- **貪心**：每步只做一個決定，不比較多個選項；實作最簡單，但需要性質保證。
- **分治**：把問題拆成互不重疊的子問題各自求解再合併。
- **動態規劃**：考慮多種狀態並比較後取優；最通用，但狀態空間可能很大。

三者並非互斥：許多演算法以貪心為外層、以分治或動態規劃為內層，例如快速排序用分治實作，Prim 演算法用最小堆（動態規劃式的選擇結構）維護候選邊。

## 前因後果

- **前因**：19 世紀的分配與排程問題實務中，人們長期依賴「先做最急迫的」這類經驗規則。
- **後果**：1950 至 1960 年代，線性規劃與組合最佳化的理論發展，把其中一部分經驗規則證明為安全並推廣到圖演算法；[1959年] [狄克斯特拉] 的最短路徑演算法即是貪心法在圖上的成功應用。

## 與相鄰分類的關聯

- 與 [分治策略] 的關聯：兩者都是求解典範，分治靠合併，貪心靠不回頭。
- 與 [動態規劃] 的關聯：貪心可視為只需保留單一路徑狀態的動態規劃。
- 與 [正確性] 的關聯：貪心的證明多依賴交換論證。
- 與 [最小生成樹] 的關聯：Kruskal 與 Prim 皆為貪心演算法。

## 容易混淆之處

- **貪心不一定正確**：沒有貪心選擇性質時會給出次優解。
- **局部最佳不等於整體最佳**：貪心只在前者成立時才推出後者。
- **啟發式不等於貪心**：爬山法常被歸為貪心，但沒有可證明的保證。
- **等權重時可能有多解**：某些問題的最優解不唯一，實作需明確定義取捨規則。
