# 終止性

> 隸屬：[演算法的可證明性]　·　狀態：初稿

> 對應維基百科：[中文維基百科：良基關係](https://zh.wikipedia.org/wiki/%E8%89%AF%E5%9F%BA%E5%85%B3%E7%B3%BB)　·　[English Wikipedia: Termination](https://en.wikipedia.org/wiki/Termination)

演算法的**終止性**是「對每個合法輸入，流程都會在有限步驟內停止」這個性質。白話說，它排除了「程式一直跑下去」的可能。終止性與 [正確性] 是完全正確性的兩半：只證明「停下來時結果正確」是部分正確性；再加上「必定停下來」，才是完整的保證。

終止性的證明有兩條路線：一是**下降度量**——找一個非負整數量，每次迭代都嚴格減少，因而最多迭代有限次；二是**良基關係**——把程式狀態放在一個不存在無限下降鏈的偏序上，這是 [命題邏輯] 與 [遞迴論] 使用的通用框架。

## 為什麼終止性難以證明

[1936年] [圖靈] 證明了一個驚人的結果：不存在能判定「任意程式是否會停止」的演算法，即**停機問題不可判定**。若存在這樣的演算法，就能構造出矛盾程式（先猜另一程式會否停止，再據此決定是否停止），從而解決邏輯悖論。

這個結果的後果是：終止性無法被全自動地、普遍地證明，只能針對特定程式結構逐一推理。因此實務上，工程師常用**可辨識的終止模式**（如迴圈變數嚴格遞減、遞迴規模嚴格縮小）來間接保證。

## 常見的終止性論證模式

- **計數變數遞減**：迴圈指數 $i$ 每輪加一，且有明確上界 $n$ 。
- **遞迴規模縮小**：遞迴呼叫的參數嚴格小於原參數，且終止於基準情形。
- **字典序下降**：巢狀迴圈中以字典序（外層優先）比較，序數集合上的下降必定有限。
- **結構歸納**：對資料結構（如樹）歸納，每個子結構的歸納假設成立。
- **良基關係**：以自然數、序數或某個偏序作為度量。

## 範例：證明 Euclid 演算法必定終止

**演算法**：

```
function gcd(a, b):
    if b == 0: return a
    return gcd(b, a mod b)
```

**終止性論證**：以第二個參數 $b$ 作為下降度量。當 $b > 0$ 時， $a \bmod b$ 滿足 $0 \le a \bmod b < b$ ，故每次遞迴呼叫的新第二參數嚴格小於舊值。由於非負整數序列不可能無限嚴格遞減，遞迴必定在有限步內抵達 $b = 0$ 的基準情形。

**數值實例**： $\gcd(1071, 462)$ 的第二參數序列為 $462 \to 147 \to 21 \to 0$ ，共 3 次遞迴後停止。

**正確性**：終止性只保證「會停下來」，還需另外證明停下時回傳的值確為最大公因數，所依據的是歐幾里得恆等式 $\gcd(a,b) = \gcd(b, a \bmod b)$ ；兩者合起來才是完全正確性。

## 與迴圈不變量的分工

在迴圈型演算法中，兩種證明針對不同對象：

- [迴圈不變量] 說明「每輪結束時狀態的意義」，用於保持正確性。
- **下降度量**說明「每輪結束時某個量變小」，用於保證終止性。

兩者常共享同一批變數：把不變量中的計數部分單獨拿出來，就是下降度量。因此寫出好的不變量，往往同時得到終止性證明。

## 實務上的提醒

- 明確寫下下降度量，比事後追查無限迴圈便宜得多。
- 對外部事件（計時器、網路回應、使用者輸入）的等待，通常無法用純程式狀態證明終止。
- 併行程式的終止性需另外處理：各執行緒可能各自終止，但組合起來仍可能活鎖。

## 前因後果

- **前因**：[1936年] 的停機問題不可判定性，確立了「終止性不是可以一勞永逸解決的問題」。
- **後果**：1960 至 1970 年代，程式語言的型別系統與 [形式化驗證] 理論大量引入良基結構作為驗證手段；今日的終止性分析工具多以模式比對尋找下降度量，作為輔助而非全自動證明，其邏輯基礎見 [遞迴論]。

## 與相鄰分類的關聯

- 與 [正確性] 的關聯：完全正確性 = 部分正確性 + 終止性。
- 與 [迴圈不變量] 的關聯：兩者共用變數，寫法互相支援。
- 與 [遞迴] 的關聯：遞迴的終止性由基準情形與規模縮小保證。
- 與 [NP完全] 的關聯：有些問題的判定版本若能解決，就等同於解決停機問題類的不可判定性。

## 容易混淆之處

- **終止性不是效率**：程式可以很快終止，也可以繞很久才停。
- **「看起來會停」不是證明**：需要明確的度量與論證。
- **遞迴深度有限不等於呼叫次數有限**：每層分支數量可能是無界的。
- **程式崩潰不算正常終止**：記憶體溢位是環境限制，不是證明。
