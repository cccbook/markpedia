# 迴圈不變量

> 隸屬：[演算法的可證明性]　·　狀態：初稿

> 對應維基百科：[中文維基百科：迴圈不變量](https://zh.wikipedia.org/wiki/%E5%BE%AA%E7%8E%AF%E4%B8%8D%E5%8F%98%E9%87%8F)　·　[English Wikipedia: Loop invariant](https://en.wikipedia.org/wiki/Loop_invariant)

**迴圈不變量**是「在迴圈每一次迭代開始時都必須為真的那個命題」。白話說，它描述「每輪結束時，程式對已經處理過的那一段資料掌握了什麼」，是 [正確性] 證明中最常用的工具。它的好處是把一個關於「整個程式結束時」的斷言，拆成可以逐步維持的局部斷言。

標準的三段證明結構是：**初始化**（第一次進入迴圈前不變量成立）、**保持**（一次迭代之後不變量仍成立）、**終止**（迴圈結束時，不變量加上迴圈條件的否定蘊含所需的結論）。三段缺一不可，尤其是「保持」常被忽略。

## 不變量的選取

好的不變量通常滿足三個性質：

- **足夠強**：能直接推出終止時想要的結論。
- **足夠弱**：能被一次迭代保持住，證明成本低。
- **可表達**：能寫成一句可讀的話，而不是需要大量輔助變數的複雜公式。

「已處理元素的某個彙總」是最常見的不變量形式，例如「已處理前 $k$ 個元素，其最大值為 `largest`」。

## 範例：二分搜尋的不變量

**演算法**：

```
lo = 0; hi = n - 1
while lo <= hi:
    mid = (lo + hi) // 2
    if a[mid] == x: return mid
    if a[mid] < x: lo = mid + 1
    else: hi = mid - 1
return -1
```

**不變量**：每次迴圈開始時， $x$ 若存在於已排序陣列中，其索引必落在區間 $[lo, hi]$ 內。

1. **初始化**： $lo = 0$ 、 $hi = n - 1$ 涵蓋整個陣列的下標範圍，不變量成立。
2. **保持**：若 $a[mid] < x$ ，因陣列遞增， $x$ 只能出現在 $mid$ 右側，於是令 $lo = mid + 1$ 後， $x$ 仍落在新区間內；若 $a[mid] > x$ ，同理令 $hi = mid - 1$ 。兩種情形皆保持不變量。
3. **終止**：迴圈結束時 $lo > hi$ ，區間為空，不變量說明 $x$ 不存在於陣列中，故回傳 $-1$ 正確；若中途命中 $a[mid] = x$ ，回傳的索引確為 $x$ 所在位置。

**複雜度的同一來源**：每次迭代把區間長度至少減半，因此迭代次數為 $O(\log n)$ ，與終止性分析是同一段推理。

## 範例：插入排序的不變量

**演算法**：

```
for i = 1 to n - 1:
    key = A[i]
    j = i - 1
    while j >= 0 and A[j] > key:
        A[j+1] = A[j]
        j = j - 1
    A[j+1] = key
```

**不變量**：在第 $i$ 輪開始時， $A[0 \dots i-1]$ 已是遞增排列，且與原陣列前 $i$ 個元素構成同一個多重集合。

- **初始化**： $i = 1$ 時， $A[0 \dots 0]$ 只有一個元素，天然遞增且多重集合不變。
- **保持**：內層迴圈把比 `key` 大的元素往右移，最後把 `key` 插入正確位置，於是 $A[0 \dots i]$ 遞增且多重集合維持。
- **終止**： $i = n$ 時，整個陣列遞增。

**複雜度**：最壞情況（完全逆序）內層迴圈執行次數總和為 $n(n-1)/2$ ，即 $O(n^2)$ ；最好情況（已排序）為 $O(n)$ 。

## 迴圈不變量與 Hoare 邏輯

不變量的三段式證明，正是 Hoare 邏輯中「while 規則」的內容：while 規則要求前置條件蘊涵不變量，且不變量與否定迴圈條件共同蘊涵後置條件。這使不變量可以交給自動證明工具處理，成為 [形式化驗證] 與 [程式驗證] 的基礎，見 [命題邏輯] 與 [謂詞演算]。

## 容易混淆之處

- **不變量不是迴圈條件**：迴圈條件決定何時繼續，不變量描述已完成的進度。
- **不變量不必在每個陳述句都成立**：只在迴圈頭部需要成立。
- **不變量太弱**：不足以推出結論；太強：無法保持。
- **「保持」段的直覺**：把 $A$ 換成 $A$ 的前後兩個狀態，比較哪些資訊被改變、哪些資訊必須被記錄。

## 前因後果

- **前因**：1960 年代的結構化程式設計運動，把「用不變量描述迴圈」提升為標準的程式設計紀律。
- **後果**：同一時期 Hoare 邏輯與 Dijkstra 的 weakest precondition 風格出現，不變量成為可機器檢查的對象；今日的程式驗證工具仍以不變量為核心介面，見 [1969年]。

## 與相鄰分類的關聯

- 與 [正確性] 的關聯：不變量是證明迴圈型演算法正確性的主力工具。
- 與 [終止性] 的關聯：終止性需要額外的變數（下降度量），兩者互相配合。
- 與 [複雜度] 的關聯：不變量中的計數部分常直接給出複雜度分析所需的迭代次數。
- 與 [遞迴] 的關聯：遞迴的正確性用歸納法表達，與不變量互為對偶。
- 與 [排序] 的關聯：插入排序、合併排序的正確性皆以不變量陳述。
