# 分治策略

> 隸屬：[貪心與分治]　·　狀態：初稿

> 對應維基百科：[中文維基百科：分治法](https://zh.wikipedia.org/wiki/%E5%88%86%E6%B2%BB%E6%B3%95)　·　[English Wikipedia: Divide and conquer](https://en.wikipedia.org/wiki/Divide_and_conquer)

**分治策略**是「把問題切成同型而更小的子問題，各自解決後再合併」的解題框架。白話說，它處理的是那些**天然具有遞迴結構**的問題：解法本身就是自己的一部分。分治把「一次做大事」改寫為「多次做小事」，讓複雜度由遞迴式決定，因此它的分析往往可以算出精確的封閉解。

分治的三個步驟是固定的：**分解（divide）—解決（conquer）—合併（combine）**。其中合併步驟最常被低估，它的成本常常決定整體複雜度。

## 三個必備條件

1. **可分解性**：問題能分成兩個或更多規模更小的同型問題。
2. **可合併性**：子問題的解能以有效成本合成原問題的解；若合併需要掃過全部資料，就必須把這成本計入遞迴式。
3. **可停止性**：分解必須在某個小到能直接求解的基準情形終止。

## 遞迴式與 Master 定理

分治的複雜度寫成 $T(n) = aT(n/b) + f(n)$ ，其中 $a$ 為子問題數， $b$ 為規模比例， $f(n)$ 為合併成本。Master 定理比較 $f(n)$ 與 $n^{\log_b a}$ ：

- $f(n) = O(n^{\log_b a})$ 時， $T(n) = \Theta(n^{\log_b a})$ 。
- $f(n) = \Omega(n^{\log_b a + \epsilon})$ 時， $T(n) = \Theta(f(n))$ 。
- 兩者同階時， $T(n) = \Theta(n^{\log_b a} \log n)$ 。

合併排序是三種情形中的第三種： $T(n) = 2T(n/2) + O(n)$ ，解得 $O(n \log n)$ 。

## 範例：最大子陣列與合併

**問題（分治版）**：給定整數陣列，找出連續子陣列的最大和。

**演算法**：

```
function max_subarray(A, lo, hi):
    if lo == hi: return A[lo]
    mid = (lo + hi) // 2
    left = max_subarray(A, lo, mid)
    right = max_subarray(A, mid + 1, hi)
    cross = max_suffix(A, lo, mid) + max_prefix(A, mid + 1, hi)
    return max(left, right, cross)
```

**數值實例**：陣列 `[-2, 5, -1, 3, -4, 2]`，最佳子陣列為 `[5, -1, 3]`，和為 7。

1. 分成左半 `[-2, 5, -1]` 與右半 `[3, -4, 2]` 。
2. 左半最佳為 `[5]` ，和 5；右半最佳為 `[3]` ，和 3。
3. 跨越中點者：左半的最大後綴和為 5（取 `[5, -1]`），右半的最大前綴和為 3（取 `[3]`），跨中點最佳為 $5 + 3 = 8$ ，對應 `[5, -1, 3]` 。
4. 取三者最大值得 8。

**遞迴式**： $T(n) = 2T(n/2) + O(n)$ ，由 Master 定理得 $T(n) = \Theta(n \log n)$ ；若合併時只掃描一次且不需前綴和陣列，則 $O(n)$ 空間的遞迴版本可降為 $O(\log n)$ 深度。

**對照**：同一問題的暴力解法是枚舉所有子陣列，時間 $O(n^2)$ ；分治把它降為 $O(n \log n)$ ，在 $n = 10^6$ 時從 $10^{12}$ 降到約 $2 \times 10^7$ 次操作。

## 分治與其他典範的差異

- **分治 vs 貪心**：分治會比較所有子問題的解再合併，貪心只做一個不回頭的選擇。
- **分治 vs [動態規劃]**：分治的子問題互不重疊，因此不需快取；動態規劃的子問題重疊，需要狀態表。
- **分治 vs 遞迴**：分治是設計策略，遞迴是表達手段；分治的遞迴式通常可用 Master 定理直接求解。

## 前因後果

- **前因**：17 世紀的歐幾里得演算法（求最大公因數）已是分治的雛形——把問題化為更小的同型問題。
- **後果**：20 世紀上半葉，快速排序、合併排序、大整數乘法與分治 FFT 等成果，使分治成為演算法分析的基本框架；[1973年] 前後快速傅立葉轉換的演算法化，就是分治在數值計算上的頂尖應用。

## 與相鄰分類的關聯

- 與 [遞迴] 的關聯：分治以遞迴表達，遞迴式是複雜度分析的起點。
- 與 [複雜度] 的關聯：Master 定理是分治複雜度的標準工具。
- 與 [貪心選擇] 的關聯：兩者是並列的求解典範。
- 與 [排序] 的關聯：合併排序與快速排序是分治最著名的實例。

## 容易混淆之處

- **分解不必平均**：不均勻分割也能用分治，只需用 Akra–Bazzi 定理求解遞迴式。
- **合併成本不可忽略**：忽略 $f(n)$ 是最常見的分析錯誤。
- **分治不保證最優**：分治給出的是精確解，但可能不如貪心快。
- **基準情形很重要**：基準太大會浪費時間，太小會讓遞迴次數暴增。
