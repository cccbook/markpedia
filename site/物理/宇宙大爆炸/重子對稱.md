# 重子對稱

> 隸屬：[宇宙大爆炸]　·　狀態：初稿

> 對應維基百科：[中文維基百科：重子不對稱性](https://zh.wikipedia.org/wiki/%E9%87%8D%E5%AD%90%E4%B8%8D%E5%B0%8D%E7%A8%B1%E6%80%A7)　·　[English Wikipedia: Baryon asymmetry](https://en.wikipedia.org/wiki/Baryon_asymmetry)

重子對稱（重子與反重子數量相等、淨重子數為零的理想狀態）是理解[早期宇宙]的起點。重子（由三個夸克或三個反夸克構成的粒子，例如質子與中子）與反重子（重子的反粒子）可成對產生並相消；重子數（重子的淨數量特徵）與反重子數在對稱狀態下因而相同。觀測顯示兩者並不對稱，這個小偏差正是重子對稱要處理的問題。

重子不對稱性（重子數與反重子數之間的非零差值）為何重要，是因為它決定早期宇宙可用的重子背景，進而影響[核合成]（氫、氦等輕元素的形成過程）、[宇宙微波背景]（早期宇宙留下的微波輻射背景）以及後續結構形成。[大爆炸模型]（以高溫、高密度初態及後續膨脹描述宇宙演化的框架）提供整體時間背景，重子對稱則專門追問宇宙如何離開粒子與反粒子的對稱原點。沙卡洛夫於 1967 年提出必要條件，但輕子生成等具體機制仍未定。

## 主題解析

### 對稱原點與淨重子背景

早期宇宙處於高溫、高密度環境，重子與反重子可由高能反應成對產生，也可互相相消。  
只要產生與相消保持平衡，這些反應就不會留下可持續累積的淨差額。

對稱原點並不表示宇宙中完全沒有反重子，而是表示每產生一對重子與反重子，就有相近數量的兩者被相消。  
由於反重子容易被現存物質 annihilate，觀測上很難直接辨認所有原初反重子。

現今的淨重子背景可透過輕元素豐富度與宇宙微波背景等資料交叉檢驗。  
這些觀測支持重子數與反重子數不對稱，但不等於能直接看見每一個原初反重子。

### 沙卡洛夫的三項必要條件

沙卡洛夫在 1967 年指出，產生重子不對稱必須具備三項條件。  
這三項條件分別處理「能否產生」、「偏向哪一邊」與「能否保留」三個問題。

第一項是重子數破壞，也就是某些反應必須能改變重子數。  
若所有相關反應都嚴格保存重子數，最初為零的淨重子數便只能維持為零。

第二項是 C 與 CP 破壞。C 代表把粒子換成反粒子的對稱操作；CP 則把這種變換與宇稱（反轉空間方向的操作）結合。  
若兩種對稱性都精確成立，粒子與反粒子的總量及反應率會彼此抵銷，難以形成固定方向的偏差。

第三項是偏離熱平衡。熱平衡是正向與逆向反應速率相等、微觀機制彼此抵銷的狀態。  
一旦某些反應因膨脹或相變而來不及恢復平衡，少量差異便可能逃過相消，累積成淨重子數。

三者必須共同作用：重子數破壞使差值有可能產生，C 與 CP 破壞提供偏好的方向，偏離熱平衡則使差值得以保留。  
但它們只是必要條件；單純列出三項條件，仍不足以得到一個完整且可計算的重子生成機制。

### 候選機制與尚未解決的問題

重子生成（從對稱原初狀態建立淨重子數的過程）可以由不同候選路徑描述。  
輕子生成（先建立輕子數不對稱，再嘗試將其轉化為重子數不對稱的機制）是其中一條受到廣泛討論的路線。

在輕子生成中，尚未確定的重粒子衰變可產生輕子數差異。  
現行粒子物理標準模型（已被廣泛驗證的基礎粒子交互作用框架）中的非微擾電弱過程，能把部分輕子數差異轉成重子數差異。

電弱重子生成則嘗試利用宇宙相變時的物理條件產生不對稱。  
它要求特定形式的電弱相變與粒子交互作用，但這些條件是否足以在現實宇宙中形成所需的偏差，仍有爭論。

另一類方案利用[夸克時期]（早期宇宙由夸克與膠子構成的階段）以前的粒子物理過程。  
其中部分模型需要尚待探索的新物理，因此不能把任何單一方案視為已經確立的答案。

不對稱一旦形成，還可能受到洗滌效應（能迅速消除既有偏差的反應）破壞。  
能解釋如何產生、卻不能解釋如何存留的模型，仍然是不完整的。

## 範例：

以沙卡洛夫於 1967 年提出的必要條件為起點，可將重子對稱的破缺整理成一個包含觀測尺度的概念算例。

1. **設定對稱原點。** 以粒子數記號表示，起點是 $ N_B=N_{\bar B} $ ，因此淨差 $ N_B-N_{\bar B} $ 為零。

2. **套用三項必要條件。** 1967 年提出的條件依次是重子數破壞、C 與 CP 破壞，以及偏離熱平衡。

3. **允許淨差產生。** 假設某一類反應能輕微改變重子數，初始為零的淨差便不再被嚴格禁止。

4. **固定偏好方向。** C 與 CP 破壞使粒子與反粒子的相關過程不一定以相同速率發生；再讓反應偏離熱平衡，已有的少量差異便不會立即被正反相消抵銷。

5. **套用所需尺度。** 所要求的重子—反重子不對稱量級約為 $ 10^{-9} $ ；換成粒子數的直覺比喻，約每 $ 10^9 $ （十億）個反重子多出一個重子。

6. **對照觀測與機制。** 核合成及宇宙微波背景支持存在這樣的淨重子背景，但輕子生成等機制仍有多種版本，尚未形成唯一且完全確立的解釋。

## 前因後果

宇宙最初的對稱狀態提供零淨重子數的起點，粒子與反粒子的成對產生及相消則維持這種平衡。  
重子數破壞讓反應能產生非零淨差，C 與 CP 破壞則使差異具有方向。

偏離熱平衡是保存差異的關鍵條件。  
若宇宙條件變化過快，或相變使某些反應的逆向過程暫時失效，少量偏差便可能累積。

[膨脹宇宙]（空間尺度隨時間增長的宇宙模型）可以參與非平衡條件的形成，但單靠膨脹並不足以保證重子不對稱。  
擴張速度、反應速率與對稱破壞仍須共同滿足沙卡洛夫條件。

形成的淨重子背景會成為核合成的原料條件，影響早期輕元素豐富度。  
它也會改變宇宙微波背景中的聲學振盪等觀測訊號。

隨後的重子物質聚集參與恆星與恆星系的形成。  
因此，一個只適用於極早期、卻留下穩定後果的機制，需要同時解釋生成、存留與觀測。

問題的閉環仍未完成：生成機制、偏差保存條件與觀測推論必須彼此相容。  
目前沒有任何單一方案能脫離整體早期宇宙條件而獨立成立。

## 與相鄰分類的關聯

與[宇宙大爆炸]及大爆炸模型的關聯在於，大爆炸模型提供宇宙由高溫高密度狀態開始演化的整體框架。  
重子對稱則聚焦其中一個具體問題：對稱原點為何轉化為淨重子背景。

與早期宇宙及夸克時期的關聯在於，重子生成必須發生於特定歷史階段。  
夸克時期及其之前的粒子、場與相變條件，會影響不對稱能否產生並逃過洗滌。

與核合成的關聯在於，核合成不只是重子不對稱的後果，也可成為觀測約束。  
輕元素豐富度提供淨重子背景的間接資訊，但本身不直接指出是哪一種生成機制。

與宇宙微波背景及大爆炸替代模型的關聯在於，宇宙微波背景提供另一組獨立測量。  
比較[大爆炸的替代模型]時，也須說明它如何解釋或避開同一組重子背景觀測。

## 容易混淆之處

重子對稱並不是說今天的宇宙仍然維持重子與反重子等量。  
它首先描述早期宇宙的對稱原點，條目重點則是這項原點如何被打破。

宇宙中仍能發現反粒子，不代表原初宇宙未曾具有對稱性。  
現存反粒子可能來自後續高能反應，不能直接等同於尚未相消的原初反重子。

「重子數破壞」不等同於已觀測到質子會任意衰變。  
前者是早期宇宙產生不對稱時對相關反應的性質要求，兩者不能直接畫上等號。

C 破壞與 CP 破壞不是同一件事。  
C 只涉及粒子與反粒子的交換，CP 還加入了空間方向反轉。

「每十億個反重子多一個重子」是量級的直覺描述。  
正式討論時仍須交代比較基準，不能把粒子數比例、數密度比例與其他歸一化方式混為一談。

重子不對稱與輕子不對稱是不同但可能互相轉化的量。  
輕子生成可先建立輕子數差異，再透過特定電弱過程產生重子數差異。

膨脹本身不會自動生成重子不對稱。  
膨脹可能協助偏離平衡，但也可能沖淡既有差異，仍須配合微觀對稱破壞條件。

「對稱破缺」不必然表示自發對稱破壞（某一對稱性因系統能量最低狀態改變而自行失效）。  
重子對稱的破缺可以是非平衡動力學逐步累積的結果。

## 技術要點

重子不對稱可用淨重子數描述，例如 $ N_B-N_{\bar B} $ 。  
這個差值必須從零變成非零，而且不能只靠把現存重子任意重新標記而得到。

引用約 $ 10^{-9} $ 的不對稱尺度時，應交代所採分母。  
「每十億個反重子多一個重子」便於理解量級，但不是完整的密度定義。

熱平衡中的詳細平衡（正反過程以相同速率進行）會消除宏觀淨產量。  
因此，能改變重子數的相互作用若仍完全平衡，通常不足以留下重子不對稱。

C 與 CP 破壞提供的是反應偏好，而不是直接保證淨重子數。  
偏好方向還必須與非平衡條件及重子數改變過程相配合。

沙卡洛夫三條件是必要條件，不是充分條件。  
滿足三條件只表示原則上可能，尚不能指定粒子種類、衰變方式、時期與偏差大小。

在現行粒子物理的標準模型中，電弱非微擾過程可同時改變重子數與輕子數。  
這提供輕子差異轉成重子差異的可能通道，但仍不等於已經證實自然界採取此路徑。

CPT（粒子—反粒子交換、空間反轉與時間反轉的組合對稱）定理不禁止 CP 破壞。  
它也不能取代重子數破壞或偏離平衡這兩項條件。

洗滌效應決定不對稱能否存留。  
若產生階段之後仍有高效反應把偏差抹去，模型即使能生成所需數量，也無法解釋今天的觀測。

觀測通常推論的是淨重子背景，而非直接盤點所有原初反重子。  
因此，核合成與宇宙微波背景的限制必須與粒子物理模型共同解讀。

## 常見的論爭

沙卡洛夫三項條件是否足以成為完整生成理論，是核心爭論之一。  
爭點不在條件本身，而在自然界是否確實提供滿足它們的粒子物理過程。

C 與 CP 破壞的來源是否足以在早期宇宙放大，是另一個問題。  
已知粒子物理中的破壞效應與宇宙學所需的偏差量級之間，仍需要完整而自洽的模型。

輕子生成是否可行取決於尚未確定的粒子性質、衰變方式與洗滌歷史。  
它是重要候選方向，但不能只因符合三項必要條件便視為答案。

電弱重子生成所依賴的相變形式仍有討論。  
若自然界不具備模型所需的相變條件，這條路徑便不能直接成立。

[暴脹]（一段尺度極速增長的早期宇宙膨脹）與重子生成的先後關係也未定。  
暴脹可能沖淡既有不對稱，也可能讓不對稱在後來重新建立，取決於具體模型。

觀測能否唯一辨識生成機制，是可驗證性的核心問題。  
即使多個候選模型都能配合現有資料，仍需尋找能區分它們的獨立觀測。
