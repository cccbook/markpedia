# 吸積盤

> 隸屬：[黑洞]　·　狀態：初稿

> 對應維基百科：[中文維基百科：吸积盘](https://zh.wikipedia.org/wiki/%E5%90%B8%E7%A7%AF%E7%9B%98)　·　[English Wikipedia: Accretion disk](https://en.wikipedia.org/wiki/Accretion_disk)

吸積盤（黑洞周圍由落入物質形成、會因摩擦與磁場作用而發熱並輻射的旋轉盤狀結構），是物質抵達事件視界（黑洞不可逃逸的邊界）之前被重排成盤狀的區域。落入氣體通常帶有角動量（描述繞行趨勢的轉動量），因此不會沿直線墜入，而會在旋轉中逐漸向內遷移，並在外側鋪展成盤。

吸積盤的重要性在於它是黑洞附近可觀測能量的主要來源之一。摩擦將氣體的軌道能轉成熱，使盤面達到數百萬 K，並產生 X 射線（高能電磁輻射波段）；活動星系核（星系中心由吸積驅動的高亮區域）的亮光也主要來自超大質量黑洞周圍的吸積盤。它與相鄰概念的分工是：黑洞提供重力中心，事件視界劃定不可逃逸的內部界線，吸積盤則是視界外的氣體、磁場與輻射結構，而噴流是另一種向外延伸的稀薄物質流。

## 主題解析

### 氣體如何形成盤面

落入氣體若完全沒有角動量，可能直接穿過事件視界；但具備角動量的氣體具有與黑洞共同旋轉的趨勢，因而先形成環狀或盤狀結構。

氣體在盤內受到黏滯力、磁場應力與局部密度波的作用，內側物質逐漸失去角動量，外側物質則獲得角動量並向外遷移。

這種向外搬運角動量的結果，是盤面不會因所有物質同時向內旋轉而迅速耗盡，整個系統因而能在較長時間內維持吸積。

在理想模型的敘述中，盤的內緣為最內穩定圓軌道（ISCO，即圓形運動尚能維持的內側界線）；其實際位置仍會受到黑洞自轉、磁場與氣體狀態影響。

1915 年提出的廣義相對性提供了描述彎曲時空與軌道穩定性的理論框架，但早期相對論測量驗證的是重力效應，並非直接看見吸積盤。

### 能量如何轉成輻射

吸積盤中的「摩擦」不是固體表面直接互相刮擦，而是湍流、磁場纏繞及密度波造成的有效黏滯作用。

黏滯作用將氣體原有的軌道能轉成熱，盤的內側因接近黑洞而具有最高的局部能量，溫度可達數百萬 K，因此主要在 X 射線波段輻射。

在薄盤模型中，溫度一般隨半徑向外下降；最靠近黑洞的區域最熱，較外側則較冷，並可能轉為紫外線、可見光或紅外線。

盤面所輻射的光子會對氣體施壓，抵抗進一步向內收縮；當輻射壓強接近或超過重力束縛時，內盤可能膨脹，形成所謂輻射壓支撐的盤。

盤面附近還可能存在較熱、較稀薄的日冕層；部分 X 射線可能由日冕或外盤的散射產生，而不全都直接來自盤面。

### 吸積盤如何影響周圍系統

活動星系核的持續亮光來自超大質量黑洞周圍持續供應的吸積盤，其亮度取決於落入質量、盤的效率及遮蔽程度。

吸積所釋放的部分能量可形成噴流（沿黑洞轉軸附近向外射出的相對論性物質流），但噴流的產生需要磁場配置，不能簡單視為盤面向外的延伸。

高速盤風與輻射可反作用於周圍氣體，抑制或促進其他區域的吸積，形成星系尺度上的正回饋或負回饋。

伴星質量轉移、潮汐擾動或天體解體，都可能短暫或長期供應吸積盤所需物質，使亮度呈現 outburst、靜止與復甦等變化。

盤的質量累積會改變黑洞周圍的時空幾何；雖然自轉與吸積方向、盤的分布共同決定自旋如何改變，但並非所有吸積都會以相同方式增加黑洞自旋。

## 範例：

以天鵝座 X-1 為觀測案例，可把歷史、尺度、供料、發熱與觀測訊號串成一條完整的吸積鏈。下列數值採概略量級，避免把持續修訂的估計視為固定常數。

在 1964 年發現天鵝座 X-1 的 X 射線源後，人們於 1971 年取得相當有力的證據，顯示其中存在一個史瓦西質量以上的緻密天體 [1964年][1971年][X射線雙星]。

天鵝座 X-1 距離地球約 7,000 光年，其中心黑洞的質量約為 20 個太陽質量的量級；伴星與中心天體共同構成 X 射線雙星 [黑洞的觀測]。

伴星提供落入的氣體，這些物質帶有角動量，不能直接穿入事件視界，而是在中心天體周圍形成向外延伸的吸積盤。

氣體沿盤面向內遷移時受到有效摩擦，軌道能轉成熱；靠近盤內緣的物質可達數百萬 K，使天鵝座 X-1 成為強烈 X 射線源。

X 射線光譜的變化、準週期訊號與偶發的短時變亮，可分別追蹤盤內區域、軌道結構和快速質量轉移，而伴星的獨立運動則提供黑洞質量的另一項限制。

觀測結果顯示，「可見的發光盤」與「本身不發光的緻密天體」同時存在；X 射線源於前者，黑洞候選的質量證據則主要來自後者。

## 前因後果

大質量恆星塌縮可形成黑洞，若伴星未在塌縮過程中被破壞，兩者便可能組成吸積雙星系統。

伴星的外層大氣或 Roche 瓣（由伴星自身重力維持的氣體區域）可提供低溫、富含角動量的物質。

物質抵達吸積盤後產生黏滯與磁場應力，使角動量持續向外傳遞，避免所有氣體在同一時間落入。

盤內側的高軌道能轉成熱，形成溫度達數百萬 K 的輻射區，並產生明亮 X 射線。

X 射線亮度可反映吸積率，但遮蔽、盤面幾何與光譜狀態也會影響觀測，因此亮度變化不等於質量流入率直接改變。

當供料速率增加時，盤面可迅速變亮並進入爆發狀態；供料停止後，盤則會逐漸冷卻。

由盤或鄰近區域逸出的風與輻射會改變周圍氣體分布，抑制後續吸積，或在特定條件下促進更多氣體落入。

盤的長期演化會改變黑洞質量與自旋，而黑洞的時空結構又會回頭決定軌道半徑、ISCO 位置及輻射效率。

潮汐擾動或天體解體可形成短暫的吸積高峰，這類事件可讓原本缺乏穩定供料的黑洞在數日尺度上顯亮。

隨著環境改變，系統可在寧靜狀態、爆發狀態與不同光譜狀態之間轉換，形成觀測上常見的多波段變化。

## 與相鄰分類的關聯

- 吸積盤是黑洞外的發光物質結構，而[黑洞]是提供吸引力與時空幾何的中心天體；兩者互相影響，但不是同一物體。

- 吸積盤位於事件視界外，能量在越過[事件視界]之前便被釋放；事件視界內部沒有可向外傳出的盤面輻射。

- 吸積盤主要分布在赤道面附近，[噴流]則多沿轉軸方向延伸；兩者共享磁場，卻具有不同的幾何、速度與輻射特性。

- [X射線雙星]中的恆星尺度吸積盤與[超大質量]黑洞周圍的盤屬於不同尺度系統，但都遵守角動量搬運、黏滯發熱及吸積供料等共同物理關係。

## 容易混淆之處

- 吸積盤不是事件視界的一部分。盤位於事件視界外，是可觀測的氣體與輻射結構；[事件視界]則是黑洞不可逃逸的邊界。

- 吸積盤也不是包住黑洞的實心氣體球。盤通常較薄、較扁，並以旋轉為主要運動形式，但具備厚度、湍流與局部垂直運動。

- ISCO 不等於事件視界。ISCO 是理想圓軌道穩定性所定義的內側界線，而事件視界是光也無法向外逃逸的邊界，兩者在半徑與物理意義上均不同。

- 所謂摩擦不是兩個固體表面互相磨擦，而是磁場、湍流與密度波等機制將軌道能轉成熱的有效黏滯作用。

- X 射線不一定全由盤面直接產生；鄰近盤面的熱日冕、磁層化區域及相對論性噴流也可能貢獻高能輻射。

- 明亮區域不等於黑洞本體。吸積盤、盤風、日冕與噴流都可發光，而真正的事件視界並不會把光送到外部。

- 吸積盤與[霍金輻射]不是同一能量來源。霍金輻射源自量子場效應，對一般恆星形成或超大質量黑洞的吸積盤而言極為微弱。

- 活動星系核的亮光不全是「摩擦生熱」或單一表面發光；盤面輻射、反射光、盤風、噴流及遮蔽共同決定觀測光譜。

- 觀測到的溫度是視向溫度。盤面各處的運動方向不同，特殊相對論效應會使接近面向觀者的區域偏藍、背向觀者的區域偏紅。

## 技術要點

- 薄盤模型將盤視為局部Keplerian旋轉（各圓環以軌道角速度旋轉）的氣體層，垂直厚度遠小於徑向尺度。

- 穩定吸積的關鍵不是氣體停止旋轉，而是角動量能藉由黏滯與磁場應力持續向外運送。

- 磁旋轉不穩定性會放大盤內的擾動，使磁場、渦旋與較長波長結構互相作用，提供維持角動量外流的常見機制。

- 對不旋轉的[史瓦西]黑洞，理想 ISCO 半徑可寫為：

$$
r_{\mathrm{ISCO}} = 6 \frac{G M}{c^2}
$$

- 上式中的 $ M $ 是黑洞質量， $ G $ 是萬有引力常數， $ c $ 是光速；黑洞自轉會使順行與逆行方向的 ISCO 位置不同。

- 薄盤的典型溫度分布可近似寫成：

$$
T(r) \propto r^{-3/4}
$$

- 同一模型中，溫度還隨中心天體質量增加而降低，因此較大黑洞的盤要在相同半徑處不會自動具有更高溫度。

- 盤的黏滯通常以 $ \nu $ 描述；它控制角動量外流時間尺度，也影響盤能否在供料改變後迅速恢復或衰退。

- 徑向光度並非平均分布。靠近 ISCO 的區域可提供大部分辐射，而外盤則可能由散射、反射及較低溫的熱輻射貢獻。

- 盤與事件視界之間的窄區域可視為邊界層；跨越該區域時，氣體的軌道運動與零旋轉參考系之間的差異可轉化為高能輻射。

- 盤面附近的高溫稀薄氣體可形成日冕層，並將部分高能光子向上散射或反射，使觀測光譜不完全符合單一溫度黑體。

- 相對論效應會改變軌道的進動、週期、偏振與頻譜；計算不能只把牛頓重力與平面幾何拼在一起。

- X 射線連續譜可用來估計溫度與吸積率，譜線寬度和輪廓則可提供內盤旋轉、元素豐度與邊界層幾何的線索。

- 時變訊號可用來追蹤盤的擾動、軌道擾動與噴流軸的移動，但訊號源不一定全部來自盤面本身。

- 由光通量反推質量時，距離、吸積率與盤效率可能互相退化，因此需要光譜、 timing 或其他波段資料輔助。

- 1915 年的[廣義相對論]建立了軌道與輻射的理論基礎，1919 年的日蝕觀測則驗證了光在重力場中的偏折；這些是間接支持，並非吸積盤的直接影像。

- 2019 年公布的[事件視界望遠鏡][黑洞影像]結果主要呈現黑洞陰影及視界尺度結構，不能直接視為已解析的吸積盤照片。

- 觀測推論還受到距離誤差、盤幾何、遮蔽、儀器響應與模型簡化影響，因此所得溫度、內緣半徑與效率通常需要報告不確定範圍。

- 模擬會把磁場、輻射傳輸、盤風與噴流耦合起來；只解重力與流體時得到的理想盤，可能無法完整重現真實系統的時間變化。

## 常見的論爭

- 盤的實際內緣究竟多接近 ISCO，仍取決於磁壓、輻射壓、黑洞自轉及氣體狀態；「ISCO 就是所有吸積盤的固定內緣」只是方便的理想化說法。

- 維持角動量外流的主要機制雖以磁旋轉不穩定性受到重視，但不同磁場強度、耗散方式與盤的厚度仍會導向不同演化結果。

- 高能輻射究竟主要來自盤面、邊界層或日冕層，會直接影響對溫度與吸積率的估計，因此觀測者需要同時比較能譜、時間變化與幾何模型。

- 噴流需要黑洞自旋、磁場或盤風中的能量來源，但不同系統中各部分的相對貢獻仍有差異，不能只憑一道明亮射線就判定形成機制。

- 標準薄盤模型能解釋不少平均光譜，卻可能低估局部磁場、盤風、垂直結構及快速變動，修正模型的細節仍持續調整。

- 活動星系核的亮度變化可能來自供料速率、盤不穩定性、遮蔽幾何或日冕變化；相同光變未必對應相同的物理原因。

- 觀測到的譜線寬度同時受到旋轉、擴散、盤風與相對論運動影響，因此「盤速」的估計存在明顯模型依賴性。

- 吸積盤對宿主星系或雙星系統的演化效應取決於能量傳遞效率；盤風、輻射與噴流的相對重要性會隨環境而改變。

- 如何由有限的 X 射線觀測唯一重建三維盤結構仍有歧義，特別是在視線方向被遮蔽或盤 winds 佔主導時。

- 黑洞自旋如何隨吸積演化取決於盤內的角動量流與自轉方向；只由「有盤」無法唯一判斷自旋增加或減少。
