# SMT

> 隸屬：[邏輯學] › [計算邏輯]　·　狀態：初稿

> 對應維基百科：[中文維基百科：SMT](https://zh.wikipedia.org/wiki/SMT)　·　[English Wikipedia: Satisfiability modulo theories](https://en.wikipedia.org/wiki/Satisfiability_modulo_theories)

SMT（Satisfiability Modulo Theories）指「在理論背景下的可滿足性問題」：在 [一階邏輯] 的框架內，判定一個公式是否存在滿足它的模型，其中內建算術、陣列、位元向量等**等值理論**。

它是 SAT 的自然推廣：保留 SAT 的效率基因，同時把結構化的推理交給專門的理論求解器。

## 一、SAT 與 SMT 的分工

| 面向 | SAT | SMT |
| --- | --- | --- |
| 語言 | 命題邏輯（CNF） | 一階邏輯 + 理論 |
| 量詞 | 無 | 有 |
| 推理方式 | 布林傳播 | 理論求解器（算術、陣列、UF） |
| 適用 | 組合問題 | 帶算術與資料結構的問題 |

**範例**：要判定「存在 $x, y$ 使 $x + y = 10$ 且 $x - y = 2$ 且 $x > 0$ 」，SAT 必須把算術展開成位元級布林編碼，規模膨脹嚴重；SMT 則直接把整數等式交給算術理論求解器，一次消元即得解 $x = 6, y = 4$ 。

## 二、內建理論

| 理論 | 對象 | 典型能力 |
| --- | --- | --- |
| 線性整數算術（LIA） | 整數線性不等式 | 消元、Simplex |
| 線性實數算術（LRA） | 實數線性不等式 | Simplex |
| 非線性整數算術（NIA） | 整數多項式 | 較弱，常作啟發式 |
| 陣列理論 | 讀寫與元素 | 決定性圖選擇 |
| 位元向量 | 有限位元運算 | 位元爆破＋理論組合 |
| 未解釋函式（UF） | 未指定語義的函式 | 結合性、單射性推論 |

**範例（UF 的作用）**：在驗證一個排序演算法時，UF 理論可記住「 $f(a) = f(b)$ 推出 $a = b$ 」這類資訊，而 SAT 無法表達。

## 三、SMT 求解流程

1. **前端**：把量詞公式轉為 Skolem 形式並做 CNF 化，見 [變元消去]。
2. **理論求解器**：分別處理各理論的原子公式，回傳蘊涵或衝突。
3. **理論組合器**：整合各理論結果，偵測不一致。
4. **搜尋**：以 SAT 式的搜尋為骨架，分支時呼叫理論求解器。

**範例（衝突回傳）**：算術理論發現 $x > 3$ 與 $x < 2$ 衝突，組合器將此衝突回傳給 SAT 引擎，用於學習子句並回溯，整個過程因此**保留了邏輯推理的全局資訊**。

## 四、標準化

SMT-LIB 語言與 SMT-COMP 競賽是推動 SMT 成長的兩項制度性力量：前者統一輸入格式與理論定義，後者以年度競賽比較求解器效能。

**範例**：SMT-COMP 的分組設計（如 QF_UF、AUFLIA、UFNIA）正是按「量詞 × 理論組合」劃分，代表求解器針對不同組合有不同最佳化策略。

## 五、應用

| 領域 | 用途 | 說明 |
| --- | --- | --- |
| 軟體驗證 | 符號執行與反例生成 | 找出觸發錯誤的具體輸入 |
| 硬體驗證 | 時序與微架構檢查 | 混合整數與位元向量推理 |
| 定理證明 | 與自動定理證明器整合 | 產生理論證明引理 |
| 合成 | 從規格產生電路 | 把存在性問題變成設計 |

**範例（反例生成）**：若要證明「除以零不會發生」，SMT 可直接求解 $\exists x (x = 0 \wedge \dots)$ ，若找到 $x = 0$ 的具體指派，那就是一個可重現的反例。

## 六、與相鄰分類的關聯

- [SAT求解]：SMT 的骨架與效率來源。
- [變元消去]：SMT 前端的關鍵技術。
- [一階邏輯]：SMT 的邏輯基礎。
- [自動定理證明]：兩者常互相借用。

## 七、容易混淆之處

- SMT 不是「邏輯的 SMT」，它是一類**問題**與求解技術。
- SMT 求解器**不等於**定理證明器：前者不做多步推理，只做模型搜尋。

## 關鍵術語速查

| 術語 | 一句話解釋 |
| --- | --- |
| 等值理論 | 處理等式與不等式的理論組件 |
| 理論組合器 | 整合各理論結論並偵測不一致的組件 |
| Skolem 化 | 把存在量詞轉為函式或常數的前處理 |
| SMT-LIB | 統一輸入格式與理論定義的標準語言 |
| 位元向量理論 | 處理有限位元運算的理論 |
