# 三段論

> 隸屬：[邏輯學] › [命題邏輯]　·　狀態：初稿

> 對應維基百科：[中文維基百科：三段論](https://zh.wikipedia.org/wiki/%E4%B8%89%E6%AE%B5%E8%AB%96)　·　[English Wikipedia: Syllogism](https://en.wikipedia.org/wiki/Syllogism)

三段論（syllogism）是亞里士多德提出的推論形式：一由前提（兩條敘述）、中項（兩前提共有的概念）與大項（結論的謂詞）構成，前提與結論各為一個「肯定或否定 + 主詞 + 謂詞」的三詞句。形式為：

$$
S \text{ 是 } P
$$

$$
S \text{ 是 } M
$$

$$
\therefore P \text{ 是 } M
$$

它與命題邏輯同屬「形式推論」，但層次不同：命題邏輯的最小單位是整句，三段論的最小單位是**詞與詞之間的關係**，這使它更貼近自然語言，也讓它無法表達現代數學所需的量化。

## 一、三段論的構成要素

以「所有人皆會死；蘇格拉底是人；故蘇格拉底會死」為例：

| 要素 | 角色 | 本例 |
| --- | --- | --- |
| 大項 | 結論的謂詞 | 會死 |
| 小項 | 結論的主詞 | 蘇格拉底 |
| 中項 | 兩前提共有、結論不出現的概念 | 人 |
| 大前提 | 含大項與中項的前提 | 所有人皆會死 |
| 小前提 | 含小項與中項的前提 | 蘇格拉底是人 |

中項必須至少出現一次 affirmative（不否定），否則推論不成立——這是亞里士多德提出的「中項規則」之一。

## 二、四種基本形式

| 形式 | 骨架 | 有效性 |
| --- | --- | --- |
| Barbara（AAA-1） | 全部 $M$ 是 $P$ ；全部 $S$ 是 $M$ ；故全部 $S$ 是 $P$ | 有效 |
| Celarent（EAA-1） | 全部 $M$ 非 $P$ ；全部 $S$ 是 $M$ ；故全部 $S$ 非 $P$ | 有效 |
| Darii（AII-1） | 部分 $S$ 是 $M$ ；全部 $M$ 是 $P$ ；故部分 $S$ 是 $P$ | 有效 |
| Ferio（EIO-1） | 全部 $M$ 非 $P$ ；部分 $S$ 是 $M$ ；故部分 $S$ 非 $P$ | 有效 |

**範例（Barbara）**：

1. 所有哺乳動物都是胎生的。
2. 鯨魚是哺乳動物。
3. 因此鯨魚是胎生的。

**範例（常見無效形式）**：「所有 A 是 B；所有 C 是 A；因此所有 C 是 B」正是 Barbara，有效。但把其中一條否定改成「有些 A 不是 B」時，就會落入 Fallacy of the Undistributed Middle（中項不周延），推論無效。

## 三、為何三段論在現代被取代

三段論有兩道無法跨越的天花板。

**第一，無法表達量化與條件**。現代數學需要「對所有 $x$ 存在 $y$ 」這類結構，以及蘊涵式 $P \to Q$ ；三段論沒有量詞，也沒有條件句。

**第二，前提本身難以檢驗**。以「所有 X 都是 Y」為前提時，若 $X$ 類本身龐雜，逐一驗證不切實際。

因此邏輯史的走向是：從三段論的主詞—謂詞分析，轉向 [Frege] 的量化邏輯，再由 [謂詞邏輯] 全面取代。三段論今日的價值在於**教學與論證分析**：它提供了一套檢查日常推論的最小工具集。

## 四、三段論與現代邏輯的對照

| 三段論 | 現代邏輯 |
| --- | --- |
| 全部 $M$ 是 $P$ | $\forall x (M(x) \to P(x))$ |
| 某個 $S$ 是 $M$ | $\exists x (S(x) \wedge M(x))$ |
| 有效／無效 | 蘊涵是否成立 |
| 中項規則、詞項分配 | 單一推理規則加上量詞限制 |

**範例**：把 Barbara 形式譯為謂詞邏輯。

$$
\forall x (M(x) \to P(x)) \wedge \forall x (S(x) \to M(x)) \models \forall x (S(x) \to P(x))
$$

這個譯法正是 [謂詞邏輯] 證明三段論有效性的方式——所有有效形式都可用 [謂詞演算] 推出。

## 五、與相鄰分類的關聯

- [命題邏輯]：同屬形式推論，但三段論的最小單位是詞而非整句。
- [邏輯史]：三段論是西方邏輯的起點，其瓶頸直接催生量化邏輯。
- [謂詞邏輯]：現代邏輯對三段論的全面取代與擴充。
- [論證理論]：三段論的「有效性」概念在現代論證理論中被重新定位為可接受性與權衡。
- [謬誤學]：形式無效的三段論是謬誤的主要形式來源。
