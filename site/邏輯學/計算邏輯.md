# 計算邏輯

> 隸屬：[邏輯學]　·　狀態：初稿

> 對應維基百科：[English Wikipedia: Computational logic](https://en.wikipedia.org/wiki/Computational_logic)

計算邏輯（computational logic）是把邏輯問題轉成**可由機器執行的演算法**的學科。它存在的原因很直接：完整的 [一階邏輯] 不可判定，因此工程上只能退守到可判定的片段；而要讓這些片段真正可用，就必須設計出高效的求解程序。

今日的兩大主力是 [SAT求解] 與 [SMT]，而它們的哲學基礎是：**把邏輯問題編譯成一個夠強又不會失控的統一格式**。

## 一、核心策略：強式語言

Cook-Levin 定理證明 SAT 是 NP-完全問題，這有兩層意義：

1. **沒有更強的**：任何可判定問題都能在多項式時間內轉成 SAT（若該問題在 NP 中）。
2. **沒有更弱的**：SAT 已足夠表達所有 NP 問題。

**範例**：要判定一個含 $n$ 個變數的命題公式是否有解，SAT 求解器會把它轉成 CNF，然後以 DPLL／CDCL 演算法搜尋。

## 二、求解器的基本策略

| 策略 | 說明 | 代表演算法 |
| --- | --- | --- |
| 完全搜尋 | 系統性枚舉所有指派 | DPLL、CDCL |
| 隨機搜尋 | 隨機指派並在衝突時跳出 | WalkSAT、GSAT |
| 局部搜尋 | 在子句啟發式引導下移動 | stochastic variants |

**範例（DPLL 的一步）**：CNF 為 $(\neg P \lor Q) \wedge (\neg Q \lor R) \wedge P$ 。求解器會由第三個子句得 $P$ 為真，代入第一子句得 $Q$ ，代入第二子句得 $R$ ——三步完成，全程不需枚舉。

## 三、從命題到量詞

SMT 求解器把量詞引入流程，並以**理論求解器**處理等式與不等式。

**範例**：公式 $\exists x \ (x > 3 \wedge x^2 < 10)$ 的求解流程是：Skolem 化引入常數 $c$ ，得到 $c > 3 \wedge c^2 < 10$ ，再交給實數理論求解器（線性算術的量詞消去或非線性代數求解）。

## 四、更上層的應用

1. **模型檢驗**：以狀態空間為框架，檢查時序性質。
2. **定理證明**：結合推理引擎與等值理論，處理更一般的命題。
3. **程式驗證**：把程式轉為邏輯公式，交給求解器判定。
4. **合成**：不只判定，而是從公式反推出一個滿足它的具體設計。

**範例**：給定「一個三輸入一輸出的布林電路，滿足 $\varphi$ 」，SAT 求解器可直接回傳線路真值表——邏輯從「驗證工具」變成「設計工具」。

## 五、代價與教訓

| 教訓 | 說明 |
| --- | --- |
| 可判定性優先 | 先限制語言範圍，再談演算法 |
| 格式決定效率 | CNF 與 Horn 子句帶來截然不同的效能 |
| 啟發式不可或缺 | 純理論演算法難以處理實務規模 |
| 翻譯損失資訊 | 把問題轉格式時可能遺失結構 |

**範例**：同一個問題用 SAT 與用 SMT 求解，耗時可能相差數個數量級——因為 SMT 保留了等值理論的結構，而 SAT 必須把一切拆成布林子句。

## 六、與相鄰分類的關聯

- [SAT求解]：最小但最強的起點。
- [SMT]：加入理論與量詞的推廣。
- [可判定性]：整體不可判定，片段可判定的取捨。
- [自動定理證明]：更一般的推理系統。
- [邏輯與電腦]：驗證與型別的應用面。

## 七、容易混淆之處

- 計算邏輯**不是**「用電腦做邏輯」，而是以演算法觀點研究邏輯問題的可解性與複雜度。
- SAT 求解器**不表示**命題邏輯的判斷；它處理的是被翻譯過的 CNF。

## 關鍵術語速查

| 術語 | 一句話解釋 |
| --- | --- |
| 強式語言 | 能表達所有 NP 問題但仍可求解的統一格式 |
| NP-完全 | SAT 求解複雜度的分界點 |
| 理論求解器 | 處理等式與不等式等領域推理的組件 |
| 理論組合 | 把多個理論的結論整合並偵測衝突 |
| 編碼 | 把問題轉為求解器可接受的格式 |

## 延伸動線

從 [SAT求解] 進入：最小而最強的起點。
從 [SMT] 進入：加入理論與量詞的推廣版。
從 [可判定性] 進入：為何只能做片段的理論背景。

## 七、計算邏輯的歷史小年表

| 年份 | 事件 |
| --- | --- |
| 1960 | DPLL 演算法問世 |
| 1971 | Cook-Levin 定理確立 SAT 的 NP-完全性 |
| 1992 | WalkSAT 與 GSAT 帶來隨機搜尋 |
| 2001 | CDCL 演算法確立 |
| 2005 | Luby 重啟序列與現代求解器框架 |
| 2006 | SMT-LIB 標準與 SMT-COMP 競賽開始 |
| 2010s | 求解器進入晶片驗證與雲端正式環境 |

**範例**：這條時間軸說明計算邏輯的進步並非來自新定理，而是來自**演算法與工程經驗的累積**——這與公理化時代「一條定理定生死」的節奏截然不同。
