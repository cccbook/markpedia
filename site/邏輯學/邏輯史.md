# 邏輯史

> 隸屬：[邏輯學]　·　狀態：初稿

> 對應維基百科：[中文維基百科：邏輯史](https://zh.wikipedia.org/wiki/%E9%80%BB%E8%BE%91%E5%8F%B2)　·　[English Wikipedia: History of logic](https://en.wikipedia.org/wiki/History_of_logic)

邏輯史不是思想史的附錄，而是一條**技術問題驅動的因果鏈**：每一次突破，都來自某個既有的假設被證明不足。主詞—謂詞分析無法表達量化，於是有了 Frege 的量化；公理化需要保證一致性，於是有了 Gödel 的編碼；數學要能被機器處理，於是有了可判定的 SAT。

## 一、古代邏輯

古希臘的辯證法（dialogue）與 Aristotle 的 [三段論] 建立了第一套形式推論系統。亞里士多德另創**范畴論**（categories）與**三段論規則**，並把無效推論分類整理，這是邏輯學作為獨立學科的開端。

**範例**：亞里士多德還發明了「歸謬法」——先假定反命題成立，再導出矛盾，從而否證反命題。這是反證法的早期形態，至今仍是 [自動定理證明] 的基本策略。

## 二、近代邏輯

1. **萊布尼茨**（1666–1716）提出「普遍特徵語」（characteristicis universalis）：用一套符號系統計算命題，使推理化為演算。他並預言推理可以交由機器執行。
2. **休姆**質疑因果與歸納的必然性，把歸納問題推上哲學議程。
3. **布爾**（George Boole，1815–1864）建立「邏輯代數」，把命題運算化為代數運算。
4. **德摩根**引入命題邏輯的符號系統，並提出「名稱」與「否定」的對偶原理。

**範例（布爾的貢獻）**：布爾指出「真值」可用 $x + y$ 表示「或」、用 $xy$ 表示「且」，並證明「和」與「積」的分配律——這正是今日 [等值式] 與 [范式] 的先聲。

## 三、從命題到謂詞

[弗雷格] 1879 年的《概念Notation》引入量化、內容與外延的區分，以及 lambda 演算；Peano 建立形式化的自然數算術；Russell 與 Frege 發現朴素集合論的悖論，促成 ZFC 的建立。

**範例**：Russell 的悖論「由所有不是自己的成員的集合所成的集合」迫使集合論重新奠基，也說明邏輯與基礎公理是互相牽動的。

## 四、公理化時代

1. **Hilbert**（[希爾伯特]）在 1920 年代提出綱領：把一切數學公理化，並證明其一致性與完備性。
2. **Gödel**（[哥德爾]）於 1931 年發表 [不完全性定理]，證明綱領無法完全達成。
3. **Tarski**（[塔斯基]）於 1933 年以語意方式定義「真」，建立 [模型語意]。
4. **Church** 與 **Turing** 分別以函數遞迴與機器模型定義可計算性，並證明一階邏輯不可判定。

**範例（綱領失敗的意義）**：Gödel 定理並未終結數學，而是把「公理化」從終極目標降格為**局部工具**——今日數學仍高度依賴公理化，但同時接受不完備性為常態。

## 五、計算邏輯時代

1950–60 年代的機器定理證明（RPM、Logic Theorist）開啟自動推理；1960 年代的 Robinson 演算法把 [一階邏輯] 的有效性轉成可計算的步驟；1990 年代起，SAT 與 SMT 求解器進入工業；2000 年代起，Coq、Lean、Isabelle 等 [定理證明器] 使大型數學定理的機器驗證成為可能。

**範例**：Lean 的數學庫已驗證數千則定理，包括一些直到近年才被證明的結果；這是邏輯史最新一階段的標誌性成果。

## 七、與相鄰分類的關聯

- [三段論]：古代邏輯的頂點。
- [命題邏輯] 與 [謂詞邏輯]：兩次根本擴充。
- [數理邏輯]：公理化時代的產物。
- [計算邏輯]：最新一階段的主題。

## 關鍵術語速查

| 術語 | 一句話解釋 |
| --- | --- |
| 形式化 | 把領域命題寫成可檢查的符號系統 |
| 公理化 | 以公理與推導規則重建一門學問 |
| 語意轉向 | 從研究推論形式轉向研究真值的意義 |
| 計算轉向 | 把邏輯問題轉為可由機器處理的演算法問題 |
| 不可判定性 | 不存在通用判定程序的結果 |
| 不完全性 | 系統無法在內部證明自身一致性的結果 |

## 七、推動邏輯發展的六個瓶頸

| 瓶頸 | 出現於 | 解法 | 推動者 |
| --- | --- | --- | --- |
| 無法表達量化 | 古代 | 量化與變元 | Frege |
| 無法保證一致性 | 1920s | 編碼與對角化 | Gödel |
| 無法判定有效性 | 1930s | 歸結與可判定片段 | Robinson、Church |
| 無法定義真 | 1930s | 語意框架 | Tarski |
| 無法機器輔助推理 | 1950s | 邏輯程式與定理證明器 | Newell、Robinson |
| 無法驗證大型系統 | 2000s | 型別理論與小型核心 | 現代理論家 |

**範例**：每一列的「解法」都成為下一列問題的舞台——量化帶來不可判定性，語意框架帶來證明論的完备性問題，而定理證明器的需求又催生了新的證明論技術。
