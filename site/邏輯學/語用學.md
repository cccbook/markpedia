# 語用學

> 隸屬：[邏輯學] › [邏輯與語言]　·　狀態：初稿

> 對應維基百科：[中文維基百科：語用學](https://zh.wikipedia.org/wiki/%E8%AF%AD%E7%94%A8%E5%AD%A6)　·　[English Wikipedia: Pragmatics](https://en.wikipedia.org/wiki/Pragmatics)

語用學（pragmatics）研究語言在**特定情境**中的使用：說話者如何選擇句子、聽者如何推論未說出口的內容、以及情境如何改變句子的意義。

在邏輯的脈絡裡，語用學負責解釋那些無法由真值條件處理的現象——指示詞、隱含意義、會話含義，以及「說話者為何不直接說」的效率考量。

## 一、語意與語用的分工

| 層面 | 研究的問題 | 例子 |
| --- | --- | --- |
| 語意 | 句子的真值條件 | 「今天下雨」何時為真 |
| 語用 | 句子在情境中的使用 | 「這裡很擠」是在批評座位不足 |
| 語用學 | 二者的交互 | 隱含、預設、會話含義 |

**範例（指示詞）**：「今天很冷」在 $20^\circ C$ 與 $0^\circ C$ 都是真，但說話者選擇說這句話通常隱含「比預期冷」。語意條件相同，交際意義卻不同——差異全在語用層。

## 二、Grice 的會話含義

Grice 認為對話遵循四項准则：

| 准则 | 內容 |
| --- | --- |
| 數量 | 說足夠但不含多餘的資訊 |
| 品質 | 說真且有證據的內容 |
| 關聯 | 內容與話題相關 |
| 方式 | 清楚、簡潔、不歧義 |

**範例（ Gricean 會話含義）**：

1. 甲問：「你今晚要來吃飯嗎？」
2. 乙答：「我今晚要加班。」

依字面，乙並未回答問題。但依關聯准则，聽者推論出「所以我不來」——這個推論不是語意推出的，而是**會話含義**。事實上乙也可以答「我今晚要加班，但我會遲到」，可見字面內容不足以決定推論。

## 三、隱含與預設

**範例（隱含層次）**：

- 句子的內容：「他會來。」
- 隱含：「他大概會來。」
- 預設：他會來這件事值得說。

這三層由低到高構成「Gricean 隱含層次」，也是語用推論的基本架構。

## 四、指示與索引icals

語用學處理的不只是含義，還有句子的**指示內容**：誰、哪裡、何時。

**範例**：「他昨天來過」中的「他」與「昨天」需由情境決定。在形式化上，這類詞語的意義是**情境參數**——同一個句型在不同的情境代入不同的意義。這是語意與語用互動最直接的例子。

## 五、語用學在人工智慧中的角色

| 應用 | 說明 |
| --- | --- |
| 對話系統 | 推論使用者未明說的意圖 |
| 語意解析 | 處理科層指代 |
| 假設生成 | 從語句推論預設 |
| 意圖識別 | 區分陳述、請求與提問 |

**範例**：使用者說「這裡有冷氣開著嗎？」，系統若只做字面匹配會回覆是或否；理解語用後，應理解為抱怨並可能回覆「有，要不要我幫你關掉？」。

## 七、容易混淆之處

- 語用學**不是**「修辭學」，它研究的是可系統描述的推論現象。
- 會話含義是**推論**，不是句子本身的意義。
