# 石油

> 類型：物品（礦物燃料）　·　領域：[石化工程]　·　狀態：初稿

> 對應維基百科：[中文維基百科：石油](https://zh.wikipedia.org/wiki/%E7%9F%B3%E6%B2%B9)　·　[English Wikipedia: Petroleum](https://en.wikipedia.org/wiki/Petroleum)

石油是**埋藏於地下的液態碳氫化合物混合物**，由數千種分子組成：從甲烷等輕烴到碳數四十以上的蠟質重分子。它是現代工業的原料母體——約三分之一被煉成汽油與柴油等燃料驅動交通，其餘成為塑膠、合成纖維、溶劑、瀝青與化肥的起點。Petroleum 一詞來自拉丁語 petra（岩石）＋ oleum（油），中文「石油」則由北宋沈括在《夢溪筆談》首次使用。

## 關鍵事實

- **成因**：遠古海洋浮游生物與藻類沉積後被埋藏，在缺氧環境與地下約 60–150°C 的「油窗」溫度內熱裂解生成；生油岩、儲集層、蓋層與圈閉四要素齊備才成油田。
- **成分**：碳約 83–87%、氫 10–14%，另含硫、氮、氧微量雜質；硫含量高低（甜原油／酸原油）直接影響煉製成本與售價。
- **分類**：依密度分輕質、中質、重質原油（以 API 度衡量）；依化學組成分石蠟基、環烷基與中間基。
- **計量**：國際以「桶」計，1 桶＝42 美制加侖≈159 公升；全球年消費約 45 百萬桶等級的日需求規模，是最大宗的貿易商品。
- **開採**：勘探（地震測勘）→鑽井→一次採收（天然壓力）→二次採收（注水）→三次採收（化學驅、蒸氣驅）；常規油田採收率約 30–50%。

## 與相關概念的關係

- **與 [石化工程] 的關係**：石油是整條石化價值鏈的物質起點——蒸餾切分、裂解轉化、聚合成型，一切從原油開始；石化工程的方法論正是為了「把油變成有用的分子與材料」而發展。
- **與 [石油炼制] 的關係**：煉製是石油從資源變成產品的唯一通道，原油性質（密度、硫含量、組成）決定煉油廠的裝置配置與排程。
- **與 [全球暖化] 的關係**：燃燒石油釋放地質儲存的碳，是溫室氣體的主要來源之一；石油消費的路徑直接連到氣候政策的成敗。
- **與 [再生能源] 的關係**：石油在交通燃料上的壟斷正被電動化侵蝕，在化工原料上則暫時難以替代——兩者的競合界線隨應用領域而不同。
