# 石油

> 隸屬：第一層 [物](../README.md)　·　狀態：初稿

> 對應維基百科：[中文維基百科：石油](https://zh.wikipedia.org/wiki/%E7%9F%B3%E6%B2%B9)　·　[English Wikipedia: Petroleum](https://en.wikipedia.org/wiki/Petroleum)

石油是埋藏在地層中的液態烴類混合物，由億萬年前的浮游生物與藻類沉積、經高溫高壓轉化而成。它同時是燃料與原料：汽油、柴油、瀝青燃燒驅動了二十世紀，乙烯、丙烯等裂解產物則是塑膠與合成纖維的起點。理解石油，就是理解現代工業文明的物質基礎與其轉型的壓力。

## 核心特徵

- **成分**：以碳氫化合物為主，含碳約 83% 至 87%、氫約 10% 至 14%，另含硫、氮、氧與微量金屬。
- **生成與移聚**：生油岩（富含有機質的頁岩）深埋後生成油氣，油氣沿滲透層向上遷移，被不透水的蓋層與構造（背斜圈閉等）攔住，才形成可開採的油田。
- **輕重與品質**：輕質低硫原油（如布倫特）易煉價高，重質高硫原油需更深的加工；比重以 API 度表示。
- **煉製階梯**：蒸餾塔按沸點把原油切成不同餾分，再以裂解、重組、加氫等程序提升價值。

## 因果鏈：為何出現、解決什麼、推動什麼

1. **前因**：工業革命後照明依賴鯨油與煤油，鯨群被大量捕殺，廉價照明燃料的需求迫在眉睫。
2. **出現**：1859 年德雷克在美國賓州鑽出第一口商業油井（21 公尺深），煤油燈照亮了夜間，石油業就此誕生。
3. **解決**：內燃機問世後，汽油與柴油成為剛需，石油從照明材料躍升為運輸命脈；1960 年代石油超越煤炭成為世界第一大能源。
4. **推動**：油價波動改寫了國際政治——1973 年禁運引發第一次石油危機，各國因此建立戰略儲油、推動省油車與核能；石化業則把煉油副產品變成塑膠、合成橡膠與化肥。
5. **今日**：減碳浪潮下，石油需求結構從「燃料為主」轉向「材料為主」，頁岩油（以水力壓裂開採的緻密油）重塑了供給格局。

## 發展脈絡

中國在北宋已有「石油」之名——沈括《夢溪筆談》（約 1088 年）記載陝北延州一帶「石油至多，生於地中無窮」，並預言「此物後必大行於世」，可謂千年前的神預言。近代油業則從洛克菲勒的標準石油托拉斯（1870 年）開始，展現了資本、運輸與煉製一體化如何壟斷產業，1911 年該公司被美國法院裁定解體，衍生出的埃克森等公司至今仍是巨頭。

二十世紀中東的油藏（1938 年沙烏地達蘭的達曼七號井噴油）把波斯灣推上世界能源的心臟位置，油元與地緣政治糾纏至今。技術上，從二次採收（注水驅油）到三次採收（注蒸汽、化學驅），採收率已可從最初的一成多提高到三成以上。

## 範例：一桶原油的煉製旅程

追蹤一桶 159 公升的原油在煉油廠的命運：

1. 常壓蒸餾：油在塔中加熱到約 350 度，輕組分上浮——塔頂是液化石油氣與石腦油，中段是汽油、煤油、柴油，塔底是重油。
2. 石腦油送入觸媒重組，提高辛烷值成為汽油；煤油段即航空燃油。
3. 重油再入減壓蒸餾塔與流化催化裂解裝置，把長鏈分子「剪短」成汽油與柴油，提高輕油收率。
4. 加氫脫硫單元把硫含量壓到法規限值（臺灣柴油現行 10 ppm）。
5. 一桶原油大約可煉出四成五左右的汽油與三成上下的餾分燃料，其餘成為瀝青、潤滑油與石化原料。

## 類型與變體

- **輕質與重質原油**：依 API 度與含硫量分級，決定煉製路線。
- **頁岩油**：蘊藏於緻密岩層，靠水平井與水力壓裂開採。
- **油砂**：加拿大的瀝青砂，開採能耗高、碳強度大。
- **海上油田**：固定式或浮式平臺，深海專案單口井造價可達數億美元。

## 容易混淆之處

- 石油不等於汽油：汽油只是煉製產品之一，原油是上百種分子的混合物。
- 「石油危機」本質是供給與地緣事件：不是地底沒油，而是供應鏈被政治切斷。
- 儲量不等於可採量：技術與油價決定哪些「地下油」算數。

## 與相鄰概念的關聯

- 與 [天然氣](../天然氣/README.md) 的關係：兩者常共生於同一圈閉，頁岩革命更使油氣開採技術互通。
- 與 [高分子塑膠](../高分子塑膠/README.md) 的關係：石油裂解的乙烯與丙烯是塑膠工業的第一原料，油價直接寫進塑膠成本。

## 小結

「石油」的價值，在於它同時記錄了需求、材料與工藝三者如何互相推動。1859 年德雷克在美國賓州鑽出第一口商業油井。 理解這條因果線，再看同類的器物或技術，便能讀出藏在細節裡的時代訊息。

**問：如果只用一句話向朋友介紹它？**

「石油」是把一群人的需求與手藝濃縮進一件實物的成果——它的形，就是它的歷史。

**問：與現代生活最直接的連結是什麼？**

許多今日視為理所當然的細節，例如規格的統一、材料的替代與保養的觀念，都是「石油」一路累積下來的答案。回頭看它的演進，常能解釋我們習以為常的設計為何如此。
