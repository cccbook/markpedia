# 光學望遠鏡

> 類型：物品自然物（科學儀器）　·　領域：[天文學]　·　狀態：初稿

> 對應維基百科：[中文維基百科：光學望遠鏡](https://zh.wikipedia.org/wiki/%E6%9C%9B%E8%BF%9C%E9%95%9C)　·　[English Wikipedia: Telescope](https://en.wikipedia.org/wiki/Telescope)

光學望遠鏡（telescope）是利用透鏡或反射鏡收集並放大遠方天體光線的儀器。它是**天文學從「肉眼觀測」走向「系統量測」的技術前提**：沒有望遠鏡，恆星的星等、光譜與視差都不可能被精密記錄。

1609 年，[伽利略] 將荷蘭的眼鏡技術改造成天文儀器，一年之內就發現了木星的衛星、金星的相位與月球表面的山脈。這套做法示範了**儀器改進如何直接打開新的科學問題**：望遠鏡的極限（口徑、像差、大氣視寧度）幾乎每一代都對應一批新的天文學分支。

## 技術要點

- **折射式與反射式**：折射式用透鏡聚光，像差控制容易、視場狹小；反射式用凹面鏡聚光，口徑可以做得更大，因此大型天文台多採反射式。牛頓 1668 年製成第一具反射式望遠鏡。
- **口徑與解析度**：口徑越大，聚光能力越強，可見的極暗天體越多；理論上解析度隨波長與口徑之比而變，短波長的 X 射線望遠鏡因此需要完全不同的設計。
- **大氣視寧度**：地面望遠鏡的實際解析度多受大氣擾動限制，這正是把望遠鏡送上太空的動因之一。
- **主鏡的尺度限制**：鏡面隨口徑增大而變形與變重，主鏡的製造、鍍膜與主動光學（如 JWST 的六面鏡）成為大型望遠鏡的瓶頸。
- **干涉量測**：以多具望遠鏡或虛擬鏡面合成極高的角解析度，事件視界望遠鏡即以此拍攝黑洞陰影。

## 與科學發現的對應

| 儀器能力 | 對應的天文發現 |
| --- | --- |
| 伽利略的 20 倍望遠鏡（1609 年） | 木星衛星、金星相位、月球山脈 |
| 折射式望遠鏡（19 世紀） | 天衛一、海衛一、雙星、星雲與星系的發現 |
| 光譜儀與大型反射鏡 | 元素的光譜線、星系紅移與哈勃定律 |
| 射電望遠鏡（1930 年代起） | 銀河系射電、脈衝星、宇宙微波背景 |
| 紅外太空望遠鏡（1990 年代起） | 塵埃內的恒星誕生、冷矮星、系外行星大氣 |

| 干涉與甚高頻陣列 | 1990 年代起 | VLBI、ALMA | 以基線合成極大解析度 |

## 觀測能力與天文學問題的對應

1. **口徑的極限與 X 射線天文學**：可見光之外，溫度極高或極低的天體只能在其他波段被看見；X 射線天文學的建立直接帶來黑洞吸積盤、高溫天體與伽瑪射線暴等新領域。
2. **解析度的極限與黑洞成像**：單一望遠鏡無法解析事件視界尺度的陰影，因此需要以甚高頻干涉把全球望遠鏡的資料拼接；這說明儀器的瓶頸決定了哪些問題「可以被提出」。
3. **時間解析度與瞬變天文**：高速攝影與快速回應網路，使流星、閃電、超新星與伽瑪射線暴等短暫事件得以被捕捉。
4. **多波段與天體的化學**：不同波段對應不同的物理機制，可見光看表面溫度，紅外看塵埃，射電看同步輻射；把各波段拼起來才得到完整圖像。

## 維護與成本

大型望遠鏡的成本集中在幾個具體項目：主鏡的鑄造與鍍膜、極低溫的環境控制（紅外觀測常需液態氮冷卻）、自適應光學的校正元件、雷達與激光量測的精度維持，以及長期的觀測排程與資料處理人力。這些成本使天文觀測成為**少數只有少數國家能承擔的科學活動**，也解釋了國際觀測組織與資料共享制度的存在理由。

## 觀測者與儀器的關係

望遠鏡並非中性窗口：

1. **決定可見之物**：口徑、波段與曝光時間共同決定哪些天體會進入資料庫；未被記錄的天體等於不存在於觀測者的視野。
2. **決定資料的形狀**：感光元件、濾光器與觀測模式決定資料是影像、光譜、時序還是偏振測量；今天的機器學習模型也受這些選擇所限。
3. **決定誰能提問**：大型設備的排程權與資料處理能力集中在少數機構，因此「提出問題的能力」實際上分布不均。
4. **改變觀測者**：長時間曝光與自動巡天意味著「觀測」逐漸由人轉為程序與模型；觀測天文因此與資料科學越來越緊密地交會。

這四點共同說明：**儀器不只放大世界，也塑造了科學家能看見的世界**。

## 使用守則與常見風險

- **不可直視**：太陽的觀測必須使用專用減光濾光器或投影法，否則可能造成永久性視網膜損傷。
- **視寧度與天氣**：地面望遠鏡的可用夜數與大氣穩定度，往往比鏡面本身更能限制觀測計畫。
- **光度校正**：不同時期、不同儀器與不同濾光器的資料必須先做光度與波長校正，才能合併分析；這一步往往是天文資料處理中最耗時的部分。
- **時間基準**：觀測紀錄必須精確到足以與其他波段（如射電、引力波）對齊，多信使天文因此對時間標準提出極高要求。

## 容易混淆之處

- **望遠鏡不是伽利略發明的**。他在 1609 年將荷蘭的望遠鏡設計改良並用於天文；「發明者」的歸屬在史學上仍有爭議。
- **「看得更遠」不等於「看得更清楚」**。口徑決定亮度與理論解析度，而像差、大氣與背景光決定實際可用的解析度。
- **放大倍數不是關鍵指標**。高倍率只放大像差；歷史上許多「更高倍」的望遠鏡反而帶來更差的影像。
- **太空望遠鏡的優勢不只是「離開大氣」**。紅外與紫外線波段在地面本就被大氣吸收，因此必須上太空才能觀測。
