# 混合方法

> 隸屬：[人工智慧] › [人工智慧的定義]　·　狀態：初稿

> 對應維基百科：中文維基百科無對應條目　·　[English Wikipedia: Neuro-symbolic AI](https://en.wikipedia.org/wiki/Neuro-symbolic_AI)

混合方法（neuro-symbolic AI）主張：**把符號推理的結構性與神經網路的學習性結合起來**，取兩者之長。它不是折衷主義的落水狗，而是一種明確的工程判斷：符號層擅長組合、驗證與少樣本泛化，神經層擅長感知、連續映射與從大資料中提煉規律。

現代大型語言模型內部的「思維鏈」推理、外部工具與結構化輸出檢查，事實上都是混合架構的雛形；知識圖譜作為 [Transformer] 的外部記憶、程式語言執行作為 verifiable reasoning 的載體，也都沿這條路徑發展。

## 技術與理論的關聯

- 混合系統通常分三層：**感知層**（神經網路處理影像、語音等連續訊號）、**推理層**（以規則、圖或程式處理離散結構）、**介面層**（把前者的向量或標籤轉成後者可用的形式）。
- 核心工程難題是**介面表示**：符號層要能讀懂神經層產出的概念，否則兩層無法真正對話。
- 符號層的價值在於**可驗證**：推論過程可被檢查、可被拒絕，這是純學習系統難以提供的。
- 神經層的價值在於**少樣本與雜訊容忍**：符號規則要覆蓋新情境成本高，神經模型可用少數例子調整。
- 訓練方式有兩條路：先學後接（模組分開訓練再串接）與端到端（讓推論層的獎勵回流到神經層）。
- 混合系統的可解釋性通常優於純端到端模型，因為關鍵步驟以符號形式留痕。

## 範例

以「從自然語言題目自動產生 SQL 並查詢資料庫」為例：

1. **感知層**：以編碼器讀入問題「列出 2023 年銷量最高的五家門市」，輸出語意向量，並以分類頭標出實體「2023 年」「門市」「銷量」。
2. **介面層**：把語意向量對齊到資料庫 schema 的節點，選出需要的表與欄位，輸出 schema linking 結果。
3. **推理層**：以符號規則限制 SQL 語法，把語意槽填入模板，得到
   ```sql
   SELECT store, SUM(sales) FROM sales
   WHERE year = 2023 GROUP BY store ORDER BY SUM(sales) DESC LIMIT 5;
   ```
4. **驗證**：以語法檢查與資料庫的 dry-run 驗證語意，若欄位不存在則回到第 2 步重新選擇。
5. **端到端微調**：以執行結果作為回饋信號，讓感知層學會更準確的 schema linking。

這裡神經模型負責「看懂」與「對齊」，符號層負責「保證正確」，兩者職責分離得相當清楚，正是混合方法的典型形態。

## 前因後果

**前因**：[符號主義] 與 [連接主義] 的長期對立，使研究者無法在不同子問題上各取所長；而 [深度學習] 的成功也讓人清楚看到純學習系統在可驗證性與結構化推理上的弱點。

**後果**：混合方法成為多個領域的主流選擇——視覺領域用「神經偵測器＋符號空間推理」，科學領域用「學習勢能面＋符號力學推演」，語言領域用「語意模型＋程式執行」。它的代價是系統複雜度上升，除錯困難，且兩層之間的錯誤會互相掩蓋。

值得注意的是，混合架構的成本並不只在運算。每一層都引入自己的介面、錯誤型態與除錯成本，當兩層串接時，錯誤歸因反而變得更困難：符號層給出錯誤答案時，人往往先懷疑上游的感知層。因此在混合系統的工程規範中，逐層記錄中間結果不是選配，而是必要條件。

## 與相鄰分類的關聯

- 與 [符號主義] 的關係：混合方法保留其推理與驗證部分，放棄其純手工知識獲取。
- 與 [連接主義] 的關係：混合方法承認其感知與表示能力，並補上結構與可檢查性。
- 與 [深度學習] 的關係：混合方法通常是深度學習系統的架構升級，而非替代。
- 與 [AI應用] 的關係：醫療、金融等高風險領域特別青睞可驗證的混合架構。

## 容易混淆之處

- 混合不等於拼接：把模型輸出直接交給規則處理，與讓兩層共同訓練，是不同深度的整合。
- 符號層不保證結論有用：推論正確與目標正確是兩回事。
- 「可解釋」不等於「可理解」：留下中間結果不代表人類能理解模型為何如此選擇。
- 混合架構的額外成本常被低估：資料流複雜度上升後，除錯與維護會佔用大量工時。
- 「符號層」不一定是邏輯：資料表、SQL 語句與版面結構同樣屬於可檢查的離散層。
- 混合方法不等於符號加神經的算術和：若介面層沒有共同表徵，兩層只是各自為政。
- 兩層各對一半錯：混合系統的總錯誤率是兩層錯誤率的乘積，改善任一層都有效，但不可互相推卸。

## 技術要點

1. 三層分層：感知、推理、介面各自封裝，替換任一層不影響其他層。
2. 概念對齊：以向量原型或蒸餾模型讓符號概念在神經空間中可定位。
3. 知識注入：以本體作為圖嵌入的先驗，或以規則約束解碼。
4. 驗證閉環：任何推論輸出都必須通過檢查器才被採用。
5. 梯度通路：設計可微的推理步驟，讓端到端訓練能回傳到感知層。
6. 失敗隔離：記錄每層輸入輸出，定位錯誤發生於何層。
7. 契約測試：為符號層的推論規則撰寫測試並與版本綁定，避免規則更新後無聲劣化。

## 常見的論爭

- 組合複雜度：多層系統的除錯成本是否高於其帶來的可靠性增益。
- 端到端的誘惑：若端到端模型在各項基準上持續領先，混合的實證收益是否仍成立。
- 標準化不足：領域缺乏統一的架構與評估慣例，使比較研究困難。
