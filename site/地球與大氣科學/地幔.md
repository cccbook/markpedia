# 地幔

> 隸屬：[地球與大氣科學] › [地球的結構]　·　狀態：初稿

> 對應維基百科：[中文維基百科：地幔](https://zh.wikipedia.org/wiki/%E5%9C%B0%E5%B9%94)　·　[English Wikipedia: Mantle (geology)](https://en.wikipedia.org/wiki/Mantle_%28geology%29)

地幔是地球介於地殼與外核之間的厚達約 2,900 公里的固體—塑性層，占地球質量的約三分之二。它主要由矽酸鹽礦物（橄欖石、輝石）組成，在短時間尺度上表現為剛性、在長時間尺度上卻能對流流動——這個「剛而能流」的雙重性質，正是板塊構造得以存在的物理前提。

地幔雖不可直接觸及，卻是地球科學推論最密集的區域：地幔對流驅動板塊，板塊俯衝帶回深部物質，深部物質又以地幔柱形式上湧。它同時也是地震波傳播的「主舞台」——多數地震波的路徑與波形變化，都需要地幔的三維速度模型才能解釋。

## 關鍵數據

| 項目 | 數值 |
| --- | --- |
| 深度範圍 | 莫霍面（約 5 至 70 公里）至古登堡面（約 2,900 公里） |
| 質量占比 | 約 67% |
| 平均密度 | 約 3.3 至 5.6 g/cm³（隨深度增加） |
| 頂部岩石圈厚度 | 大陸約 100 至 200 公里，海洋約 50 至 100 公里 |
| 對流循環時間尺度 | 約 1 億至 2 億年 |
| 主要組成 | 橄欖石、輝石、鈣長石、含水礦物 |
| 深度範圍下限 | 自莫霍面起算，向下延伸約 2,900 公里 |
| 最深部壓力 | 約 140 GPa，相當於 1.4 萬個大氣壓 |
| 最深部溫度 | 估計 3,500 至 4,000 K（依熱流模型而定） |

## 技術要點

- **地震波 tomography**：全球數千個地震台站記錄的走時可反演三維速度結構，現今已能辨識出俯衝板片與地幔柱的精細形態。
- **黏度估計**：地幔的黏度由地震波衰減、遷移現象與實驗室變形實驗共同推得，約 $10^{20}$ 至 $10^{23}\ \mathrm{Pa \cdot s}$ 。
- **相變**：低壓下橄欖石穩定，高壓下轉化為密度更大的尖晶石相與石榴石相，進一步深處轉為鈣長石相與布里奇曼石型結構（CaSiO₃ 的鈣鈦礦型相）。
- **地幔柱**：夏威夷等熱點下方被解讀為來自核幔邊界的熱柱，其成因仍有模型差異。
- **地震各向異性**：橫波在具有方向性構造的地幔中傳播速度不同，可用於推斷晶體優向方向。
- **含水量**：地幔含水可影響黏度與熔點，是俯衝板片「能否沉下去」的關鍵變數。
- **深部壓力**：在核幔邊界壓力約 140 GPa，超過絕大多數礦物的穩定相界，導致下地幔以布里奇曼石型結構為主。
- **熱流的量測**：地表熱流密度在古老地盾上僅約 40 至 50 mW/m²，而在年輕洋中脊可超過 150 mW/m²，這組差異是對流存在的直接證據。

## 範例

以俯衝板片的演化作為追蹤地幔物質循環的案例：

1. **生成**：一條成熟海溝兩側的海底地殼與上地幔物質被拉入海溝，隨板片下沉。
2. **相變**：隨深度增加，板片中的水化礦物在 300 至 500 公里深處發生相變，釋出水分。
3. **影響**：水降低上覆地幔楔的黏度，促進部分熔融，這正是島弧火山（如日本、印尼）的岩漿來源。
4. **脫落**：部分板片在過深或過熱時斷裂，形成「脫落板片」沉入下地幔，時間尺度約一千萬年。
5. **再循環**：板片最終可下沉到核幔邊界，物質再以地幔柱形式上湧，完成循環。
6. **觀測對照**：地震層析影像已能直接看到俯衝板片呈「波狀」下沉，並在其上方看到低速（熱）的地幔楔，理論預測與觀測一致。

## 前因後果

地幔研究的第一步是「發現它的存在」：地質學家發現山區地層中的岩石含有只能在高壓高溫下形成的礦物（如金剛石、藍晶石），才意識到地球內部並非均質。這項發現把地球的「內部」變成一個可以提問的對象。

接著，地震網的建立提供了連續的穿透剖面，讓地幔從「推測」變成「可成像」。當板塊構造說需要一個能持續翻新的地幔時，地幔對流恰好提供了機制；反過來，板塊構造的證據（俯衝板片、海溝、火山弧）又成為地幔對流最有力的經驗證據。兩者是彼此鎖定的。

## 與相鄰分類的關聯

- 與 [地殼] 的關係：地殼是地幔冷卻、分異後的產物，兩者以莫霍面為界。
- 與 [板塊] 的關係：地幔對流提供板塊運動的動力，是「板塊」概念的物理基礎。
- 在上位概念 [地球的結構] 中，本概念扮演的角色：占地球質量三分之二的巨大部分，是解釋地球如何「活動」而非僅僅「存在」的關鍵單元。
- 與 [地球的演化] 的關係：地幔是儲熱體，深部地熱流決定了地表的熱演化史。

## 容易混淆之處

- **地幔不是液態**：地幔整體是固體，只是長時間尺度下能以對流方式流動。
- **「地幔柱」不是煙囪**：它是固態的熱上升流，密度差異極小、速度極慢。
- **下地幔不是液態鐵**：深度 660 公里處的相變是礦物相變，不是金屬化。
- **地幔與地核的化學界線不銳利**：核幔邊界附近的化學漸變區（Ure 及其他 CMB 層）是研究焦點。
- **地幔不是「空洞」**：地幔占地球體積約四分之一，卻承擔了地球內部幾乎全部的機械支撐與熱傳遞功能。

## 常見的論爭

- **對流的驅動力**：熱對流、下沉板片的重力驅動、或兩者組合，權重仍有爭論。
- **全地幔對流與分層對流**：下地幔是否也參與對流，直接影響板塊尺度的模型選擇。
- **地幔柱的存在性**：熱點下方低速區是主動上湧的柱體，還是被動的化學非均質造成的假象，尚無定論。
