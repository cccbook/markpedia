# markpedia —— 繁體中文通用百科全書

一個純 Markdown 的百科全書專案：每個條目一個 `.md` 檔，用 Python 標準庫腳本做連結與格式檢查，無框架、無建置流程、無外部套件。

- 總目錄：[site/README.md](site/README.md)
- 撰寫規範（agent 與人皆必讀）：[AGENTS.md](AGENTS.md)
- 原始需求：[prompts.md](prompts.md)（歷史文件，勿改）

## 內容結構

```
site/
├── README.md            全域總目錄（主類表）
├── 人/ 時/ 地/ 物/ 歷史/ 生活/ 社會/ 科技/ 其他/          主類資料夾
├── 數學/ 物理/ 化學/ 生醫/ 電機/ 電腦/                    基礎科學與工程主類
├── <主類>/<概念>/       概念資料夾（README.md 表格入口 + 概念本文 + 子/孫分類）
├── 人/<人物類別>/       人名實體（如 人/數學家/高斯.md）
├── 時/NNNN年.md         年份實體（每年一檔）
├── 地/<地名>.md         地名實體
└── 物/<物品>.md         物品實體
```

- 同一概念可掛在多個主類之下（多維度歸類），但實體資料夾只有一份，其他主類以參考式連結指到正式落點。
- 全站內文連結一律用參考式連結，定義集中在各檔文末的「## 連結定義」。
- 每個概念條目開頭附「對應維基百科」行，條名經維基百科 API 查證。

## 工具（`tools/`，Python 3 標準庫，無需安裝）

```bash
python3 tools/check_links.py              # 全站連結與格式檢查
python3 tools/check_links.py 科技/人工智慧 # 只查某概念資料夾（相對 site/）
python3 tools/wiki_check.py 候選.json 結果.json  # 批次查證維基百科條名
python3 tools/fix_math_spacing.py <資料夾> # 自動修行內公式 $ 前後空格
```

`check_links.py` 是唯一可靠的機器檢查，強制：每檔 ≥100 行、參考式連結與文末連結定義一致、無 `TODO`/「待補」佔位、行內公式 `$` 前後有空格、開頭有「對應維基百科」行。

**注意**：`tools/build_tables.py`、`tools/build_progress.py` 與 `tools/data/` 下的資料檔仍對應舊版結構（19 個第一層分支、概念資料夾在 `site/` 頂層），執行會崩潰或寫到錯誤路徑；`json/` 目錄為各批次產生時的暫存查證結果。

## 專案狀態

目前仍在**分類結構遷移期**：內容已從舊版 20 分支頂層結構搬進新的十五大主類（人、時、地、物、歷史、生活、社會、科技、其他、數學、物理、化學、生醫、電機、電腦）。全站仍有多數規劃中的條目尚未撰寫，既有斷鏈有空再逐一處理即可。條目品質規範與禁止事項詳見 [AGENTS.md](AGENTS.md)。
