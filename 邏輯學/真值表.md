# 真值表

> 隸屬：[邏輯學] › [命題邏輯]　·　狀態：初稿

> 對應維基百科：[中文維基百科：真值表](https://zh.wikipedia.org/wiki/%E7%9C%9F%E5%80%BC%E8%A1%A8)　·　[English Wikipedia: Truth table](https://en.wikipedia.org/wiki/Truth_table)

真值表（truth table）是命題邏輯的判定工具：把公式中每個原子命題的所有真值組合逐一枚舉，對每一列依照連接詞的真值條件算出結果。它之所以關鍵，在於**判定是有限且完全機械的**——只要列出所有列，就沒有遺漏任何可能情形。

## 一、怎麼列真值表

步驟固定：

1. 找出所有不同的原子命題，記為 $P, Q, R$ 。
2. 若有 $n$ 個原子命題，共 $2^n$ 種組合。
3. 依序分配真／假，並盡量讓每個命題的分組交替變化，避免漏列。
4. 對每一列，由內層連接詞往外層逐步計算。

**範例**： $n = 3$ 時的排列方式。

| $P$ | $Q$ | $R$ |
| --- | --- | --- |
| 真 | 真 | 真 |
| 真 | 真 | 假 |
| 真 | 假 | 真 |
| 真 | 假 | 假 |
| 假 | 真 | 真 |
| 假 | 真 | 假 |
| 假 | 假 | 真 |
| 假 | 假 | 假 |

共 $2^3 = 8$ 列，沒有遺漏任何一組可能。

## 二、範例：判定一個推論是否有效

有效性判準是：**若前提全真，結論必真**。只要找到一列前提全真而結論為假，便構成反例，推論即不成立。

**範例**：檢驗「若 $P$ 且 $Q$ ，則 $P$ 」是否有效。

| $P$ | $Q$ | $P \wedge Q$ | $(P \wedge Q) \to P$ |
| --- | --- | --- | --- |
| 真 | 真 | 真 | 真 |
| 真 | 假 | 假 | 真 |
| 假 | 真 | 假 | 真 |
| 假 | 假 | 假 | 真 |

沒有任何一列出現前提真而結論假，故推論有效——這正是「合取引入律」。

**範例**：檢驗「若 $P$ ，則 $Q$ 」是否有效。

| $P$ | $Q$ | $P \to Q$ |
| --- | --- | --- |
| 真 | 真 | 真 |
| 真 | 假 | **假** |
| 假 | 真 | 真 |
| 假 | 假 | 真 |

第二列構成反例，故不成立。日常語言中的「如果…就…」常被誤當成有效推論，這正是需要邏輯的地方。

## 三、真值表能回答哪些問題

| 問題 | 判定方式 |
| --- | --- |
| 兩公式是否等價 | 兩欄逐列比較 |
| 推論是否有效 | 前提真時結論是否恆真 |
| 公式是否恆真（重言式） | 整欄全真 |
| 公式是否恆假（矛盾式） | 整欄全假 |
| 公式是否可滿足 | 是否存在一列為真 |

**範例**： $P \lor \neg P$ 的真值表每一列都為真，故為重言式——這就是排中律。而 $P \wedge \neg P$ 每一列都為假，故為矛盾式。兩者合起來說明：命題邏輯預設了二值世界。

## 四、限制：規模爆炸

真值表的列數隨原子命題數指數成長，三個命題 8 列，十個命題就是 $2^{10} = 1024$ 列。對人類而言這已難以手算，對機器而言大型實例（例如晶片驗證的時序公式）更可能超出記憶體。

因此實務上走向兩條路：

1. **化簡先行**：先用等值式把公式化為范式或更簡形式，再判定。
2. **以推導取代枚舉**：改用推導系統，只走與目標相關的分支。

這兩條路的分工，正是 [計算邏輯] 中 SAT 求解器設計的出發點：現代求解器並不列真值表，而是以子句傳播與非平稱回溯**隱性地**做同樣的事。

## 五、與相鄰分類的關聯

- [命題邏輯]：真值表是其判定程序，兩者互相定義。
- [等值式]：真值表是驗證等價的最直接方法，等價演算則是它的符號化替代。
- [范式]：化為范式可大幅減少需要核對的列數。
- [可判定性]：真值表說明命題邏輯是可判定的，而一階邏輯不可判定，正是這條對比推動了邏輯的分支。

## 六、延伸：從表格到 SAT

現代求解器把真值表換成**子句傳播**：若某子句出現互補文字對（例如某子句含 $P$ 、另一子句含 $\neg P$ ），便可推導新子句並刪去該變數。這在效果上等同於跳過真值表中必然無法滿足的列。

**範例**：子句 $(\neg P \lor Q)$ 與 $(\neg Q \lor R)$ 搭配 $P$ ，傳播後可得 $R$ 。真值表要列 4 列才看得出來，傳播只要一步。
