# 自動定理證明

> 隸屬：[邏輯學] › [計算邏輯]　·　狀態：初稿

> 對應維基百科：[中文維基百科：自動定理證明](https://zh.wikipedia.org/wiki/%E8%87%AA%E5%8B%95%E5%8C%96%E5%AE%9A%E7%90%86%E8%AD%89%E6%98%8E)　·　[English Wikipedia: Automated theorem proving](https://en.wikipedia.org/wiki/Automated_theorem_proving)

自動定理證明（automated theorem proving, ATP）是讓電腦自動找出形式命題之證明的技術。它把 [證明論] 的規則實作成搜尋程序，讓 [謂詞演算] 的演算法真正跑起來。

今日的自動定理證明分兩條路線：**乘積型**（如 E、Vampire）以高階邏輯與超級位置為基礎做搜索；**整合型**（如 Coq、Lean、Isabelle）則以可信核心加上互動式介面，服務於大型形式化專案。

## 一、證明搜尋的兩種策略

| 策略 | 說明 | 典型 |
| --- | --- | --- |
| 前向搜尋 | 從公理出發，套用規則產生新命題 | 演繹法（Otter、Prover9） |
| 後向搜尋 | 從目標出發，反推所需前提 | 归结（Robinson）、重寫 |

**範例（归结法）**：要證明 $\{P \to Q, \neg Q\} \models \neg P$ ， Robinson 归结法把 $P \to Q$ 化為 $\neg P \lor Q$ ，與 $\neg Q$ 归结得 $\neg P$ ，與目標直接相符，全程三步完成。

## 二、關鍵技術

1. **子句化**：把公式轉為 CNF，見 [范式]。
2. **歸結**：以「若 $A \lor B$ 與 $\neg B \lor C$ 則得 $A \lor C$ 」規則合併子句。
3. **重寫**：以等式規則做正規化，是高階證明器的主要手段。
4. **關鍵引理抽取**：從成功子證明中歸納出可重用的中間命題。

**範例（重寫）**：把 $\sin^2 x + \cos^2 x$ 化為 $1$ ，只需一條重寫規則 $\sin^2 x + \cos^2 x \to 1$ ，這類「局部化簡」在自動證明中往往比归结更有效率。

## 三、整合型證明器

以 Lean、Coq、Isabelle 為代表，它們的架構是「小型可信核心 + 大量自動化 tactic」。

| 層次 | 內容 | 信任度 |
| --- | --- | --- |
| 可信核心 | 極小的推導規則與型別檢查 | 完全信任 |
| 內建資料庫 | 已驗證的引理 | 信任（已機器檢查） |
| 自動化 tactic | 搜尋與重寫 | 需保證終止與正確 |
| 使用者互動 | 選擇目標、填入引理 | 人工 |

**範例**：在 Lean 中證明「三角函數平方和為一」，只需 `nlinarith [Real.sin_sq_add_cos_sq]` 一行——核心只負責確認 tactic 產生的證明項合法，尋找工作則交給外部工具。

## 四、效能與瓶頸

| 瓶頸 | 說明 | 對策 |
| --- | --- | --- |
| 搜尋空間爆炸 | 規則與分支太多 | 啟發式排序、隨機化 |
| 找不到引理 | 關鍵中間命題缺失 | 引理庫與機器學習輔助 |
| 終止性 | 搜尋可能不停止 | 限制搜尋策略與時間預算 |
| 自動化不足 | 需人工選擇步驟 | 互動式介面與 tactic 組合 |

**範例**：Lean 的 mathlib 以「數學家先寫好策略、機器負責細節」的模式推進，大幅提高了形式化的實際可行性——這是「半自動」而非「全自動」的成功案例。

## 五、歷史與應用

| 時期 | 代表 | 意義 |
| --- | --- | --- |
| 1956 | Logic Theorist | 首次以機器做定理證明 |
| 1960s | Logic Theorist、SAINT | 證明部分數學定理 |
| 1965 | Robinson 归结 | 归结法成為主流 |
| 1970s | 汽車與戰機驗證 | ATP 進入工業界 |
| 1990s | PVS、ACL2 | 工業驗證工具鏈 |
| 2000s | Coq、Isabelle、Lean | 大型數學形式化 |

**範例**：Lean 的數學庫已驗證數千則定理，包含一些先前僅有計算機輔助證明或長期未解的命題——這是 ATP 技術累積三十年的結果。

## 六、與相鄰分類的關聯

- [證明論]：規則與定理的來源。
- [謂詞演算]：搜尋的規則基礎。
- [定理證明器]：整合型系統的工程實現。
- [SMT]：理論求解器常被納入證明器作為組件。
- [不完全性定理]：說明自動化的邊界。

## 七、容易混淆之處

- 自動定理證明**不表示**自動發現新數學，它多半是把已知的推理路徑自動化。
- 「證明完成」需要可信核心保證，不是靠求解器的宣稱。

## 關鍵術語速查

| 術語 | 一句話解釋 |

| 歸結 | 以子句合併規則進行推理的技術 |

| 半自動 | 人給目標、機器找證明的協作模式 |
