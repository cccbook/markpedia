# 謬誤學

> 隸屬：[邏輯學] › [論證理論]　·　狀態：初稿

> 對應維基百科：[中文維基百科：謬誤學](https://zh.wikipedia.org/wiki/%E8%AC%AC%E8%AA%A4)　·　[English Wikipedia: Fallacy](https://en.wikipedia.org/wiki/Fallacy)

謬誤學（fallacy study）研究**無效推論的形式**。它把日常推理中反覆出現的錯誤整理成可辨識的類型，使推理錯誤從「聽起來有道理」變成「可被指認的結構缺陷」。

它不是零散的反例集，而是一套**分類學**：形式謬誤來自推論結構，實質謬誤來自內容與語境。

## 一、形式謬誤

| 謬誤 | 形式 | 說明 |
| --- | --- | --- |
| 肯定後件 | $P \to Q$ , $Q$ ⟹ $P$ | 由結果反推原因 |
| 否定前件 | $P \to Q$ , $\neg P$ ⟹ $\neg Q$ | 否定前件即否定一切後果 |
| 否定結論 | $P \to Q$ , $\neg Q$ ⟹ $\neg P$ | 此形式有效（否定後件） |
| 中項不周延 | $A \to B$ , $C \to A$ ⟹ $C \to B$ | 當 $A$ 為全稱時無效 |
| 四詞謬誤 | 四個詞項的推論 | 詞項數不等於三段論的三項 |

**範例（肯定後件）**：「若下雨則地濕；地濕了；所以下雨了。」反例：洒水器。

**範例（中項不周延）**：「所有鳥會飛；所有蝙蝠都是鳥；所以所有蝙蝠都會飛。」此處「鳥」作為全稱前提的謂詞並未在結論中周延，故推論無效。

## 二、實質謬誤

| 謬誤 | 說明 | 範例 |
| --- | --- | --- |
| 訴諸權威 | 以權威取代論證 | 「某專家說���，所以是真的」 |
| 訴諸無知 | 以「無法證明不存在」推論不存在 | 「沒有人能證明外星生命不存在」 |
| 訴諸情感 | 以情緒代替理由 | 「這政策害我們失去工作」 |
| 訴諸多數 | 以人數代替理由 | 「多數人相信，所以正確」 |
| 稻草人 | 扭曲對方立場 | 把「部分支持」說成「完全支持」 |
| 滑坡謬誤 | 把可能的連鎖推為必然 | 「若允許例外，接下來就會全毀」 |
| 訴諸後果 | 以結果好壞判斷真偽 | 「這個說法有用，所以是真的」 |
| 循環論證 | 結論預設在前提中 | 「他很可靠，因為他說自己可靠」 |

**範例（滑坡謬誤）**：在工程除錯中常見「若放寬這個檢查，錯誤就會擴散，所以不能放寬」——但滑坡的每一環都需要獨立證據，而不是直覺。

## 三、謬誤與修辭策略

需注意：許多被列為謬誤的說法，在**修辭**或**啟發式**情境中是有用的。

**範例**：訴諸多數在風險評估中是合理啟發式（多數專家的共識通常有資訊價值），但作為嚴格證明則不成立。區分二者，才能正確地批評而不濫用。

## 四、謬誤的偵測與防範

1. **形式化**：把論證寫成符號，檢查是否落入已知的無效形式。
2. **反例搜尋**：為每一步尋找使前提真而結論假的情境。
3. **權重檢查**：分辨「支持強度」與「真值」。

**範例**：把「所有人都會死，所以蘇格拉底會死」形式化後，可以直接檢查其為有效（Barbara 形式）；而「所有人都會死，所以蘇格拉底會贏」雖同樣形式有效，但結論的真值需另外考察——這說明形式有效性只保證「前提真則結論真」，不保證前提為真。

## 六、容易混淆之處

- 犯謬誤**不等於**結論必錯；謬誤涉及推論步驟，不是結論。
- 「謬誤」有時被當作修辭武器使用，需以形式化分析為準。

## 關鍵術語速查

| 術語 | 一句話解釋 |
| --- | --- |
| 肯定後件 | 由「若 P 則 Q」與 Q 推出 P 的無效形式 |
| 否定前件 | 由「若 P 則 Q」與非 P 推出非 Q 的無效形式 |
| 實質謬誤 | 推論形式可能有效，但內容相關性有問題的錯誤 |
| 形式謬誤 | 推論結構本身無效的錯誤 |
| 稻草人 | 把對方立場扭曲成較弱版本再加以反駁 |
| 滑坡謬誤 | 把可能的連鎖後果當作必然後果 |

## 七、謬誤的處理原則

1. **先形式化再批判**：把論證寫成符號，確認推論步驟確實無效。
2. **區分結論與推論**：推論形式無效不代表結論為假。
3. **考慮脈絡**：許多謬誤在啟發式決策中是有用的（訴諸多數、類比推理）。
4. **避免武器化**：把謬誤標籤當作修辭工具會反過來損害理性對話。

**範例（同一結構的兩種評價）**：「經驗豐富的醫師通常診斷較準確，因此應優先由資深醫師看診」在形式上並非謬誤，而是一種可靠度推理；但若省略了「通常」並推成必然，便是量詞的濫用。區分二者需要回到前提的量化範圍。
