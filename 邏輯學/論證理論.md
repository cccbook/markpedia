# 論證理論

> 隸屬：[邏輯學]　·　狀態：初稿

> 對應維基百科：[English Wikipedia: Argumentation theory](https://en.wikipedia.org/wiki/Argumentation_theory)

論證理論（argumentation theory）研究的是**論證**——有前提、有主張、有推理規則的整體結構——以及一個論證何時可被接受。與形式邏輯不同，它處理的通常是不完全的前提、可能為真的命題，以及需要權衡的實踐考量。

它是 [邏輯學] 走向日常推理、法律推理與人工智慧推理的橋樑。

## 一、論證的結構

Toulmin 模型把論證拆成六個部件：

| 部件 | 說明 | 範例 |
| --- | --- | --- |
| 主張（claim） | 要論證的結論 | 學校應禁止帶手機 |
| 資料（data） | 支持主張的事實 | 學生分心程度與手機使用相關 |
| 推理規則（warrant） | 資料為何支持主張 | 分心會降低學習成效 |
| 限定語（qualifier） | 限縮主張的條件 | 「在多數情況下」 |
| 駁斥（rebuttal） | 對方可能的反駁 | 學校無權管私人用品 |
| 限定（limitation） | 主張的適用範圍 | 僅限高中階段 |

**範例**：若只陳述「手機使用與分心相關」而不提供推理規則與駁斥，聽者無從評估論證的強度——這說明自然語言論證的結構性元素不可省略。

## 二、有效性、可接受性與權衡

| 概念 | 判準 | 適用 |
| --- | --- | --- |
| 有效性 | 前提為真時結論是否必真 | 形式邏輯 |
| 可接受性 | 論證在整體辯論中是否站得住 | 論證理論 |
| 權衡 | 支持與反對理由的相對強度 | 實踐決策 |

**範例**：「所有抽菸者都會得肺癌，因此張先生（抽菸）會得肺癌」在形式上有效，但醫學上更嚴謹的表述會加入基準率與風險權衡——這是從有效性走向可接受性的典型調整。

## 三、謬誤與無效推論

[謬誤學] 系統整理常見的無效推論形式，如肯定後件、否定前件、訴諸權威等。

**範例（肯定後件）**：「若下雨則地濕；地濕了；所以下雨了。」此形式在形式上無效——洒水器也會讓地濕。

## 四、辯論框架

Dung 的辯論框架（argumentation framework）以「攻擊關係」比較多個論證的可接受性。

- 論證集合 $AR$ 。
- 攻擊關係 $\mathrel{\mathord{\to}}$ ： $A \to B$ 表示 $A$ 攻擊 $B$ 。

在此框架上定義可接受性的公理（無循環、避免自我防衛、可被反駁者被排除），再以最小封閉集給出語意。

**範例**：三個論證—— $A$ ：「該政策有效」、 $B$ ：「該政策無效」、 $C$ ：「證據不足故不該推論」。若 $A \to C$ 且 $C \to B$ ，則 $B$ （對政策不利的結論）被排除，而 $A$ 保持可接受。這正是辯論框架處理「攻擊者本身被攻擊」的方式。

## 五、举证責任與對話

| 概念 | 說明 |
| --- | --- |
| 舉證責任 | 誰必須先提供理由 |
| 對話的優先次序 | 誰的論證先被檢驗 |
| 反證與卸責 | 對方舉證不成立時的處理 |

**範例**：在科學的「異常現象—對抗假設—新假設」對話中，異常現象承擔舉證責任；當原假設無法解釋異常時，負擔轉移給新假設。這套對話規則正是 [邏輯與語言] 中預設推理的一部分。

## 六、與相鄰分類的關聯

- [論證有效性]：形式有效性在自然語言中的延伸。
- [謬誤學]：無效推論的系統整理。
- [辯論推理]：攻擊關係與可接受性。
- [舉證責任]：對話結構中的權責分配。
- [語意論]：為自然語言提供形式語意。

## 七、容易混淆之處

- 論證理論**不是**放棄形式性，它用可接受性取代有效性作為核心判準。
- 「謬誤」指推論形式無效，不必然指結論為假。
