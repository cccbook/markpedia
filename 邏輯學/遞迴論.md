# 遞迴論

> 隸屬：[邏輯學] › [數理邏輯]　·　狀態：初稿

> 對應維基百科：[中文維基百科：遞迴論](https://zh.wikipedia.org/wiki/%E9%80%92%E5%BD%92%E8%AE%BA)　·　[English Wikipedia: Computability theory](https://en.wikipedia.org/wiki/Computability_theory)

遞迴論（recursion theory）研究「可計算」這個概念：哪些函數可以由演算法算出、哪些問題可以由機器判定、哪些集合可以由機器辨認。它源於 Church 與 Turing 在 1930 年代對可計算性的獨立定義，並以 Church-Turing 命題證明兩者等價。

它是數理邏輯中**最直接連接電腦科學**的分支：可判定性的邊界，就是軟硬體工程能走多遠的邊界。

## 一、可計算函數

遞迴函數（recursive function）以自然數為輸入與輸出，由三種基本運算封閉而成：

1. 零函式 $z(n) = 0$ 。
2. 後繼函式 $s(n) = n + 1$ 。
3. 投影函式 $p_i^{(n)}(n_1, \dots, n_n) = n_i$ 。
4. 原始遞迴：若 $f$ 是遞迴的，則 $\mu(f, g)$ 也是。

**範例**：加法 $add(m, n)$ 可定義為 $\mu$ 反覆執行「加一」直到第一個參數耗盡；乘法 $mul(m, n) = \mu(h, k)(k = 0, h = add(m, k))$ 。這說明常見運算都能由最小算術出發建構。

## 二、Church-Turing 命題

**命題**：直覺上可計算的函數恰為遞迴函數。

**範例（等價表述）**：以下三者等價——(a) 可被某台電腦計算；(b) 可被某個 Turing 機器計算；(c) 是遞迴函數。

這條命題的深遠影響是：**「可計算」不再取決於機器種類**。今日的電腦、手机與超算只是不同的 Turing 機器，其能力邊界相同。

## 三、不可判定性

**定理（Church，1936）**：一階邏輯的有效性不可判定。

**範例（不可判定問題的典型）**：判定「某 Turing 機器是否會停止」的停機問題不可判定。若有通用演算法，則可構造矛盾：令機器 $M$ 在輸入 $n$ 時，若 $H(n)$ 說「機器 $n$ 不停」就停、若說「停」就不停，則 $H(M)$ 必自我矛盾。

**範例（不可判定性的傳遞）**：許多工程問題（如程式的終止性、模板匹配、格柵問題）都藉由歸約到已知的不可判定問題而被證明不可判定。

## 四、可判定片段

不可判定是整體性質，片段則往往可判定：

| 片段 | 判定方法 |
| --- | --- |
| 命題邏輯 | 真值表（指數時間） |
| 一階 Horn 子句 | 飽和演算法（多項式時間） |
| 單一變數片段 | 量詞消去 |
| 有限論域 | 有限模型檢查 |

**範例**：Horn 子句的判定用飽和法——把已知事實反覆與規則結合，直到不再產生新事實；若目標出現在飽和集中則成立，否則不成立。Prolog 的推理引擎正是此法。

## 五、可數性與階層

遞迴論不只研究「能不能算」，還研究「有多難算」：

- **算術階層**：可判定性在自然數上的分層（ $\Sigma_0, \Sigma_1, \dots$ ）。
- **圖靈階層**： $\Sigma^0_1$ （半可判定）、 $\Pi^0_1$ 、 $\Delta^0_2$ 等。
- **相對可計算性**：以 oracle 機器分層，如相對可計算性對應不可判定性。

**範例**：停機問題屬於 $\Sigma^0_1$ （存在有限步驟可證明停機），其補集屬於 $\Pi^0_1$ ；兩者都無法在沒有 oracle 的機器上完全判定。

## 六、與相鄰分類的關聯

- [可判定性]：遞迴論的核心應用面。
- [不完備性定理]：與不可判定性共同構成形式化的雙重邊界。
- [SAT求解]：把不可判定的邏輯問題限制在可判定片段的成功案例。
- [模型論]：模型存在性問題的複雜度同樣由遞迴論分析。

## 七、容易混淆之處

- 遞迴論與 [計算機網路] 、[程式設計] 不同：前者研究的是抽象的計算能力邊界。
- 「不可判定」指沒有**通用**演算法，個別實例仍可能判定。

## 六、計算能力的三個等價層次

| 層次 | 模型 | 代表人物 |
| --- | --- | --- |
| 函數遞迴 | 原始遞迴、 $\mu$ 運算 | Church、Herbrand |
| 機器模型 | Turing 機器、lambda 演算 | Turing、Church |
| 組合邏輯 | SKI 組合子 | Schönfinkel |

三者的等價性就是 Church-Turing 命題的實質內容。

**範例（以 lambda 演算表示布林邏輯）**：真值可寫成 $\lambda x.\lambda y.x$ （真取第一個參數）與 $\lambda x.\lambda y.y$ （假取第二個），而「非」可寫成 $\lambda p.\lambda x.\lambda y.p\,y\,x$ 。這說明 lambda 演算足以表達全部可計算函數。

## 七、理論到實務的傳遞

1. **不可判定性**告訴我們哪些問題不該指望通用解法。
2. **可判定片段**告訴我們哪些限制能換來演算法。
3. **複雜度理論**進一步告訴我們，即使可判定，實用性仍需分析。
4. **工程實例**：SAT 的 NP-完全性（Cook-Levin 定理）說明它雖可判定，卻沒有多項式演算法——這正是 SAT 求解器工程投入數十年持續改良的原因。

**範例**：現代 SAT 求解器（CDCL）在實務上表現極佳，儘管最壞情況仍是指數時間；這說明複雜度理論給的是最壞情況界限，而實務效能由結構與啟發式決定。
