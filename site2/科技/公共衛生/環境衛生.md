# 環境衛生

> 隸屬：[公共衛生]　·　狀態：初稿

> 對應維基百科：中文維基百科無對應條目　·　[English Wikipedia: Environmental health](https://en.wikipedia.org/wiki/Environmental_health)

環境衛生是公共衛生中**處理人體之外一切健康決定因素**的分支：飲水與污水、空氣、固體廢棄物、食品安全、職場暴露、病媒（蚊、鼠、蟑）與住居環境。WHO 估計，全球每年約有一千三百萬人死亡可歸因於可避免的環境因素——不安全飲水、空氣污染、職業傷害等。它的哲學是「在源頭切斷」：與其治療腹瀉病童，不如修好供水系統；與其治療肺癌，不如降低 PM2.5 濃度。這也使環境衛生成為公共衛生中**成本效益比最高**的一環：歷史學者常說，自來水與下水道對平均餘命的貢獻大於所有藥物的總和。

## 技術與理論的關聯

- **劑量—反應關係是核心工具**：任何毒物的風險都取決於濃度與暴露時間，環境衛生標準（如飲水每公升硝酸鹽上限 $50$ 毫克）就是建立在劑量—反應曲線上的保護閾值。
- **水衛生鏈**：水源保護 → 淨水（混凝、過濾、消毒）→ 配水管網 → 污水收集與處理——任何一環破洞都會讓病原重回人口。
- **空氣污染的顆粒物分級**：PM10 與 PM2.5（粒徑小於 2.5 微米）可深入肺泡與血管，與心血管疾病、肺癌的死亡率上升呈穩定相關；空氣品質指標（AQI）把濃度轉成行動建議。
- **病媒控制的整合策略**：不是隻靠噴藥，而是結合清除孳生源（積水容器）、物理防護（蚊帳、紗窗）、生物防治（魚類食孑孓）與化學防治，避免抗藥性。
- **風險評估四步**：危害確認 → 劑量反應評估 → 暴露評估 → 風險特徵描述——把「這個污染物危不危險」變成可計算的程序。
- **環境正義議題**：污染設施（焚化爐、工業區）的選址常落在弱勢社區，暴露風險的分配不均是環境衛生與社會學的交會點。

## 範例：1854 年布羅德街水井——環境衛生的誕生現場

1. **疫情**：[1854年] 倫敦蘇活區霍亂爆發，十天內五百餘人死亡，死亡率高得驚人。
2. **調查**：[約翰斯諾] 逐戶標記死亡位置，發現死亡病例密集圍繞布羅德街公共水井，而附近釀酒廠工人（每日自飲啤酒，幾乎不喝水）幾乎無人罹病。
3. **介入**：他說服當局拆除水井幫浦把手，疫情隨之消退；事後追查發現污水坑滲漏污染了井水。
4. **因果機制**：當時主流「瘴氣說」認為臭氣致病，斯諾卻用地理分佈與飲水行為的對比證明**病原經水傳播**——這是「環境介質（水）—暴露（飲用）—疾病」模型的第一次實證。
5. **後續工程**：巴扎爾杰特（Bazalgette）主持的倫敦下水道系統於 1870 年代完成，把污水與飲水分離，霍亂從此在倫敦絕跡——環境衛生工程改寫了城市的死亡結構。

## 前因後果

- **前因**：工業革命把人口擠進缺乏衛生基礎設施的城市，霍亂、傷寒經水傳播；環境衛生正是對這場都市危機的制度性回應。
- **後果**：水與衛生工程的成功使傳染病死亡率銳減，公共衛生的重心得以轉向慢性病與健康促進；同時，新的環境威脅（PM2.5、PFAS、氣候變遷下的熱浪與病媒北移）持續擴大本分支的議程。

## 與相鄰分類的關聯

- 與 [公共衛生系統] 的關係：環境監測（水質檢驗、空氣測站）是疾病監測之外的另一套早期警報。
- 在上位概念 [公共衛生] 中，本條目是最上游的初級預防；與 [健康促進] 相比，環境衛生改造「人的周圍」，健康促進改造「人的行為」。
- 與 [污染防治] 的關係：污染防治是工程與法規端的同源學科，兩者共享檢測方法與排放標準。
- 與 [永續發展] 的關係：SDG 指標中的「安全飲水與衛生設施」直接對應環境衛生。

## 容易混淆之處

- **環境衛生不等於環境保護**：環保以生態為最終目的，環境衛生以人類健康為最終目的；兩者常同向，但權衡時可能分歧（例如殺蟲劑對健康與生態的取捨）。
- **瘴氣說的遺緒**：以為「聞起來臭纔有危險」——一氧化碳、無臭的 PM2.5 都是人聞不到的殺手；感官不可作為污染判準。
- **「天然」不等於安全**：砷污染的地下水、自然產生的黴菌毒素同樣致命，安全與否取決於劑量與暴露，不取決於來源是否天然。

## 技術要點

- 飲水三指標：餘氯（消毒持續性）、濁度（過濾成效）、微生物（大腸桿菌羣）。
- 空氣標準常用日均濃度：WHO 2021 年準則建議 PM2.5 年均不高於 $5$ 微克／立方公尺。
- 病媒控制優先次序：孳生源清除 → 物理阻隔 → 生物防治 → 化學防治。
- 廢棄物處理層級：減量 → 重用 → 回收 → 能源化 → 掩埋。
- 風險評估四步驟是任何污染物標準制定的必經程序。
- 氣候變遷屬環境衛生議題：熱浪、洪患與登革熱分佈北移都是健康影響。

## 常見的論爭

- **氯消毒與消毒副產物**：加氯有效殺菌但產生三鹵甲烷，致癌風險與微生物風險如何權衡——主流結論是先保微生物安全，再降副產物。
- **PM2.5 有無安全閾值**：流行病學研究顯示即使低濃度仍與死亡率相關，標準應設在「可達成的最低值」還是「無觀察效應值」，政策爭論不休。
- **環境正義**：污染選址與弱勢社羣的關聯是否應納入許可程序，涉及科學判斷與政治正義的界線。
