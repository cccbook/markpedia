# 急診體系

> 隸屬：[急診醫學]　·　狀態：初稿

> 對應維基百科：[中文維基百科：紧急医疗服务]　·　[English Wikipedia: Emergency medical services]

急診體系是讓「急救」變成制度的一切基礎建設：從民眾撥打求救專線，到救護車派遣與到院前照護，到醫院的檢傷分診、復甦室與加護病房，再到轉院與後送的醫療網路。它的核心洞見是：**急救的品質由體系決定，而不只是由個別醫師的技術決定**——一家醫院再有能力，如果派遣延遲、檢傷失準或轉院管道不通，黃金時間照樣流失。

## 技術與理論的關聯

- **求救專線與派遣是第一環**：統一號碼（如 119）接通後，派遣員以結構化提問判斷優先序，同時在線上指導呼叫者做心肺復甦——派遣員的每一次問答都可能決定心跳停止者的存活。
- **檢傷分診是急診的排序數學**：五級制（如台灣的急診檢傷分級）以生命徵象與主訴把病人分為復甦、危急、緊急、次緊急與非緊急；檢傷正確率是急診品質的核心指標。
- **急診科設定是動線工程**：救護車入口、復甦室、觀察區、隔離與動線分流（兒科、傳染病、精神科）的物理設計，直接影響處置速度與院內感染控制。
- **到院前照護分兩級模式**：「快送」模式儘快抵達醫院，「現場穩定」模式在現場完成氣道與循環處置；創傷偏快送、內科急症偏現場處置，各國體系在兩極間取捨。
- **醫療網路與分級轉送**：創傷中心、中風中心、心導管與創傷團隊的值班分布，讓重症被送往「能力正確」的醫院；繞過較近但能力不足的醫院（bypass）是體系設計的重要決策。
- **大量傷患是體系的壓力測試**：以檢傷（如 START 法：能走、能呼吸、脈搏與意識指令分類）在現場完成群體分流，指揮體系（ICS）統一救護、消防與醫院的調度。

## 範例：一起三車追撞的大量傷患應變

1. **通報與派遣**：第一通 119 來電回報多人受困；派遣中心同時派出救護車、消防與救災指揮車。
2. **現場檢傷**：第一支抵達的救護小組以 START 法檢傷——能走的（綠）自行集合；呼吸異常者先開通氣道（紅，優先後送）；無呼吸且開通後仍無呼吸者列黑（不做現場復甦，資源留給可救者）。
3. **指揮體系**：現場成立指揮站，統一指定後送醫院與人數配比，避免「所有傷患湧向最近一家醫院」的經典錯誤。
4. **醫院端啟動**：目標醫院接獲預警，啟動大量傷患代碼——檢傷前推到門口、清空復甦室、召回人力、啟動血液庫存。
5. **事後檢討**：以後送時間、檢傷準確率與醫院負載曲線做系統性檢討，把演習假設與真實表現對帳。
6. **核心教訓**：大量傷患的成功不是哪家醫院搶救出色，而是**現場分流、預警通報與分散後送**三件事同時做對。

## 前因後果

急診體系的現代化來自戰爭與災難的教訓：戰場傷患分級（triage）的經驗、社會對車禍與心臟病猝死的關注，催生了救護技術員制度與急診專科；而 1968 年之後緊急電話系統與無線電派遣的普及，把「民眾求助→救護車→醫院」串成閉迴路。反過來，體系的成熟又推動了 [創傷處置] 與 [復甦與特殊狀況] 的標準化——ATLS、大量傷患演習與時間指標（門到球囊、門到針）都以體系為前提，也以體系數據為改進依據。

## 與相鄰分類的關聯

- 與 [常見急症] 的關係：檢傷與派遣的設計直接服務於胸痛、中風等時限急症；急症的預後是體系品質的成績單。
- 與 [創傷處置] 的關係：創傷分級、繞道後送與轉診規則由體系決定，現場 ABCDE 由團隊執行，兩者缺一不可。
- 與 [公共衛生] 的關係：大量傷患、災害應變與全民急救教育（CPR 訓練、AED 部署）是公共衛生與急診的共享領域。
- 在 [急診醫學] 中，本領域是**骨架**：所有臨床技術都掛在體系的時間與資源上運作。

## 容易混淆之處

- **急救專線不是「叫車服務」**：派遣員的結構化問答是在評估優先序與給線上指引，配合回答能縮短派遣時間。
- **檢傷不是掛號**：檢傷以危急度排序，輕症等候是重症優先的制度代價；「等很久」不等於被忽略。
- **大量傷患時的檢傷倫理不同**：平常「盡一切努力救人」，大量傷患時轉為「最多人受益」的功利分配；黑級不是放棄，是資源的理性配置。
- **救護車不是愈快愈好**：超速本身就製造事故；風險控管的平穩駕駛與正確的現場處置常比快幾分鐘更重要。
- **急診擁塞是體系問題**：住院床滿使急診無法後送，擁塞的主因常在醫院其他環節，而非急診本身效率不彰。

## 技術要點

- 五級檢傷以生命徵象（體溫、心跳、呼吸、血壓、血氧、意識）加危險主訴評分，一級須立即處置、五級可等候。
- START 檢傷口訣：能走（綠）→ 呼吸（紅/黑）→ 灌流（繞脈與微血管回填）→ 意識指令（能否服從簡單指令）。
- 心跳停止的「生存之鏈」：及早求救、及早 CPR、及早去顫、進階照護與復甦後照護，前兩環在體系端。
- 公共場所 AED（自動體外去顫器）的部署與地圖化，把「黃金四分鐘」從救護車提早到路人手上。
- 中風與心肌梗塞的時間指標：門到針（血栓溶解）約三十分鐘、門到球囊（心導管）約九十分鐘，是醫院體系的硬指標。
- 大量傷患演習每年至少一次，且須納入跨機關（消防、警察、衛生）的聯合演練才有意義。

## 常見的論爭

- **到院前照護的快送與現場穩定之爭**：歐陸醫師到院前模式與英美技術員快送模式各有效果證據，成本與文化使其難有單一答案。
- **急診擁塞的解方**：加開急診床、留觀單元、住院流程改造與分級醫療強化，各政策的效果與代價仍在實驗。
- **繞道後送的成本**：重症繞過近端醫院提升預後，但拉長到院時間並掏空地區醫院的創傷經驗；網路設計的公平與效率難兩全。
