# 鼠疫桿菌

> 隸屬：[瘟疫大流行](瘟疫大流行.md) › [黑死病](黑死病.md)　·　狀態：初稿

> 對應維基wikipedia：[中文維基百科：鼠疫桿菌](https://zh.wikipedia.org/wiki/%E9%BC%A0%E7%96%AB%E6%A1%BF%E8%8F%8C)　·　[English Wikipedia: Yersinia pestis](https://en.wikipedia.org/wiki/Yersinia_pestis)

鼠疫桿菌（學名：*Yersinia pestis*）是造成鼠疫的致病細菌，也是理解黑死病、香港鼠疫及歷史上多次鼠疫大流行的核心微生物。
它原本主要在野生嚙齒動物與跳蚤之間循環，後來因貿易、戰爭、人口移動與城鎮化而反覆進入人類社會。
本條目位於 [瘟疫大流行] 的分類架構之下，並以細菌的起源、傳播機制、致病原理及防疫經驗作為主要討論範圍。

## 定義

鼠疫桿菌是一種短桿狀、可單獨生長的細菌，屬於革蘭氏陰性菌。
「革蘭氏陰性」是指經過革蘭氏染色後呈現粉紅色或紫色的細菌類型，與呈現藍紫色的革蘭氏陽性菌不同。
它屬於兼性厭氧菌，也就是能夠在有氧或無氧環境中生長，並且不會形成芽孢。
鼠疫桿菌不會自行製造大部分生存所需的養分，必須利用宿主提供的環境繁殖。

從疾病分類來看，鼠疫桿菌造成的是一組具有不同傳播方式的臨床表現，而不是只有單一症狀。
其中最常見的是腺鼠疫、敗血症鼠疫與肺鼠疫。
腺鼠疫的特徵是發燒及疼痛的腫大淋巴結，淋巴結腫塊在早期文獻中常被稱為「鼠疫腫」。
敗血症鼠疫是細菌大量進入血液並在全身散布的型態，可能出現發燒、內臟損傷、凝血異常與休克。
肺鼠疫則影響肺部，可由患者附近的含菌微粒傳播，是最容易發生人際傳播的型態。

鼠疫桿菌具有多項促使宿主發病的分子構造。
這些構造包括可將蛋白質注入宿主細胞的第三型分泌系統、抗吞噬作用的 F1 莢膜，以及有利於血管周圍擴散的蛋白酶。
這些因素使它不只是一種能在環境中存活的細菌，也是一種能有效侵入血液、淋巴與肺部的專門病原體。

## 歷史起源與關鍵人物

### 演化起源

現代分類與古代 DNA 研究顯示，鼠疫桿菌與假腸結核桿菌具有接近的共同祖先。
所謂古代 DNA，是從古代遺骸或保存於特殊環境中的生物材料中取得的遺傳物質。
2010 年代後，研究人員在歐亞大陸數千年前的人類遺骸中確認了鼠疫桿菌。
其中，約四千八百至五千年前的歐洲材料，是目前已知最早的明確證據之一。

這些發現改變了過去將鼠疫視為十四世紀突然出現的觀點。
較早的鼠疫可能在歐洲及亞洲多次出現，後來的中世紀疫情只是更大規模傳播的階段之一。
古代病原體分析也支持多次移入的模型，而非所有黑死病病例都源自同一條單一路徑。
現今許多中世紀及現代支系，可追溯至中亞天山一帶的祖先樣本，但更精確的地理起源仍在研究中。

交易路線、牧業活動及野生嚙齒動物的移動，可能促成宿主與跳蚤的長期接觸。
人口增加、城鎮擴張及糧食儲藏，也讓鼠類更容易在人類居住區內繁殖。
因此，鼠疫桿菌的演化並非單由人類活動造成，而是自然宿主、媒介、病原體與社會環境共同作用的結果。

### 黑死病時期

十四世紀中葉的疫情通常以 1347 年抵達歐洲為重要起點。
船隻把受感染者、鼠類與跳蚤帶入地中海港口後，疫情沿貿易路線向北擴張。
1347 年至 1353 年間，鼠疫在歐洲造成極高比例的人口死亡。
傳統估計認為，歐洲約有百分之三十至五十的人口死亡；更廣泛的全球估計則常落在七千五百萬至二億人之間。
由於中世紀人口、戶籍及疾病分類資料殘缺，不同估算之間存在很大差距。

中世紀歐洲主要受到屋頂鼠或黑鼠影響，而不是今天常見的褐家鼠。
褐家鼠直到十八世紀才廣泛進入歐洲，因此不能用十九世紀城市褐鼠的情況直接解釋 1347 年疫情。
船上貨物、鼠類、其他野生宿主、人體寄生虱及人與人之間的呼吸道傳播，可能共同促成傳播。
近代研究因此將黑死病視為包含鼠蚤傳播與肺鼠疫人際傳播的複合疫情，而非單純由一批「染鼠船」造成的故事。

### 近代發現

十九世紀末的香港疫情，使醫學界終於能直接分離並研究鼠疫桿菌。
下列人物在病原體、媒介與防疫方法的確認過程中具有關鍵地位。

| 人物 | 年份 | 主要貢獻 |
| --- | --- | --- |
| 亞歷山大．耶爾辛 | 1894 年 | 在香港從患者材料中分離出鼠疫桿菌，並描述其微生物特徵。 |
| 北里柴三郎 | 1894 年 | 在香港獨立觀察到鼠疫桿菌，其研究推動日本細菌學與傳染病學發展。 |
| 保羅－路易．西蒙 | 1898 年 | 在印度提出並以實驗支持鼠類與鼠蚤參與傳播的證據。 |
| 伍連德 | 1910 至 1911 年 | 主持東北肺鼠疫防治，推動病例隔離、醫療管理、交通管制及使用紗布口罩。 |

耶爾辛與北里柴三郎在相近時間內得到細菌學證據，說明當時病原體鑑定已進入可重複驗證的階段。
西蒙對鼠蚤的研究則補上了「細菌如何由動物宿主進入人類」的傳播環節。
這些發現共同取代了單靠.bad air 或惡劣環境解釋鼠疫的觀點，使防疫措施能針對宿主、媒介及感染途徑設計。

## 技術要點

### 宿主與傳播媒介

鼠疫桿菌具有多個已知自然宿主，包括家鼠、旱獺及多種野生嚙齒動物。
「自然宿主」是指在一般生態環境中長期攜帶病原體的動物。
其最重要的媒介是蚤類，其中印度鼠蚤或東方鼠蚤（*Xenopsylla cheopis*）最為知名。
不同地區的鼠疫仍可能由其他蚤類及野生小型哺乳動物維持，因此只控制單一鼠種並不足以涵蓋所有風險。

典型的鼠蚤傳播可分成數個互相連接的步驟。
首先，鼠疫桿菌經由受感染跳蚤叮咬而進入鼠類血液，並在鼠類體內增殖。
受感染鼠類死亡後，失去宿主的跳蚤會尋找其他動物或人類。
帶菌跳蚤吸血時，細菌可因前胃形成生物膜而增加，生物膜是附著於表面、由微生物及其分泌物構成的群聚層。
跳蚤的消化道因此受到阻塞，之後叮咬時可能將菌液反流至宿主傷口。
人類若在這段過程中遭帶菌跳蚤叮咬，便可能發生腺鼠疫。

黑鼠與褐家鼠的年代差異，是辨識中世紀疫情的重要線索。
現代都市環境中的褐色鼠群雖可能參與傳播，但不能直接套用於 1347 年。
跳蚤、宿主及病原體的移動也不完全同步，疫情可能先在鼠類間流行，再因宿主死亡而轉向人類。

肺鼠疫可由患者呼出的含菌微粒近距離進入他人呼吸道。
近距離飛沫、氣膠或污染物均可能參與傳播，實際風險取決於通風、距離、咳嗽及臨床處置。
因此，肺鼠疫需要比腺鼠疫更嚴格的病例隔離、呼吸道防護及接觸者追蹤。

### 分子致病機制

第三型分泌系統是鼠疫桿菌的重要武器。
它可利用類似注射器的蛋白質複合體，將 Yop 效應蛋白送入宿主吞噬細胞。
這些效應蛋白會干擾細胞訊息傳遞、細胞骨架與免疫反應，使細菌得以在吞噬作用後存活。

F1 莢膜是另一項關鍵致病因子。
它由蛋白質抗原組成，可在哺乳動物體內降低細菌被吞噬細胞清除的機會。
F1 相關基因位於常稱為 pFra 或 pYMT 的質體上。
「質體」是細菌染色體之外、能自行複製並攜帶基因的小型 DNA 分子。

pPCP 質體上的 pla 基因可編碼蛋白酶。
該蛋白酶能分解纖維蛋白及其他蛋白質，有助於細菌在宿主組織內擴散，也會干擾跳蚤體內的凝血與血液流動。
因此，同一分子特性可以同時促進宿主內感染和媒介內生存。

不同致病因子受到溫度與環境調控。
在哺乳動物體內，第三型分泌系統、F1 莢膜及其他免疫逃避機制較活躍。
在蚤體內，則更有利於生物膜形成與腸道定殖。
這種可塑性使鼠疫桿菌能利用兩種截然不同的宿主環境。

染色體與質體上的移動基因、重組及插入突變，也提供了快速適應的機會。
它們可能改變抗原表現、藥物敏感度及對不同媒介的適應能力。
這也是現代監測需要同時追蹤細菌基因組與臨床流行的原因。

### 臨床表現

腺鼠疫的典型病程可突然出現發燒、寒顫、虛弱及淋巴結疼痛。
受影響部位常為鼠蹊部、腋下或頸部，腫大的淋巴結可能出現壓痛與中心壞死。
未接受適當治療時，腺鼠疫的死亡率約可達百分之三十至六十。

敗血症鼠疫可由腺鼠疫發展，也可能一開始就出現。
其徵狀包括高燒、心跳急促、低血壓、凝血異常及器官衰竭。
細菌若進入腦膜或肺部，病情可迅速轉為腦膜炎或肺鼠疫。

肺鼠疫可能出現咳嗽、呼吸困難、咯血及快速進展的呼吸衰竭。
其潛伏期通常約為一至六天，發病後惡化很快。
未治療的肺鼠疫死亡率可接近百分之百，但，及早使用有效抗生素能大幅降低死亡風險。

腹鼠疫、扁桃體鼠疫及腸鼠疫是較少見的表現。
這些名稱指出病灶或主要症狀所在位置，不代表由不同病原體造成。
臨床上仍須結合症狀、暴露史、流行地區與實驗室檢查判斷。

### 診斷方法

最簡單的臨床線索是發燒、淋巴結腫大或肺炎，並結合近期到訪疫區、鼠蚤暴露或接觸病例。
對這些高危患者，醫療人員不應因等待完整檢查而延誤治療。

血液或病灶抹片的革蘭氏染色有時可見兩端濃染的「安全別針」形態。
這項形態可提供線索，但其他細菌也可能出現相似外觀，不能單獨作為確診依據。
微生物培養能分離並鑑定菌株，但必須由具備適當生物安全條件的實驗室操作。

聚合酶連鎖反應可檢測鼠疫桿菌特有序列，pla 基因是常見目標之一。
血清抗體檢測則可協助回溯性調查或判斷曾經感染。
在疫情調查中，菌株全基因體定序可用於比較傳播路徑，並辨認可能的共同來源。

### 治療與抗藥性

鼠疫需要儘早使用抗生素，常選用藥物包括慶大黴素、鏈黴素、環丙沙星、左氧氟沙星及多西環素。
氯黴素可在特定情況下作為替代或輔助藥物。
實際選擇應依當地治療指引、病情、藥物可取得性及藥敏試驗決定。
所謂藥敏試驗，是將分離出的菌株暴露於不同藥物，觀察其生長是否受到抑制。

部分地區已發現對多種抗生素具有抵抗力的鼠疫桿菌。
2007 年起，馬達加斯加的監測即確認了多重抗藥性菌株。
這代表單靠傳統抗菌藥物並不能消除風險，藥物使用、疫情監測及公共衛生隔離仍不可省略。

抗病毒藥物不能直接治療鼠疫桿菌感染。
雖然肺鼠疫與某些呼吸道病毒疾病的早期症狀相似，治療方向卻完全不同，因此及早鑑別具有實際意義。
[抗病毒治療] 的概念在此處應與細菌性疾病的抗生素治療清楚區分。

### 防疫措施

鼠疫防疫需要同時處理患者、媒介、宿主及社會傳播風險。
病例隔離、呼吸道防護、接觸者追蹤及必要的採樣送驗，是控制肺鼠疫的基本工作。
腺鼠疫患者則需處理傷口、衣物與可能受感染的跳蚤。

滅鼠措施應與防蚤、清除食物殘渣及改善住屋衛生共同推行。
單純大量使用鼠藥可能殺死捕食者，若未處理鼠類屍體與受感染跳蚤，也可能提高人類接觸風險。
長期控制通常更重視垃圾管理、糧食密封、鼠洞阻隔及生態友善的綜合治理。

疫苗是降低高風險族群疾病負擔的另一條路徑。
截至本條目初稿，世上尚無獲廣泛採用、能針對所有流行菌株提供一致保護的人類鼠疫疫苗。
既有研究曾評估減毒活菌疫苗，以及以 F1、V 等抗原為基礎的重組疫苗。
這些研究證明免疫反應可以被誘導，但廣泛使用仍需要安全性、效力、製程及跨地區適用性的資料。

教育與社區參與可降低疫情初期延誤就醫、隱瞐病例及自行處理感染動物所帶來的風險。
[防疫措施] 與 [預防教育] 必須同時處理病原學資訊與公眾行為，才能形成可持續的防線。

## 範例

### 1347 年抵達歐洲的鼠疫

1347 年，來自黑海及高加索地區的船隻抵達義大利墨西拿等地。
船上的人、鼠類與跳蚤把疫情帶入港口，之後再沿海路與陸路擴散至歐洲各地。
這次傳播不是單純由單一船隻或單一種鼠造成，而是包含反覆的人際傳播。

1347 年至 1353 年，歐洲約有百分之三十至五十的人口死於相關疫情。
部分傳統研究更把全球死亡人數估為七千五百萬至二億人。
這些數字雖有巨大不確定性，仍足以說明此次疾病對勞動、農業、稅收、宗教與政治秩序造成的衝擊。
[黑死病] 是這段特定歷史疫情及其後果的名稱，而 [1347年] 則是進入歐洲的常用年代錨點。
高死亡率造成的勞動力短缺與 [歐洲人口崩跌] 成為理解 feudalism、城市制度及歐洲社會變遷的重要背景，但人口衝擊並非所有制度變化的唯一原因。

### 1894 年香港鼠疫

1894 年，香港發生急性鼠疫疫情。
當地約有 2,500 人死亡，顯示這不是只存在於中世紀歐洲的遠古疾病。
殖民地政府因而組成調查團，並邀請巴斯德研究所的微生物學家參與研究。

亞歷山大．耶爾辛在 1894 年從患者材料中分離出致病細菌，北里柴三郎也在相近時間得到相關發現。
這項突破使疾病可以從臨床描述轉化為可培養、可實驗及可檢驗的微生物學對象。
[香港鼠疫] 因而同時成為病原體發現史、殖民公共衛生史及實驗醫學形成的關鍵案例。

### 1910 至 1911 年東北肺鼠疫

1910 年，肺鼠疫由滿洲里一帶向中國東北及哈爾濱等城市擴散。
這次疫情常被估計造成約六萬人死亡，顯示肺鼠疫的人際傳播可在短時間內形成嚴重城市災難。
不同史料對病例與死亡的認定並不完全一致，因此數字應視為歷史估計，而非現代 surveillance 系統下的精確統計。

伍連德主持防治工作，推行病例隔離、醫院管理、消毒、交通管制及工作人員防護。
他也推廣使用紗布口罩，這是早期呼吸道防護的重要嘗試。
這些措施不能全部歸因於單一器具，檢疫、病例發現、隔離與限制移動同樣重要。
此案說明 [防疫措施] 必須依病原體的實際傳播方式選擇，而不是沿用上一場疫情的固定程序。

### 2017 年馬達加斯加疫情

2017 年，馬達加斯加發生近代最大規模的鼠疫疫情之一。
官方公布約有 2,400 名病例及超過 200 人死亡，部分地區因交通、醫療資源不足而難以迅速控制疫情。
這次事件顯示鼠疫並未隨著抗生素現代化而消失，社會不平等、脆弱醫療系統與氣候因素仍會影響風險。

該國既有的抗藥性監測也讓病例治療變得更複雜。
公共衛生團隊必須同時進行病例治療、主動搜尋、接觸者管理、鼠蚤控制與社區溝通。
世界衛生組織近年公開概述常以全球每年約 1,000 至 5,000 例鼠疫作為估計範圍。
這些數字提醒公共衛生體系維持長期監測，而不是只在疫情已經擴散後才建立能力。
對 [新興傳染病] 與再浮現疾病而言，能源、運輸及實驗室能力同樣重要。

## 前因後果與互相驅動

鼠疫桿菌最初的出現，是細菌演化、野生宿主生態與跳蚤媒介共同作用的結果。
數千年來，它能在鼠類與蚤類之間維持低調而持續的循環，不必依賴人類。
當農耕、運輸和城鎮把鼠類帶入更密集的人類生活環境，宿主、媒介與病原體才開始形成對人類更具威脅的傳播鏈。

這種傳播鏈曾形成難以跨越的防治瓶頸。
人們早期雖能觀察到城市死亡與船舶、糧食及鼠類有關，卻不知道真正的致病因子和傳播途徑。
耶爾辛與北里柴三郎的細菌分離解決了「病原體是什麼」的問題。
西蒙及後續研究則解答「細菌如何移動」的問題，使定向滅鼠、改善衛生及處理媒介成為可行策略。
抗生素出現後，治療瓶頸又由「無法控制感染」轉為「能否及時用藥及處理抗藥性」。

黑死病造成大量人口死亡、勞動力短缺與經濟結構改變，也促成城市衛生、公共紀錄與隔離制度的重要發展。
瘟疫同時曾被用來迫害猶太人、移民、窮人及其他被指為「帶病者」的群體。
這些社會後果說明有效防疫不能只追求病例數下降，也必須防止污名、差別待遇及權力濫用。

中世紀港口、十九世紀鐵路城市與現代航空運輸會把鼠疫帶往新的地區。
人口密集可讓腺鼠疫透過跳蚤擴散，而肺鼠疫則能利用人際接觸形成更快速的傳播。
因此，貿易可能放大疫情，疫情又會促使政府加強邊境檢查、港口管理與運輸限制。
這些措施若缺乏科學依據或一致標準，也可能造成不必要的經濟與人權成本。

抗生素能降低死亡率，但過度或不當使用會篩選出更具抗藥性的菌株。
抗藥性增加後，治療需要更多區域性資訊、藥物取得及感染控制，於是形成新的瓶頸與政策需求。
現代監測、藥敏試驗和病原體全基因體定序，正是為了減少這種資訊落差。

環境、社會與醫療措施也會互相回饋。
洪水、乾旱或糧食歉收可能改變鼠群密度與跳蚤活動，住宅擁擠及醫療延誤則增加人傳人的機會。
良好衛生及快速治療可降低疫情，回饋則是政府更願意投資疾病監測、公共衛生人員及實驗室能力。
[疫苗] 與 [預防教育] 若能在風險升高前運作，便可進一步減少後端的病例搜尋、隔離與治療負擔。

從科學史看，「鼠疫桿菌」這個明確概念是在反覆疫情造成的人命損失與治理需求中形成的。
它不僅是一種細菌名稱，也代表以病原體、媒介、宿主和社會環境共同分析流行病的 方法。
這套方法後來擴展到霍亂、流感、SARS、MERS、COVID-19 及其他新興感染病的研究與防治。

## 與相鄰分類的關聯

| 相鄰概念 | 區別或連結 |
| --- | --- |
| [瘟疫大流行] | 鼠疫桿菌可造成跨地區的大流行，但「鼠疫」也包括較局部或反覆出現的疫情。 |
| [黑死病] | 黑死病是十四世紀歐洲鼠疫大流行及其社會後果，不等同於鼠疫桿菌的全部歷史。 |
| [霍亂與鼠疫] | 兩者都曾造成城市與國際流行，但病原、傳播途徑、臨床症狀及防治方法不同。 |
| [流感] | 流感由流感病毒引起；鼠疫桿菌則是細菌，肺鼠疫雖可呼吸道傳播，病原學完全不同。 |
| [愛滋病] | 愛滋病由人類免疫缺乏病毒造成，是慢性病毒感染；它與鼠疫不屬同一病原或疾病類別。 |
| [新興傳染病] | 鼠疫是古老的再浮現傳染病，抗生素抗藥性與環境變化使「新興」一詞也可用於其現代風險。 |
| [1347年] | 1347 年常用來標誌鼠疫進入歐洲並引發黑死病高死亡期的關鍵年份。 |
| [歐洲人口崩跌] | 黑死病造成歐洲人口急劇下降，進而影響勞動、農業、稅收及社會制度。 |
| [霍亂] | 霍亂由霍亂弧菌引起，主要經污染水源或食物傳播；鼠疫桿菌則依賴宿主、跳蚤及呼吸道途徑。 |
| [香港鼠疫] | 1894 年香港疫情促成鼠疫桿菌的分離與鑑定，是現代鼠疫學的起點之一。 |
| [防疫措施] | 鼠疫防治需結合病例隔離、接觸者管理、滅鼠、防蚤、衛生及藥物治療。 |
| [1918年] | 1918 年主要指流感大流行，不是鼠疫疫情；兩者的致病病原及流行機制不同。 |
| [疫苗] | 鼠疫疫苗仍處於研發與有限使用階段，尚無廣泛採用的通用人類疫苗。 |
| [季節性流感] | 季節性流感是週期性病毒呼吸道感染；腺鼠疫與肺鼠疫則分別涉及淋巴結及肺部細菌感染。 |
| [起源] | 病原體起源涉及古代 DNA、宿主遷徙與貿易路線，和人類開始辨識鼠疫是不同層次的歷史問題。 |
| [抗病毒治療] | 鼠疫桿菌是細菌，治療核心為抗生素與支持性療法，而非抗病毒藥物。 |
| [預防教育] | 避免處理死鼠、及早就醫、遵守隔離與報告規定，可降低延誤及歧視造成的風險。 |
| [SARS] | SARS 由 SARS 冠狀病毒引起；肺鼠疫與其臨床表現可能相似，但檢驗及治療方式不同。 |
| [MERS] | MERS 由 MERS 冠狀病毒引起，與鼠疫在病原分類、宿主和傳播條件上均屬不同疾病。 |
| [COVID-19] | COVID-19 由 SARS-CoV-2 引起；其 pandemic 經驗促進全球監測與快速檢驗能力，但不能直接套用鼠疫的媒介控制。 |
