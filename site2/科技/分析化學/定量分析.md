# 定量分析

> 隸屬：[分析化學]　·　狀態：初稿

> 對應維基百科：[中文維基百科：定量分析](https://zh.wikipedia.org/wiki/%E5%AE%9A%E9%87%8F%E5%88%86%E6%9E%90)　·　[English Wikipedia: Quantitative analysis (chemistry)](https://en.wikipedia.org/wiki/Quantitative_analysis_%28chemistry%29)

定量分析是**測定樣品中某成分「有多少」**的分析方法。定性分析回答「含不含」，定量分析回答「濃度或含量是多少」，兩者構成 [分析化學] 的兩大支柱。古典定量方法以質量與體積這兩種可直接測量的物理量為基礎：[重量分析] 把待測成分轉成可稱量的純物質，[滴定分析] 用已知濃度的試劑把反應滴到計量點，[比色法] 則由顏色深淺推算濃度。這些方法不需要昂貴儀器，今天仍是藥典、食品與環境標準方法的骨幹，也是一切儀器定量結果的校驗基準。

## 技術與理論的關聯

- **化學計量的直接應用**：定量分析的核心是反應方程式的計量關係。滴定到計量點時，消耗的試劑莫耳數與待測物之比等於方程式係數比，濃度由此可算。

- **化學平衡決定終點**：酸鹼滴定的終點由 $\mathrm{pH}$ 突躍決定，沉澱滴定由溶度積決定，氧化還原滴定由電位突躍決定——每一類滴定背後都是一種平衡計算。

- **誤差分級**：定量結果必須附帶準確度（與真值接近程度）與精密度（重複測定的一致程度），平行測定與空白試驗是區分系統誤差與隨機誤差的基本手段。

- **重量分析的沉澱條件**：沉澱要顆粒大、純度高、溶解損失小，因此需要控制過飽和度、陳化時間與洗滌液組成，這些都是平衡與動力學的實際操作。

- **指示劑的選擇邏輯**：指示劑的變色範圍必須落在滴定突躍之內，例如鹽酸滴碳酸鈉用甲基橙而非酚酞，因為第一計量點在弱鹼性區。

- **與 [儀器分析] 的銜接**：儀器測的是訊號強度，訊號換算成濃度仍需標準品與化學計量；定量分析的思維是所有儀器方法的基礎語法。

## 範例

**問題**：以 0.1000 M 鹽酸滴定 25.00 mL 濃度未知的氫氧化鈉溶液，酚酞褪色時用去鹽酸 23.45 mL，求氫氧化鈉濃度。

1. **寫計量關係**： $\mathrm{HCl} + \mathrm{NaOH} \to \mathrm{NaCl} + \mathrm{H_2O}$ ，莫耳比 1:1。
2. **算試劑莫耳數**： $n_{\mathrm{HCl}} = 0.1000 \times 0.02345 = 2.345 \times 10^{-3}$ mol。
3. **直接換算**：氫氧化鈉莫耳數相同，濃度 $c = 2.345 \times 10^{-3} / 0.02500 = 0.09380$ M。
4. **估誤差**：滴定管讀數誤差每次約 ±0.02 mL，兩次讀數合計 ±0.04 mL，相對誤差約 $0.04/23.45 \approx 0.17\%$ ；這就是古典滴定法「四位有效數字」的由來。
5. **同場比較**：若改用重量法測同一鹼液，蒸乾稱重受吸濕與二氧化碳干擾，誤差通常大於滴定法——方法選擇本身就是定量分析的一部分。

## 前因後果

1. [拉瓦錫] 在十八世紀末以精密天平確立質量守恆，使「稱重」成為化學論證的權威，重量分析由此誕生。

2. 十九世紀 [李比希] 把定量分析變成教學與研究的日常：他的吉森實驗室以有機元素定量分析訓練出一代化學家，有機化學的分子式幾乎都出自燃燒分析。

3. 滴定法隨工業需求（漂白粉有效氯、蘇打純度）在十九世紀中葉標準化，指示劑與容量器皿的進步使快速定量成為可能。

4. 比色法先靠肉眼比對標準色階，二十世紀光電技術接手後演化為分光光度法，成為 [儀器分析] 的先聲。

5. 二十世紀後期，藥典與 ISO 標準把定量方法寫成可驗證的正式程序，定量分析從實驗室技藝轉為受法規約束的品管活動。

## 與相鄰分類的關聯

- 與 [定性分析] 的關係：定性找出成分、定量量出含量，實務上先定性後定量，兩者共同構成完整的樣品解答。

- 與 [無機化學] 的關係：滴定的終點計算就是酸鹼、沉澱、錯合與氧化還原四大平衡的應用題。

- 與 [儀器分析] 的關係：儀器定量仍依賴校正曲線與化學計量，古典定量是它的理論母體。

- 與 [品質管制] 的關係：定量方法的準確度必須用標準品驗證，定量與品管是方法與制度的關係。

- 在 [分析化學] 中，定量分析扮演「出數字」的角色：環境、食品、藥品與工業的所有含量規格，最終都由它背書。

## 容易混淆之處

- **計量點不等於終點**：計量點是反應恰好完全的理論點，終點是指示劑變色的觀察點，兩者的差就是「終點誤差」，選對指示劑可把它壓到可忽略。

- **精密度高不代表準確度高**：平行測定互相接近可能只是系統偏差一致，必須用標準品或對照方法查核。

- **百分含量與濃度的單位陷阱**：w/w%、w/v% 與莫耳濃度混用是計算錯誤的常見來源，務必先統一單位。

- **重量法稱的是沉澱形式而非待測形式**：由硫酸鋇的質量反推硫酸根含量時要乘換算因數 $\frac{96.06}{233.39}$ ，漏乘是經典錯誤。

## 技術要點

- 滴定前必須標定試劑濃度：以鄰苯二甲酸氫鉀標定鹼、以無水碳酸鈉標定酸，基準物質的純度直接決定結果品質。

- 平行測定至少三份，相對標準偏差通常應小於 0.2%（滴定法）或 2%（微量比色法），超標需找原因而非平均了事。

- 空白試驗扣除試劑與環境背景，是低含量測定不可省略的步驟。

- 沉澱重量法三原則：完全沉澱（加入過量沉澱劑）、純化（陳化與再沉澱）、準確稱量（恆重）。

- 氧化還原滴定常用高錳酸鉀自我指示（終點呈微紅色）或碘量法以澱粉指示，兩者終點判讀條件不同，酸度與溫度必須照方法規定。

- 報告結果須註明方法依據、有效數字與量測不確定度，缺一即不符合品管要求。

## 常見的論爭

- **古典法與儀器法的標準地位**：藥典仍以容量分析為許多品項的第一法，批評者認為儀器法更快更準，支持者強調古典法結果直接、無需複雜校正。

- **有效數字的保守程度**：檢驗機構傾向多報位數以留計算空間，統計學者批評這虛報了不確定度水準。

- **比色法的「目視 versus 光度」**：快速現場檢測仍用目視色階，但法規判定多要求光光度計讀值，兩套結果的界線與效力常有爭議。
