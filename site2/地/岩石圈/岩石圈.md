# 岩石圈

> 隸屬：第一層 [地]　·　相關分類：[板塊構造]、[地質學]　·　子分類總表見 [README]

> 對應維基百科：[中文維基百科：岩石圈](https://zh.wikipedia.org/wiki/%E5%B2%A9%E7%9F%B3%E5%9C%88)　·　[English Wikipedia: Lithosphere](https://en.wikipedia.org/wiki/Lithosphere)

岩石圈是地球外層**具有力學強度、可承受應力不輕易流動**的固體殼層，包含地殼與最上部的一部分地函，厚度約從洋域的一百公里到大陸區的兩百公里以上。它的關鍵性質不是「由岩石組成」（地函深部也是岩石），而是「行為是剛性」：正因為岩石圈是剛性的，板塊才能以整體移動，地震也才能累積應變後一次釋放。

岩石圈與其下的軟流圈是力學分類，與地殼、地函的化學分類是兩套座標：[地質學]描述物質組成，[板塊構造]描述力學行為，岩石圈正是兩套語言的接口。

## 核心問題

1. **岩石圈包含哪些部分？** 上覆的大洋岩石圈由海洋地殼加岩石圈地函組成，大陸岩石圈則有大陸地殼與更厚、更古老的地函根。
2. **為何它剛硬而底下可流動？** 溫度控制岩石的力學行為：岩石圈底部約一千三百度的等溫線之下，物質在高溫長時間尺度下會緩慢蠕動，形成軟流圈。
3. **它如何運動與更新？** 岩石圈在的中洋脊裂處誕生、在隱沒帶沉回地函；洋底岩石圈因此平均年齡不超過兩億年，而大陸岩石圈可保存四十億年。
4. **它如何被觀測？** 地震波速、重力與大地測量（GNSS 板塊移動速率每年數公厘到十餘公分）是主要的直接證據。

## 因果鏈

1. **地殼均衡的發現**：十九世紀喜馬拉雅重力測量異常，促成「地殼浮在較軟物質上」的均衡概念，為日後的層圈力學分類鋪路。
2. **地震學畫出分層**：莫霍洛維奇（1909 年）發現地殼底界，古騰堡與李曼畫出地核；「固體地球分層」的地圖完成。
3. **軟流圈概念的出現**：二十世紀上半的地震波衰減與重力研究推斷上部地函存在低速度帶——岩石在該處強度大降，剛性層與軟性層的分野成形。
4. **板塊理論的定義性一步**：1960 年代板塊構造直接把板塊定義為岩石圈板塊，運動的是力學層而非化學層；岩石圈自此成為地球科學的核心術語。
5. **海底鑽探與蛇綠岩**：深海鑽探與造山帶中的蛇綠岩套（搬上陸地的古洋殼）讓人直接檢驗洋底岩石圈的層序與年齡分布。
6. **大陸岩石圈的長壽之謎**：大陸地函根為何能漂浮並保存數十億年，成為地球化學與流變學的熱門題目，克拉通研究因此復興。
7. **觀測革命**：衛星雷射測距與 GNSS 直接量到板塊速率，與百萬年地質紀錄一致；岩石圈力學模型可與即時觀測對話。

## 子分類的定位與相互驅動

### 地殼與岩石圈地函

地殼提供化學多樣性（花崗質大陸、玄武質洋殼），岩石圈地函提供厚度與強度。兩者耦合的研究解釋了為何大陸不隱沒、洋底會更新，是板塊演化的基本分工。

### 軟流圈與層圈力學

岩石圈的定義依賴與軟流圈的對比。流變實驗（高溫高壓下岩石如何變形）把「軟硬」量化；軟流圈黏度的估算又直接控制板塊動力模型的行為。

### 板塊邊界與岩石圈循環

擴張、聚合與轉形邊界是岩石圈生滅的現場：洋殼在脊生成、在溝消減。這條循環線也控制礦產與地震的分布，把基礎科學與資源探勘、防災串成一線。

### 大陸克拉通與古岩石圈

克拉通是保存最久的大陸岩石圈，記錄地球最早的地質歷史。同位素地化讀出古岩石圈的年齡；克拉通的穩定性又對比出活動帶的風險，兩者是同一枚硬幣的兩面。

## 容易混淆之處

- 岩石圈不等於地殼：岩石圈還包含岩石圈地函，範圍大得多。
- 岩石圈與軟流圈是力學區分，地殼與地函是成分區分，兩組界線位置不同、不可互換。
- 板塊不是「地殼板塊」：移動的單元是岩石圈板塊。
- 軟流圈不是液態：它是固態但能極緩慢流動的岩石，地震波仍能穿過。

## 具體範例

- **厚度對比**：大洋岩石圈厚約一百公里，古老克拉通（如[加拿大]地盾）的岩石圈可達兩百五十公里以上。
- **莫霍面**：1909 年莫霍洛維奇由震波突然加速確認地殼底界，克羅埃西亞附近約三十三公里深。
- **洋底年齡**：最老洋底岩石圈約兩億年（西太平洋），而大陸岩石圈保存逾四十億年（加拿大 Acasta 片麻岩約四.零三億…四十.三億年）。
- **板塊速率實測**：GNSS 顯示太平洋板塊相對歐亞板塊每年移動約七到十公分，與地質百萬年平均一致。
- **軟流圈**：約一百至三百公里深、地震波低速帶，岩石在此可於萬年尺度緩慢流動。
- **蛇綠岩套**：[加拿大]與阿曼山區保存被推上陸地的古洋殼層序，直接展示洋底岩石圈的剖面。
- **板塊拉力**：俯衝板片長而冷、密度大，其下拉力估計佔板塊驅動力的多數。
- **克拉通地函根**：低溫、貧鐵的地函根使克拉通像軟流圈上的木塞，漂浮數十億年。
- **熱流觀測**：大洋岩石圈熱流隨年齡平方根衰減，是「冷板塊生成、冷卻、下沉」模型的定量證據。
- **[地球]層圈對比**：岩石圈（力學）與地殼（化學）界線不重合——岩石圈地函屬地函但行為剛性。
- **地震層析**：俯衝板片可被成像至地函深處（如法拉倫板片殘影），證明岩石圈循環深入地函。
- **月球對照**：月球岩石圈厚且無板塊運動，其撞擊紀錄反襯地球板塊循環對地表的「重置」功能。
- **大陸不隱沒**：大陸地殼密度低於地函，隱沒帶前緣因此堆疊成造山帶而非整體下沉。
- **地熱梯度**：岩石圈內平均每公里增溫約攝氏二十到三十度，是地熱資源與流變計算的基礎。

### 指標速覽

| 項目 | 數值 | 意義 |
| --- | --- | --- |
| 大洋岩石圈厚度 | 約100公里 | 板塊的基本尺度 |
| 克拉通岩石圈厚度 | 可達250公里以上 | 大陸穩定的根基 |
| 最老洋底年齡 | 約2億年 | 洋底不斷更新的證據 |
| Acasta片麻岩年齡 | 約40.3億年 | 最古老岩石圈紀錄之一 |
| 太平洋板塊速率 | 約7—10公分/年 | GNSS直接量測 |
| 莫霍面深度 | 大陸約30—70公里 | 地殼底界 |
| 地熱梯度 | 約20—30°C/公里 | 地熱資源的依據 |
| 低速度帶深度 | 約100—300公里 | 軟流圈的震波證據 |

- **岩石圈應力**：現地應力量測顯示板塊內部也存在數十 MPa 級的差應力，板內地震因此有力學來源。
- **地殼均衡補償**：冰川消融後的冰後回彈（如斯堪地那維亞每年約一公分的抬升）是均衡的活展示。
- **蛇綠岩的層序**：自上而下為沈積層、噴出玄武岩、岩牆群、輝長岩與地函橄欖岩，與鑽探結果吻合。
- **大陸邊緣類型**：被動邊緣（大西洋型）與活動邊緣（太平洋型）的沉積與構造截然不同。
- **岩石圈透鏡**：部分弧後地區發現薄化岩石圈，是拉伸構造的深部證據。
