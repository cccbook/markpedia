# 礦物學

> 隸屬：第一層 [地]　·　相關分類：[地質學]、[岩石圈]　·　子分類總表見 [README]

> 對應維基百科：[中文維基百科：矿物学](https://zh.wikipedia.org/wiki/%E7%9F%BF%E7%89%A9%E5%AD%A6)　·　[English Wikipedia: Mineralogy](https://en.wikipedia.org/wiki/Mineralogy)

礦物學研究礦物——**天然產出、無機過程形成、具有確定化學成分與規則晶體結構**的固體——的成分、結構、性質與生成條件。目前已命名的礦物約六千種，但地殼體積的絕大部分由少數幾十種常見礦物（長石、石英、輝石、角閃石、雲母、方解石等）構成。礦物是岩石的基本積木：讀懂[地質學]的岩石敘事，必須先認識它的零件。

礦物學是「地」主類中與物質科學最近的一支：晶體結構決定硬度、解理與光性，而生成條件（溫度、壓力、化學環境）記錄在礦物組合裡——因此礦物同時是資源，也是[岩石圈]深部過程的探針。

## 核心問題

1. **礦物如何分類？** 以化學成分與晶體結構為雙軸，分成矽酸鹽、碳酸鹽、氧化物、硫化物等大類；矽酸鹽佔地殼礦物的九成以上。
2. **晶體結構如何決定性質？** 原子排列決定解理方向、硬度（莫氏硬度一到十）與光性；同成分不同結構即為不同礦物（石墨與金剛石皆為碳）。
3. **礦物如何指示生成環境？** 礦物組合是溫度與壓力的函數：變質礦物帶（如藍閃石指示高壓）讓我們讀出岩層經歷過的深部條件。
4. **礦物資源如何形成與找尋？** 岩漿分異、熱液沉澱與風化富集把稀有的有用元素集中成礦床，礦物學因此直接支撐探礦與材料工業。

## 因果鏈

1. **從寶石鑑定到系統分類**：十六至十八世紀的礦物蒐藏與鑑定累積大量標本；1779 年起的化學分析讓「成分＋晶形」取代外觀成為分類依據。
2. **摩氏硬度與系統鑑定**：1812 年摩氏硬度標尺等簡易鑑定工具使田野鑑定標準化，礦物學成為地質調查的基礎技能。
3. **晶體結構的革命**：1912 年勞厄發現晶體 X 光繞射，次年布拉格父子解出第一個晶體結構，礦物學從「晶形描述」進入「原子級結構」的時代。
4. **矽酸鹽結構的解碼**：矽氧四面體的孤立、鏈狀、層狀與架狀連接方式被逐一解出，解釋了雲母可剝離、長石風化等巨觀行為。
5. **實驗岩石學與相平衡**：高溫高壓實驗（二十世紀中葉起）畫出礦物穩定域，變質相與地溫梯度可以定量重建，礦物成為「地質溫度計與壓力計」。
6. **電子顯微與微區分析**：電子探針、透射電鏡使微米甚至奈米尺度的成分與缺陷可見，礦物學開始處理交代作用、擴散與晶格缺陷。
7. **新材料與環境應用**：沸石催化、鋰雲母提鋰、黏土封存，使礦物學與能源轉型直接掛鉤——[澳洲]等地鋰礦的開發即是礦物知識變成戰略資源的例子。

## 子分類的定位與相互驅動

### 晶體化學與結構

結構分析是礦物學的核心技術。結構知識解釋固溶體（成分連續變化的系列，如斜長石）與類質同像；新材料研發（電池正極材料多為礦物結構的模仿）又回頭供給結構化學新問題。

### 矽酸鹽與造岩礦物

造岩礦物是[地質學]岩石分類的基礎。鑑定方法（偏光顯微鏡薄片）自十九世紀以來是地質學家的母語；顯微鏡資料的累積又反過來修正礦物系統。

### 變質與成因礦物學

礦物組合記錄溫壓歷史。地質溫壓計的精度提升，使山脈抬升與俯衝深度的重建更準確，直接支撐[板塊構造]的地體研究；實驗相圖與野外觀察互相校準。

### 礦床與應用礦物學

礦床是礦物富集的特例。成因模型（熱液、紅土風化、砂礦）指導探勘佈局；選礦與冶煉的效率又依賴礦物物性（可浮性、解理），資源經濟與基礎研究在此合流。

## 容易混淆之處

- 礦物不等於岩石：礦物是化合物層級的積木，岩石是礦物的集合體。
- 顏色不可靠：石英可呈任何顏色，鑑定需靠硬度、解理與光性。
- 「人造寶石」不是礦物：礦物定義要求天然產出，實驗室合成的同成分晶體只能稱「類礦物質」。
- 稀土不是「稀」在含量，而是「分散難採」：多數稀土礦床以風化殼或碳酸岩形式富集。

## 具體範例

- **石墨與金剛石**：同為碳，前者層狀結構故軟且導電，後者四面體網狀故最硬（莫氏十度）。
- **莫氏硬度標尺**：1812 年訂定，滑石一度到金剛石十度，指甲約二.五、鋼刀約五.五。
- **雲母的解理**：層狀矽酸鹽結構使其可剝成透明薄片，曾是爐窗與電容器材料。
- **X 光繞射**：1912—1913 年布拉格父子解出食鹽與金剛石結構，開啟晶體結構學。
- **斜長石系列**：鈉長石到鈣長石成分連續變化，薄片中的雙晶與成分是岩石定名的關鍵。
- **[澳洲]鋰礦**：西澳 Greenbushes 為全球最大鋰輝石礦，鋰雲母與鋰輝石成為能源轉型戰略礦物。
- **沸石分子篩**：結構中的孔道可篩分分子，用於催化與軟水，是礦物結構知識的直接應用。
- **藍閃石**：僅在低溫高壓（俯衝帶）穩定，其出現即標記古老俯衝帶的位置。
- **石英壓電性**：結構缺少對稱中心，受壓生電，早期電子與鐘錶工業的基礎。
- **斑岩銅礦**：全球銅產量的多數來自淺成岩漿熱液系統，[智利]與秘魯的安第斯帶最集中。
- **磁鐵礦定年與古地磁**：其磁疇記錄地磁場方向，是海底磁條帶與[板塊構造]證據的物理基礎。
- **黏土封存**：蒙脫石層間可吸附金屬與水分子，成為廢料封存研究的對象。
- **礦物命名速度**：國際礦物學會每年核准新礦約五十到一百種，總數已逾六千。
- **稀土礦物**：獨居石與氟碳鈰礦是稀土主要來源，風化殼型礦床（華南）以離子吸附態富集。

### 指標速覽

| 礦物/主題 | 數值 | 意義 |
| --- | --- | --- |
| 莫氏硬度 | 1—10 | 鑑定的基準標尺 |
| 已命名礦物 | 逾6000種 | 每年新增約50—100 |
| Greenbushes鋰礦 | 全球最大 | 能源轉型戰略資源 |
| X光繞射解結構 | 1912—1913 | 晶體學誕生 |
| 藍閃石 | 低溫高壓指標 | 俯衝帶的礦物簽名 |
| 石英壓電 | 受壓生電 | 電子工業基石 |
| 斑岩銅礦 | 全球銅產多數 | 聚合邊界資源 |
| 離子吸附型稀土 | 華南風化殼 | 稀土供應鏈關鍵 |

- **硬度測試的實務**：刻劃法只能在礦物間比較，現代以顯微硬度計取得定量數值。
- **礦物的成因分類**：岩漿、沉積、變質與風化成因的礦物各有標誌性組合。
- **寶石級條件**：透明、無裂、色美與稀有四條件使少數礦物成為寶石，多數礦物只存在於標本櫃。
- **隕石礦物**：隕石中發現的高壓相（如林伍德石）擴展了礦物學的壓力邊界。
- **晶體缺陷**：色心與雜質使同一礦物呈不同顏色，缺陷化學是寶石優化處理的基礎。
