# 碳循環

> 隸屬：第一層 [地]　·　相關分類：[生態系統]、[全球暖化]　·　子分類總表見 [README]

> 對應維基百科：[中文維基百科：碳循环](https://zh.wikipedia.org/wiki/%E7%A2%B3%E5%BE%AA%E7%8E%AF)　·　[English Wikipedia: Carbon cycle](https://en.wikipedia.org/wiki/Carbon_cycle)

碳循環描述碳在大氣、海洋、陸地生物圈、土壤與地質儲庫之間的**移動與轉換**。碳以二氧化碳、甲烷、碳酸鹽與有機質等形態存在：大氣二氧化碳雖只佔大氣約百分之零.零四，卻是溫室效應的關鍵；海洋儲存約大氣五十倍的無機碳；地質儲庫（石灰岩、化石燃料）則鎖住了最深、最慢的一層。

碳循環之所以是當代最重要的地球科學題目，是因為人類每年把約一百億噸碳從化石儲庫搬進大氣，而自然過程只吸收其中約一半——剩下累積的部分，就是[全球暖化]的直接驅動力。理解碳的收支，等於掌握氣候政策的會計帳本。

## 核心問題

1. **碳如何在快慢兩個循環中移動？** 快循環（光合作用、呼吸、海氣交換）以年為尺度；慢循環（風化—沉積—板塊俯衝—火山釋出）以百萬年計，兩者透過地質過程相連。
2. **光合與呼吸的收支多大？** 陸地植物每年光合固定約一千二百億噸碳，呼吸與分解幾乎抵消；淨差額（加上土地利用排放）才是大氣濃度的變化量。
3. **海洋如何吸收碳？** 物理溶解（二氧化碳溶於冷海水下沉）與生物幫浦（浮游植物固定後沉降至深海）合計吸走人為排放約四分之一，但海水酸化隨之而來。
4. **臨界點在哪裡？** 永凍層融化解凍有機碳、亞馬遜森林退化、海洋吸收效率下降，都是可能把循環從「幫忙」變「幫倒忙」的回饋。

## 因果鏈

1. **光合作用的發現**：十八世紀普利斯特里與殷豪斯確立植物「逆轉」燃燒效應，碳在生物與空氣之間往返的事實首次被看見。
2. **地質碳的覺醒**：十九世紀地質學理解石灰岩與煤層是古代碳的倉庫；工業革命大規模燒煤，使「地質碳回到快循環」成為可以量測的趨勢。
3. **基林曲線**：1958 年起夏威夷冒納羅亞觀測站的二氧化碳紀錄（年增約三至四 ppm、且有季節呼吸波動），把碳循環變成每年更新的實證數據。
4. **碳同位素辨識來源**：化石碳缺碳十三與碳十四，同位素比值的下降直接證明大氣二氧化碳增量來自化石燃料，爭論自此有了指紋證據。
5. **全球碳收支的建立**：1980 年代起全球碳計畫每年出版收支表：排放、大氣增量、海洋匯與陸地匯的殘差法核算，使「消失的碳匯」成為研究題目。
6. **回饋風險的量化**：永凍層儲碳約一.五兆噸、泥炭地與森林碳的估算完成，碳循環模型開始把[生態系統]的臨界行為納入氣候預估。
7. **淨零與負排放**：因為殘存排放難以歸零，「負排放技術」（植樹、土壤固碳、直接空氣捕捉）進入政策，碳循環研究從描述轉為設計。

## 子分類的定位與相互驅動

### 大氣碳與溫室效應

大氣是循環中變化最快的帳戶。觀測網（地面＋衛星如 OCO-2）提供濃度與通量的即時圖像；濃度資料反過來校準陸海模型的模擬能力，是整個收支表的裁判。

### 陸地生物圈與土壤碳

森林與土壤各儲存數千億噸碳，與[生態系統]研究共用方法。FLUXNET 通量塔網直接量測森林呼吸與固定；增溫實驗則揭示土壤碳分解對溫度的敏感度——這是預估的最大不確定性之一。

### 海洋碳幫浦

海洋吸收人為碳約四分之一，同時酸化（pH 已下降約零.一）威脅鈣化生物。化學幫浦（溶解度）與生物幫浦（顆粒沉降）的研究互相分工；GLODAP 等全球航次資料庫使海洋碳儲量的年代際變化可以相減比較。

### 地質碳與人為干預

化石燃料與碳酸鹽是慢循環的儲庫；人類正以百年尺度抽取千年積累的化石碳。碳捕捉與封存（把二氧化碳注入地層）等於把循環接到新的人工支線，其長期封存可靠性是地質學的新任務。

## 容易混淆之處

- 碳循環一直存在，問題不是「有碳」而是「碳搬得太快」：速率遠超自然匯的消化能力。
- 森林碳匯不是永久保險：火災、病蟲害與砍伐可以把儲存的碳一夜歸還大氣。
- 海洋吸收不是免費服務：每吸收一噸碳都伴隨酸化，代價由珊瑚與貝類支付。
- 甲烷單位質量的百年暖化潛勢約為二氧化碳的二十八倍，短期效應更強，不可與二氧化碳混為一談。

## 具體範例

- **基林曲線**：1958 年冒納羅亞站二氧化碳約 315 ppm，2024 年已逾 420 ppm，年增約二到三 ppm。
- **化石碳搬家**：人類每年燃燒化石燃料排放約一百億噸碳（約 367 億噸二氧化碳），速率是火山的一百倍以上。
- **去哪了**：大氣約留四成五，海洋吸約四分之一，陸地[生態系統]吸收約三成。
- **同位素指紋**：大氣碳十四因化石碳稀釋而下降（蘇斯效應），碳十三同步輕化，證明增量來自化石燃料。
- **季節呼吸**：北半球春季 CO2 下降、秋冬季上升，年振幅約六 ppm，可直接「看見」光合與呼吸。
- **永凍層**：北極永凍層儲碳約一.五兆噸，融化後微生物分解可釋出二氧化碳與甲烷。
- **海洋酸化**：工業革命以來表層海水 pH 約下降零.一，氫離子濃度增約三成。
- **[全球暖化]殘差法**：年度收支以「排放−大氣增量−海洋吸收＝陸地匯」核算，是 IPCC 碳預算的骨架。
- **甲烷突增**：2020 年起大氣甲烷年增屢創紀錄，濕地排放與化石洩漏被列為主要候選原因。
- **土地變遷**：毀林每年貢獻約十億噸碳，熱帶泥炭地排水與焚燒是集中來源。
- **負排放成本**：直接空氣捕捉目前每噸二氧化碳成本約數百美元，植樹與土壤固碳便宜但易逆轉。
- **地質封存**：挪威 Sleipner 計畫自 1996 年起每年注入約一百萬噸二氧化碳於鹽水層，是最長的封存示範。
- **碳匯效率下滑**：模型與觀測顯示部分亞馬遜地區已由碳匯轉為碳源。
- **城市碳帳**：城市消耗全球約七成能源，碳盤查已成為城市治理的標配。

### 指標速覽

| 碳收支項 | 數值 | 意義 |
| --- | --- | --- |
| 年化石排放 | 約100億噸碳 | 暖化驅動核心 |
| CO2濃度 | 315→420+ ppm（1958—2024） | 基林曲線 |
| 海洋吸收 | 約1/4 | 酸化代價 |
| 陸地吸收 | 約30% | 受乾旱波動 |
| 永凍層碳 | 約1.5兆噸 | 最大回饋風險 |
| 表層pH變化 | 約−0.1 | 氫離子+30% |
| 年振幅 | 約6 ppm | 生物圈呼吸節奏 |
| Sleipner封存 | 1996年起 | 地質封存示範 |

- **土壤碳的深度**：多數土壤碳儲存在表層一公尺內，深層碳的周轉時間可達千年。
- **甲烷的人為來源**：約六成甲烷排放來自人為（畜牧、稻作、化石洩漏與廢棄物）。
- **碳定價**：全球碳市場與碳稅已覆蓋約四分之一的排放，碳循環會計成為商業語言。
- **遙測甲烷**：衛星（如 TROPOMI）可偵測單一洩漏點，使超級排放源無所遁形。
- **碳中和語言**：「淨零」指排放與吸收相抵，而非零排放，會計定義的差異是政策爭議核心。
