# 鄰國與域外年號

> 隸屬：[年號](README.md)　·　狀態：初稿

> 對應維基百科：[中文維基百科：鄰國與域外年號](https://zh.wikipedia.org/wiki/%E9%84%B0%E5%9C%8B%E8%88%87%E5%9F%9F%E5%A4%96%E5%B9%B4%E8%99%9F)

「鄰國與域外年號」是[年號]的子分類，專門整理中國歷代王朝直接年號體系以外，
由鄰近國家、海外政權或受中國曆史文化影響的地區所使用的紀年名稱。
這些名稱可能借用漢字、模仿中國改元制度，也可能經過翻譯、重新解釋或完全在地化。

本分類所稱「域外」是史料與曆法研究上的範圍描述，不代表現代國際法或政治立場。
收錄對象包括越南、朝鮮、日本等使用漢字紀年的國家，也包括受中國政治文化影響而建立年號制度的其他政權。
單純使用animal cycle、干支、星期或宗教紀年，而沒有固定名稱與起算範圍者，不自動視為年號。

分類的必要性在於避免把域外年號硬套入中國帝王年號表。
各國的起元年、紀日方式、曆法換算、官方使用情形與中文讀法未必一致。
若只按照中國正史的年代欄排列，便容易混淆「當地正式使用的名稱」與「後世史家整理出的對應年代」。

整理工作必須同時記錄名稱原文、當地讀音、適用政權、起訖日期、頒布或採行依據及史料出处。
如此才能說明某一年在當地究竟如何被標記，也能呈現改名、停用、同名再用與政權並立所造成的複雜情況。

「鄰國與域外年號」也是觀察歷史上政治秩序流動的入口。
年號往往在即位、遷都、冊立、獲取正統名義、重大戰爭或政權更替時出現，
因此其名稱與期限可以反映統治者如何塑造新秩序，以及後世如何延續、修正或重新詮釋那段歷史。

## 技術要點

- **地理與政治範圍**：分類以歷史上的文化交流及政治接觸為主要判準，不以今天的國界直接劃分；同一地區若先後由不同政權統治，可能分別建立年號體系。
- **名稱的漢字書寫**：越南、朝鮮與日本等地多以漢字記錄年號，漢字形體相同時，當地讀音和意義未必與現代標準漢語相同。
- **名稱結構**：[二字]、[三字]及[數字複合]可協助辨認形式，但不能單憑字數判定名稱的來源、效力或使用年代。
- **制度來源**：中國以帝王即位或特定政治事件為起點的改元方式，經使節往來、冊封、移民、佛教交流與政治模仿傳播到周邊地區。
- **開始與結束**：年號通常以即位、改元或詔令生效為起點，可能在午夜、日出或特定節日改換；不能一律視作西曆一月一日換年。
- **改元程序**：[改元]既可能只是同一君主更換年號，也可能發生於王朝交替；[改元換代]則提醒讀者區分「名號改變」與「政權更替」兩種事件。
- **非連續使用**：戰亂、攝政、篡位、殖民統治或中央權威衰落，可能造成年號中斷；後來政權也可能沿用或重新啟用舊號。
- **並立局面**：[並立年號]指不同政權在同一時期各自頒布年號，使單一時間軸出現多套正式的紀年基準。
- **名稱再使用**：相同字形或相同讀音可能在不同君主、不同政權或相隔較久的年代反覆出現，應以政權與日期判定，不可只列名稱。
- **史料層次**：詔令、冊文、官修實錄、碑刻、奏摺與地方志各有證據價值；後出的[年號與文獻]整理應交代所採底本及校訂方式。
- **正統宣示**：域外政權採用近似年號制度，往往是在回應誰有資格紀年、代表王朝及受何者承認的問題，須結合[年號與正統]判讀。
- **年代換算**：對照表需同時標示當地年號紀年、干支或西曆年份；涉及農曆時，還應註明曆法版本與換算日期。
- **當時使用與後世追述**：當代公文所用的年號、後世史書採用的年號及現代資料庫的正規化標示，可能不是同一層次。
- **語言與字形**：同一語境中的繁簡字、異體字、通行字與訓讀差異應分開記錄，不能因字形相同便認定為同一套政治制度。

## 範例

### 範例一：日本由「平成」改為「令和」

日本年號是本分類中最便於觀察制度化程序的例子，相關內容見[日本年號]。
日本在昭和天皇退位前，便依法律與內閣程序預先決定下一代年號，使行政機關得及準備文書、印章與曆表。

1. 1989年1月7日，昭和退位，平成開始使用；平成一直延續至2019年4月30日。
2. 2019年4月1日，日本政府公布「令和」為新年號，讓各界在正式切換前得知名稱。
3. 2019年5月1日，令和天皇即位，平成結束，令和正式起算。
4. 「令和」通常被認為取自《萬葉集》所收的一首和歌，人們常引用「初春令月，氣淑風和」解釋其中的「令」與「和」。
5. 在[2024年]與[2025年]，日本公文仍以「令和六年」或「令和七年」書寫；中文年表則多直接列西元年，並在括號中附「令和」。

這個程序解決了傳統改元最常見的交接瓶頸：若新君即位後才宣布名稱，行政文書與民間計日可能在短時間內失去共同基準。
預先公布名稱，使宮廷、政府與民間都能以同一名號準備新年度，也讓「年號」從君主的個人紀年成為現代行政制度的一部分。
「平成」與「令和」皆屬[二字]形式；這次更替則是[改元換代]的典型案例，而「元年」則從2019年5月1日起算，並非2019年1月1日。

### 範例二：越南的「嘉隆」與「明命」

越南長期借用漢字建立正史、年表與宮廷紀年，區域性整理見[越南]。
越南阮朝建立後，嘉隆帝於1802年擊敗西山朝並進入昇龍，隨後使用「嘉隆」作為年號。

1. 嘉隆帝於1802年即位，「嘉隆」年號大致用於1802年至1820年。
2. 阮福淍即位後，明命帝於1820年改用「明命」，延續至1841年。
3. 在越南史料中，「嘉隆」通常依越南語讀作 *Gia Long*，並不是把普通話讀音直接搬入越南文件。
4. 漢字詞可以保留政治象徵，同時透過當地音讀、諺解與禮制儀式取得新的文化意義。
5. 殖民時期法國行政與現代越南國號並行，使後世必須區分阮朝年號、法國管治時期與共和時期的紀年。

這個案例顯示，域外年號並非只做文字形式的複製。
越南統治者藉由年號宣告新王朝已完成戰爭、獲得正統並建立秩序，解決了「以何名號記錄新時代」的制度需求。
此類年號為後世編年、碑刻與正史提供共同骨架，也推動了越南本土史學對自身王朝年代的獨立整理。

### 範例三：朝鮮「光武」的兩度使用

朝鮮王朝與大韓帝國的年號多以漢字書寫，區域背景見[朝鮮]。
其中「光武」曾出現在不同時期，不能只因字面相同便把相關紀年合併。

1. 朝鮮哲宗在位期間，「光武」年號用於1861年至1863年。
2. 1897年，大韓帝國成立後，高宗再次採用「光武」，相關年號延續至1907年。
3. 其後「大韓」成為帝國末期正式使用的年號，直到1910年王朝終結。
4. 今天的朝鮮史與韓國史資料會以韓文讀音分別標示這些名稱，漢字原文則仍保存在正式文書與年表中。

兩次「光武」都具有紀年功能，但對應的君主、政權及政治語境不同。
這說明[中斷與重祚]的分類必須進一步辨別王朝實際中斷、舊號恢復與同名再用三種情況。
名稱再使用也反映朝鮮王朝末期及大韓帝國建國前後對正統、國號與君主紀年的重新安排。

### 範例四：製作一份可核對的跨國年代表

跨國年表不能只把名稱排成清單，還必須保留換算規則與來源。
以日本在[2024年]和[2025年]的紀年為例，可依下列程序處理。

1. 選定基準資料，例如日本內閣或官方年表所載的年號起訖資料。
2. 記錄日本年號原文「令和」、當地讀音、代數及起算日。
3. 核對同一頁面或相關法令所載的起止規則，避免把西曆年份誤當作年號切換點。
4. 為每一年配置年號紀年，例如令和六年、令和七年，並保留羅馬字或其他轉寫供索引使用。
5. 在中文欄位加入西元年與中文換算說明，標明資料是當時官方用法還是後世整理。
6. 比較朝鮮、越南等同期年號時，各自建立起訖列，不以任何一地的元旦作為共同換日點。
7. 在表尾記錄資料版本、換算日期與尚待核對的異文。

這套[紀年對照表]能避免把同一西曆年度切成互不相容的日期格式。
它同時服務於[年號紀年]、歷史事件定位、人物生卒年推算及外交文書日期解讀。

## 前因後果

1. [春秋]時期已有以「某王元年」計算年代的習慣，雖未普遍使用固定名號，卻提供按君主紀年的先例。
2. 一般認為中國自[年號始於漢武帝]後建立較完整的年號制度，帝王即位與改元逐漸成為公開的時間標記。
3. 冊封使節、僧侶、商人與移民把漢字、曆法及帝王年號觀念帶往周邊地區，促成域外政權仿用相關形式。
4. 地方政權依自己的語音重新讀出年號，並以名稱解釋統治成果，使原本具有中心王朝象徵的制度轉為在地政治語言。
5. 年號被納入詔令、戶籍、兵籍、曆法、碑刻與土地文書後，官方行政與民間生活獲得可共享的年代基準。
6. 即位、冊封、戰爭勝利或政權轉移促使[改元]發生；[改元換代]則讓年號成為觀察政權更替的重要指標。
7. 戰亂與分裂可造成[中斷與重祚]，而政權並存則形成[並立年號]，使同一地區出現多套有效的紀年系統。
8. 朝廷文書中的[避諱]可能改寫年號文字、官名或地名，研究者須區分原名、避諱後字形與後世追補。
9. 殖民統治、共和改革及國際標準的推廣，使公曆逐漸成為一般行政基準；舊年號則轉為正史、博物館與學術研究中的歷史紀年。
10. 當代紀年需求下降後，跨國年表與[紀年對照表]成為保存名稱、推定日期及重建政治記憶的重要工具。

## 與相鄰分類的關聯

- [年號]是上位分類；本頁聚焦年號制度越出中國王朝直接年號表後，在鄰國與域外形成的在地版本。
- [年號的起源]說明中國年號制度的形成背景，是理解周邊政權採用或改造相關制度的前提。
- [年號的形式]可用來分析二字、三字、數字複合及其他詞形，並比較不同地區的命名偏好。
- [年號與文獻]處理詔令、實錄、碑刻、奏議、地方志與外國史料之間的異文及年代證據。
- [年號與正統]連結名號、即位、冊封與政權承認，有助於分析域外統治者為何採用特定年號。
- [年號紀年]則從實際書寫與查找角度呈現年號如何運作，涵蓋紀年、代數、起算日與文獻標示。

## 容易混淆之處

- **鄰國不等於域外**：越南、朝鮮與日本可因地理接近而被稱為鄰國，也可被廣義視為域外紀年；分類重點是制度與史料關係，而非現代國界。
- **年號不等於君主稱號**：君主即位後的年號與終身尊號、廟號、諡號可能同名，但用途及開始時間不同。
- **有固定名稱才可能是年號**：單純使用干支、生肖或年次循環，若沒有特定名稱及適用範圍，不應任意列為年號。
- **元年不等於西曆一月**：年號元年通常從即位或詔令生效日起算，可能只包含該年的部分月份。
- **漢字相同不等於名稱相同**：同字在越南語、朝鮮語與日本語中的讀音和語義可能不同，必須保留當地形式。
- **正式採用不等於後世沿用**：某年號可能只出現在追史記載，實際文書卻已改用其他紀年，兩者應分欄說明。
- **同名不等於延續**：如「光武」在不同時期出現，可能代表重新採用，而非同一段年號延續。
- **政權並立不等於名號互不相干**：並立政權可能各自頒布年號，也可能在外交文書中選用對方承認的名號。
- **換算一致不等於曆法一致**：公曆換算、儒略曆換算與當地農曆換算可能相差一日，不能只核對年份數字。
- **年代接近不等於制度同源**：兩個政權都使用二字年號，可能分別來自中國制度、區域模仿或完全獨立的政治傳統。
