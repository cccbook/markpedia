# 地區差異

> 隸屬：[石器時代](README.md)　·　狀態：初稿

> 對應維基百科：[中文維基百科：地區差異](https://zh.wikipedia.org/wiki/%E5%9C%B0%E5%8D%80%E5%B7%AE%E7%95%B0)

地區差異是[石器時代]研究中的重要分類面向，用來描述不同地理範圍內的石器技術、原料利用、聚落形態、經濟活動與社會聯絡。這種差異並非僅指器物的外觀不同，也包括製作程序、功能、取得原料的方法，以及人們如何適應各地環境。

建立地區差異分類，是為了避免把 Stone Age 理解成一條各地皆同步經歷的單一路徑。相同技術可能因原料性質、需求強度或傳統而產生不同形態；不同技術也可能因人口接觸、物品流動或知識交換而在鄰近地區互相結合。

本文所稱的地區，是以可比較的考古資料界定的分析單位，而非現代行政區或 presumed ethnic group。判斷地區差異時，須同時考慮年代、地層、原料來源、製作程序、使用痕跡、遺址保存條件與採樣偏差，避免單憑一件典型器物劃分文化。

## 技術要點

- **比較單位**：應先確定比較的是單一器種、技術組合、遺址群體，還是較廣泛的區域傳統。
  - 器種比較適合觀察形態變化。
  - 技術組合比較能呈現採集、加工、狩獵與食物處理之間的關係。
  - 遺址群體比較則較能納入聚落位置、保存條件與經濟活動。
- **區域不是單一文化**：同一區域內可能同時存在數種技術、經濟策略或社會群體。
- **年代先於地域**：先建立各區域自己的年代序列，再比較相近時期的資料，才能避免把時間差誤認為地理差異。
  - 不同地區不一定共享相同的起始年代。
  - 舊技術可能在某些地區長期延續，卻已在其他地區被新技術取代。
- **原料分布**：石質原料的物理性質會影響打片方式、修整方式與成品形態。
  - 燧石、玄武岩、石英、石英岩與角岩不能用完全相同的標準衡量。
  - 原料可能由遠方交換而來，因此器物產地不一定等於使用者所在地。
- **操作鏈**：完整的石器分析應涵蓋取得原料、製作、修整、使用、再利用與廢棄的各個階段。
  - 單件器物的完成度不等於整個生產程序。
  - 廢料與碎片能顯示未完成品、維修活動及現場加工情形。
- **形態與功能分開**：形狀相近的器物可能具有不同用途，形狀不同的器物也可能處理相同物質。
  - 刃口、撞擊痕、殘留物與微痕可協助判斷功能。
  - 功能推定仍須考量保存條件與使用次數。
- **遺址背景**：洞穴、河流階地、海岸、開放草原與盆地會形成不同的保存與回收過程。
  - 洞穴容易累積多種時期的遺物。
  - 開放遺址較可能因侵蝕而流失細小碎片。
- **經濟面向**：漁獵、採集、食物加工與居住移動會共同改變工具需求。
  - 工具數量增加未必表示人口增加，也可能是加工活動更頻繁。
  - 廢棄型態可用來推測獵捕、屠宰、食物加工或原料備存。
- **聚落尺度**：單一遗址、聚落中心、短期營地與區域採集網絡具有不同的分析意義。
  - 單一遺址難以代表整個地區。
  - 多遺址的分布與重複利用情形，可協助重建流動範圍。
- **人際與物資網絡**：遷徙、婚姻、貿易、模仿與戰略競爭都可能使技術跨越自然地理界線。
  - 形態漸變有時反映鄰居間的接觸，而非文化突然更替。
  - 稀有原料、特殊飾件或新技術可作為接觸強度的指標。
- **環境不是唯一原因**：氣候與資源提供可能性，卻不能單獨決定技術發展。
  - 同一環境可容納不同適應方案。
  - 技術選擇也受到人口歷史、知識傳承與社會規範影響。
- **比較標準一致**：不同地區的資料應使用一致的紀錄欄位與定義，才能降低人為差異。
  - 建議記錄原料、尺寸、重量、器種、部位、技法、磨耗、層位與保存狀況。
  - 缺漏資料應標示為不可判定，而不是直接視為該特徵不存在。
- **解釋層次分明**：考古現象、區域類型、社會組織與族群認同應分開論證。
  - 技術相似不必然代表共同族源。
  - 技術不同也不必然代表彼此沒有接觸。
- **可重複性**：公開測量資料、影像、採集紀錄與分析程式，能讓其他研究者重新比較同一批材料。
- **命名原則**：地區名稱宜依據明確的地理範圍與資料條件，並避免暗示古代政治邊界。

## 範例

### 案例：瑪麗·利基與東非古峽的地區分類

二十世紀中葉，瑪麗·利基參與坦尚尼亞古峽的發掘與早期石器整理。這批材料之所以重要，不只是因為年代古老，而是因為它們迫使研究者面對一個基本問題：應以器物形狀劃分地區，還是應以完整操作鏈理解地方 traditions。

1. **界定比較問題**
   - 研究者先確認各件器物來自哪一地層，而不是把所有早期石器混成單一集合。
   - 地層關係顯示，不同時期的材料在原料比例與製作痕跡上並不完全相同。
   - 這一步排除了部分「同一地區始終使用相同技術」的簡化假設。

2. **建立可重複的採樣流程**
   - 沉積物經過系統篩分，並將較大碎片與細小碎片分開記錄。
   - 每件標本都標明產物位置、深度、層位、原料與是否受到河水搬運。
   - 同一流程使未經仔細觀察的碎片也能進入整體分析，而不再只依靠保存良好的完成品。

3. **區分原料與製作行為**
   - 當地玄武岩能產生較厚、邊緣清楚的斷片。
   - 石英與石英岩性質不同，打擊時較容易沿特定結構產生不規則裂痕。
   - 因此，形狀差異不能全部歸因於工匠選擇；原料品質本身就是造成差異的原因之一。

4. **重建操作鏈**
   - 石核、削片與石片被視為同一生產程序的不同階段。
   - 碎片接合可協助研究者判斷敲擊方向、力度，以及工具是在現場完成或攜帶至現場。
   - 修整痕、撞擊痕與刃口磨耗再提供使用階段的資料。

5. **採用固定的資料表**
   - 每件器物至少記錄七項資料：層位、原料、器類、尺寸、製作痕跡、刃部狀態與保存狀況。
   - 完 whole、廢料與再利用器物分列，避免以精緻成品代表全部技術。
   - 同一表格也可用於比較其他非洲遺址、歐洲遺址與亞洲遺址。

6. **進行區域比較**
   - 古峽材料呈現以石核、削片與石片為核心的技術傳統。
   - 與其他區域比較時，可以辨認哪些做法具有廣泛分布，哪些只在特定原料或環境下特別發達。
   - 研究者也能辨認鄰近地區的混合形態，而不將每一點差異都解釋為獨立族群。

這個案例解決了早期石器分類中「只挑典型完成品」的瓶頸。分類結果顯示，地區差異往往不是單純的器物清單差異，而是原料、製程、功能與保存條件共同形成的組合。現代研究因此得以把古峽材料納入更完整的區域序列，並進一步比較非洲其他地區、歐洲及亞洲的早期技術，而不必假定所有地區都沿用同一條標準化道路。

## 前因後果

1. **自然資源分布不均**
   - 不同地區可取得的石質原料種類與品質不同。
   - 原料限制影響打片效率、修整方式與器物耐用度。
   - 因而形成最初的可見技術差異。

2. **季節性與移動需求**
   - 某些地區的動物、植物或水源具有明顯季節性。
   - 居住點移動會改變工具攜帶量、規格與再利用方式。
   - 因而形成經濟與聚落方面的地區差異。

3. **人口分化與接觸**
   - 長期人口分隔使各地累積不同的操作習慣。
   - 鄰居之間的接觸又把部分技術帶入新的地區。
   - 因而形成兼具地方性與交流痕跡的混合組合。

4. **原料與物品流動**
   - 交換可能沿穩定的河流、海岸或陸路進行。
   - 稀有石料與成品的流動，使技術分布不必然等於原料分布。
   - 因而需要結合地質來源分析與考古分布。

5. **地方性保存與採樣**
   - 洞穴、湖泊、沼澤與乾燥洞穴會保存不同種類的遺物。
   - 研究者若只比較保存最好的器物，就會放大某些地區的特徵。
   - 因而產生表面上的文化差異。

6. **區域類型形成**
   - 當年代、原料與製作程序被記錄後，學者開始以區域整理反覆出現的技術組合。
   - 這類分類有助於建立地方序列，並保存不同發展路徑。
   - 但名稱若被過度概括，也可能把地方差異誤寫成固定文化。

7. **單一器形造成的分類瓶頸**
   - 以手斧、石片或特殊器物作為單一指標，容易忽略其他技術與廢料。
   - 功能測試、原料分析與操作鏈重建因此成為必要補充。
   - 分類從「器物中心」轉向「程序與脈絡中心」。

8. **後續的跨區域研究**
   - 地方序列建立後，研究者才能比較技術如何傳播、混合或被放棄。
   - 新的年代模型、原料來源分析與使用痕跡研究，也不斷修正既有的地區界線。
   - 最終形成多層次、可重複驗證的區域差異架構。

## 與相鄰分類的關聯

- **[石器時代]**
  - 地區差異是[石器時代]之下的分類面向。
  - 它不取代年代分期，而是補充「在哪裡、何時、以何種方式形成差異」的問題。
  - 各地區的序列仍須置於[石器時代]的整體框架中理解。

- **[舊石器時代]**
  - 舊石器時代提供早期打製技術與大型古猿類群活動的主要背景。
  - 同一時期內，不同地區可能使用不同石核、削片、修整與工具組合。
  - 因此，舊石器時代不能被理解為全球同步且內部均質的單一階段。

- **[中石器時代]**
  - 中石器時代的地區差異常表現在細石器技術、漁採活動、狩獵武器與移動策略。
  - 技術延續可能跨越舊石器時代與中石器時代的界線。
  - 分類時需要依當地序列判斷，而不應全球套用同一條界線。

- **[新石器時代]**
  - 新石器時代的磨製石器、陶器、農業起源與畜養活動，使地區差異更為明顯。
  - 部分舊石器技術仍可能與新技術並存，並形成混合經濟。
  - 因此，年代分類與地區分類在此處尤其需要分層處理。

- **[石器技術]**
  - 石器技術是地區差異的核心比較軸。
  - 打製、磨製與片狀剝片等程序可跨越多個地區，也可能在某地特別發達。
  - 技術分類若缺少原料、功能與遺址背景，便難以解釋其地區分布。

## 容易混淆之處

- **地區差異不等於年代差異**：較晚發明的器物可能只出現在部分地區，不能據此將所有器物差異都視為技術進步或落後。
- **技術相似不等於共同族源**：相同製程可能透過模仿、交換或獨立發明出現。
- **器形相似不等於功能相同**：外觀接近的器物仍須經磨耗、撞擊痕與殘留物分析。
- **原料相同不等於文化相同**：鄰近地區可以取得同類原料，卻採取不同的取得與加工策略。
- **遺物稀少不等於活動不存在**：開放遺址的流失、洞穴的年代混合與採樣方式都會改變器物比例。
- **海岸與內陸不是絕對二分**：聚落位置會隨季節、資源與交通路線變動，邊界通常呈漸變。
- **環境差異不等於環境決定論**：氣候與資源提供限制，卻不直接決定唯一的文化結果。
- **獵採經濟不是單一模式**：不同地區的狩獵、捕魚、採集、食物加工與移動比例可能很不一樣。
- **半遊牧不是固定的「中間階段」**：它可能是長期維持的生活策略，而非通往農業或定居生活的必經道路。
- **洞穴遺址不等於單一文化層**：反覆利用與洞穴堆積可能使數個時期的器物混在一起。
- **區域名稱不等於古代政體**：考古學上的區域框架不應直接投射為國家、民族或語言集團。
- **精緻器物容易造成取樣偏差**：只研究完成品會忽略廢料、維修、再利用與低階加工活動。
