# 相對年代

> 隸屬：[考古年代學](README.md)　·　狀態：初稿

> 對應維基百科：[中文維基百科：相對年代](https://zh.wikipedia.org/wiki/%E7%9B%B8%E5%B0%8D%E5%B9%B4%E4%BB%A3)

相對年代是考古年代學中用來判斷遺物、遺址、活動層或歷史事件先後順序的方法。
它回答的是「哪一個較早，哪一個較晚」，而不是直接回答「距今多少年」。
其基本證據包括地層關係、器物型態變化、生物化石 succession、古地磁紀錄及其他遺物間的共存關係。

相對年代之所以重要，是因為考古發掘最初得到的往往是混雜的土層、器物與動植物遺留。
若無法先建立可靠的先後順序，後來的定年、跨遺址比較及歷史解釋便缺少共同基準。
[考古年代學] 因而把相對年代視為重建考古時間序列的基礎工具。

相對年代通常先形成「甲早於乙、乙早於丙」等有序關係，再視需要與[絕對年代]結合。
兩者的分工不是互相取代：相對年代提供結構與接觸關係，絕對年代則把部分序列錨定在日曆時間上。
由於材料可能受擾動、抽樣或保存條件影響，相對年代也必須說明證據強度、推定方向與不確定性。

## 技術要點

- 相對年代的核心是建立事件之間的「早於」與「晚於」關係。
- 單一器物通常不足以判定年代，必須結合其所在層位、接觸關係與共存材料。
- [地層疊壓]是基本原則：在未受擾動的沉積序列中，下層通常早於上層。
- 對地層是否受擾動的判斷，決定了疊壓原則能否直接套用。
- 早期研究者有時將下層誤判為較晚，顯示地層記錄本身也可能包含解釋誤差。
- [文化層]是保存活動與事件的重要單位，包含堆積物、器物、爐灶、灰坑及其他相關遺留。
- 文化層之間的界面可表示快速堆積、停滯、侵蝕、洪水或再度活動。
- 器物型態可用來建立型態序列，但型態變化未必完全同步於實際年代。
- 缺乏精確器物組合時，序列通常只能表示相對次序，而不能直接換算為年數。
- 器物共存關係可用來判斷不同遺址或不同區域是否可能屬於同一時期。
- [生物地層]利用生物化石或生物群的出現、消失與更替判斷地層先後。
- [古生物對比]則把不同遺址中的生物指標相互對照，以建立較廣泛的區域性序列。
- [古地磁]可利用沉積物或燒土保存的磁化方向，輔助判斷層位關係或提供年代錨點。
- 當地層具有清楚且未受擾動的關係時，[年代對照表]能把若干遺址的局部序列連接起來。
- [碳十四]能為有機遺留提供絕對年代基準，但樣本脫層、再沉積及原木偏老效應都會影響解讀。
- [熱釋光]可用於最後一次受熱的陶土、磚石或燒土，[鉀氬法]則常用於火山岩及火山灰層。
- 以自然事件或已知年代材料作為界標，是把相對序列轉換為絕對時間的常見方式。
- [校準曲線]用來把特定測年方法的原始數值轉換為日曆年代區間。
- [測年誤差]會影響絕對錨點的精度，也會限制考古學者對相對序列中各階段時距的推論。
- [樣本偏差]可能來自遺材選擇、保存條件、採樣位置及樣本數量不足。
- [方法上限]指出某些材料只能提供年代範圍、事件界標或先後關係，不能無限提高時間解析度。
- 對同一問題採用不同證據鏈交叉驗證，通常比只依賴單一器物或單一樣本更可靠。
- 最終成果應區分直接觀察、由推論得出的關係，以及仍待驗證的替代解釋。

## 範例

以下以虛構的「甲遺址」為例，示範如何把三個文化層排成可靠序列。
發掘區共劃分出 L1、L2、L3 三個主要文化層，並記錄每一層的器物組合與上下界線。

1. 第一步是劃定文化層。
   - L1 為含黑色腐植土的基層，出土 P1 型陶罐。
   - L2 為灰白色火山灰透鏡體，出土 P2 型陶罐及少量炭化種子。
   - L3 為黃色洪水砂層，出土 P3 型陶罐與磨製石器。
   - 每一層都使用獨立的[文化層]編號，避免只按器物名稱混記。

2. 第二步是記錄直接接觸關係。
   - L1 頂面被 L2 底面直接覆蓋。
   - L2 頂面被 L3 底面直接覆蓋。
   - 剖面照片、測量圖與層位描述均保存這些觀察結果。

3. 第三步是檢查是否受到後期擾動。
   - L1 內發現一枚 P3 型陶片，位置接近裂隙。
   - 裂隙填充物色澤不同，可能代表晚期侵入。
   - 因此不能僅因 P3 陶片位於 L1，就把它當作 L1 原始堆積的組成物。

4. 第四步是套用[地層疊壓]。
   - 在確認三層皆為原位堆積且未被翻轉後，可建立 L1 早於 L2、L2 早於 L3 的初步序列。
   - 此時只處理方向，不把三層視為連續且等時的沉積。

5. 第五步是比較器物型態。
   - P1 容器口緣外撇、底部較平。
   - P2 容器口緣較直，繩紋由疏轉密。
   - P3 容器輪製痕跡明顯，柄部輪廓與前兩型不同。
   - 型態資料支持 L1、L2、L3 的先後次序，但不能單獨證明它們沒有重疊。

6. 第六步是檢查生物與磁性地層指標。
   - L1 的底栖生物比例較高，L2 的草原型小型哺乳動物比例增加。
   - 這種[生物地層]變化與一次環境過渡相符。
   - L2 的火山灰則具有一致的[古地磁]訊號，可與區域其他剖面對照。
   - [古生物對比]提供的環境序列與器物序列大致一致，兩條獨立證據鏈因此可以相互支持。

7. 第七步是從 L2 採集測年材料。
   - 選取與短命植物直接相關的炭化種子，不使用可能多年後才倒伏的整段原木。
   - 送測結果為 7,420 ± 35 年，這是一項[碳十四]原始測定值。
   - 樣本與火山灰的關係已在採樣紀錄中說明，可降低[樣本偏差]造成的誤判風險。

8. 第八步是把測年結果轉換成日曆年代。
   - 7,420 ± 35 年不能直接被當作單一精確年份。
   - 使用適當的[校準曲線]後，該測定值對應一段年代區間。
   - 區間表示 L2 很可能落在該時段，但不能排除誤差分布邊緣的可能結果。

9. 第九步是界定相對年代的意義。
   - L2 的年代基準可作為 L1 與 L3 之間的年代錨點。
   - L1 中的活動應早於 L2，因而受到「不晚於」與「早於」兩種方向不同的限制。
   - L3 中的活動則晚於 L2，但不能只憑 L2 一筆測值精確指定其發生年份。

10. 第十步是處理測量不確定性。
    - 依照[測年誤差]記錄樣品量、背景值、污染校正及區間分布。
    - 不把測量誤差誤寫成活動本身的持續時間。
    - 若要進一步縮小區間，仍需增加獨立樣本，而不能只重複同一塊殘片。

11. 第十一步是進行區域比較。
    - 乙遺址也具有「早期陶器層、灰燼層、晚期陶器層」的三段序列。
    - 將兩地序列並列於[年代對照表]，可判斷哪些層可能同時，哪些層必定有先後。
    - 這項比較使甲遺址不再只是孤立的地方序列，而能接入更大的[年代框架]。

12. 第十二步是記錄仍待解決的問題。
    - L1 上層是否完全未被洪水改造，仍須由沉積構造判斷。
    - L2 炭化種子是否可能由未記錄的動物活動帶入，也需要顯微觀察。
    - 在這些問題未解決前，結論應表述為「目前證據最支持 L1 → L2 → L3」，而非聲稱絕對無疑。

這個例子顯示，相對年代先解決了器物彼此混雜、無法排列的瓶頸。
接著，碳十四與校準程序把其中一段序列錨定到日曆時間，再由年代對照表推廣到其他遺址。
即使如此，樣本偏差與方法上限仍會留下不確定性，並可能引發後續的[年代爭議]。

## 前因後果

1. 早期發掘常把不同年代的器物混在同一「文化層」中，造成器物先後無法判讀。
2. 學者因此開始逐一記錄堆積單位、接觸界面與器物共存關係。
3. [地層疊壓]提供最基本的先後方向，但也促使研究者檢查翻土、洞穴、裂隙與洪水等擾動。
4. [文化層]逐漸成為組織出土資料、比較遺址與重建事件過程的基本單位。
5. 單靠地層不足以涵蓋未形成清楚堆積的活動，器物序列與[生物地層]遂成為重要補充。
6. 各遺址形成局部序列後，考古學者需要共同尺度，[年代對照表]因而連接區域內的先後關係。
7. 隨著[碳十四]等絕對測年技術成熟，局部相對序列得以與日曆年代接軌。
8. 原始測值與日曆年代並非一對一，因此[校準曲線]成為測量值與歷史敘事之間的重要橋樑。
9. 絕對錨點增加後，學者更注意[測年誤差]及[樣本偏差]，不再把區間誤寫成精確日期。
10. 當不同方法給出不完全一致的結果時，學者會比較材料保存、採樣策略與關係假設，形成可檢驗的替代模型。
11. 這些模型又回頭改善採樣、記錄與發掘策略，使相對年代建立在更可追溯的程序上。
12. 對文化起源、舊石器技術等長期過程的研究，進一步把方法誤差放大為[舊石器年代]與[文明起始年代]的爭論。
13. 當來源、統計區間與文化連續性不能同時確定時，[年代爭議]便成為研究的一部分，而非單純的行政或聲譽問題。
14. 在[1949年]，威拉・利比與芝加哥大學團隊公開發表碳十四定年成果，展示了把相對序列錨定到絕對時間的全新可能。
15. 此後的校正、統計整合與跨方法比較，使相對年代不再只是「先後判斷」，而成為可量化、可反駁的考古時間模型。

## 與相鄰分類的關聯

- [考古年代學]是上位分類，涵蓋相對定年、絕對定年、年代校正及年代框架等問題。
- 相對年代處理事件次序，屬於建立考古時間模型的第一層工作。
- [年代框架]把不同遺址、區域與事件序列組成可比較的整體架構。
- [絕對年代]提供日曆年代錨點，但本身未必能說明事件的先後與延續關係。
- [測年誤差]處理精確度與可信區間，是解讀相對與絕對年代共同結果時不可忽略的一環。
- [考古學家]關係到證據採集、年代模型選擇、替代解釋及研究結論的責任。
- 研究者必須區分資料中的先後關係、模型推估的年代，以及依文化框架作出的歷史解釋。
- 跨專業合作可結合地質學、古生物學、磁性地學與物理測年，提高序列的獨立驗證程度。

## 容易混淆之處

- 相對年代不等於「誤差較小的絕對年代」，兩者回答的是不同問題。
- 「A 早於 B」不表示兩者相隔固定的年數，也不表示兩者完全不能同時存在。
- 相對年代不是單純依照器物漂亮程度或工藝高低排列。
- 地層較深不必然代表年代較早，前提是堆積未曾受擾動。
- 型態序列通常建立的是風格先後，風格邊界不必然等同於人群或政治實體邊界。
- [文化層]是考古解釋單位，不應把每一個自然土層都自動視為單一文化層。
- [生物地層]提供的是生物更替序列，生物遷移可能使不同地區的指標不完全同步。
- [古地磁]是輔助證據，磁化紀錄仍須確認形成時機與保存條件。
- [碳十四]、[熱釋光]與[鉀氬法]通常用於提供絕對年代錨點，本身不直接取代相對序列。
- 校準後的區間不應被簡化為唯一年份，也不應被解讀為活動必然持續整個區間。
- [樣本偏差]可以存在於看似精確的大型資料集中，不能只靠增加樣本數量自動消除。
- [方法上限]表示證據可支持的問題邊界，超出此邊界的精確度屬於過度推論。
- [年代對照表]能顯示比較關係，但表格本身不會證明兩個遺址之間存在直接接觸。
- [舊石器年代]涉及廣大時間尺度與稀少材料，分辨率通常低於器物豐富的歷史時期。
- [文明起始年代]往往取決於「文明」的定義，不能只由單件器物或單一測值決定。
- [年代爭議]可能來自新材料、方法進步、定義改變或統計模型更新，不應被簡化為學者彼此否定。
