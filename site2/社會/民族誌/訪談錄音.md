# 訪談錄音

> 隸屬：[民族誌] › [口述史]　·　狀態：初稿

> 對應維基百科：中文與英文維基百科均無對應條目（參考：訪談錄音 相關文獻）

## 定義

在「民族誌→口述或訪談方法→具體記錄形式」的層次中，訪談錄音是孫級類目；民族誌是以現場觀察、訪談與文件分析理解社會生活的研究取向。
訪談錄音就是把研究者與受訪者之間的對話保存成聲音檔，並將這些聲音作為社會生活與文化意義之證據的材料類型。
它的分類依據是「受訪者的談話是否構成主要研究材料」，而不是錄音設備、聲音品質或訪問主題。
如果錄音只保存群眾大會、婚禮或街頭活動，卻沒有研究者與受訪者之間的對話，該檔案便不必然屬於訪談錄音。
反之，一次非正式聊天若被錄下並用於民族誌分析，也可被歸入訪談錄音。

田野調查是研究者離開日常環境、進入研究場域並蒐集資料的實地工作。
族群誌是整理家族、氏族或群體之世系、來源與親屬關係的記錄工作。
民俗誌是研究並保存民間習俗、信仰、口述故事與日常儀式材料的取向。
口述史是以親歷者的口述回憶作為歷史證據，並透過錄音、逐字稿或出版文本加以保存的方法。
深度訪談是讓受訪者沿著主題與提示深入回憶、觀感及經驗的半結構式或開放式談話。
參與觀察是研究者直接參與被研究的生活場景，同時觀察、提問並留下記錄。
長期駐點是研究者在同一社區反覆停留，以建立關係、追蹤變化並累積經驗的駐點策略。
身份與認同是個人或群體如何理解「我是誰」、歸屬於何處，以及自身價值與邊界的研究範圍。

就方法層級而言，深度訪談是「怎麼問」，訪談錄音則是「如何保存問答」。
就專案層級而言，口述史通常以歷史重建為主要目的，訪談錄音則可能只為回答一次具體的民族誌問題。
因此，一次深度訪談可以成為口述史材料，也可以只是某項地方研究中的田野紀錄。
若研究者把個人回憶與地方制度、社群分類及文化實踐相互對照，它便具有超出個人故事的民族誌意義。

訪談錄音的原始證據包括聲音、停頓、語氣、音量、笑聲、沉默與說話次序。
逐字稿則是把談話中的詞語、停頓和沉默依照特定規則轉寫為文字，是便於搜尋與分析的衍生文件。
同一段聲音可以因轉寫規則、方言判讀或上下文標註不同，而產生不同的文字版本。
因此，檔案應同時保留原始錄音、錄音日期、參與者代碼、話題索引及田野情境等中繼資料。

訪談錄音並非透明而中立的声音容器。
受訪者可能因錄音者在場、敏感問題、場合壓力或日後可能被引用，而調整敘述。
錄音也會使口語表達暫時轉為可保存、可重播與可被後來讀者重新解讀的對象。
研究者因而不能把錄音內容直接等同於受訪者「不經修飾的真實想法」。
它較能被理解為某時、某地、某種互動關係中的一次敘述表現。

## 技術與理論的關聯

- **證據位階**：原始錄音應被視為第一手材料，逐字稿則是依研究目的與轉寫規範製作的分析中介。
- **提問設計**：深度訪談的問題可採漏斗式安排，由一般生活經驗逐步進入敏感或抽象議題。
- **追問原則**：追問應協助受訪者澄清時間、人物與因果，而不是替受訪者補出研究者預設的答案。
- **訪談指引**：半結構式問題清單能提高不同受訪者之間的可比性，同時保留追問與新線索的空間。
- **錄音品質**：清楚的收音、穩定的供電、雙份備份與檔案校驗，可降低設備故障造成資料永久損失的風險。
- **情境記錄**：研究者應記錄每次訪談的地點、氣氛、在場者、座位安排及可能影響談話的外部事件。
- **倫理同意**：知情同意不只涵蓋錄音，也應說明保存期限、匿名方式、使用目的、分享對象與撤回機制。
- **風險溝通**：涉及政治衝突、疾病、犯罪或家庭暴力時，需評估聲音本身是否可能使受訪者或第三方暴露身份。
- **去識別處理**：移除姓名並不等於完成匿名化，職業、稀有經歷、聲音及時間組合仍可能讓熟人辨識受訪者。
- **逐字稿規範**：轉寫者應區分原話、停頓、笑聲、方言、不可辨識處與分析者註解，避免把修飾語混入引文。
- **語言轉譯**：方言、族語或非標準語的翻譯必須保留語域差異，並將不可直譯之處另列註解。
- **受訪者效應**：訪談者的年齡、性別、階級立場與生活經驗，可能改變哪些內容被說出、略過或重新解釋。
- **反思性實踐**：研究者應記錄自己與研究場域的關係，並在分析中說明這些位置如何影響提問與資料篩選。
- **記憶性質**：口述回憶提供的是受訪者在訪談時重新組織的過去，而不是過去事件未經中介的複製。
- **時間不一致**：不同日期的敘述可能互相矛盾，矛盾本身可用來研究記憶選擇、角色立場與社會規範。
- **敘事結構**：敘事分析是分析故事中的事件次序、角色配置、因果連接、沉默與遺漏，並比較不同敘事模式的方法。
- **口述材料的界線**：口述傳說是透過口頭流傳、情節具有變異且未必能以單一史實驗證的故事；訪談錄音可保存受訪者講述這類故事的情況。
- **傳說的表演性**：受訪者重述口述傳說時會因聽眾、場合與個人技藝而表演，不能把每次敘述當成固定文本。
- **觀察互證**：參與觀察提供事件發生時的行為脈絡，訪談則可補充受訪者對同一事件的解釋與意義。
- **反覆追問**：觀察與訪談之間的落差可形成新問題，使下一輪深度訪談更深入，而非只把訪談當成一次性問卷。
- **儀式現場**：儀式觀察是按事件發生的先後記錄程序、參與者位置、互動與象徵物；儀式記錄則把這些內容整理成可重複查核的步驑文件。
- **回憶與現場的差異**：直接儀式觀察能記錄受訪者當時做了什麼，回憶性訪談則能呈現他們如何理解、評價或遺漏該次儀式。
- **物質對照**：物質記錄是對器物、建築、照片、文件或可見痕跡進行辨識、拍照、測量與描記，以核對訪談中的陳述。
- **儀式材料互動**：訪談錄音可蒐集對週期性儀式、生命儀式或危機儀式的個人解釋，現場記錄則保留其程序與集體動力。
- **長期脈絡**：長期駐點使研究者能比較受訪者在不同時期的說法，並辨認哪些敘述受近期事件影響。
- **回訪差異**：反覆錄音可顯示受訪者如何修正先前敘述，也顯示研究者自身的問題設計是否影響答案。
- **單一群體深度**：單一族群記錄是以一個群體為檔案與描述單位，保留群體內部的年齡、性別、階級及地域差異。
- **比較基礎**：跨族群比較是以共同問題對照不同群體的答案；沒有先建立細緻的單一群體檔案，比較容易淪為表面類比。
- **認同分析**：聲音中的代詞、歸屬宣稱、反身敘述與排斥語彙，可協助分析身份與認同如何被協商。
- **樣本與代表性**：受訪者數量不能單獨保證代表性，還須交代招募方式、拒訪者、沉默者及社群內部的選取偏差。
- **檔案可重複性**：保存原始檔、備份、校驗值、設備資訊、同意文件與脈絡筆記，可讓其他研究者重新聆聽及查核。
- **詮釋的公開性**：研究報告應區分受訪者原話、研究者轉述與理論推論，並說明聲音、文本及脈絡各自能支持什麼主張。
- **限制聲明**：訪談錄音容易受到記憶選擇、訪談關係、場合與轉錄選擇影響，不能單獨承擔重建整個社群的任務。

## 範例

1950年代中葉，民族學家奧斯卡·路易斯（Oscar Lewis）在墨西哥莫雷洛斯州特波茲特蘭研究家庭與地方變遷，並於1961年出版《Sánchez 家族的孩子》（*The Children of Sánchez*）。
這項工作的前因，是單一住戶統計能呈現年齡、教育、職業與親屬結構，卻難以說明同一家庭中不同世代如何理解遷移、土地、婚姻及現代化。
路易斯因此把住戶資料與跨代的深度訪談結合，讓家庭成員分別敘述自己的生命歷程。
訪談內容被錄成聲音，再經逐字稿整理，使不同成員的說法能夠按主題、年齡與角色位置相互對照。

這種做法使訪談錄音成為口述史與民族誌之間的橋樑。
口述史提供個人時間軸，民族誌則把個人敘述放回家庭、村落與地方制度的脈絡。
逐字稿中的重複、停頓與矛盾，使研究者能看見一位父親、一名兒女或一位妻子如何分別定位同一事件。
錄音也保留口語的節奏與情緒，避免所有材料都被整齊的第三人稱摘要抹平。
因此，選擇錄音並非只為節省整理時間，而是為了保存敘述方式本身。

在分析上，家族記憶是家庭成員共同保存、選擇或競爭的祖先故事與過往事件框架；它會影響誰被描寫為家庭創始者，也會影響成功、挫折與責任如何被分配。
敘事分析可比較不同成員如何排列事件、安排因果及運用「我們」或「他們」等代詞。
當幾位受訪者對同一段家族史有不一致之處時，差異不必只被判定為錯誤，也可能顯示世代、位置與身份與認同的差異。
例如，對外出工作、土地處置或家庭遷移的描述，會隨受訪者在家庭中扮演的角色而改變。
這些比較使身份與認同不再只是抽象變數，而成為可由具體語句與敘事位置觀察的對象。

訪談錄音也會反過來推動其他材料類型的採集。
當受訪者提到一座房屋、一件農具、一次婚禮或一套喪葬程序時，研究者會帶著具體線索返回現場。
這些線索可導向物質記錄，核對器物所有權、居住安排或照片中的空間關係。
對涉及生命儀式與危機儀式的敘述，現場的儀式觀察則可協助辨認哪些步驟是實際可見的，哪些只是事後記憶或象徵性重述。
由此形成「訪談提出問題—現場核對—回訪追問—修訂解釋」的循環，而不是把不同檔案平行堆放。

在分類上，這項研究先是一份單一族群記錄。
它以一個家庭的細密材料呈現地方社會，而不急於把家庭經驗代表整個墨西哥村莊。
這種深度也為後來的跨族群比較提供條件：研究者能將同一套生命史問題套用於其他家庭，再比較遷移模式、世代期待與家庭權力。
若跳過單一群體的脈絡化步驟，跨族群比較很容易只比較抽象比例，而忽略同一比例在不同生活史中的意義。

出版後，《Sánchez 家族的孩子》成為家庭生活史研究經常援引的先例。
其影響不在於示範一套可完全複製的訪談程序，而在於示範如何使用錄音保存分歧的個人敘述，並將分歧與族群誌中的親屬關係及地方制度互相參照。
它也提醒後續研究者：跨代口述不能取代參與觀察與文件核對，但可以讓研究者知道應到現場追問哪些問題。
因此，這個1961年的案例顯示，訪談錄音的價値不只在於「採到什麼答案」，也在於答案如何被說出、由誰說出，以及說完之後又如何改變研究者的下一步。

## 與相鄰分類的關聯

- **與民族誌及田野調查的關聯**：訪談錄音是民族誌工作的一種材料形式，通常產生於田野調查，但「有錄音」本身並不保證研究具有民族誌深度。
- **與深度訪談的關聯**：深度訪談規範提問與互動方式，訪談錄音保存其問答；前者偏向方法，後者偏向可保存、可重播的證據形式。
- **與口述史的關聯**：口述史著重以口述重建歷史，訪談錄音則可承載歷史敘事，也可以記錄不直接服務歷史重建的當代經驗。
- **與參與觀察的關聯**：參與觀察記錄人在場時如何行動，訪談錄音則記錄人如何回憶、評價與敘述，兩者互補而不互相替代。
- **與長期駐點的關聯**：長期駐點提供反覆訪談的時間條件，使錄音能呈現同一受訪者在不同時期的說法變化。
- **與儀式觀察及儀式記錄的關聯**：現場記錄保留程序次序，訪談錄音則提供參與者對程序意義、情緒與記憶的回顧。
- **與週期性儀式的關聯**：週期性儀式是依季節或固定週期反覆舉行的儀式；訪談可比較不同年份對同一週期活動的期待與解釋。
- **與生命儀式的關聯**：生命儀式是標記出生、成年、婚配或死亡等人生轉折的儀式，個人訪談能補充制度記錄中較少呈現的主觀經驗。
- **與危機儀式的關聯**：危機儀式是針對災難、疾病、哀悼等威脅與不確定性舉行的儀式，錄音可保存當事人在事件後反覆調整的因果解釋。
- **與物質記錄的關聯**：物質記錄提供可觀察的器物、空間與文件，訪談錄音提供這些事物被命名、記憶和赋予意義的方式。
- **與口述傳說的關聯**：受訪者講述口述傳說時的錄音仍屬訪談錄音，但研究問題會轉向故事流傳、角色協商與表演，而非僅確認受訪者個人經歷。
- **與民俗誌的關聯**：民俗誌可使用訪談錄音蒐集歌謠、諺語、故事及習俗口述，但必須保留其發話場合與傳播群體，不能只抽取孤立文本。
- **與族群誌的關聯**：族群誌整理世系與親屬來源時，可利用訪談錄音辨識不同支系對祖先事件的不同說法及其政治意義。
- **與家族記憶的關聯**：家族記憶是家庭成員共同保存或競爭的過往故事框架；訪談錄音能呈現這套框架如何在不同成員口中運作。
- **與敘事分析的關聯**：敘事分析處理事件順序、因果、人物配置與遺漏，訪談錄音則保留判斷這些敘事特徵所需的語氣和停頓。
- **與身份與認同的關聯**：歸屬宣稱、名字使用、方言選擇及對他人的稱呼，都可在訪談錄音中成為分析身份與認同的語言線索。
- **與單一族群記錄的關聯**：單一族群記錄要求在同一群體內保留差異，訪談錄音可避免把最響亮的受訪者聲音誤當成整個群體的共同聲音。
- **與跨族群比較的關聯**：跨族群比較若要有效，應先在各群體內建立可追溯的錄音脈絡，再比較共同主題，而不只比較訪談摘要中的次數或比例。
- **方法上的界線**：訪談錄音偏重研究者的問答痕跡與受訪者的口述表現；儀式現場錄音偏重事件本身，兩者即使使用同一支麥克風，也不能視為同一分類。
- **證據上的互動**：最有效的分類通常不是二選一，而是以訪談錄音提出問題，以參與觀察核對事件，以物質記錄驗證細節，再以回訪修正原本的敘事分析。
- **倫理上的界線**：保存聲音不必然比保存文字更中立；聲音可能保留口音、情緒與可辨識特徵，因此風險評估及同意範圍應比單純文字摘錄更細密。
